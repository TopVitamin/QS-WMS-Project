# 需求调研和分析

本目录说明强盛WMS一期的业务问题、功能需求和取舍。项目为课程沙盘，尚未开展真实企业访谈或生产验证。

## 阅读顺序

先读[需求分析总览](00-项目总览/02-需求分析总览.md)了解范围、业务链路和功能，再查对应模块。需要了解需求缘由时读[调研总览](00-项目总览/01-需求调研总览.md)与[竞品取舍](00-项目总览/03-竞品参考与需求取舍.md)。

### 文件夹编号 vs 主链顺序

物理目录按历史编号排列：**`03-出库业务` 在 `04-库存与库内业务` 之前**。收存发主链的逻辑阅读顺序仍是 **IN（02）→ INV（04）→ OUT（03）**；下表已按主链排序，不必按文件夹数字跳读。

范围以[项目定位](../01-全局背景信息/02-项目定位与范围.md)和[阶段规划](../01-全局背景信息/04-阶段规划与交付边界.md)为依据，具体规则在负责模块维护，其他文档只保留必要摘要与引用。资料缺口留在调研稿；未决规则、走查待执行与仅设计缺口集中在[需求分析总览第六节](00-项目总览/02-需求分析总览.md#六未决规则走查与开放输入)。业务设计展开执行与结果，应用设计落实字段、状态、页面和接口。

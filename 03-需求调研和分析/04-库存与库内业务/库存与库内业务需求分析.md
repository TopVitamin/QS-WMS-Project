# 库存与库内业务需求分析

> 本稿说明一期范围与系统需求。业务背景见[调研稿](库存与库内业务需求调研.md)。

## 一、分析结论

本模块统一维护仓库实物库存的数量、品质、位置与追溯口径，供入库和出库引用。库存以仓库＋货主＋SKU为基础，按货位、批次、SN和品质细分；支持查询、流水、移库、盘点以及报损／销毁。箱、托只作为作业容器，一期不维护箱库存或托盘库存。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| INV-FR-001 | 库存维度与汇总 | 按仓库、货主、商品、货位、批次和SN查看并汇总 |
| INV-FR-002 | 数量与品质状态口径 | 实际＝预占＋可用，锁定不重复计量，品质另行记录 |
| INV-FR-008 | 货主归属与多仓 | 按货主和仓库分别记账，同一货位只归一个货主 |
| INV-FR-011 | 批次效期与SN库存 | 保留批次、效期与SN；临期正品可出，过期转不良 |
| INV-FR-003 | 预占、货位锁定与释放 | 接单按类型准入，SKU预占与货位分配分开 |
| INV-FR-004 | 库存流水 | 数量及品质变化留流水，可追到关联业务 |
| INV-FR-007 | 调整入口 | 通过盘点或业务单据调整，不提供无依据改数入口 |
| INV-FR-010 | 负库存校验 | 提交时阻断导致负库存的操作 |
| INV-FR-005 | 移库 | 移库只改变位置，保持归属、品质和库存总量 |
| INV-FR-006 | 盘点 | 先完成进行中任务，再快照实盘，确认差异后调整 |
| INV-FR-012 | 报损与销毁处置 | 报损确认扣账；独立销毁实际完成后确认扣账 |

### 库存查询与共同口径

#### INV-FR-001 库存维度与汇总

基础记录至少包含仓库、货主、SKU、库位、批次、SN、库存品质状态（正常品／不良品）和数量；效期商品另显示效期等级，临期标记与品质状态分开展示和筛选；未启用的维度可为空。系统支持下列视角及组合查询：

- 仓库库存：整个仓库全部SKU的实际库存汇总；
- SKU库存：仓库内某个SKU的实际、预占和可用数量；
- 库位库存：某个库位上的库存数量；
- 批次库存：某个批次的库存数量和效期信息；
- SN库存：某个SN的所属SKU、货主、仓库、库位及当前状态，数量通常为1；
- SKU－库位库存、SKU－批次库存、SKU－批次－库位库存；
- SKU－SN库存：某SKU下具体SN的库存状态。

#### INV-FR-002 数量与品质状态口径

- 实际库存＝预占库存＋可用库存。
- 预占库存是锁定数量，不是独立实物；同一库存可以因出库单、盘点或品质控制被锁定；锁定原因分别留痕，合计按不重复的实物数量计算，不能把同一件上的多个原因直接相加。
- 解除某一原因后，仍存在其他有效锁定的数量不可恢复可用。
- 库存品质状态另行标识正常品或不良品：正常品可以按业务规则分为预占和可用，不良品默认全量锁定、可用为0。
- 例如正常品实际8、预占3、可用5；不良品实际2、预占2、可用0，则总实际10＝总预占5＋总可用5。
- 已收货未上架的实物按质检进度及正常品／不良品区分显示，上架前不纳入实际库存。

#### INV-FR-008 货主归属与多仓

- 库存按货主分别记录、按仓库过滤，不合并跨仓可用量。
- 一个货位同一时点只能归一个货主使用，同货主多个SKU可以共位；货位内该货主实物（含报损后非库存暂存实物）、入库过程数量及未完结任务全部清零后，才能改由其他货主使用。
- 用户拥有仓库权限后可查看该仓全部货主库存，不能查看未授权仓库；动作权限由[COM分析稿](../07-公共能力/公共能力需求分析.md)承接。

#### INV-FR-011 批次效期与SN库存

- 启用批次／效期的商品按批次记录生产日期、有效期、实际、预占和可用数量。
- 效期等级按MD-FR-002配置计算：低于过期天数时进入过期，未过期且低于临期天数时进入临期，过期判定优先；按业务所属仓库当地日期判断，展示时区切换不改变结果。
- 在库商品进入过期时自动将对应数量的品质状态转为不良品（残品），实际数量不变，保留批次、SN、原位置和自动转换流水，不良品全量品质锁定。
- 未过期临期品保持正常品品质并标临期等级，允许出库，不因临期增加效期锁定；订单、盘点或品质等其他有效锁定仍保留。
- 普通出库从未过期且品质正常的库存中优先推荐有效期更早的批次，临期可参与。
- 已预占或已拣数量转过期时保留原单关联和锁定原因，不重复累计锁定；普通出库校验品质与效期，异常按既有缺量／取消规则处理，不良品处置由OUT-FR-014和INV-FR-012承接。
- 启用SN的商品按SN记录库存位置和状态，收货、上架、移库、拣货、取消回库、盘点、处置和确认出库均保留轨迹。
- SN身份按货主＋SKU＋SN跨四仓判断；不同货主或不同SKU可以使用相同SN文本，不要求全集团SN文本永久唯一。具体状态及采集界面由应用设计落实。

### 占用、变动与校验

#### INV-FR-003 预占、货位锁定与释放

- 接单准入、SKU 级预占、货位锁定与释放、确认出库扣减及缺量结案以[出库业务需求分析](../03-出库业务/出库业务需求分析.md) OUT-FR-002、OUT-FR-004、OUT-FR-006、OUT-FR-009 为准；本模块维护三量口径（INV-FR-002）与流水（INV-FR-004）。
- 货位锁定表示拣货分配，不新增预占总量；换位释旧锁新，SKU 预占不变。预占合计不得超过实际库存。
- 盘点、品质等锁定可并存，合计按不重复实物计量（见 INV-FR-002）。

#### INV-FR-004 库存流水

每次实际、预占、可用或品质状态变化生成流水，含类型（正常品上架、不良品上架、品质状态转换、移库、盘点调整、报损／销毁、确认出库扣减、预占、释放，以及IN-FR-007的异常账面上架与关联盘亏）、数量变化、关联单据、货主、SKU、库位、批次、SN、品质状态、操作者与时间；支持按单据号、SKU、库位、批次和SN查询。

#### INV-FR-007 调整入口

不提供直接修改库存数量的入口；调整只能通过盘点或经确认的业务单据产生；操作权限由COM配置。

#### INV-FR-010 负库存校验

出库扣减、移库、盘点调整等动作提交时校验结果不为负；会导致负数的操作被阻断并提示现有数量。

### 库内作业与处置

#### INV-FR-005 移库

- PDA选择或扫描源货位、货主、SKU、批次／SN和目标货位，数量不得超过源货位实际数量；目标货位为空或已由同一货主占用时才允许移入，其他货主已占用时阻断。
- 订单预占按货主＋SKU记录，不随货位移动，但已被拣货任务锁定的货位数量不得直接移走。
- 移库只改变库位分布，不改变品质状态及实际、预占和可用总量，并生成流水；目标货位还须满足品质适配，不能借移位把不良品变成正常可用品。
- 过期自动转不良品按INV-FR-011执行，不能借普通移库把不良品改为正常可用品。
- 不良品通过OUT-FR-014其他出库或INV-FR-012报损／销毁处置。

#### INV-FR-006 盘点

- **范围：**按仓库、库区、货位或SKU创建盘点单；SKU范围为“所选仓库＋SKU”，不影响其他仓库。
- **盘点准备：**命中范围内尚未开始的收货、上架、拣货、移库任务整单不得开始；已开始且已锁定或占用库存的任务可执行到整单完成。
- **新单准入：**新出库请求命中盘点阻断时整单拒收，不新增订单预占、不生成待受理单，返回上游原因；盘点结束后由上游重提。已有有效单据的盘点等待计入已开始的履约时长。
- **快照与实盘：**进行中任务全部完结后生成账面快照。快照至盘点结束期间，范围内上架、确认出库、移库及其他业务引起的库存变化不得提交，本次盘点自身的差异调整及自动过期转不良为例外；过期转换保留原快照和原因，不改实际数量与位置，不重复累计品质锁定。PDA录入实盘数量或扫描SN，差异经确认后调整实际库存并生成流水。
- **调减校验：**按盘点结束后仍有效的订单或其他占用校验，不将本次即将解除的冻结作为永久下限；实盘低于有效占用时中止本盘、不调账，仅解除本盘冻结并保留其他有效锁定；按原业务取消／回库并释放相应占用后重新生成快照盘点。旧快照和中止依据保留，校准完成前不将已知差异量供新单使用。
- **不良品差异：**实盘短少时同步调减实际数量与对应品质锁定，剩余不良品仍全量锁定。报损／销毁按INV-FR-012处置，不伪造实盘短少。

#### INV-FR-012 报损与销毁处置

- 管理端记录不良品报损或销毁。货主明确处置意图，仓库授权责任人核实指定实物及结果；记录仓库、货主、SKU、品质、库位、批次／SN、数量、通知来源、原因、操作者和时间。
- 报损确认时按确认量扣减实际库存及对应品质锁定；实物仍留仓时以非库存隔离暂存记录保留身份、数量、位置和跟进责任。
- 独立销毁须实际完成后才确认扣账；只有销毁计划、尚未报损的实物仍计不良品实际库存。已报损实物后续移出或销毁只更新暂存去向，不再扣库。
- 两条路径均生成关联流水，剩余不良品仍全量品质锁定、可用为0，不先转为正常品或普通可用。
- 数量不得超过对应在库实物，也不得扣减其他订单或任务占用的实物；有业务占用时先按已有取消／回库等规则处理，不能越过锁定扣减，也不得绕过实盘冻结。
- 未确认记录不扣库，同一记录重复确认不重复扣库。
- 该入口与OUT-FR-014其他出库分别承接处置，同一批同一数量已经由一条路径扣减后不能再重复扣减；真实盘点差异仍按INV-FR-006记录。
- 处置步骤按业务设计执行，记录字段和页面在应用设计中落实。

## 三、范围取舍与模块依赖

一期不包含：箱库存、托盘库存、货位容量管理、货主对账与账单、财务核算、ERP逻辑库存同步和跨仓库存调度。箱、托可作为作业容器记录，但容器数量不计入库存数量；箱库存转换留作后续扩展。

| 依赖模块 | 依赖能力与使用约束 |
| --- | --- |
| MD | 取得货主、商品、仓库、货位资料；作业资料缺失时阻断相应动作，不改写既有库存 |
| IN／OUT | 上架、损失处理、接单预占、取消和出库分别引用业务依据，使用本模块的数量与锁定口径 |
| COM | 按仓库授权和角色动作权限查询、盘点或处置；效期判断使用所属仓库当地日期 |

## 四、应用设计输入与资料缺口

- 按业务设计落实SN状态表达、盘点差异确认页面及处置记录；所需批次、SN、盘点表和处置依据样例见调研稿。

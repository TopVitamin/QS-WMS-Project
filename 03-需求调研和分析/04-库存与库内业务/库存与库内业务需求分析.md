# 库存与库内业务需求分析

> 本稿说明一期范围与系统需求。
> 业务背景与场景见[库存与库内业务需求调研](库存与库内业务需求调研.md)。

## 一、分析结论与模块边界

本模块维护四仓实物库存的数量、品质、位置与追溯，供入库、出库引用；范围与现状见[项目定位](../../01-全局背景信息/01-项目定位与范围.md)及[调研稿](库存与库内业务需求调研.md)。

**职责范围**

- 三量口径（实际、预占、可用）、品质状态、流水、移库、盘点及效期/SN 在库规则在本模块维护。
- 上架形成库存、入库损失等见[入库业务需求分析](../02-入库业务/入库业务需求分析.md)；接单预占、货位分配、扣减与缺量结案见[出库业务需求分析](../03-出库业务/出库业务需求分析.md)。
- 货主、商品、货位资格见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)；仓库权限与效期日历见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

**不在本模块**

- 报损／销毁及报损后非库存暂存跟踪；箱库存、托盘库存、货位容量管理。
- 货主对账与账单；财务核算；ERP 逻辑库存同步；跨仓库存调度与在途账。
- 箱、托仅作为入出库过程作业容器记录，容器数量不计入库存；箱库存转换留作后续扩展。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| INV-FR-001 | 库存维度与汇总 | 按仓库、货主、商品、货位、批次和 SN 查看并汇总 |
| INV-FR-002 | 数量与品质状态口径 | 实际＝预占＋可用，锁定不重复计量，品质另行记录 |
| INV-FR-003 | 预占、货位锁定与释放 | 接单按类型准入，SKU 预占与货位分配分开 |
| INV-FR-004 | 库存流水 | 数量及品质变化留流水，可追到关联业务 |
| INV-FR-005 | 移库 | 移库只改变位置，保持归属、品质和库存总量 |
| INV-FR-006 | 盘点 | 先完成进行中任务，再快照实盘，确认差异后调整 |
| INV-FR-007 | 调整入口 | 通过盘点或业务单据调整；差异校准前限制新单，主管确认解除 |
| INV-FR-008 | 货主归属与多仓 | 按货主和仓库分别记账，同一货位只归一个货主 |
| INV-FR-010 | 负库存校验 | 提交时阻断导致负库存的操作 |
| INV-FR-011 | 批次效期与 SN 库存 | 保留批次、效期与 SN；临期正品可出，过期转不良 |
| INV-FR-013 | PDA 库内作业 | PDA 执行移库、盘点等，与管理端共用记录 |

#### INV-FR-001 库存维度与汇总

基础记录至少包含仓库、货主、SKU、货位、批次、SN、库存品质状态（正常品／不良品）和数量；效期商品另显示效期等级，临期标记与品质状态分开展示和筛选；未启用的维度可为空。系统支持下列视角及组合查询：

- 仓库库存：整个仓库全部 SKU 的实际库存汇总；
- SKU 库存：仓库内某个 SKU 的实际、预占和可用数量；
- 货位库存：某个货位上的库存数量；
- 批次库存：某个批次的库存数量和效期信息；
- SN 库存：某个 SN 的所属 SKU、货主、仓库、货位及当前状态，数量通常为 1；
- SKU－货位库存、SKU－批次库存、SKU－批次－货位库存；
- SKU－SN 库存：某 SKU 下具体 SN 的库存状态。

#### INV-FR-002 数量与品质状态口径

- 实际库存＝预占库存＋可用库存。
- 预占库存是锁定数量，不是独立实物；同一库存可以因出库单、盘点或品质控制被锁定；锁定原因分别留痕，合计按不重复的实物数量计算，不能把同一件上的多个原因直接相加。
- 解除某一原因后，仍存在其他有效锁定的数量不可恢复可用。
- 库存品质状态另行标识正常品或不良品：正常品可以按业务规则分为预占和可用，不良品默认全量锁定、可用为 0。
- 在库或拣货时发现非效期原因的受损实物，先停止该实物的普通出库；由具备本仓授权和对应权限的仓库主管核实转不良并通知货主。实际数量不变，保留位置、批次／SN、原订单关联及转换依据，品质锁定按并集计量；转换不绕过实盘冻结。具体执行见[库存业务设计第8.4节](../../04-业务分析和设计/04-库存与库内业务设计.md#84-非效期受损与冻结期间过期的模拟走查)。
- 例如正常品实际 8、预占 3、可用 5；不良品实际 2、预占 2、可用 0，则总实际 10＝总预占 5＋总可用 5。
- 已收货未上架的实物按质检进度及正常品／不良品区分显示，上架前不纳入实际库存。

#### INV-FR-003 预占、货位锁定与释放

- 接单准入、SKU 级预占、货位锁定与释放、确认出库扣减及缺量结案以[出库业务需求分析](../03-出库业务/出库业务需求分析.md) OUT-FR-002、OUT-FR-004、OUT-FR-006、OUT-FR-009 为准；本模块维护三量口径（INV-FR-002）与流水（INV-FR-004）。
- 货位锁定表示拣货分配，不新增预占总量；换位释旧锁新，SKU 预占不变。预占合计不得超过实际库存。
- 盘点、品质等锁定可并存，合计按不重复实物计量（见 INV-FR-002）。

#### INV-FR-004 库存流水

每次实际、预占、可用或品质状态变化生成流水，含类型（正常品上架、不良品上架、品质状态转换、移库、盘点调整、确认出库扣减、预占、释放，以及 IN-FR-007 的异常账面上架与关联盘亏）、数量变化、关联单据、货主、SKU、货位、批次、SN、品质状态、操作者与时间；支持按单据号、SKU、货位、批次和 SN 查询。

#### INV-FR-005 移库

- PDA 选择或扫描源货位、货主、SKU、批次／SN 和目标货位，数量不得超过源货位实际数量；目标货位为空或已由同一货主占用时才允许移入，其他货主已占用时阻断。
- 订单预占按货主＋SKU 记录，不随货位移动，但已被拣货任务锁定的货位数量不得直接移走。
- 移库只改变货位分布，不改变品质状态及实际、预占和可用总量，并生成流水；目标货位还须满足品质适配，不能借移位把不良品变成正常可用品。
- 过期自动转不良品按 INV-FR-011 执行，不能借普通移库把不良品改为正常可用品。
- 不良品保留在库身份、位置和品质锁定；实际移出仓库时按 OUT-FR-014 其他出库处理。

#### INV-FR-006 盘点

- **范围：**按仓库、库区、货位或 SKU 创建盘点单；SKU 范围为“所选仓库＋SKU”，不影响其他仓库。
- **盘点准备：**命中范围内尚未开始的收货、上架、拣货、移库任务整单不得开始；已开始的收货、上架、拣货、移库任务允许完成当前任务，不以已经占用实际库存为前提，不等待整张分批入库单后续到货，也不启动尚未开始的后续任务。
- **新单准入：**新出库请求命中盘点阻断时整单拒收，不新增订单预占、不生成待受理单，返回上游原因；盘点结束后由上游重提。已有有效单据的盘点等待计入已开始的履约时长。
- **快照与实盘：**当前已开始作业任务收尾后生成账面快照；收货完成但未上架量不计入实际库存，已拣未出量按暂存位置纳入快照。快照至盘点结束期间，范围内上架、确认出库、移库及其他业务引起的库存变化不得提交，本次盘点自身的差异调整及自动过期转不良为例外；过期转换保留原快照和原因，不改实际数量与位置，不重复累计品质锁定。PDA 录入实盘数量或扫描 SN，差异经确认后调整实际库存并生成流水。
- **调减校验：**按盘点结束后仍有效的订单或其他占用校验，不将本次即将解除的冻结作为永久下限；实盘低于有效占用时中止本盘、不调账，仅解除本盘冻结并保留其他有效锁定；按原业务取消／返库上架并释放相应占用后重新生成快照盘点。旧快照和中止依据保留，校准完成前不将已知差异量供新单使用。
- **校验粒度：**订单预占按仓库＋货主＋SKU 校验拟调整后的本仓总量，含本盘范围外同 SKU 库存；具体货位分配或其他出库指定实物另按原关系校验，不将未定位的 SKU 占用复制到各货位。
- **不良品差异：**实盘短少时同步调减实际数量与对应品质锁定，剩余不良品仍全量锁定。实物仍在库时继续保留实际数量与品质锁，不能以计划移出或处置伪造实盘短少。

#### INV-FR-007 调整入口

不提供直接修改库存数量的入口；调整只能通过盘点或经确认的业务单据产生。已拣实物真实丢失后的取消，由仓库主管确认关联盘亏与对应占用释放同时生效，不伪造返库；不要求先完成常规盘点，实盘冻结仍须遵守，同一损失不得重复调整；操作权限由[公共能力需求分析](../07-公共能力/公共能力需求分析.md)配置。

**差异校准前的新单限制**

- 短拣、换位或盘点发现疑似短少时，登记原业务、位置和差异依据，立即暂停受影响“仓库＋货主＋SKU”的新出库接单；请求包含任一受限SKU则整单拒收、不新增占用，返回原因。普通出库、上游及手工来源不良品其他出库均适用。
- 限制不新增库存数量或重复锁量；已有占用保留，允许原单取消、实际返库、损失核实及重盘在各自规则下继续。盘点中止不解除本限制，实盘冻结亦不被本规则绕过。
- 仓库主管负责接收差异并协调处理；确认该SKU差异已排除或库存校准完成、无未解决差异后解除，记录责任人、依据、时间和结果。账面可用恢复、补货及取消不自动解除；解除后上游重新提交原拒收业务。
- 完整交接见[库存业务设计第5.3节](../../04-业务分析和设计/04-库存与库内业务设计.md#53-已知账实差异在校准前限制新单)。本条是库存准入与差异调整的共同规则，不另设库存类型。

#### INV-FR-008 货主归属与多仓

- 库存按货主分别记录、按仓库过滤，不合并跨仓可用量。
- 一个货位同一时点只能归一个货主使用，同货主多个 SKU 可以共位；货位内该货主实物（含已确认出库待交接实物）、入库过程数量及未完结任务全部清零后，才能改由其他货主使用。
- 用户拥有仓库权限后可查看该仓全部货主库存，不能查看未授权仓库；动作权限见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

#### INV-FR-010 负库存校验

出库扣减、移库、盘点调整等动作提交时校验结果不为负；会导致负数的操作被阻断并提示现有数量。

#### INV-FR-011 批次效期与 SN 库存

- 启用批次／效期的商品按批次记录生产日期、有效期、实际、预占和可用数量。
- 效期等级按[基础资料需求分析](../01-基础资料/基础资料需求分析.md) MD-FR-002 配置计算：低于过期天数时进入过期，未过期且低于临期天数时进入临期，过期判定优先；按业务所属仓库当地日期判断，展示时区切换不改变结果。
- 在库商品进入过期时自动将对应数量的品质状态转为不良品（残品），实际数量不变，保留批次、SN、原位置和自动转换流水，不良品全量品质锁定。
- 未过期临期品保持正常品品质并标临期等级，允许出库，不因临期增加效期锁定；订单、盘点或品质等其他有效锁定仍保留。
- 普通出库从未过期且品质正常的库存中优先推荐有效期更早的批次，临期可参与。
- 已预占或已拣数量转过期时保留原单关联和锁定原因，不重复累计锁定；普通出库校验品质与效期，异常按既有缺量／取消规则处理，不良品实际移出按 OUT-FR-014 其他出库处理。
- 启用 SN 的商品按 SN 记录库存位置和状态，收货、上架、移库、拣货、取消返库上架、盘点、品质转换和确认出库均保留轨迹。
- SN 身份按货主＋SKU＋SN 跨四仓判断；不同货主或不同 SKU 可以使用相同 SN 文本，不要求全集团 SN 文本永久唯一。具体状态及采集界面由应用设计落实。

#### INV-FR-013 PDA 库内作业

- PDA 支持移库、盘点实盘录入及授权范围内的库存查询，扫描货位、SKU、批次／SN 与目标位校验。
- 与管理端共用库存记录与流水；重复提交不重复移库、不重复盘点调整。业务后果见[库存与库内业务设计](../../04-业务分析和设计/04-库存与库内业务设计.md)第五节与第十节。

## 三、调研诉求处理

依据[库存与库内业务需求调研](库存与库内业务需求调研.md)第三、四节，**调研所列场景均纳入一期**；规则见**第二节**。下列为跨模块或需单独指明的处理结论。

| 主题 | 处理结论 |
| --- | --- |
| 上架形成库存、已收未上架进度 | 由[入库业务需求分析](../02-入库业务/入库业务需求分析.md)落实；本模块只接收上架后的实际库存与流水 |
| 预占、扣减、缺量、取消返库上架 | 由[出库业务需求分析](../03-出库业务/出库业务需求分析.md)落实；本模块提供三量与锁定口径 |
| 效期阈值与商品追溯开关 | 商品配置在[基础资料需求分析](../01-基础资料/基础资料需求分析.md)；在库等级与转不良由本模块维护 |
| 不良品实际移出仓库 | 由[出库业务需求分析](../03-出库业务/出库业务需求分析.md)不良品其他出库处理；本模块保留在库品质锁定与位置 |
| 箱库存、报损销毁、ERP 库存同步 | 不纳入一期 |

## 四、范围取舍与模块依赖

一期不包含项与[调研第一节「不在本模块调研范围」](库存与库内业务需求调研.md#一调研范围与资料来源)及项目定位一致，此处不重复罗列。

**编号说明：**沿用现有编号，不为填补断号新增功能或重排编号。009当前未使用；012保留至后续阶段，不进入一期功能、字段清单或验收范围。

| 关联模块 | 衔接说明 |
| --- | --- |
| [基础资料](../01-基础资料/基础资料需求分析.md) | 取得货主、商品、仓库、货位资料；作业资料缺失时阻断相应动作，不改写既有库存 |
| [入库业务](../02-入库业务/入库业务需求分析.md) | 上架增加实际库存；损失与异常账由入库规则产生流水 |
| [出库业务](../03-出库业务/出库业务需求分析.md) | 预占、货位锁、扣减与缺量使用本模块口径；盘点范围内新出库拒收与出库规则一致 |
| [系统集成与对接](../06-系统集成与对接/系统集成与对接需求分析.md) | 一期只交回入出库执行及关联差异结果；独立库存回传留待后续，回传重试不重复改变库存 |
| [公共能力](../07-公共能力/公共能力需求分析.md) | 按仓库授权和角色动作权限查询、移库、盘点或核实品质；效期判断使用所属仓库当地日期 |

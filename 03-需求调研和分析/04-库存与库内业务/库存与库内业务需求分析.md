# 库存与库内业务需求分析

> 本稿说明一期范围与系统需求。
> 业务背景与场景见[库存与库内业务需求调研](库存与库内业务需求调研.md)。

## 一、分析结论与模块边界

本模块维护四仓实物库存的数量、品质、位置与追溯，供入库、出库引用；范围与现状见[项目定位](../../01-全局背景信息/01-项目定位与范围.md)及[调研稿](库存与库内业务需求调研.md)，对象与状态骨架见[库存模块宏观系统架构](../../01-全局背景信息/07-库存模块宏观系统架构.md)。

**职责范围**

- 三量口径（实际、预占、可用）、品质状态、流水、移库、盘点及效期/SN 在库规则在本模块维护。
- 收货形成暂存库位库存、上架移库及暂存期间丢失的处理见[入库业务需求分析](../02-入库业务/入库业务需求分析.md)；**退货收货确认与上架提交**与入库同口径（暂存库位→存储或不良隔离），不另设「退货库存」类型，见[退货业务需求分析](../05-退货业务/退货业务需求分析.md) RT-FR-010。接单预占、货位分配、扣减与缺量结案见[出库业务需求分析](../03-出库业务/出库业务需求分析.md)。
- 货主、商品、货位资格见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)；仓库权限与效期日历见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

**不在本模块**

- 报损／销毁及报损后非库存暂存跟踪；箱库存、托盘库存、货位容量管理。
- 货主对账与账单；财务核算；ERP 逻辑库存同步；跨仓库存调度与在途账。
- 箱、托仅作为入出库过程作业容器记录，容器数量不计入库存；箱库存转换留作后续扩展。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| INV-FR-001 | 库存维度与汇总 | SKU 库存与库存明细两层记账；按仓库、货主、商品、货位、批次和 SN 查看并汇总 |
| INV-FR-002 | 数量与品质状态口径 | 实际＝预占＋可用；预占＝订单占用＋不良品；可用＝正常品实际－订单占用 |
| INV-FR-003 | 订单占用与拣货分配 | 接单在 SKU 层按可用占用，分配在库存明细上记已分配，不另加占用 |
| INV-FR-004 | 库存流水 | 两层共用一本流水，一行只记一个数的一次变化，可追到关联业务 |
| INV-FR-005 | 移库 | PDA 一次提交，只改货位，不改归属、品质和三量合计 |
| INV-FR-006 | 盘点 | 按 SKU 冻结库存变动，实盘后经主管确认直接调账 |
| INV-FR-007 | 调整入口 | 数量只经盘点调整；发现账实不符即对该 SKU 发起盘点 |
| INV-FR-008 | 货主归属与多仓 | 按货主和仓库分别记账，同一货位只归一个货主 |
| INV-FR-010 | 负库存校验 | 实际不能为负；可用只在盘点调减或品质转换后可能为负 |
| INV-FR-011 | 批次效期与 SN 库存 | 保留批次、效期与 SN；临期正品可出，存储、拣货货位上的过期品转不良 |
| INV-FR-013 | PDA 库内作业 | PDA 执行移库、发起盘点和实盘录入，与管理端共用记录 |

#### INV-FR-001 库存维度与汇总

库存分两层记：

- SKU 库存：仓库＋货主＋SKU，记正常品实际、不良品实际和订单占用，三量由此算出；接单预占在这一层校验和增减。
- 库存明细：仓库＋货主＋SKU＋货位＋批次＋库存品质状态（正常品／不良品），记实际数量和已分配数量；分配、移库和各类收发在这一层发生。启用 SN 的商品不按 SN 拆行，另按 SN 记录当前货位、批次、品质和是否在库（见 INV-FR-011）。
- 两层对得上：SKU 库存的正常品、不良品实际等于库存明细按品质加总，订单占用等于未结案出库单明细的预占数量合计；库存明细的已分配等于拣货任务分到该行、尚未拣走的数量，加上其他出库指定在该行的数量。

效期商品另显示效期等级，临期标记与品质状态分开展示和筛选；未启用的维度可为空。系统支持下列视角及组合查询：

- 仓库库存：整个仓库全部 SKU 的实际库存汇总；
- SKU 库存：仓库内某个 SKU 的实际、预占和可用数量；
- 货位库存：某个货位上的库存数量；
- 批次库存：某个批次的库存数量和效期信息；
- SN 库存：某个 SN 的所属 SKU、货主、仓库、货位及当前状态，数量通常为 1；
- SKU－货位库存、SKU－批次库存、SKU－批次－货位库存；
- SKU－SN 库存：某 SKU 下具体 SN 的库存状态。

#### INV-FR-002 数量与品质状态口径

- 三量按仓库＋货主＋SKU 计算：实际库存＝预占库存＋可用库存。
- 预占＝订单占用＋不良品。订单占用是各出库单明细上的预占数量；不良品整体不可用，全部计入预占。不按锁定原因逐件去重。
- 可用＝正常品实际－订单占用。收货暂存、出库暂存库位允许多货主混放，上面的正常品计入可用，接单可以预占，但不参与分配。普通出库接单按可用预占；分配只取存储、拣货库位上库存明细的可分配（实际－已分配），货还在暂存的要等上架或返库上架后才能分配、拣货。
- 库存品质只有正常品、不良品两种，与数量分开表达。
- 例：正常品 8、订单占用 3，不良品 2：实际 10＝预占 5（3＋2）＋可用 5。
- 收货确认即按实收、按品质计入本仓收货暂存库位的实际库存，上架单提交时移到目标库位；出库拣货提交时，库存从来源库位移到出库暂存库位，仍计实际库存和该出库单的订单占用。规则见[入库模块宏观系统架构](../../01-全局背景信息/04-入库模块宏观系统架构.md)与[出库模块宏观系统架构](../../01-全局背景信息/05-出库模块宏观系统架构.md)。
- 在库或拣货时发现非效期受损的实物，由具备本仓授权和对应权限的仓库主管核实转不良并通知货主；复核发现已拣残损的，在出库暂存库位转不良后退拣；收货暂存库位上发现的，先按原品质上架再转。实际数量不变，写品质转换流水。具体执行见[库存与库内业务设计第 8.3 节](../../04-业务分析和设计/04-库存与库内业务设计.md#83-非效期受损的模拟走查)。

#### INV-FR-003 订单占用与拣货分配

- 接单准入、SKU 级预占、拣货分配与释放、确认出库扣减及缺量结案以[出库业务需求分析](../03-出库业务/出库业务需求分析.md) OUT-FR-002、OUT-FR-004、OUT-FR-006、OUT-FR-009 为准；本模块维护三量口径（INV-FR-002）与流水（INV-FR-004）。
- 接单只占 SKU 数量，不指定货位。拣货分配把订单占用落到具体货位、批次，不增加预占，只增加库存明细的已分配；分到的数量不能再分给其他任务，也不能移库或做品质转换。拣货任务提交时已分配随实物从来源货位减掉；换位释旧分新，订单占用不变。
- 已分配的货残损或过期，等拣货时上报货位缺货、换位释放后再转不良；已拣的货在出库暂存库位转不良后退拣。两种情况订单占用都照算，订单另找好货补拣。
- 不良品其他出库在出库单明细上指定货位、批次／SN，建单时计入这些库存明细的已分配，不加订单占用；同一批不良品因此不会被两张其他出库重复指定。

#### INV-FR-004 库存流水

两层共用一本流水，一行只记一个数的一次变化：

- 实际的变化记在库存明细那一行，带货位、批次、品质；SKU 库存的实际不另记，按 SKU 汇总即得。
- 订单占用的变化（预占、补占、释放、确认出库扣减）记在 SKU 层，货位、批次、品质为空。
- 在货位或品质之间转移（上架、拣货提交、返库上架、移库、品质转换）记两行，一减一加。
- 分配和其他出库的指定只改已分配，不写流水，追溯看拣货任务和出库单明细。

每行含类型（收货入暂存库位、上架移库、拣货移入出库暂存库位、返库上架、品质转换、移库、盘点调整、确认出库扣减、预占、释放）、变化量与变化前后数量、关联单据、货主、SKU、货位、批次、品质状态、操作者与时间，启用 SN 的商品另带本次涉及的 SN；支持按单据号、SKU、货位、批次和 SN 查询。按库存明细查，一行的流水合计等于其实际；按 SKU 汇总，实际与订单占用的合计等于 SKU 库存。品质转换的原因、依据和通知结果记在流水上。

#### INV-FR-005 移库

- 移库只在 PDA 上一次扫描提交：选择或扫描源货位、货主、SKU、批次／SN、数量和目标货位，提交即完成，不设待执行、执行中。
- 数量不得超过源货位上未被分配的实际数量（实际－已分配）；目标货位须启用、品质适配，为空或已由同一货主占用，其他货主已占用时阻断。
- 收货暂存、出库暂存库位不作移库的源或目标；盘点中的 SKU 不能移库。
- 移库只改变货位分布，不改变仓库、货主、品质及三量合计，并生成流水；不能借移库把不良品变成正常可用品。
- 不良品实际移出仓库时按 OUT-FR-014 其他出库处理。

#### INV-FR-006 盘点

- **范围：**按仓库＋SKU 创建盘点单，可一次选多个 SKU；盘这些 SKU 在本仓存储、拣货、不良隔离货位上的库存。收货暂存、出库暂存库位上的货跟随上架单、出库单，不盘。需要按库区盘点时，选出该库区的 SKU 建单。
- **发起：**计划盘点由管理端创建；拣货、复核、上架时发现账实不符的人员，提交手上单据后在 PDA 上对该 SKU 发起（见 INV-FR-007）。盘点单记录来源与差异依据。
- **创建条件：**这些 SKU 有进行中的上架单、返库上架单或拣货任务时不能创建；创建即生成账面快照，进入盘点中。
- **冻结：**盘点中的 SKU 不能有任何库存变动：不能收货；含这些 SKU 的上架单、返库上架单不能开始；含这些 SKU 的出库单只能接单和取消，接单照常预占，不能分配、组波、拣货、复核、确认出库或重新分配；不能移库和人工品质转换；过期转换暂停，盘点完成后补做。
- **实盘：**PDA 或管理端按货位、货主、SKU、批次／SN、品质录入实盘数量，SN 商品逐件扫描；可分人、分次录入，差异确认前可重录。实盘只记数，不动库存。
- **差异确认：**仓库主管确认差异后，直接按实盘调整库存明细和 SKU 库存并生成流水，不因订单占用或已分配中止。调减后正常品不够订单占用时，可用为负，相关出库单按出库缺货规则处理；其他出库指定的不良品盘亏时，该其他出库只能取消后重新指定。不良品差异同步调整不良品数量。
- **取消：**建错或暂时无法盘点时，由仓库主管取消，不调账，解除冻结。
- 盘点结果仓内可查，不单独回传上游。

#### INV-FR-007 调整入口

- 不提供直接修改库存数量的入口；数量调整只能通过盘点产生。
- 入库暂存期间丢失、出库已拣后丢失，都先按应上架、应返库数量提交，再对该 SKU 发起盘点，同一损失只调整一次；残损另做品质转换。
- 拣货短拣或换位、复核少件、上架或返库上架时找不到等账实不符，由发现人员提交手上单据后对该 SKU 发起盘点，不另设差异登记或新单限制。该 SKU 还有他人进行中的任务时，待其提交后再发起。
- 操作权限由[公共能力需求分析](../07-公共能力/公共能力需求分析.md)配置。完整交接见[库存与库内业务设计第 5.3 节](../../04-业务分析和设计/04-库存与库内业务设计.md#53-发现账实不符就发起盘点)。

#### INV-FR-008 货主归属与多仓

- 库存按货主分别记录、按仓库过滤，不合并跨仓可用量。
- 一个货位同一时点只能归一个货主使用，同货主多个 SKU 可以共位；货位内该货主实物（含已确认出库待交接实物）、入库过程数量及未完结任务全部清零后，才能改由其他货主使用。收货暂存、出库暂存库位允许多货主混放，不受此限。
- 用户拥有仓库权限后可查看该仓全部货主库存，不能查看未授权仓库；动作权限见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

#### INV-FR-010 负库存校验

- 出库扣减、移库、盘点调整等动作提交时校验实际数量不为负；会导致负数的操作被阻断并提示现有数量。
- 接单预占、补占只在可用范围内进行，不会使可用为负。盘点调减或品质转换使正常品少于订单占用时，可用可以为负，表示订单占用的好货不足，相关出库单按缺货规则处理。
- 分配、其他出库指定、移库和品质转换都不能超过该库存明细的实际－已分配。

#### INV-FR-011 批次效期与 SN 库存

- 启用批次／效期的商品按批次记录生产日期、有效期和数量。
- 效期等级按[基础资料需求分析](../01-基础资料/基础资料需求分析.md) MD-FR-002 配置计算：低于过期天数时进入过期，未过期且低于临期天数时进入临期，过期判定优先；按业务所属仓库当地日期判断，展示时区切换不改变结果。
- 存储、拣货货位上未被分配的商品进入过期时自动转为不良品，实际数量不变，保留批次、SN、原位置和品质转换流水。收货暂存库位上的商品上架后再判断；出库暂存库位上已拣的商品不做过期转换，照常复核、发出。盘点中的 SKU 暂停转换，盘点完成后补做。
- 未过期临期品保持正常品品质并标临期等级，允许出库，不因临期增加占用。
- 普通出库从未过期且品质正常的库存中优先推荐有效期更早的批次，临期可参与。
- 已分配未拣的商品过期后不再拣出：拣货时按货位缺货换位，释放后再转不良；订单占用不变，按出库缺货规则处理。不良品实际移出按 OUT-FR-014 其他出库处理。
- 启用 SN 的商品按 SN 单独记录当前货位、批次、品质和是否在库，库存明细不按 SN 拆行；收货、上架、移库、拣货、退拣返库上架、盘点、品质转换和确认出库的流水都带 SN，保留轨迹。
- SN 身份按货主＋SKU＋SN 跨四仓判断；不同货主或不同 SKU 可以使用相同 SN 文本，不要求全集团 SN 文本永久唯一。具体状态及采集界面由应用设计落实。

#### INV-FR-013 PDA 库内作业

- PDA 支持移库、发起盘点、实盘录入及授权范围内的库存查询，扫描货位、SKU、批次／SN 与目标位校验。
- 与管理端共用库存记录与流水；重复提交不重复移库、不重复盘点调整。业务后果见[库存与库内业务设计](../../04-业务分析和设计/04-库存与库内业务设计.md)第五节与第十节。

## 三、调研诉求处理

依据[库存与库内业务需求调研](库存与库内业务需求调研.md)第三、四节，**调研所列场景均纳入一期**；规则见**第二节**。下列为跨模块或需单独指明的处理结论。

| 主题 | 处理结论 |
| --- | --- |
| 收货形成暂存库位库存、上架移库与待上架进度 | 由[入库业务需求分析](../02-入库业务/入库业务需求分析.md)落实；本模块维护暂存库位与目标库位的实际库存及流水 |
| 预占、扣减、缺量、退拣返库上架 | 由[出库业务需求分析](../03-出库业务/出库业务需求分析.md)落实；本模块提供三量口径 |
| 效期阈值与商品追溯开关 | 商品配置在[基础资料需求分析](../01-基础资料/基础资料需求分析.md)；在库等级与转不良由本模块维护 |
| 不良品实际移出仓库 | 由[出库业务需求分析](../03-出库业务/出库业务需求分析.md)不良品其他出库处理；本模块保留在库品质与位置 |
| 箱库存、报损销毁、ERP 库存同步 | 不纳入一期 |

## 四、范围取舍与模块依赖

一期不包含项与[调研第一节「不在本模块调研范围」](库存与库内业务需求调研.md#一调研范围与资料来源)及项目定位一致，此处不重复罗列。

**编号说明：**沿用现有编号，不为填补断号新增功能或重排编号。009当前未使用；012保留至后续阶段，不进入一期功能、字段清单或验收范围。

| 关联模块 | 衔接说明 |
| --- | --- |
| [基础资料](../01-基础资料/基础资料需求分析.md) | 取得货主、商品、仓库、货位资料；每仓在暂存类库区指定收货暂存、出库暂存库位；作业资料缺失时阻断相应动作，不改写既有库存 |
| [入库业务](../02-入库业务/入库业务需求分析.md) | 收货确认增加收货暂存库位实际库存，收到的正常品即计入可用、可被接单预占；上架单提交时移到目标库位，之后才能分配；暂存期间丢失按应上架数量提交后发起盘点，上架前残损上架后做品质转换；盘点中的 SKU 不能收货、上架 |
| [出库业务](../03-出库业务/出库业务需求分析.md) | 接单按 SKU 库存的可用预占，拣货分配计入库存明细的已分配；扣减与缺量使用本模块口径；拣货提交时库存移入出库暂存库位，退拣经返库上架移回；盘点中 SKU 的出库单可接单预占，不能分配、拣货、确认出库 |
| [系统集成与对接](../06-系统集成与对接/系统集成与对接需求分析.md) | 一期只交回入出库执行及关联差异结果；独立库存回传和盘点结果回传留待后续，回传重试不重复改变库存 |
| [公共能力](../07-公共能力/公共能力需求分析.md) | 按仓库授权和角色动作权限查询、移库、盘点或核实品质；效期判断使用所属仓库当地日期 |

## 一、调研范围与资料来源

本次调研要弄清楚：3PL 转自营后，账实与占用如何对齐、移库与盘点如何留痕、效期与 SN 如何追溯，以及一期演示覆盖哪些库内场景。**一期库存能力边界**以[项目定位与范围](../../01-全局背景信息/01-项目定位与范围.md#22-仓内业务与上游协作)库存行为准；下表只列调研环节，不重复项目级「不做什么」全文。

| 环节 | 本次关注内容 | 主要交接 |
| --- | --- | --- |
| 库存查询 | 按仓、货主、SKU、货位、批次、SN 等视角查看；汇总与明细对应 | 业务安排发货、现场找货 |
| 数量与品质口径 | 实际、预占、可用；正常品与不良品；多原因锁定不重复计量 | 入库上架形成库存；出库预占与扣减 |
| 在库环节区分 | 已收未上架、已拣未出、已确认待交接等待遇不同 | 与入库、出库模块分界，避免混记 |
| 预占与货位锁定 | SKU 级预占与拣货货位锁分开；换位不增占用总量 | 细则在出库分析；本模块维护三量与流水 |
| 流水与调整 | 变化须关联业务与操作者；禁止无依据改数 | 盘点或经确认的业务单据调整 |
| 移库 | 只改位置，不改归属、品质与三量总量 | PDA 扫描源位与目标位 |
| 盘点 | 任务收尾、快照、实盘、差异确认；与进行中收发冲突 | 新出库命中范围时拒收见出库衔接 |
| 批次效期与 SN | 临期标记、过期转不良、SN 轨迹 | 商品配置在基础资料；出库推荐批次 |
| 不良品在库 | 隔离存放与品质锁定；实际移出交出库其他出库 | 不报损销毁一期能力 |

**不在本模块调研范围：**报损／销毁及报损后非库存暂存跟踪；箱库存、托盘库存、货位容量与占用率；货主对账与账单；财务 ERP 与 WMS 库存自动同步；跨仓库存调度与在途账（调拨仍按各仓独立入出库执行）。

## 二、当前角色与系统分工

### 2.1 立项时点的业务职责

| 角色 | 已知职责 | 仍需确认 |
| --- | --- | --- |
| 跨境与渠道业务 | 向海外仓要库存与履约结果；多渠道争用同一 SKU | 3PL 时期能否区分可用量、占用与货位明细 |
| 第三方海外仓（3PL） | 代运营在库实物与本地库存账 | 强盛是否持有货位、批次、占用明细 |
| 仓储物流（规划） | 租仓后组织四仓存放、移库、盘点 | 盘点频率与范围习惯、PDA 使用、差异确认流程 |
| 外部品牌货主（规划） | 关心自有商品数量与归属 | 一期由 Mock 货主演示；对账方式待二期 |
| 数字化／项目组 | 建设 WMS | 库存查询与流水展示范围；与入出库联调样例 |

自营阶段：**入库上架**形成本模块实际库存；**出库预占、扣减**使用本模块三量口径；**移库、盘点**在本模块执行；业务端通过 OMS Mock 看执行结果，不经营 WMS 内库存账。

### 2.2 当前系统与作业流转

立项前海外库存由 3PL 维护，强盛主要靠**交接汇总**掌握数量，难以统一追溯占用、货位分布、批次效期与盘点调整。

```mermaid
flowchart LR
    B[业务端] -->|要库存/发货| P[3PL 海外仓]
    P -.->|汇总或部分结果| B
```

一期课程演示目标形态：

```mermaid
flowchart LR
    W[强盛 WMS 库存与库内]
    IN[入库上架] -->|增加实际库存| W
    W -->|可用量/预占| OUT[出库预占扣减]
    W --> M[移库 / 盘点]
    S[管理端 / PDA] --> W
```

| 载体 | 与本期库存的关系 | 已知问题或空白 |
| --- | --- | --- |
| 3PL | 立项前海外账实 | 占用与货位不透明；自营后需自建流水与盘点 |
| 强盛 WMS | 三量、位置、品质、流水 | 新建；四仓独立，不合并跨仓可用 |
| 入库 / 出库 | 上架增库存；预占与扣减 | 进度与库存分界见各模块分析 |
| 基础资料 | 货主、商品、货位 | 效期阈值、SN/批次开关来自商品配置 |

## 三、核心场景与业务问题

| 场景 | 当前情况 | 主要问题 | 证据状态 |
| --- | --- | --- | --- |
| 发货前看库存 | 订单要量、系统可用、货位实物可能不一致 | 须区分实际、预占、可用；不跨仓合并 | 方向已确认；查询样例待补 |
| 找货与核对位置 | 同 SKU 多货位、多批次 | 汇总与明细须能对应 | 视角方向已确认；沙盘分布待补 |
| 多货主同仓 | 自营与外部品牌共四仓 | 归属混记会导致错发、错盘 | 货位不混货主已确认；案例待走查 |
| 在库环节与占用争用 | 未上架、已拣未出、待交接等待遇不同；多笔出库争用同一 SKU | 不能把进度当成库存；总量不等于仍可分配量 | 方向已确认；与入出库联动的沙盘待补 |
| 移库 | 现场常调整存放位置 | 须留痕且不改变品质与三量总量 | PDA 样例待补 |
| 盘点 | 盘点时仍有收发货；范围内新出库指令须与冻结规则一致 | 范围、快照、差异依据清楚；与出库拒收口径一致 | 方向已确认；冻结与拒收联合案例待走查 |
| 流水与改数 | 仅有最新数不足以解释差异；提交须防负库存 | 变化关联业务与操作者；禁止无依据改数 | 方向已确认 |
| 批次效期与 SN | 3C 等存在批次、效期、SN | 临期、过期、轨迹须可辨；过期转不良 | 配置在基础资料；效期/SN 样例待补 |
| 不良品在库与移出 | 不可用但仍占实物与位置 | 品质锁定与出库其他出库分工 | 一期纳入；移出样例待补 |

## 五、待补资料与确认清单

| 确认方向 | 重点问题 | 需要提供的资料 |
| --- | --- | --- |
| 查询与展示 | 业务方看汇总还是货位明细；多货主切换习惯 | 库存查询与货位分布样例（可用沙盘） |
| 三量与占用 | 可用不足、多单争用时的现场理解 | 含预占数字的出库沙盘案例 |
| 在库环节 | 未上架、已拣未出、待交接如何区分展示 | 与入库、出库联动的完整链说明 |
| 移库 | 源位、目标位、批次/SN 扫描步骤 | PDA 移库操作样例 |
| 盘点 | 范围选择、冻结感受、差异确认谁签字 | 盘点单与差异确认样例 |
| 效期与 SN | 临期、过期转不良、SN 状态 | 至少一批效期商品 + 若干 SN 沙盘数据 |
| 不良品 | 在库位置与其他出库衔接 | 不良品库存 + 移出依据样例 |

建议优先补齐**一条含上架后库存查询的案例**、**一条盘点冻结与出库拒收联动案例**，以及**一条效期临期/过期转不良案例**。走查组织见[关键走查场景](../../04-业务分析和设计/06-海外仓典型业务场景与方案.md#84-关键走查场景)。竞品仅作参考，见[竞品原文入口](../../02-竞品调研和分析/00-双边能力对比矩阵.md#四资料入口与证据边界)；箱库存转换、盲盘、自动循环盘点不自动纳入一期。

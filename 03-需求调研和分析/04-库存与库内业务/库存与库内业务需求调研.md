# 库存与库内业务需求调研

> 本文整理课程沙盘的目标业务场景与诉求。系统需求见[库存与库内业务需求分析](库存与库内业务需求分析.md)。

## 一、业务背景与参与方

强盛未来自行运营四仓后，需要掌握实物属于哪个货主、存在哪里、处于什么品质状态，以及哪些数量已经被业务占用。库存记录要能支持发货安排、找货、差异核对和追溯。立项时第三方海外仓的具体库存工具及账实情况未说明。

仓库人员执行存放、移库和盘点，业务端依据库存与执行结果安排履约，货主关心自有商品的数量与归属。本模块研究库存查询、数量与品质口径、批次／SN追溯、流水、移库、盘点及报损／销毁；入库和出库作业由对应模块研究，财务核算与货主账单不在本期范围。

## 二、主要业务场景与诉求

| 业务场景 | 约束或风险 | 业务诉求 |
| --- | --- | --- |
| 安排发货前查看库存 | 总实物数量中可能已有业务占用 | 能区分实际数量、已占用与可用数量，按仓库和货主判断，不合并跨仓可用量 |
| 寻找某个商品或核对位置 | 同一SKU可能分布在多个货位、批次 | 能按商品、货位及追溯维度查询，汇总与明细对应 |
| 多货主货物同仓存放 | 相同商品编码或混放容易造成归属混淆 | 每条库存保留货主归属，实物位置管理满足隔离要求 |
| 已收货物尚未上架、已拣货物尚未出仓 | 作业进度与实际库存容易被混记 | 能查清实物所处环节，明确哪些动作形成或扣减库存 |
| 货物在仓内挪位 | 位置改变，货主、商品和总实物数量未变 | 移动结果可查，库存位置与现场实物对应，不借移库改变品质 |
| 盘点期间仍有进行中的作业 | 盘点账面与实物可能因作业变化失去可比性 | 明确盘点范围、作业冲突处理和差异确认依据，调整过程可追溯 |
| 库存数量或品质发生变化 | 仅有最新数量不足以解释差异 | 能追到关联业务、变化数量、操作者和时间，不提供无依据直接改数 |
| 批次效期、SN商品在库 | 商品总量无法代替批次或单品身份 | 保留日期、品质及历次位置与动作；临期、过期与品质状态需要分清 |
| 不良品报损或销毁 | 普通可用为0，但仍存在需要处置的实物 | 根据处置依据记录类型和数量，合法调减对应库存，避免重复扣减 |

## 三、需要补充的资料

- 库存查询、货位分布与盘点差异样例，用于细化查询视角和差异确认；无真实资料时用明确标注的课程样例。
- 批次效期与SN商品样例，用于落实追溯记录及SN状态表达。
- 报损通知、实物暂存去向、销毁完成依据及现场步骤样例，用于落实处置记录。

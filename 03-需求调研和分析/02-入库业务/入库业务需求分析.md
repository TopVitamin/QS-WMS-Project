# 入库业务需求分析

> 本稿说明一期范围与系统需求。业务背景见[调研稿](入库业务需求调研.md)。

## 一、分析结论

WMS接收正常入库、调拨入库指令，完成到货登记、收货、按商品配置质检、上架和结果回传。正常品与不良品分别上架后形成对应品质库存，管理端和PDA共用记录。调拨入库作为普通入库来源，不关联调出仓单据。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| IN-FR-001 | 入库指令接收 | 接收正常入库和调拨入库指令，校验必要资料 |
| IN-FR-011 | 入库单来源 | 常规单由OMS Mock生成，认领是唯一手工入口 |
| IN-FR-002 | 到货登记与签收 | 识别到货；已知货主补单，未知归属登记待认领 |
| IN-FR-012 | 无主件认领 | 先确定归属，再清点收货、按配置质检与上架 |
| IN-FR-003 | 收货 | 分次记录实收，校验追溯及效期，区分超收与短少 |
| IN-FR-004 | 质检 | 需检商品按配置检验，正常品与不良品分别上架 |
| IN-FR-005 | 上架任务 | 按品质和形态推荐货位，支持扫描及部分上架 |
| IN-FR-006 | 上架校验 | 上架不得超过已收货未上架数量 |
| IN-FR-013 | PDA入库作业 | PDA执行同一入库任务，重复提交不重复增库存 |
| IN-FR-007 | 入库完成与结果 | 收货完结且必要质检、上架完成后结案，差异保留 |
| IN-FR-010 | 库存影响 | 入库进度与实际库存分开，上架才形成库存 |
| IN-FR-008 | 取消与变更 | 未实收可变更或取消，已实收拒绝；退回走独立出库 |
| IN-FR-009 | 多货主归属与仓库权限 | 单据与库存按货主归属，访问范围引用公共能力 |

### 接单、到货与认领

#### IN-FR-001 入库指令接收

- 接收OMS Mock推送的正常入库或调拨入库通知，生成入库单（状态“待收货”），含业务类型、货主、仓库、商品与预计数量、到货方式；货主或商品无法匹配时拒绝建档并记录异常。
- 调拨入库单不要求提供调出仓单号，也不与调出仓结果核对。

#### IN-FR-011 入库单来源

- 常规入库单仅由OMS Mock指令生成；管理端不提供常规手工新建入口；无主件认领产生的入库记录是唯一的手工入口。
- 演示数据通过预置提供。

#### IN-FR-002 到货登记与签收

- 支持按入库单号、运单号或箱唛定位入库单并登记到货。
- 无预报到货分两路处理：能判断货主的，联系货主补推入库单，到单后按正常入库执行；无法判断货主的，登记为“待认领”，认领前不计入任何货主库存、不可上架、不可出库，仅在待认领列表可见。
- 示例：到货1托3箱，按箱唛匹配到2张入库单；无法匹配的1箱进入待认领；若送货单能指明货主，则联系该货主补推入库单。

#### IN-FR-012 无主件认领

- 待认领货物使用专门位置，不与已识别货主实物混放。
- 管理端确认归属后生成对应入库记录（货主自助认领随OMS二期评估）。
- 认领只确定归属；仓库完成清点并按商品配置决定是否质检后，实收数量按正常品或不良品记录，上架前不计实际库存。
- 认领前不计任何货主库存。

### 收货、质检与上架

#### IN-FR-003 收货

- 按商品记录每次实收，支持多次到货和部分收货。启用SN时采集SN，启用批次／效期时记录批次、生产日期和有效期，校验有效期不早于生产日期。
- 效期准入引用MD-FR-002，按仓库当地业务日期计算剩余保质期，只与允许入库天数比较：小于时拒收、大于或等于时允许。临期、过期用来标识效期等级，不追加收货限制。
- 效期拒收记录批次、日期、数量和原因，不计实收、不生成质检或上架任务、不计库存；不能改记不良品绕过准入。在库过期转不良由INV-FR-011负责。
- 按箱／托清点时记录容器内SKU与数量，不形成箱库存或托盘库存。预报范围内符合条件的实物按商品配置执行：需检商品质检后上架，免检商品可直接上架。
- 超出预报的实物不接收，登记超收事实并放入该仓异常处理区，不计实收、实际或可用库存。货主补发新入库单后按新单校验收货；直接退还或处置在线下完成，不建立出库单，WMS不记录后续移出或处置结果。
- 收货未完结时，“预计10、累计实收8”表示未收2；确认收货完结后才形成最终短少2。

#### IN-FR-004 质检

- 仅对商品配置为需质检的已收数量生成质检任务，并按商品指定流程记录质检方式、正常品数量、不良品数量、原因和操作者。
- 正常品与不良品分别执行后续上架，两者上架前都属于已收货未上架实物、不计实际库存。
- 免检商品不生成质检任务；在收货或上架时发现残损，由授权仓库人员登记残损数量、原因并直接判定品质，正常／不良分别上架。记录指向原入库、实收和对应实物，保留操作者与时间，不把残损无记录按正常品上架。
- 具体检验项目和原因明细结合商品样例在应用设计中细化。

#### IN-FR-005 上架任务

- 按已收货未上架实物中的正常品、不良品分别生成任务；需质检商品须完成相应质检后才可上架，免检商品可直接上架。
- 正常品推荐正常存储／拣货位置，不良品推荐不良隔离位置。
- 先按形态适配和品质状态筛选候选货位，再按“同货主同商品货位优先→该货主其他可用货位”推荐。
- 一个货位只能存放一个货主的实物；目标货位已有其他货主实物、入库过程数量或未完结任务时阻断。
- 支持人工改位，仍校验货位启用、仓库归属、货主占用和品质适配。
- PDA扫描货位、商品及配置要求的批次／SN后确认上架；支持部分上架，剩余继续记为已收货未上架。
- 示例：已收货8件，分两次上架5＋3。真实丢失的特殊处理见IN-FR-007，不为缺失实物补造落位或扫描记录。

#### IN-FR-006 上架校验

上架数量不得超过已收货未上架数量；超出时阻断提交并提示可上架数量。

#### IN-FR-013 PDA入库作业

- PDA支持按单号、运单号或箱唛定位任务，完成收货、批次效期与SN采集、按商品配置执行质检、货主与货位扫描校验和上架。
- 管理端与PDA提交同一业务记录，重复提交不重复增加库存。

### 完成、库存与变更

#### IN-FR-007 入库完成与结果

- 常规入库在收货明确完结、需检实物完成质检、正常品与不良品均完成对应上架后置为「已完成」。
- 短少、超收、不良品及**真实丢失**的结案与数量后果见[入库业务设计](../../04-业务分析和设计/02-入库业务设计.md#84-模拟补充分支实收正确未上架真实丢失立即盘亏收口)（含异常账面上架与关联盘亏、原实收误记不适用等）；本稿只要求：损失同次收口、不补造检验或落位事实、中间账面量不得供新单分配。
- 存在差异时可标记「有差异」，不阻断已完成数量的入库；各段结果分别可查并回传 OMS Mock。

#### IN-FR-010 库存影响

- 入库单记录累计实收、质检正常／不良、已上架和已收货未上架数量，未完成质检的实物仍包含在已收货未上架数量内；这些是作业进度记录，质检与上架进度不另设单据状态或库存数量类型。
- 完成上架后，正常品与不良品都进入实际库存：正常品按可用与业务锁定计算，不良品默认全量锁定、可用为0。
- 数量口径、品质状态与流水引用INV-FR-001～INV-FR-004；真实丢失按IN-FR-007生成相互关联的异常账面结转与盘亏记录，同一损失只扣减一次，不能用报损／销毁不良品的入口代替这一分支。

#### IN-FR-008 取消与变更

- 尚未产生任何实收时，可以接受OMS Mock取消并关闭入库单；此时也可接受明细变更。
- 仓库、货主和业务类型等身份字段不得在原单上变更，须在允许取消时取消原单并重新下发。
- 一旦产生实收，无论货物是否质检或上架，WMS均拒绝取消和明细变更，并向OMS Mock返回原因；已发生的实收和原入库记录必须保留。
- 已收货物需要通过系统退回时，必须先按商品配置完成必要质检、上架并形成实际库存，再由OMS Mock另行下发退回出库指令；WMS不得删除或反向改写原入库记录。
- 未进入入库流程的实物留在暂存区线下处理，不进入WMS退回出库。

#### IN-FR-009 多货主归属与仓库权限

入库单、收货与上架记录均带货主维度并分别形成对应货主库存；用户拥有仓库权限后可查看该仓全部货主入库数据，不能查看未授权仓库，规则引用[COM分析稿](../07-公共能力/公共能力需求分析.md)。

## 三、范围取舍与模块依赖

一期不包含：退货入库、换标换包装、仓外运输；不良品后续其他出库或盘亏处置由OUT／INV承接；收货前置预约（未提出，后置）。

管理端查询与结果回传纳入一期，货主自助查看及自助认领留在OMS二期评估。

| 依赖模块 | 依赖能力与使用约束 |
| --- | --- |
| INT | 接收入库指令并交回已有执行结果；回传失败只重试结果交接 |
| MD | 接单校验仓库、货主、商品；上架再校验目标货位、货主占用及品质适配 |
| INV | 上架和损失处理使用统一数量口径及流水；命中盘点阻断时不得绕过冻结提交 |
| COM | 管理端与PDA共用记录；质检、认领和异常确认按动作权限执行 |

## 四、应用设计输入与资料缺口

- 质检项目、原因明细和输入／结果表单结合商品与业务样例在应用设计中细化。
- 免检残损的登记载体、原因明细及两端操作按IN-FR-004落实；具体授权岗位随权限配置确定，不新增审批或异常质检流程。

**业务验收示例（IN-FR-004／005／010）：**免检商品符合收货准入，实收10、其中残损2，由授权仓库人员登记并判为不良。预期不生成质检任务，正常8与不良2分别上架后实际10、品质锁2、可用8；原实收仍为10，记录可追到原单与操作者。上架时才发现残损的，先登记并调整尚未上架部分的品质与目标位置，再确认落位；已在库受损按INV规则处理。**文档逻辑走查已通过**（2026-10-08，见[需求分析总览§6.4](../00-项目总览/02-需求分析总览.md#64-文档逻辑走查记录2026-10-08)）；演示/PDA 实操待执行。

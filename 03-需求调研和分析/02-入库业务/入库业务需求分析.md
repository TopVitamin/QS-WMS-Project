# 入库业务需求分析

> 本稿说明一期范围与系统需求。
> 业务背景与场景见[入库业务需求调研](入库业务需求调研.md)。

## 一、分析结论与模块边界

WMS接收正常入库、调拨入库指令，完成到货登记、新品维护（量方称重）、按容器或按SKU收货、按商品配置质检、**按容器或按SKU上架**和结果回传。正常品与不良品分别上架后形成对应品质库存，管理端与PDA共用记录。调拨入库作为普通入库来源，不关联调出仓单据。

**职责范围**

- 本模块记录到仓识别、实收进度、品质分流、上架落位及入库差异；库存影响见第二节。
- 入库指令与结果回传经[系统集成与对接需求分析](../06-系统集成与对接/系统集成与对接需求分析.md)；货主、商品、货位资格见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)。
- 已收货物从仓库退回仓外由出库模块按退回出库指令执行；超收线下退还或处置不在本模块记录移出。

**不在本模块**

- 客户退货接收与重新入库；换标换包装；仓外运输与收货预约（一期未纳入）。
- 入库取消、无主货认领与OMS客户查看由后续真实OMS承接。
- 商业计费与仓租。
- **LPN全仓跟踪**：不建立箱库存或托盘库存，不以作业容器为在库库存维度，不提供库内按容器移库、按容器查可用量或容器主数据全生命周期管理（容器编号仅服务本单收货—上架绑定与追溯）。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| IN-FR-001 | 入库指令接收 | 接收正常入库和调拨入库指令，校验必要资料 |
| IN-FR-002 | 到货登记与签收 | 识别到货；已知货主补单，未知归属登记无主货 |
| IN-FR-003 | 收货 | 分次记录实收，校验追溯及效期，区分超收与短少 |
| IN-FR-004 | 质检 | 需检商品按配置检验，正常品与不良品分别上架 |
| IN-FR-005 | 上架任务 | 按品质和形态推荐货位，支持扫描及部分上架 |
| IN-FR-006 | 上架校验 | 上架不得超过已收货未上架数量 |
| IN-FR-007 | 入库完成与结果 | 收货完结且必要质检、上架完成后结案，差异保留 |
| IN-FR-008 | 取消与变更 | 一期未实收可接收明细变更；入库取消待OMS上线，由上游发起 |
| IN-FR-009 | 多货主归属与仓库权限 | 单据与库存按货主归属，访问范围引用公共能力 |
| IN-FR-010 | 库存影响 | 入库进度与实际库存分开，上架才形成库存 |
| IN-FR-011 | 入库单来源 | 一期全部入库单由OMS Mock指令生成，不提供手工入口 |
| IN-FR-012 | 无主货登记 | 一期只登记和暂存；OMS上线后推送信息、在OMS认领并下发入库指令 |
| IN-FR-013 | PDA入库作业 | PDA执行同一入库任务，重复提交不重复增库存 |
| IN-FR-014 | 新品维护 | 首次到仓SKU量方称重并更新仓内规格；可按规则拍照留底 |
| IN-FR-015 | 作业容器收货与上架 | 可选按容器或按SKU收货；容器路径支持扫容器上架 |

#### IN-FR-001 入库指令接收

- 接收OMS Mock推送的正常入库或调拨入库通知，生成入库单（状态「待收货」），含业务类型、货主、仓库、商品与预计数量、到货方式等；货主或商品无法匹配时拒绝建档并记录异常。
- 入库单可携带或展示明细是否「需新品维护」（由上游标记或按商品是否已有仓内规格判定，具体见应用设计与样例）。
- 调拨入库单不要求提供调出仓单号，也不与调出仓结果核对。

#### IN-FR-002 到货登记与签收

- 支持按入库单号、运单号或箱唛定位入库单并登记到货。
- 同一货主的一次送货可能对应多张入库单；一次到仓按识别信息分别登记到对应单据，不混记货主。
- 无预报到货：能判断货主的，联系货主补推入库单，到单后按正常入库执行；无法判断货主的，登记无主货并专门暂存，不生成入库单、实收或库存。
- 示例：同一货主到货1托3箱，其中2箱分别匹配到入库单，另1箱货主已知但缺少指令，暂存并联系补单。若另有一箱连货主也无法确定，才登记无主货。

#### IN-FR-003 收货

- 按商品记录每次实收，支持多次到货和部分收货。启用SN时采集SN；启用批次／效期时记录批次、生产日期和有效期，校验有效期不早于生产日期。
- 效期准入按[基础资料需求分析](../01-基础资料/基础资料需求分析.md)商品效期配置，按仓库当地业务日期计算剩余保质期，只与允许入库天数比较：小于时拒收、大于或等于时允许。临期、过期等级不追加收货限制；在库过期转不良见库存与库内需求分析。
- 效期拒收记录批次、日期、数量和原因，不计实收、不生成质检或上架任务、不计库存；不能改记不良品绕过准入。
- 实收数量按入库商品明细累计；与作业容器的绑定、容器内分SKU数量及容器上架见[作业容器收货与上架](#in-fr-015-作业容器收货与上架)。预报范围内按商品配置：需检商品质检后上架，免检商品可直接上架。
- 超收不接收，登记超收事实并放入该仓异常处理区，不计实收与库存；货主补发新单后按新单校验收货，线下退还或处置不建出库单。
- 收货未完结时，「预计10、累计实收8」表示仍待收2；确认收货完结后才形成最终短少。

#### IN-FR-004 质检

- 仅对配置为需质检的已收数量生成质检任务，记录质检方式、正常品与不良品数量、原因和操作者。
- 正常品与不良品分别上架；上架前均属于已收货未上架，不计实际库存。
- 免检商品不生成质检任务；收货或上架时发现残损，由授权人员登记残损数量、原因并判定品质，正常／不良分别上架，须保留操作者与时间。
- 检验项目与原因明细结合商品样例在应用设计中细化。

#### IN-FR-005 上架任务

- 按已收货未上架实物中的正常品、不良品分别生成任务；需检商品须完成质检后才可上架。
- 正常品推荐存储／拣货位置，不良品推荐不良隔离位置；按形态适配与货主占用规则推荐，支持人工改位。
- 同一货位同一时点只能存放一个货主的实物；存在其他货主的实物、入库过程数量或未完结任务占用时阻断，具体见[基础资料的货位规则](../01-基础资料/基础资料需求分析.md#md-fr-004-库区与货位资料)。
- 支持按SKU扫描货位确认与部分上架；容器路径支持扫描作业容器整容器或分次落位。真实丢失处理见[入库完成与结果](#in-fr-007-入库完成与结果)。

#### IN-FR-006 上架校验

上架数量不得超过已收货未上架数量；超出时阻断并提示可上架数量。按容器上架时，不得超过该容器当前可上架数量及对应商品行的已收未上架数量。

#### IN-FR-007 入库完成与结果

- 累计实收大于0，且收货完结、需检完成质检、正常品与不良品均完成对应上架后，常规入库置为「已完成」。
- 收货未完结时只表达仍待收数量；授权人员确认收货完结后，未收部分记为**最终短少**（预计数量减累计实收），不与超收、效期拒收数量重复加总。
- 超收、效期准入拒收等单独记录差异事实，不计入累计实收；结案回传时分别说明，不能用单一「有差异」替代各事实。
- 存在短少、不良或已隔离超收时，可将单据标记「有差异」并完成结案；已实收且完成上架的数量正常形成库存，执行结果按原指令回传OMS Mock。
- 累计实收为0且确定不再接收时，原单保持待收货，保留到货与拒收原因；仓库线下通知上游，由OMS发起取消（一期Mock不模拟取消结案）。WMS不能按零实收完成入库或生成库存。
- 已收未上架实物经核实真实丢失时，保留原实收、已有质检结果、现场剩余和损失依据。由仓库主管确认，实际落位、异常账面结转与立即关联盘亏同次生效，同一损失只扣一次；缺失件不生成现场落位、扫描或质检记录。收货完结、实有需检数量检完、实物上架及损失处理完成后，入库单可带差异完成。实收误记不适用此路径，盘点冻结限制仍生效。
- 模拟例：免检商品预计并实收10件、未上架前丢失2件，现场8件完成落位；异常账面结转10并立即关联盘亏2，库存净增8，原实收仍为10，损失2不计入未收短少。未扣除损失的中间数量不可供新单使用。完整案例见[入库业务设计第8.4节](../../04-业务分析和设计/02-入库业务设计.md#84-模拟补充分支实收正确未上架真实丢失立即盘亏收口)。

#### IN-FR-008 取消与变更

- 尚未产生实收时可接受OMS Mock明细变更；产生实收后拒绝明细变更。
- WMS不提供入库取消；零实收待上游处理。身份字段不得在原单变更。
- 已收货物退回须先形成库存，再由OMS Mock下发退回出库指令；未进入实收的实物线下处理，不建WMS退回出库。

#### IN-FR-009 多货主归属与仓库权限

入库单、收货与上架记录均带货主维度；用户只能访问授权仓库，具体操作还须具备相应动作权限，规则见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

#### IN-FR-010 库存影响

- 入库单记录累计实收、质检分流、已上架与已收货未上架数量；为作业进度，不另设库存类型。
- 每次实际落位确认后，正常品、不良品进入对应实际库存，无需等待整张入库单完成；数量口径与流水见[库存与库内需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)。真实丢失的异常账面结转与盘亏按[入库完成与结果](#in-fr-007-入库完成与结果)执行。

#### IN-FR-011 入库单来源

- 一期全部入库单由OMS Mock指令生成，管理端不提供手工新建入口。
- 演示所需资料可预置，入库单仍由Mock指令生成。

#### IN-FR-012 无主货登记

- 记录无主货所在仓库、暂存位置、箱唛／运单等识别线索，实物使用专门位置，不与已识别货主实物混放。
- 登记只保留识别线索与暂存事实，不生成入库单、实收、库存或入库执行结果；WMS不提供认领入口。
- OMS上线后，WMS推送无主货信息供客户在OMS认领并下发入库指令；一期不以Mock代做认领。

#### IN-FR-013 PDA 入库作业

- PDA支持按单号、运单号或箱唛定位任务，完成新品维护（若需）、收货（按容器或按SKU）、追溯采集、质检、扫容器或扫SKU上架及货位校验。
- 与管理端共用业务记录，重复提交不重复增加库存。

#### IN-FR-014 新品维护

- **含义：**对首次进入本WMS仓网、尚未有仓内实测规格的SKU，在该SKU首次收货提交前完成量方称重（长宽高、毛重等），将结果写入该货主商品的**仓内规格**（见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)维护与同步方式）。
- **维护范围：**同一货主 + 商品编码在WMS内首次维护成功后，四仓共用该仓内规格，后续入同一仓网不再重复量方；多仓并发首次维护以先确认提交为准。
- **作业节点：**可在到货登记后、该SKU首次收货提交前执行；需维护且未完成的明细，阻断该SKU在本单的后续收货与上架，直至维护确认完成。
- **与预报关系：**可展示OMS预报尺寸重量供对照；实测以仓库提交为准写入仓内规格，差异可留操作记录，是否回写上游不在一期验证范围。
- **影像留底：**按商品或入库规则，在签收验收前对外箱、标签、破损等拍摄并关联本次到货或收货记录；一期落实关键节点留痕与差异场景可关联原单，完整附件产品与在线沟通不纳入一期。
- 一期量方称重使用手工或模拟数据；DWS／电子秤对接留待后续集成。
- 业务展开与走查见[入库业务设计第3.7节与第8.6节](../../04-业务分析和设计/02-入库业务设计.md#37-新品维护首次到仓量方后再收该-sku)。

#### IN-FR-015 作业容器收货与上架

- **含义：**作业容器指现场一箱、一托或等价装载单元。在选用容器作业时，为容器绑定**作业容器编号**（可扫描货主箱唛／托唛，或由WMS生成），并登记容器类型（箱／托等）及容器内各商品的数量（含批次、效期、SN等按商品配置采集）。用于串联本入库单的清点、待上架与落位，便于现场跟踪。
- **作业方式（可选项）：**每次清点可选择以下一种方式，数量统一计入商品明细实收，不重复记账。
  - **按容器收货：**实收数量登记在作业容器及容器内分SKU明细上；后续可扫容器上架。
  - **按SKU收货（不绑容器）：**直接在商品明细上登记实收，不生成作业容器记录；后续仅支持按SKU（及货位）上架。
  - 一张入库单可混用（例如部分SKU按箱、部分散件按SKU），以现场包装形态为准。各仓**默认收货方式**在[基础资料需求分析](../01-基础资料/基础资料需求分析.md)仓库资料中配置，PDA可按次改选。
- **收货绑定（容器路径）：**一容器可含多条商品，一条商品可拆到多容器。容器归属本入库单货主，同一容器不混记不同货主。收货确认后，容器处于待质检或待上架进度（与商品质检配置一致）。
- **质检与品质：**需检商品在质检分流前，容器内数量视为待检；质检完成后，容器内可上架的正常品、不良品数量分别更新，上架任务按品质推进。免检商品在容器内直接参与可上架数量计算。
- **容器上架：**支持扫描作业容器编号并确认目标货位，将容器内当前可上架数量落位；支持同一容器分次上架到同一或不同货位。与按SKU逐件扫货位上架共用同一套已收未上架数量口径，两种方式不重复增加库存。
- **库存与追溯：**上架完成后，实际库存仍按SKU、货位、品质及追溯维度记录；库内移库、盘点、出库预占不按作业容器编号执行。管理端与PDA可按入库单、作业容器编号查询收货与上架关联；结果回传以SKU汇总为主，是否附带容器明细由应用设计与集成约定。
- 容器编号规则、托与箱的层级展示见第五节应用设计待输入。
- 业务展开与走查见[入库业务设计第3.8节与第8.6节](../../04-业务分析和设计/02-入库业务设计.md#38-作业容器按容器或按-sku数量仍记商品明细)。

## 三、调研诉求处理

依据[入库业务需求调研](入库业务需求调研.md)第四节，处理结论如下。具体规则见**第二节**。

| 诉求 | 处理结论 |
| --- | --- |
| 到货识别、分批收货、差异和分批上架 | 纳入一期，由入库业务记录执行过程与结果 |
| 新品维护、质检与追溯 | 纳入一期，基础资料提供商品配置，入库执行采集与检验 |
| 容器与SKU两种作业方式 | 纳入一期，使用统一商品数量口径 |
| 已收未上架丢失 | 纳入一期，由入库记录事实与确认结果，库存模块记录关联结转和盘亏 |
| 调拨入库 | 纳入一期，共用入库主流程 |
| 无主货、零实收与取消 | 一期保留登记或等待记录，认领与取消由后续OMS承接 |
| 指令变更与结果交接 | 未实收明细变更、进度及结果回传纳入一期，与系统集成协作 |

## 四、关联模块

| 关联模块 | 衔接说明 |

| [系统集成与对接](../06-系统集成与对接/系统集成与对接需求分析.md) | 接收入库指令并回传执行结果；失败只重试结果交接 |
| [基础资料](../01-基础资料/基础资料需求分析.md) | 校验仓库、货主、商品；各仓默认入库收货方式；上架校验货位与货主占用；新品维护回写仓内规格 |
| [库存与库内业务](../04-库存与库内业务/库存与库内业务需求分析.md) | 上架与损失使用统一数量口径；盘点阻断不得绕过 |
| [出库业务](../03-出库业务/出库业务需求分析.md) | 已收货物形成库存后的退回出库、不良品其他出库 |
| [公共能力](../07-公共能力/公共能力需求分析.md) | 管理端与PDA共用记录；动作权限与关键操作留痕 |

## 五、应用设计待输入

- 质检项目、原因明细及入库／回传表单：结合[调研第五节](入库业务需求调研.md#五待补资料与确认清单)样例细化。
- 新品维护：量方字段与单位、是否与OMS预报同屏比对、拍照必填项与附件存储。
- 免检残损登记载体与权限岗位：按质检条目不新增审批流程。
- 作业容器：编号生成规则、箱／托层级、仓库默认收货方式及PDA按次改选的交互、容器上架与上架任务界面关系；与收货记录「容器内容明细」字段对齐（仅容器路径写入）。

**走查与示例（规则已确认，演示待执行）**

- **零实收：**预计10件效期不符全部拒收，实收0；原单待收货，拒收原因可查，不能零实收结案（第二节「入库完成与结果」「取消与变更」）。
- **无主货：**无法确定货主的一箱，登记线索与暂存位置，无入库单与库存；后续OMS上线并完成认领、下发指令后，再按普通入库执行。
- **免检残损：**实收10、残损2，不生成质检任务，正常8／不良2分别上架。文档逻辑走查见[需求分析总览第六节走查记录](../00-项目总览/02-需求分析总览.md#64-文档逻辑走查记录2026-10-08)。

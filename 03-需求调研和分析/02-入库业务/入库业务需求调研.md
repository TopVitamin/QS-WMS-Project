# 入库业务需求调研

> 文档状态：调研初稿（案头整理，课程沙盘）
> 调研范围：正常入库、调拨入库的到仓、收货、品质录入、上架及结果交接；货从仓外退回本仓见[退货业务需求调研](../05-退货业务/退货业务需求调研.md)
> 系统需求与已确认规则见[入库业务需求分析](入库业务需求分析.md)

## 一、调研范围与资料来源

本次调研关注从3PL履约转向自营仓后的入库作业：到仓实物怎样对应指令，实收、品质与上架如何交接，差异由谁记录并反馈上游。环节覆盖指令接收、到货登记、收货清点与品质录入、上架落位、整单完成结果回传；**调拨入库**与正常入库共用现场主链，业务类型不同，不要求与调出仓对账。

| 环节 | 本次关注内容 | 主要交接 |
| --- | --- | --- |
| 指令与到仓 | 入库单生成、随货识别；一次到仓可对应多张入库单（同一货主） | 上游推送指令；仓库登记到仓 |
| 收货与差异 | 按容器或按SKU分次记录实收，区分短少、超收与效期拒收 | 仓库记录；业务端核对预报 |
| 作业容器上架 | 扫容器落位库位，串联收货与上架进度 | 将容器内商品数量对应到本单的收货与上架记录 |
| 新品维护 | 首次到仓 SKU 量方称重（长宽高、毛重），写入仓内商品规格；签收验收前可按规则拍照留底 | 实测规格写入商品资料，需维护的商品完成维护后才能提交首次收货 |
| 收货品质 | 实收内录入良品、不良品，拒收单独记录 | 不设质检任务与质检配置；不同品质分别上架 |
| 上架与库存 | 推荐库位、分次保存、整张上架单提交移库；收货确认先形成暂存库存 | 与基础资料位置、库存模块衔接 |
| 无主货 | 无法确定货主的到货识别与暂存 | 一期只登记；认领与入库单待 OMS 二期 |
| 变更与取消 | 未实收时的明细变更、零实收上游取消及已收货物退回 | 变更与入库取消由 Mock 推送；已收退回由出库业务执行 |
| 结果回传 | 整单完成时的实收、拒收、短少与上架结果；过程进度仓内查询 | WMS 交回 OMS Mock |

**不在本模块调研范围：**派送失败退回、客户退货、平台仓退件（见退货业务调研）；报损／销毁；WMS 自行导入上游入库指令；跨仓调拨主单与在途账（调拨仅作本仓入库指令类型）。

主要依据：

- [公司背景与业务概况](../../01-全局背景信息/00-公司背景与业务概况.md)、[项目定位与范围](../../01-全局背景信息/01-项目定位与范围.md)、[阶段规划与一期交付标准](../../01-全局背景信息/03-阶段规划与一期交付标准.md)
- [需求调研总览](../00-项目总览/01-需求调研总览.md)、[基础资料需求调研](../01-基础资料/基础资料需求调研.md)（货主、商品、库区库位先于或并行入库作业）

尚未取得真实海外仓访谈、现场清点表或生产级入库样单。课程演示使用标明性质的模拟样例。

## 二、现有交接与目标作业分工

### 2.1 立项时的入库交接

立项前海外仓内作业由3PL负责，强盛业务侧安排备货并获取入库和库存结果。现有材料尚未说明服务商提供的是逐次收货、质检、上架明细，还是汇总结果；结果的字段、粒度与交接方式需要样表核实。

这部分资料用于了解转向自营仓后的交接变化。一期演示依据已确认的目标流程准备样例。

### 2.2 租仓自营后的作业分工

| 参与方 | 业务职责 | 需要补充的资料 |
| --- | --- | --- |
| 自营业务侧、外部货主业务侧 | 提供入库要求，对漏单补充指令，对差异给出处理意见 | 指令、补单与差异交接样例；外部货主一期使用模拟资料 |
| 仓储物流 | 组织到货识别、清点、品质录入和上架，记录实际数量、位置与异常 | 各仓岗位分工、PDA操作步骤、品质判断与交接记录 |
| 数字化／项目组 | 建设WMS和OMS Mock，提供指令接收、作业记录与结果交接能力 | 指令与回传字段、可操作的演示样例 |

一期由OMS Mock下发入库指令，仓库通过管理端和PDA执行作业，WMS在整单完成时将执行结果与差异返回Mock，收货和上架过程不回传进度。指令接收依赖已匹配的货主与商品资料，目标库位在上架时校验。无主货认领由后续真实 OMS 承接；入库取消一期由 Mock 演示，边界见需求分析。

## 三、核心场景与业务问题

下表依据目标业务整理。项目方向和规则的确认情况单独列出，业务风险不作为已发生的现场问题。

| 场景 | 业务条件 | 需要解决的问题 | 当前确认情况 |
| --- | --- | --- | --- |
| 到仓对应指令 | 同一货主的一次送货，可能拆在多张入库单上；需用入库单号、运单或箱唛等把实物对到正确单据 | 对单错误会导致记错单或重复登记 | 识别方式已纳入一期；字段习惯待样例 |
| 分批到货与收货 | 一张单可多次到仓、多次清点 | 须区分「仍待收货」与「完结后短少」 | 方向已确认；数字走查见业务设计 |
| 短少、超收与破损 | 实物与预报不一致 | 分别记录差异数量、原因和处理结果 | 已确认；异常区与资料类型见基础资料、分析稿 |
| 新品维护（量方称重） | 商品首次进入本仓库网络时需实测尺寸、重量并做「新品维护」；页面联查新品维护记录，展示哪些 SKU 需要维护；收货前或收货环节可要求对外箱、标签等拍照 | 实测规格与预报的差异如何展示，影像怎样关联本次到货或收货 | 同一货主商品首次维护后四仓共用已确认；量方字段、照片清单和跨仓复用样例待补 |
| 品质与追溯 | 商品配置决定 SN、批次、效期采集；收货时录入良品／不良品 | 采集什么、正常品与不良品如何分流 | 追溯配置在基础资料；收货残损等分支见分析稿 |
| 效期与零实收 | 部分商品收货要校验剩余保质期 | 全部拒收时仍需保留到货与拒收记录 | 准入规则在基础资料与入库分析；零实收通知上游取消，Mock 受理后已取消 |
| 上架前丢失 | 已实收但未上架的实物可能短少 | 区分原实收、现场剩余和损失，说明异常处理后如何完成入库 | 已确认；与库存损失衔接 |
| 分批上架 | 收货与上架可不同步完成 | 进度与库存须分开；货主与品质不混记 | 已确认 |
| 作业容器收货与上架 | 可按容器或按 SKU 清点；容器路径可扫容器上架 | 容器内商品怎样记录，分次落位后怎样核对剩余数量 | 按仓设默认方式、PDA可按次改选已确认；混用与分次上架样例待补 |
| 调拨入库 | 由上游以调拨类入库指令下发，现场链路与正常入库相同 | 不要求调出仓单号关联或对账 | 已确认 |
| 无主货 | 到货实物无法确定货主 | 未知归属只能暂存；已知货主漏单须补推指令 | 一期只登记；认领待 OMS 二期 |
| 变更与取消 | 上游可能改明细或要求取消 | 已实收事实不能删除；入库取消须上游发起，一期 Mock 可演示 | 未实收变更与取消见分析稿与总览 |
| 进度与结果交接 | 业务端需知整单实收、上架及差异结果 | 回传须能对回原指令与明细 | 一期 Mock 回传；字段见集成与应用设计 |

## 四、业务诉求

| 场景 | 业务诉求 | 当前判断 |
| --- | --- | --- |
| 到仓对应指令 | 能识别指令并记录到仓与归属 | 一期核心 |
| 分批到货与收货 | 分次实收，区分待收与完结差异 | 一期核心 |
| 短少、超收与破损 | 差异透明、超收可处理 | 一期核心 |
| 新品维护 | 首次到仓完成量方称重并更新仓内规格；签收验收前按规则拍照留底 | 一期核心；规则见分析稿第二节；拍照范围与附件能力待样例与应用设计确认 |
| 品质与追溯 | 按商品配置采集并分品质 | 一期核心 |
| 效期与零实收 | 效期不符可拒收并留痕；零实收可走上游取消 | 一期核心；全单拒收视同零实收 |
| 上架前丢失 | 保留实收，提交应上架数量后通过盘点核实差异 | 一期使用库存盘点路径，入库内不设损失收口 |
| 分批上架 | 记录位置与数量；上架单保存不动库存、提交移库 | 一期核心 |
| 作业容器收货与上架 | 可选按容器或按 SKU 收货；容器路径可扫容器上架 | 一期核心；容器档案与批次库存维度按现行架构处理，不做箱规换算或自动装载优化 |
| 调拨入库 | 按调拨类指令走同一入库链 | 一期核心 |
| 无主货 | 暂存登记，不直接入账 | 一期登记；认领与入库单待 OMS |
| 变更与取消 | 保留已发生事实；取消有依据 | 一期纳入未实收变更与入库取消（Mock） |
| 进度与结果交接 | 上游获取最终结果，仓内查询过程进度 | 一期由 Mock 演示整单完成回传 |

上表诉求对应的系统规则写在[入库业务需求分析](入库业务需求分析.md)。指令拒收、消息变更见[系统集成与对接需求分析](../06-系统集成与对接/系统集成与对接需求分析.md)；权限与多端一致见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

## 五、待补资料与确认清单

| 资料主题 | 内容与待细化事项 | 用途 |
| --- | --- | --- |
| 现场作业 | PDA收货、品质录入及上架操作步骤和岗位交接样例 | 验证现场操作顺序及记录交接 |
| 差异与异常 | 超收、效期拒收、收货残损、已收未上架丢失的登记与处理样例 | 核对实收、拒收、品质与损失分别如何记录 |
| 新品维护 | 新品维护记录查询、量方字段与单位、预报比对方式、签收前拍照清单及跨仓复用案例 | 细化维护入口、首次收货前校验和影像关联 |
| 商品与品质 | 与基础资料一致的追溯商品配置、良品／不良品和拒收原因 | 验证商品配置、追溯采集和品质分流 |
| 指令与回传 | OMS Mock入库指令、明细变更、零实收取消及整单完成结果样例 | 核对结果能否对应原指令和商品明细 |
| 到仓识别 | 一次到仓多单多箱、已知货主缺单、未知货主三类案例 | 区分正常匹配、补单等待和无主货登记 |
| 作业容器 | 编号扫描与生成、一托多箱、按容器与按SKU混用、分次上架案例 | 核对容器内容、商品实收与落位数量，并细化层级展示 |

先准备一条完整入库链（指令→到仓→新品维护（首次）→收货入暂存→上架提交移库→完成回传）和一条含差异或拒收的案例，再补齐其他分支。演示样例标明课程沙盘性质，覆盖要求见[一期交付标准](../../01-全局背景信息/03-阶段规划与一期交付标准.md#三一期完成的判断标准)。竞品资料保留[原文来源](../../02-竞品调研和分析/00-双边能力对比矩阵.md#四资料入口与证据边界)，具体采用规则以需求分析为准。

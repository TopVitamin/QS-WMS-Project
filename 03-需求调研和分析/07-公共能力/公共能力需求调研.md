# 公共能力需求调研

> 状态：沙盘推演稿。公共能力只收跨模块反复使用且必须统一的要求，不因建立目录便默认引入审批中心或复杂权限产品。目标判断见[分析稿](公共能力需求分析.md)。

## 一、范围与来源

项目[定位与范围](../../01-全局背景信息/02-项目定位与范围.md)确认四仓和多货主共用系统；[能力蓝图](../../01-全局背景信息/03-能力蓝图与系统架构.md)要求考虑时区、现场语言及数据隔离。[业务场景分析](../00-项目总览/强盛WMS竞品与业务场景分析.md)列出跨模块作业风险。无真实组织架构、角色清单或设备清单。

竞品原文线索：领星[初始化页](../../02-竞品调研和分析/领星WMS/01-原始页面/LX-WMS-001_WMS初始化操作.md)把角色、仓库和客户授权分别配置；极风[员工角色与权限](../../02-竞品调研和分析/极风WMS/01-原始页面/JF-BAS-016-员工角色与权限设置.md)也有角色及仓库范围。[极风时区页](../../02-竞品调研和分析/极风WMS/01-原始页面/JF-BAS-011-仓库注册时国际化时区的设置【仓库注册必看】.md)写明注册时选择仓库时区且创建后不可改。强盛应明确跨仓业务时间的展示和记录口径；“创建后不可改”是竞品限制，不自动成为强盛规则。

## 二、沙盘场景与问题

| 编号 | 场景 | 问题 |
| --- | --- | --- |
| COM-S-001 | 货主A与货主B在同一仓作业 | 仓库人员需要查看本仓全部货主业务，同时必须保留每条记录的货主归属，不能跨仓查看。 |
| COM-S-002 | 美西与德国仓跨时区查看交接记录 | 仅显示无时区的时间，容易误判先后。 |
| COM-S-003 | 管理端与PDA都能查看或操作任务 | 谁确认差异、谁完成实物动作必须可追查。 |
| COM-S-004 | PDA作为WMS作业端，打印和称重使用模拟数据 | 管理端与PDA必须共用同一业务结果，模拟数据不能被误解为真实硬件接入。 |

## 三、沙盘目标诉求

| 编号 | 诉求 | 场景 |
| --- | --- | --- |
| COM-R-001 | 一期按仓库授权；有仓库权限即可查看该仓全部货主数据 | COM-S-001 |
| COM-R-002 | 界面支持中文、英文；时间统一以UTC+0存储，可切换展示时区并按所选时区导出；履约时限和效期判断按业务所属仓库当地时区计算 | COM-S-002 |
| COM-R-003 | 差异确认、取消、库存调整等操作留下人员和时间 | COM-S-003 |
| COM-R-004 | 管理端和PDA复用同一业务结果，不产生两套库存 | COM-S-003、COM-S-004 |
| COM-R-005 | 菜单、目录和业务动作通过RBAC角色授权，不按管理员或操作员名称硬编码动作权限 | COM-S-003 |

## 四、待核实

权限、语言和时间口径已经确认。数据范围按仓库授权；拥有仓库权限即可查看该仓全部货主数据。菜单、目录和业务动作由RBAC角色权限控制，不预设固定的管理员／操作员动作清单。履约时限、效期日期等业务判断按业务所属仓库当地时区，以对应业务起始时间加约定时长计算；页面展示时区切换不改变判断结果。后续PRD落实授权配置、中文／英文切换、右上角时区切换和导出时间转换，不再作为需求范围问题。PDA功能已纳入一期，不再把设备方式作为待核实范围。

# 竞品原始手册取舍与证据清单

> 核读日期：2026-09-24。只读本项目留存的领星、极风原始页面，不访问官网。本清单用于回答“哪些原文值得借鉴，哪些不进入强盛一期”。竞品做法不是强盛已确认规则；“不取用”也不等于断言该功能无价值。强盛边界以[项目定位与范围](../../01-全局背景信息/02-项目定位与范围.md)和[需求分析总览](强盛WMS需求分析总览.md)为准。

## 一、核读范围与判断方法

本地原始页共 642 篇（领星 273、极风 369）。本次及前一轮累计逐页打开并核读与四仓、多货主、收存发调有关的 **97 篇**：领星 35 篇、极风 62 篇。另按文件名盘点了全部原始页，未将文件名盘点当作正文核读。部分页面只有标题或图片，见下文“原文不足”。未核读的 545 篇不作具体功能结论。没有据此判断市场份额、价格或效率提升百分比。

取舍按三层进行：先看原文实际写了什么，再看强盛一期有没有对应场景，最后判断它是否会改变库存、责任或系统边界。下面“取用”指提炼业务问题与必要控制点，**不表示照搬竞品状态、页面、配置开关或操作顺序**。

## 二、一期取用：支撑已确认的主链

| 业务点 | 原文能证实的做法 | 强盛一期取用与边界 |
| --- | --- | --- |
| 四仓、多货主资料初始化 | 领星初始化涉及仓库、库区库位、客户、SKU、初始库存和员工权限；极风也将仓库、货区、货位及角色分开设置。[LX-WMS-001][JF-BAS-016][JF-BAS-017] | 取“先有可识别资料再作业”和按仓限制可见范围；一期有仓库权限即可查看该仓全部货主数据，商品、库存和单据仍分别记录货主归属，一个货位只允许一个货主使用。不取领星代理仓、OMS客户开户或极风仓库数量上限。初始化库存是切换场景，是否进入课程一期另列样例。 |
| 库位与实物定位 | 领星库区先于库位创建，库位码创建后不可改，可设拣货推荐优先级；极风区分拣货区、备货区、不良品区。[LX-WMS-012][LX-WMS-014][JF-BAS-017] | 取仓、区、位层级和正品／不良品定位；是否强制拣储分离、库位容量与优先级算法，需要样例，不直接写死。 |
| 到仓、清点、分批收货 | 领星按箱混扫可匹配不同货主与入库单，实收数量可按清点修改，分批收货后继续收；极风可按托批量签收收货。[LX-WMS-022][LX-WMS-031][JF-IN-009][JF-IN-016] | 取“识别到货、按实收记录、保留未收与差异”的问题；强盛无预报到货的管理端认领是项目自身一期目标，不由竞品退件认领推导。 |
| 收货与上架分账 | 领星收货未上架不形成产品库存，部分上架仅对应部分形成库存；极风收货时可预选、上架时改选货位。[LX-WMS-031][LX-WMS-032][JF-IN-003] | 取待上架与在库分开、实放货位后增加可用；不把极风“预选货位”写成预锁容量。 |
| 库存维度、流水与盘点 | 领星支持按商品、库位及关联单据看库存流水；极风可按仓、客户、商品、货位查，并提供纸质任务盘点和PDA盘点。[LX-WMS-036][JF-INV-023][JF-INV-014][JF-PDA-008] | 取货主＋仓＋SKU＋库位＋批次＋SN＋品质状态的查询、数量流水和盘点差异处理；强盛盘点采用“先允许已开始任务完成，再生成快照并冻结”的项目规则，不能从极风原文推出盲盘或动态循环盘点。 |
| 出库单预占与现场短拣 | 领星可设置库存锁定／分配策略；极风区分进单先占货位与先锁仓总量、生成波次后占货位，PDA可标记具体缺货商品。[LX-WMS-044][JF-OUT-007][JF-PDA-005] | 强盛按货主＋SKU总可用预占；B2C包裹整仓缺货时不部分发货、不更换商品，取消前持续锁定已预占库存。取“锁定、实拣、回库与释放必须衔接”的控制点，不照搬竞品分配策略。 |
| 出库类型与交接 | 领星包裹出库有拣货、复核、异常、截单回库；备货中转有箱托明细与交接附件；极风 B2B 有按商品／箱拣货与扫描出库。[LX-WMS-055][LX-WMS-049][JF-PDA-021] | 取包裹履约、平台仓转运、当地 B2B 和调拨出库共用库存动作但分别记录复核单位与交接凭据；不取换标、平台仓签收、货主端结算。调拨出库不与调拨入库建立WMS内跨仓关联。 |
| 出库末端再校验 | 极风扫描发货会提示已取消或已发货包裹，并在发货确认时扣库存；领星可扫描出库单／跟踪号核对后确认。[JF-PDA-003][JF-OUT-031][LX-WMS-021] | 取“确认出库前二次识别，防取消后误发和重复发”的业务要求；强盛统一以仓库执行“确认出库”为完成与扣库节点，不要求承运商已经揽收，不取“打印面单即发货”的竞品可选设置。 |
| 调拨处理 | 极风跨仓调拨说明调出出库后原仓减、目的仓收货入库后增加。[JF-INV-004] | 强盛不取其跨仓单据链：调出按出库、调入按入库分别执行，WMS不维护两端关联和途中差异。 |

## 三、条件取用：真实，但一期不能无条件复制

| 原文线索 | 使用条件与强盛判断 |
| --- | --- |
| 领星箱库存可通过“库存转换”变为产品库存，按入库时箱内SKU数量计算并生成流水；极风也写明B2B箱库存转一件代发库存。[LX-WMS-041][JF-INV-021] | 一期不启用箱库存、不设托盘库存；箱、托只作为作业容器并记录所含SKU及数量。竞品转换路径留作后续扩展参考。[LX-WMS-002]所说退货库存是另一库存类型。 |
| 领星库位可分存储区／拣货区，拣货区不足时订单进入待移库；极风备货区可移到拣货区，也可配置从备货区出库。[LX-WMS-026][JF-FAQ-OUT-006][JF-INV-018] | 如果四仓确有前置拣货位、补货频繁，应设计补货建议与移货任务；当前缺平面图、SKU动销和货位容量样本，先保留基本移库和短拣处理。不写“备货区一律不能发”。 |
| 两家都有波次、边拣边分或先拣后分；领星波次按勾选生成有单波上限（页面示例为500／1000单），规则需要手动触发；极风可设置智能自动分波。[LX-WMS-019][LX-WMS-052][LX-WMS-055][LX-WMS-054][JF-OUT-017][JF-OUT-022] | 一期仅B2C包裹可选择基础波次，且同一波次不跨仓、不跨货主；B2B按单摘果拣货。不取人员派工、自动产能调度和“单次1000单”等产能宣传，具体B2C分拣动作在出库PRD中设计。[JF-OUT-020] |
| 领星、极风都可按SKU配置序列号采集；领星包裹复核对SN商品禁用自动批量复核。[LX-WMS-039][JF-BAS-013][LX-WMS-047] | SN按商品配置启用，入库采集并形成SN库存，移库、盘点、拣货和出库保留SN轨迹；具体唯一性与状态在PRD中设计。 |
| 领星、极风均有批次／效期管理；极风入库可记录生产／过期日期，出库会推荐临期批次。[LX-WMS-043][JF-INV-007] | 批次和效期纳入一期，按商品配置启用；启用后入库记录批次及日期，库存可按批次查询，出库按效期优先规则推荐。 |
| 领星称重与极风扫描称重均能记录出库重量，部分配置会在称重或打印后自动出库。[LX-WMS-051][JF-OUT-005][JF-OUT-031] | 取包裹实重的记录和异常复核问题。是否接电子秤、实重作为何种凭据需设备与交接样本；一期不照搬自动出库。 |
| 极风截单可按状态决定能否取消及是否人工审核；领星也有截单回库。[JF-OUT-030][LX-WMS-055] | 取“已拣取消必须实物回库后再释放预占”的问题；上游有权取消到哪个节点、谁审核，属于强盛自身接口与责任设计。 |

## 四、一期不取用与证据不足

| 项目 | 判断与依据 |
| --- | --- |
| 代理仓、卖家 OMS、仓租和计费 | 强盛一期四仓自营／共享实体仓作业，OMS货主端与商业计费已在范围外。领星初始化页的代理仓和客户结算币种、极风计费模板不能移进一期。[LX-WMS-001][JF-BAS-017] |
| 客户退货入库、换标、FBA逆向与跨境直邮 | 两家手册有对应流程，但强盛一期边界未纳入；“无预报货物认领”只借鉴隔离与追溯问题，不复制竞品的退件公有认领池。已收货物按后续指令退回仓外的退回出库属于一期异常处理，不等同于客户退货入库。[LX-WMS-030][JF-IN-013] |
| 把竞品“转运”当作强盛调拨链 | [LX-WMS-046]讲的是快进快出／交叉转运；强盛一期也不建设跨仓调拨链，只分别处理调拨出库和调拨入库。 |
| 爆款抽样一键验货 | 极风允许先验一个包裹后批量通过，前提是特定爆款波次；这会改变强盛每包复核责任，一期不直接采用。[JF-OUT-015][JF-OUT-037] |
| 预选货位预锁、动态盲盘、绝对禁止备货区发货 | 这些说法在已核读原文没有得到相应支持，或有相反的配置路径。[JF-IN-003][JF-INV-014][JF-PDA-008][JF-FAQ-OUT-006] |
| 图片为主的短页 | 极风“扫描上架按箱批量添加货架”本地正文只有标题；“PDA签收”仅给入口；不能据此推导校验规则、库存生效或异常处理。[JF-IN-007][JF-PDA-011] |

## 五、原始页纠偏与下一步补证

1. 领星二次整理曾把“箱库存转产品库存”写成未见；[LX-WMS-041]原文明确有此功能，必须修正本项目分析。这里与[LX-WMS-002]所说“**退货库存**不能一键转产品库存”不是同一库存类型。
2. 极风二次整理称“预选上架位即预锁”及“存货位不能出库”；前者原文没有，后者被[JF-FAQ-OUT-006]的备货区出库配置否定为绝对规则。
3. 极风[JF-OUT-034]标题写“边拣边分”，正文开头却描述先汇总拣货后二次分拣；具体路径应以[JF-OUT-022]的设置分类和现场样例交叉核对，不据该短页单独定流程。
4. 需补强盛沙盘原始样例：四仓各自库区／货位与时区、两家货主商品及箱规、按商品配置的免检／质检样例、批次效期商品、单品与多品出库单结构、B2C基础波次、B2B按单拣货、短拣与已拣取消。箱库存和跨仓调拨链不作为一期样例。

本清单与[竞品与业务场景分析](强盛WMS竞品与业务场景分析.md)共同作为模块调研稿的输入。页面编号链接均指向用户留存的本地原始文件；编号之外的原始页，本清单不作已核读声明。

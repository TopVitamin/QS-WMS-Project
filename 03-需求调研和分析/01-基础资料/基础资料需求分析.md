# 基础资料需求分析

> 本文维护基础资料模块的一期范围与功能规则。业务场景见[基础资料需求调研](基础资料需求调研.md)。

## 一、分析结论与模块边界

基础资料为香港、美西、美东、德国四仓提供货主、商品、仓库、库区、货位和物流渠道六类对象，供入库、出库和库存引用。商品按货主独立建档，自营与外部品牌使用同一套能力。

货主与商品身份由上游提供，仓内资料和作业配置由WMS维护，具体接收与更新规则见第二节。

本模块不维护供应商、客户档案、采购价、销售价及供货关系，也不建立箱库存或托盘库存资料。一期不做货位容量、体积、承重与占用率管理，不提供批量文件导入、不验证真实跨系统资料同步协议；货主自助维护由二期OMS承接。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| MD-FR-001 | 货主资料 | 接收货主资料，预置自营货主并保留上游标识 |
| MD-FR-002 | 商品资料 | 按货主建档，配置形态、质检、SN、批次和效期 |
| MD-FR-003 | 仓库资料 | 预置四仓及其时区，一期无业务侧新增入口 |
| MD-FR-004 | 库区与货位资料 | 维护库区货位及类型，同一货位同一时点不混放不同货主实物 |
| MD-FR-005 | 形态适配 | 按商品形态推荐适配位置，不做容量硬性阻断 |
| MD-FR-006 | 停用校验 | 有实物或未完结业务时拒绝停用，历史记录保留 |
| MD-FR-007 | 变更留痕 | 保留变更与历史快照，追溯开关受库存及作业限制 |
| MD-FR-008 | 数据权限 | 按仓库授权访问，维护须有动作权限 |
| MD-FR-009 | 维护与同步方式 | 上游推送身份资料，WMS维护自有资料及仓内属性 |
| MD-FR-010 | 物流渠道资料 | 维护最小承运商与渠道资料，供模拟交接使用 |
| MD-FR-011 | 分节点准入 | 接收指令校验仓库、货主、商品，具体作业再验货位 |

#### MD-FR-001 货主资料

- 字段含货主编码、名称、类型（自营／外部）、状态（启用／停用）、联系人等。
- 自营货主系统预置，不可删除；外部货主由OMS Mock推送，WMS接收并保留上游标识。
- 已停用货主不得作为新业务指令的货主引用；停用条件见[停用校验](#md-fr-006-停用校验)。

#### MD-FR-002 商品资料

- 每个货主独立建商品档案，包含商品编码、名称、规格、计量单位、形态、状态，以及带电、SN、批次、效期、是否质检和质检流程配置。同货主商品编码唯一，不同货主可使用相同编码，档案不共用。
- **匹配键：**业务匹配使用「货主编码 + 商品编码」，与上游推送身份一致；更新与冲突处理见[维护与同步方式](#md-fr-009-维护与同步方式)。
- **效期配置：**效期商品维护保质期、允许入库天数、临期天数、过期天数；须满足允许入库天数≥临期天数≥过期天数（可相等），否则拒绝保存。剩余保质期按有效期与所属仓库当地业务日期计算（见公共能力时间规则）。具体阈值按商品样例，不默认过期天数为0。
- **效期执行：**收货是否准入、在库临期／过期等级及出库是否可用，分别由[入库业务](../02-入库业务/入库业务需求分析.md)和[库存与库内业务](../04-库存与库内业务/库存与库内业务需求分析.md)执行；本模块维护配置与保存校验。
- **追溯与质检：**启用SN的商品按SN管理库存；启用批次／效期的商品在作业中采集批次、生产日期和有效期。是否质检及质检流程由商品配置决定，检验项目在应用设计中细化。
- **带电：**一期在资料中表达，不单独触发仓内校验规则。
- 已停用商品不得作为新业务指令的SKU引用；停用条件见[停用校验](#md-fr-006-停用校验)。

#### MD-FR-003 仓库资料

- 预置香港、美西、美东、德国四仓；含仓库编码、名称、时区等展示属性。
- 各仓可配置**默认入库收货方式**（按作业容器收货，或按SKU收货且不绑容器）；现场PDA收货可在该默认值基础上按次改选。规则与混用边界见[入库业务需求分析](../02-入库业务/入库业务需求分析.md)作业容器条；选项展示见应用设计。
- 时间存储、展示和导出口径见公共能力需求分析中的语言与时间规则。
- 一期不提供业务侧新增仓库。

#### MD-FR-004 库区与货位资料

- 按仓库维护库区与货位；货位字段含货位编码、所属库区、状态（启用／停用）。库区编码、货位编码均在同一仓库内唯一；跨仓可出现相同货位编码文本，以仓库与货位共同定位。
- 库区类型一期为存储、拣货、暂存、不良隔离、异常处理；无主货暂存、超收暂存等位置的使用场景见[入库业务需求分析](../02-入库业务/入库业务需求分析.md)。
- 一个货位同一时点只能存放一个货主的实物，可存放该货主多个SKU；已有该货主实物（含已确认出库待交接实物）、入库过程数量或未完结任务占用时，其他货主不得使用该货位。
- 库区停用不自动批量停用下属货位；申请库区停用时，若下属任一货位存在上述占用则拒绝。库区合法停用后不得新建下属货位，且不得把新的首次落位或推荐默认指向该库区下仍启用的货位。已有实物或任务的货位、库区不得通过改资料变更所属仓库或库区归属，须先移库或收口后停用旧位。业务展开见[基础资料业务设计](../../../04-业务分析和设计/01-基础资料业务设计.md)第五节与第七节。

#### MD-FR-005 形态适配

大件、异形商品按形态限定推荐库区／货位类型，上架推荐避开不适配货位；人工可改位，不做容量类硬性阻断。

#### MD-FR-006 停用校验

- 商品、货主、货位停用前校验当前实际库存、已确认出库待交接实物、入库过程数量和未完结业务（预占、盘点锁定等）；存在实物或未完结业务时拒绝停用，并提示对应数量或单据。
- 仅有历史流水且当前实物和任务均已清零时，可停用，历史记录保留。
- 不提供物理删除入口；已被业务引用的资料只能停用，历史单据与流水保持可追溯。

#### MD-FR-007 变更留痕

- 商品名称、形态、SN方式等关键字段变更保留记录；业务单据引用资料快照，资料变更不回溯改写历史单据。
- SN、批次、效期管理开关在该货主商品任一仓库有实际库存时禁止切换，包含正常品、不良品、锁定以及已拣未出库数量，须先清空库存。
- 实际库存为0但入库单已开始作业时也禁止切换（含已收货未上架）；禁止原因应能定位到数量或正在作业的单据。
- 仅有已推送、尚未开始作业且无库存的预报单，不因此阻断开关切换。
- 各仓库存清零且无正在作业的入库单后才可切换；历史单据、批次和SN轨迹保留。

#### MD-FR-008 数据权限

资料访问受仓库授权范围约束，维护操作还须具备相应动作权限。有某仓访问权限即可查看该仓全部货主数据，一期不设置货主级用户授权；资料仍按货主分别记录。具体规则见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

#### MD-FR-009 维护与同步方式

- 一期由OMS Mock推送货主、商品；WMS保留上游标识并用于单据匹配。仓库、库区、货位、物流渠道由管理端维护或系统预置。
- WMS可补充商品仓内执行属性（含经入库新品维护写入的仓内规格：长宽高、毛重等），不得静默改写上游身份（货主编码、货主内商品编码等）。
- 同一身份再次推送时按集成约定更新可变更字段；身份冲突或无法匹配时拒收并记录原因，不另建一套商品身份，消息处理见[系统集成与对接需求分析](../06-系统集成与对接/系统集成与对接需求分析.md)。

#### MD-FR-010 物流渠道资料

维护承运商与物流渠道最小资料（名称、渠道类型、状态），供出库交接和承运商Mock引用；出库单如何必选或引用渠道见出库分析。一期不接真实承运商生产服务。
- 渠道停用关闭后续引用；存在未完结出库或交接仍引用该渠道时拒绝停用，历史保留渠道快照。业务展开见[基础资料业务设计](../../../04-业务分析和设计/01-基础资料业务设计.md)第七节。

#### MD-FR-011 分节点准入

- 业务指令进入WMS时校验仓库、货主、商品存在且为启用状态；入库上架时再校验目标货位及货主占用，出库拣货时再校验来源货位与货主。
- 资料缺失、已停用或货位已被其他货主占用时，按节点记录拒收或作业异常；不因入库预报尚未指定货位而拒绝接收有效指令。

## 三、调研诉求处理

调研诉求均纳入一期，具体规则见第二节，分工如下。

| 诉求 | 处理结论 |
| --- | --- |
| 多货主建档、位置管理、资料变更 | 由本模块处理归属、维护和变更校验 |
| 指令与资料匹配 | 本模块提供资料匹配与准入规则，系统集成负责消息拒收和原因反馈 |
| 商品属性与作业 | 本模块维护配置，入库、出库和库存业务按配置执行 |
| 物流渠道 | 本模块维护档案，出库业务负责引用和交接 |
| 四仓共用框架 | 本模块提供各仓资料，演示覆盖按一期交付标准安排 |

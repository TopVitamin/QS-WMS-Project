# 基础资料需求分析

> 本稿说明一期范围与系统需求。业务背景见[调研稿](基础资料需求调研.md)。

## 一、分析结论

基础资料为四仓、自营与外部货主提供货主、商品、仓库、库区、货位和物流渠道六类资料。商品按货主独立建档，自营使用同一套能力。货主、商品身份由OMS Mock推送；WMS维护仓内执行属性及自有位置资料，供入库、出库和库存业务引用。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| MD-FR-001 | 货主资料 | 接收货主资料，预置自营货主并保留上游标识 |
| MD-FR-002 | 商品资料 | 按货主建档，配置形态、质检、SN、批次和效期 |
| MD-FR-003 | 仓库资料 | 预置四仓及其时区，一期无业务侧新增入口 |
| MD-FR-004 | 库区与货位资料 | 维护库区货位及类型，同一货位只归一个货主使用 |
| MD-FR-005 | 形态适配 | 按商品形态推荐适配位置，不做容量硬性阻断 |
| MD-FR-006 | 停用校验 | 有实物或未完结业务时拒绝停用，历史记录保留 |
| MD-FR-007 | 变更留痕 | 保留变更与历史快照，追溯开关受库存及作业限制 |
| MD-FR-008 | 数据权限 | 按授权仓库查看资料，货主归属分别记录 |
| MD-FR-009 | 维护与同步方式 | 上游推送身份资料，WMS维护自有资料及仓内属性 |
| MD-FR-010 | 物流渠道资料 | 维护最小承运商与渠道资料，供模拟交接使用 |
| MD-FR-011 | 分节点准入 | 接收指令校验仓库、货主、商品，具体作业再验货位 |

### 资料对象

#### MD-FR-001 货主资料

- 字段含货主编码、名称、类型（自营／外部）、状态（启用／停用）、联系人等。
- 自营货主系统预置，不可删除；外部货主由OMS Mock推送，WMS接收并保留上游标识。
- 资料停用按MD-FR-006校验。

#### MD-FR-002 商品资料

- 每个货主独立建商品档案，包含商品编码、名称、规格、计量单位、形态、状态，以及带电、SN、批次、效期、是否质检和质检流程配置。同货主商品编码唯一，不同货主可使用相同编码，档案不共用。
- 效期商品维护保质期、允许入库天数、临期天数、过期天数，剩余保质期按有效期与仓库当地业务日期计算。三个天数须满足允许入库天数≥临期天数≥过期天数，可以相等；不满足时拒绝保存并提示顺序要求。数值按商品样例确定，不默认过期天数为0。
- 收货只按允许入库天数判断：剩余保质期小于时拒收、大于或等于时允许。临期标记不另设收货限制。
- 低于临期天数进入临期，低于过期天数进入过期，过期判定优先；品质与效期等级分开维护。在库临期正品可以出库，不设置最短出库剩余效期阻断。
- 启用SN的商品跟踪SN库存；启用批次／效期的商品在入库和库存记录批次、生产日期和有效期。是否质检及质检流程由商品配置决定，检验项目在应用设计中细化。

#### MD-FR-003 仓库资料

- 预置香港、美西、美东、德国四仓；含仓库编码、名称、时区等展示属性。
- 时间存储、展示和导出口径见COM-FR-002。
- 一期不提供业务侧新增仓库。

#### MD-FR-004 库区与货位资料

- 按仓库维护库区与货位；货位字段含货位编码、所属库区、状态（启用／停用）。
- 库区类型一期为存储、拣货、暂存、不良隔离、异常处理。
- 一个货位同一时点只能存放一个货主的实物，可以存放该货主的多个SKU；已有某货主实物（含报损后仍留仓的非库存实物）、入库过程数量或未完结任务时，其他货主不得使用该货位。
- 无法识别货主的到货使用专门待认领位置，不与已识别货主实物混放。
- 异常处理区用于暂存超收等尚未形成库存的实物。
- 只管理位置、类型和货主隔离，不管理货位容量、体积、承重和占用率。

#### MD-FR-005 形态适配

大件、异形商品按形态限定推荐库区／货位类型，上架推荐避开不适配货位；人工可改位，不做容量类硬性阻断。

#### MD-FR-010 物流渠道资料

维护承运商与物流渠道最小资料（名称、渠道类型、状态），供出库交接和承运商Mock引用；一期不接真实承运商生产服务。

### 维护、变更与业务准入

#### MD-FR-009 维护与同步方式

- 一期由OMS Mock模拟上游推送货主、商品等业务基础资料，WMS保留上游资料标识并用于单据匹配；仓库、库区、货位和物流渠道等WMS自有资料由管理端维护并可系统预置。
- WMS可补充商品的仓内执行属性，但不得静默改写OMS Mock提供的身份标识。
- 批量文件导入和真实跨系统同步协议不属于一期验证范围。

#### MD-FR-006 停用校验

- 商品、货主、货位停用前校验当前实际库存、非库存暂存实物、入库过程数量和未完结业务（预占、盘点锁定等）；存在实物或未完结业务时拒绝停用，并提示对应数量或单据。
- 仅有历史流水且当前实物和任务均已清零时，可停用但历史记录保留。
- 不提供物理删除入口；已被业务引用的资料只能停用，历史单据与流水保持可追溯。

#### MD-FR-007 变更留痕

- 商品名称、形态、SN方式等关键字段变更保留记录；业务单据引用资料快照，资料变更不回溯改写历史单据。
- SN、批次、效期管理开关在该货主商品任一仓库有实际库存时禁止切换，包含正常品、不良品、锁定以及已拣未出库数量，必须先清空库存。
- 实际库存为0但入库单已开始作业时也禁止切换，包括已收货但尚未上架的数量；禁止原因应能定位到数量或正在作业的单据。
- 单纯已推送、尚未开始作业且无库存的预报单不因此阻断。
- 该商品各仓库存清零且无正在作业的入库单时才可切换；历史单据、批次和SN轨迹保留。

#### MD-FR-011 分节点准入

- OMS Mock业务指令进入WMS时校验仓库、货主、商品；入库上架时再校验目标货位及货主占用，出库拣货时再校验来源货位与货主。
- 资料缺失或货位已被其他货主占用时记录拒收或作业异常，不因为入库预报尚无货位而拒绝接收有效指令。

#### MD-FR-008 数据权限

- 一期按仓库授权；用户拥有某仓库权限后，可以查看该仓全部货主的资料。
- 商品、库存和单据仍按货主记录归属，不因用户可见多个货主而合并数据。
- 具体规则由[公共能力需求分析](../07-公共能力/公共能力需求分析.md)维护。

## 三、范围取舍与模块依赖

一期不包含：商品与供应商供货关系、价格资料；货位容量、体积和承重；货主自助维护（OMS，二期）；真实跨系统资料同步协议；批量文件导入；箱库存资料。

| 依赖模块 | 依赖能力与使用约束 |
| --- | --- |
| COM | 用户按授权仓库访问资料；已授权仓内可见全部货主，维护动作仍须对应角色权限 |
| INT | 接收OMS Mock资料并匹配上游标识；匹配失败记录原因，不静默创建另一套商品身份 |
| IN／OUT／INV | 引用资料身份并按节点校验：指令缺仓库／货主／商品时拒收，上架或拣货所需货位无效时阻断该动作 |

## 四、应用设计输入与资料缺口

- 商品、仓库和货位样例用于细化字段及校验；具体效期数值和检验项目不预设统一值。

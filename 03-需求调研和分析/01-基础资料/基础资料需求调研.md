# 基础资料需求调研

> 本稿依据课程沙盘资料整理，尚未取得真实海外仓访谈、服务商系统截图或生产级主数据样表。已确认的功能规则见[基础资料需求分析](基础资料需求分析.md)。

## 一、调研范围与资料来源

本次关注货主、商品、仓库、库区、货位和物流渠道六类资料：由谁提供和维护，怎样对应业务指令，以及仓内作业需要读取哪些信息。

| 资料对象 | 关注内容 | 主要使用业务 |
| --- | --- | --- |
| 货主 | 自营与外部品牌的业务归属、上游标识 | 单据和库存归属、业务指令匹配 |
| 商品 | 商品身份，以及形态、带电、质检、SN、批次和效期等作业属性 | 收货、质检、上架、库存追溯与出库 |
| 仓库 | 仓库身份、时区 | 按仓接单、作业及业务日期判断 |
| 库区、货位 | 位置划分、货主隔离、商品形态适配 | 上架、移库、拣货和盘点 |
| 物流渠道 | 承运商与渠道资料 | 出库交接、承运商Mock引用 |

公司与仓网现状、业务规模见[公司背景](../../01-全局背景信息/00-公司背景与业务概况.md)，一期边界见[项目定位与范围](../../01-全局背景信息/01-项目定位与范围.md)。项目共性资料缺口见[需求调研总览](../00-项目总览/01-需求调研总览.md)，本模块需要的样例列在第五节。供应商、价格、客户档案和集团库存协同不在本次调研范围。

## 二、现有资料交接与目标维护分工

### 2.1 立项时的资料交接

强盛的海外本地履约由第三方海外仓承担，仓内实物与作业由服务商管理。跨境与渠道业务侧安排备货和履约，并获取仓库执行结果；货主、商品、位置及批次资料具体如何维护、匹配和交接，尚缺服务商样表与交接样例。

需要了解的现有交接包括：双方如何对应商品编码，强盛能获取哪些位置或批次信息，以及库存与履约结果如何返回。这些资料用于说明从第三方仓转向自营仓时的交接变化，不能仅凭缺少样表判断强盛没有相关资料或维护入口。

### 2.2 租仓自营后的维护分工

| 参与方 | 资料职责 |
| --- | --- |
| 自营业务侧、外部货主业务侧 | 提供货主与商品身份资料，使入出库指令能够匹配对应货物 |
| 强盛仓储运营方 | 维护仓内位置、物流渠道和商品作业配置，供收货、上架、拣货等业务使用 |
| 数字化／项目组 | 建设资料接收与维护能力，准备一期预置资料和推送样例 |

一期由OMS Mock模拟上游资料推送，WMS预置四仓和自营货主，并提供仓内资料维护入口。外部货主使用模拟资料，先验证不同货主的商品能否正确接收、匹配和引用；真实货主的字段习惯与接入要求，在二期OMS设计时明确。

业务ERP是目标协作方，建设状态尚未明确。自营业务未来直连ERP还是经OMS接入，见[系统职责边界](../../01-全局背景信息/01-项目定位与范围.md#三系统职责边界)。仓储侧还需提供各仓位置规划与资料维护岗位样例，以便细化管理端的维护操作。

## 三、核心场景与业务问题

以下场景依据已确认的项目方向整理，其中的风险为目标业务推演，并非现场事故记录。表中区分已确认结论与仍需补充的样例，具体规则由需求分析维护。

| 场景 | 业务条件与问题 | 当前确认情况 |
| --- | --- | --- |
| 多货主同仓 | 自营与外部品牌将共用仓库，不同货主可能使用相同商品编码，需要分清商品、单据和实物归属 | 按货主建档已确认；需用同编码、不同货主的样例验证匹配和展示 |
| 指令与资料匹配 | 入出库指令引用上游货主、商品，缺资料或身份冲突会影响接单；入库预报可能尚未指定货位 | 身份匹配与分节点准入规则已确认；需补正常、缺资料和冲突推送样例 |
| 位置资料与现场 | 目标四仓尚未确定布局，库区货位需要对应现场位置，大件／异形商品还需适配存放区域 | 同一货位同一时点不混放不同货主已确认；位置区划与编码待样例 |
| 商品属性与作业 | 商品的追溯、质检及存放要求不同，作业时需要读取对应配置 | 配置方向已确认；效期阈值、质检项目和不同商品属性组合待样例 |
| 资料变更与在库 | 商品改名、属性调整或停用，可能影响已有库存、未完结作业及历史查询 | 变更留痕、停用及追溯开关限制已确认；需用有库存、作业中和清零后的案例检查结果 |
| 物流渠道 | 出库需要引用承运商与渠道，以便记录货物交给谁、通过什么渠道发出 | 一期维护基本档案、使用承运商Mock；渠道样例需与出库场景配套 |
| 四仓共用框架 | 各仓位置和时区不同，资料既要支持按仓作业，也要使用共同功能 | 四仓预置已确认；按一期交付标准安排样例，不要求每仓重复全部异常案例 |

## 四、业务诉求

| 场景 | 业务诉求 |
| --- | --- |
| 多货主同仓 | 按货主区分商品，自营与外部货主使用共同能力 |
| 指令与资料匹配 | 保留上游标识，能反馈缺失或不匹配的资料 |
| 位置资料与现场 | 统一维护位置，同一时点不混放不同货主的实物 |
| 商品属性与作业 | 配置商品的仓内作业要求，供各作业环节读取 |
| 资料变更与在库 | 变更、停用前检查库存和未完结作业的影响，保留历史记录 |
| 物流渠道 | 提供出库模拟交接所需的基本档案 |
| 四仓共用框架 | 按仓查看和维护资料，支持四仓演示 |

## 五、待补资料

| 资料 | 需要包含的内容 | 用途 |
| --- | --- | --- |
| 库区与货位样例 | 各仓位置布局、编码、大件／异形推荐存放位置，以及维护岗位分工 | 将位置类型落实到可操作的仓库样例，检查货主隔离和形态推荐 |
| 商品与质检样例 | 至少两货主的多品类商品，覆盖带电、SN、批次效期、需检／免检；提供效期阈值和检验项目 | 配置商品作业要求，验证不同商品进入收货、质检和库存环节后的处理差异 |
| 上游推送样例 | 货主、商品资料及关联指令，包含正常接收、重复推送更新、缺资料和身份冲突案例 | 检查资料与指令能否匹配，以及更新、拒收结果是否清楚 |
| 资料变更案例 | 有库存、入库作业中、库存与作业均清零时的变更和停用样例 | 验证操作允许或拒绝的条件，并检查历史记录是否保留 |
| 物流渠道样例 | 与出库案例配套的承运商、渠道及模拟交接信息 | 检查渠道资料能否被出库单正确引用 |

可先准备两货主商品、一个仓的位置和一套推送样例开展走查，再补齐[一期交付标准](../../01-全局背景信息/03-阶段规划与一期交付标准.md#三一期完成的判断标准)要求的覆盖。演示样例标明课程沙盘性质。

3PL交接资料用于补充现状背景，不作为一期演示的前置条件。若采用竞品样例，保留[原文来源](../../02-竞品调研和分析/00-双边能力对比矩阵.md#四资料入口与证据边界)，与本项目规则的取舍分开说明。

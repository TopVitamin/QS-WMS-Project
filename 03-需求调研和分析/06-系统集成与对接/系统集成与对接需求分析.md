# 系统集成与对接需求分析

> 本稿说明一期范围与系统需求。
> 业务背景与场景见[系统集成与对接需求调研](系统集成与对接需求调研.md)。

## 一、分析结论与模块边界

目标协作中，外部货主经OMS交接资料、指令与执行结果；强盛自营业务ERP直连WMS或经OMS接入，路径尚未确定，见[系统职责边界](../../01-全局背景信息/01-项目定位与范围.md#三系统职责边界)。一期用 OMS Mock 模拟上游、承运商 Mock 提供模拟运单与交接数据，覆盖接收、拒收、重复消息、明细变更、出库取消及回传失败重试；无主货面向 OMS 客户认领与入库取消待真实 OMS 上线。调拨出库与调拨入库分别发送和回传，WMS 不做两端匹配、在途或差异结案。

**职责范围**

- 上游资料与业务消息的接收、原始留痕、拒收原因反馈、幂等与变更／取消消息的识别与路由。
- 仓内已有业务结果的向上游交接；回传失败时的重试交接，不重复触发收货、上架、预占或扣库。
- 一期外部协作模拟边界：OMS Mock、承运商 Mock、打印与称重模拟或手工数据；演示范围明示。

**不在本模块**

- 入库、出库、库存模块内的作业规则、状态机与数量口径（由各域分析稿规定）；本模块负责传递输入与结果，并在边界上表达拒收或交接结论。
- 基础资料字段定义与仓内维护规则（见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)）；匹配失败时的拒收与原因展示在本模块与资料准入衔接。
- 真实 ERP、OMS、承运商生产接口、鉴权、消息中间件选型及吞吐与可靠性方案；不在本稿指定 REST、MQ 或数据库实现。
- 跨仓调拨主单、在途账、两端差异结案；箱库存或物流轨迹经营。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| INT-FR-001 | OMS Mock 输入 | 先推送基础资料，再发送完整业务表单并保留原始输入 |
| INT-FR-002 | 拒收可见 | 资料非法、盘点阻断或 B2C 不足时拒收并返回原因 |
| INT-FR-003 | 幂等与业务对象识别 | 区分业务对象与消息，合法变更可处理，重发只生效一次 |
| INT-FR-006 | 变更与取消消息 | 一期按节点处理明细变更和出库取消；入库取消待 OMS 上线 |
| INT-FR-004 | 结果交接 | 回传已有结果，失败只重试交接，不重做仓内动作 |
| INT-FR-005 | 外部服务模拟 | 明确 OMS、承运商、打印及称重模拟范围 |

### 输入与消息处理

#### INT-FR-001 OMS Mock 输入

- OMS Mock 先发送货主、商品等基础资料，再按入库单、出库单、退回出库单和不良品其他出库单的完整表单字段发送业务指令。
- 业务指令至少覆盖来源、业务类型、上游指令号、货主、仓库、业务对象、明细 SKU 与数量，以及该业务表单已经定义的其他字段；演示样例尽量填满，不只发送最小建单字段。
- 调拨出库与调拨入库分别按出库、入库所需字段发送，不要求两端共用调拨号。
- 消息接收后保留原始输入与接收时间，业务单据引用各自的上游指令号。

#### INT-FR-002 拒收可见

- 货主缺失、商品无法匹配、仓库不在一期范围、数量非法等情况不得生成可执行单据；记录拒收原因，OMS Mock 侧可查。
- 业务准入也可能拒收：新出库请求被盘点或差异校准前限制阻断，或 B2C 任一 SKU 无法足量预占时，整单拒收并交回明确原因，不创建可执行单或待受理单，也不留下部分订单占用。类型规则见[出库业务需求分析](../03-出库业务/出库业务需求分析.md)第二节「库存校验与预占」。
- 已有效接收后的短拣或缺货属于执行异常；日常 B2B 等允许部分预占的普通类型可接收并保留缺货，与指令格式错误、接单准入失败分别表达。

#### INT-FR-003 幂等与业务对象识别

- 「来源＋业务类型＋上游指令号」用于定位同一上游业务对象，不等于每次消息都只能有相同内容。
- 新建、合法变更和取消是针对该对象的不同消息；消息标识用于判重，对象版本用于顺序校验；具体定义已在[接口与OMS Mock消息设计](../../05-应用设计方案/20261002-MVP版本/系统架构设计/06-接口与OMS Mock消息设计.md#二消息身份版本与处理顺序)中定义，样例与联调按该设计核对。
- 同一消息同内容重发返回已有结果，不重复建单、预占或执行库存动作；同一消息标识携带不同内容时记录冲突，不静默覆盖。
- 合法变更和取消按 INT-FR-006 的节点校验处理，不能仅因与原新建内容不同就判为冲突。
- 真实接口的协议与唯一键在后续集成设计中确认。

#### INT-FR-006 变更与取消消息

- 一期 OMS Mock 模拟新建、明细变更及出库取消；无主货认领与入库取消不纳入一期 Mock 功能。
- 仓库、货主和业务类型等身份字段不得在原单变更。按各域允许的取消节点，由上游取消后重新下发；入库取消须待 OMS 上线。
- 入库单未实收时可接受明细变更，产生实收后拒绝。出库单未开始拣货时可接受明细变更或取消，变更须原子重算预占；开始拣货后拒绝明细变更，取消按是否已拣和是否已确认出库处理。
- OMS 上线后，入库取消由 OMS 发起，WMS 只接受尚无实收的原单取消；零实收不能由 WMS 直接完成或关闭。
- 一期支持的请求按节点向 OMS Mock 返回结论和原因，不由 WMS 自行假设上游决定。

### 结果交接与外部模拟

#### INT-FR-004 结果交接

- 一期回传已有入出库执行结果及其关联差异、盘亏等处理记录；独立的库存查询、盘点或品质转换结果不作为单独库存消息回传，独立库存回传留待后续。仓内库存记录与流水仍按原规则维护。

- 入库回传收货、质检、实际落位和差异结果；真实丢失分支交回原实收、现场剩余、损失及异常账面结转与盘亏记录，出库回传需求、预占、实发、未发量、整单完结和确认出库结果；支持缺量的类型只回传一次出库结案，不保留原单续发；调拨出库、调拨入库分别回传各自结果，不在 WMS 内生成两端差异。
- 邮件来源手工其他出库在 WMS 可查，保留线下来源，不伪造上游指令；其他入库／出库结果按原指令交接。
- 无主货一期只在 WMS 登记、查询；OMS 上线后将信息推送给所有 OMS 客户查看，由 OMS 认领并下发入库指令，不新增 WMS 手工认领或手工入库消息。
- 已拣丢失后取消的结果分别回传原实拣、实际返库、损失、关联盘亏与占用释放及取消完成结论，不把损失量记为返库或实发；解除差异限制不自动重放被拒请求。
- 回传失败记录失败原因与待重试状态；重试只发送已有业务结果，不重复触发收货、上架或扣库。

#### INT-FR-005 外部服务模拟

- OMS Mock 提供出库指令及已有物流信息，承运商 Mock 补充模拟运单与交接信息；打印和称重使用模拟或手工数据。
- PDA 扫码属于 WMS 内部功能，不标为外部模拟。
- 演示不宣称已购买真实面单、完成真实交运或获得物流轨迹。

## 三、调研诉求处理

依据[系统集成与对接需求调研](系统集成与对接需求调研.md)第三、四节，**调研所列场景均纳入一期**；规则见**第二节**。下列为须在本模块落实或跨模块分工的处理结论。

| 主题 | 处理结论 |
| --- | --- |
| 资料先于指令、完整表单推送 | 本模块落实；资料匹配规则见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)，本模块反馈接收或拒收结论 |
| 重试同一消息、变更与取消 | 本模块落实幂等与节点路由；仓内节点准入由入出库模块规定 |
| 拒收可见（含盘点阻断、B2C 不足） | 本模块返回原因；盘点阻断与预占规则由[出库业务需求分析](../03-出库业务/出库业务需求分析.md)、[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)规定 |
| 回传失败重试、进度与结案回传 | 本模块负责交回已有结果及失败重试；回传内容与各域「结果」条一致，不在此重复字段 |
| 邮件来源其他出库 | 本模块保留来源区分；单据创建与执行见[出库业务需求分析](../03-出库业务/出库业务需求分析.md)不良品其他出库 |
| 运单、面单、重量模拟 | 本模块界定模拟范围；履约展示与时间规则见[公共能力需求分析](../07-公共能力/公共能力需求分析.md) |
| 无主货认领、入库取消 | 不纳入一期 Mock；登记与查询见入库分析，取消待 OMS 上线 |
| 真实生产接口与中间件 | 不纳入一期 |

## 四、范围取舍与模块依赖

一期不包含项与[调研第一节「不在本模块调研范围」](系统集成与对接需求调研.md#一调研范围与资料来源)及[项目定位「一期不做什么」](../../01-全局背景信息/01-项目定位与范围.md)一致，此处不重复罗列。

| 关联模块 | 衔接说明 |
| --- | --- |
| [基础资料](../01-基础资料/基础资料需求分析.md) | 接收 OMS Mock 资料推送；指令进入时校验货主、商品、仓库等，匹配失败拒收并记录原因 |
| [入库业务](../02-入库业务/入库业务需求分析.md) | 接收入库类指令并路由建单；回传收货、质检、上架与差异；未实收变更与入库取消边界与各域一致 |
| [出库业务](../03-出库业务/出库业务需求分析.md) | 接收出库类指令及变更、取消；回传预占、实发、结案与交接；准入拒收与执行缺货分别表达 |
| [库存与库内业务](../04-库存与库内业务/库存与库内业务需求分析.md) | 回传与重试不重复触发库存生效；盘点阻断导致的接单拒收与库存范围一致 |
| [公共能力](../07-公共能力/公共能力需求分析.md) | 关键操作留痕；打印、称重与履约时间展示使用一期模拟或统一规则 |

OMS Mock 与承运商 Mock 的界面、内置收发台及回传展示由应用设计确定。

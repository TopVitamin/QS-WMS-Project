# 出库业务需求分析

> 本稿说明一期范围与系统需求。
> 业务背景与场景见[出库业务需求调研](出库业务需求调研.md)。

## 一、分析结论与模块边界

本模块覆盖[项目定位](../../01-全局背景信息/01-项目定位与范围.md)所列六类出库：接单预占 → 拣货（含 B2C 基础波次）→ 复核 → 确认出库 → 结果回传。完成与扣库以仓库**确认出库**为准，不以承运商揽收为前提；调拨不关联调入仓单据。现状与证据缺口见[调研稿](出库业务需求调研.md)；管理端与 PDA 共用记录。

**职责范围**

- 出库指令准入、预占、拣货分配、复核打包、确认出库、缺货／短拣、取消回库及结果表达在本模块记录；数量扣减与流水口径见[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)。
- 出库指令与结果回传经[系统集成与对接需求分析](../06-系统集成与对接/系统集成与对接需求分析.md)；货主、商品、物流渠道资格见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)。
- 已收正常品退回仓外走本模块退回出库；不良品移出走其他出库。

**不在本模块**

- 客户退货接收与重新入库；报损／销毁及报损后非库存暂存跟踪；仓外运输、运单跟踪与渠道订单经营。
- 跨仓调拨主单、在途账与两端差异对账；人员派工、自动波次、产能调度与大促方案。
- 真实承运商面单、打印机与电子秤接入（一期使用 Mock 或手工数据）。
- 箱库存或托盘库存；作业容器仅作出库过程记录，不形成在库箱托维度。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| OUT-FR-001 | 出库指令接收 | 先校验资料、盘点阻断及类型准入，再接收并预占 |
| OUT-FR-002 | 库存校验与预占 | B2C 足量预占才接收；其他普通类型按可用量预占 |
| OUT-FR-003 | 拣货任务 | 按单或波次锁定建议货位，按配置扫描追溯信息 |
| OUT-FR-004 | 拣货校验与换位 | 错扫阻断；货位无货可换位，整仓缺货留异常 |
| OUT-FR-005 | 复核打包 | 包裹复核 SKU 及数量，箱／托只记录作业容器 |
| OUT-FR-006 | 确认出库 | 按类型判断足量或缺量资格，确认后扣库并结案 |
| OUT-FR-007 | 出库结果 | 需求、实发、未发及交接结果分别可查、可回传 |
| OUT-FR-008 | 取消与变更 | 未拣可变更或取消；已拣取消先回库，已出库拒绝 |
| OUT-FR-009 | 缺货处理 | 缺货与短拣有明确处理结果；已接单补货后由仓库人工重试，不静默改量 |
| OUT-FR-010 | 多货主归属与仓库权限 | 货主分别扣库，用户只访问已授权仓库 |
| OUT-FR-011 | 库存影响 | 预占、扣减、释放与流水引用库存模块 |
| OUT-FR-012 | 基础波次 | 同仓同货主 B2C 可手工成波，非 B2C 按单拣货 |
| OUT-FR-013 | 退回出库 | 先保留原入库事实并形成库存，再独立退回出库 |
| OUT-FR-014 | 不良品其他出库 | 支持上游或邮件依据手工创建，直接处置不良品 |
| OUT-FR-015 | 出库单来源 | 普通出库由 OMS Mock 生成；其他出库可 Mock 或管理端手工 |
| OUT-FR-016 | PDA 出库作业 | PDA 执行拣货与复核等现场动作，与管理端共用记录 |

### 出库类型差异

| 出库类型 | 接单或占用方式 | 确认出库的数量条件 |
| --- | --- | --- |
| B2C包裹履约 | 所有SKU足量预占才接收；任一不足整单拒收，不保留本次请求占用 | 每项明细足量 |
| 平台仓转运、当地B2B批发 | 按需求与可用库存的较小值预占，不足部分保留为缺货 | 允许缺量，至少一项明细实发大于0，一次确认整单完结 |
| 调拨出库、退回出库 | 按需求与可用库存的较小值预占，不足部分保留为缺货 | 每项明细足量 |
| 不良品其他出库 | 核对并占用指定在库不良品 | 指定数量足量 |

接单时允许部分预占，不代表确认时允许缺量出库。各类型均须通过资料、盘点及相应作业校验。

#### OUT-FR-001 出库指令接收

- OMS Mock 推送 B2C 包裹履约、平台仓转运、B2B、调拨出库和退回出库指令，含货主、仓库、SKU 与数量、收货或交接信息。先校验资料、盘点阻断和本类型预占要求，满足准入后生成可执行出库单并完成预占；失败返回拒收原因，不留下该请求的部分占用。
- B2C 包裹出库单复核打包后交承运商；平台仓转运和 B2B 按件并辅以箱／托容器记录；调拨出库按普通出库执行，不与调入仓记录关联；退回出库引用原入库单和退回原因。

#### OUT-FR-002 库存校验与预占

- 普通出库在所属仓库内按货主＋SKU 预占总可用，接单阶段不锁定货位、不跨仓借量；不良品其他出库按 OUT-FR-014 处理指定实物。
- 新出库请求命中盘点阻断时整单拒收，不预占、不生成可执行单或待受理单。盘点结束后由上游重提，不自动受理原拒收请求。
- 各类型的接单数量要求见[出库类型差异](#出库类型差异)。
- 示例：B2C 需求 5、可用 3 时整单拒收、不占这 3 件；日常 B2B 同样数据可接收，需求 5、预占 3、缺货 2 分别保留。
- 示例：美西仓该货主 SKU 实际库存 10、已预占 3、可用 7；新出库单需 5 后，预占变为 8、可用变为 2、实际库存仍为 10，美东仓库存不参与计算。

#### OUT-FR-003 拣货任务

- 按出库单或波次生成拣货任务，列出并锁定建议货位、批次和数量；普通出库的效期商品排除过期或不良品批次，从未过期的正品中优先推荐有效期更早且可用的批次；临期正品允许参与推荐与出库，不设置最短出库剩余效期阻断，引用 INV-FR-011。
- PDA 扫描货位、SKU、批次及配置要求的 SN 确认拣货。
- 订单级预占仍按仓库＋货主＋SKU 记录，货位锁定只表示当前拣货分配。

#### OUT-FR-004 拣货校验与换位

- 扫描货位、SKU、批次或 SN 不匹配时阻断并提示。
- 建议货位无货时，作业人员上报货位缺货；系统释放原货位锁定，重新推荐并锁定其他有货货位，SKU 级预占总量不变。
- 若存储区和拣货区都无可拣库存，记录并上报整仓缺货异常；已有效接收的 B2C 等待补货后按 OUT-FR-009 人工恢复，或由 OMS Mock 取消；其他允许缺量出库的类型按 OUT-FR-009 收口。
- 取消后关闭异常并按实物环节释放对应预占。
- 实拣少于应拣时记录短拣数量，不允许静默按实拣完成。
- 已拣未确认出库数量仍属于实际库存并保持预占，其作业位置由拣货任务或暂存位置记录。

#### OUT-FR-005 复核打包

- B2C 包裹履约类出库单在确认出库前复核 SKU、批次、SN 和数量，登记包裹件数与模拟重量；复核差异阻断确认出库。
- 平台仓转运、B2B、调拨出库和退回出库可记录箱／托容器及其所含 SKU 数量。

#### OUT-FR-006 确认出库

- 所有出库类型均由仓库执行“确认出库”。
- 确认时可记录承运商 Mock、司机、客户自提等交接对象与凭证，但承运商尚未揽收也不阻止仓库确认。
- 数量须满足[出库类型差异](#出库类型差异)中的确认条件；不满足时拒绝确认，不扣库或完结。零实发单继续等待补货或异常处理，也可接受合法取消。
- 平台仓转运、B2B缺量结案前，已拣未发部分须先回库核对，原订单占用继续保留。确认时按实发扣减实际库存与对应预占，同时释放全部未发部分的订单及货位占用；一次确认即整单完结，原单不续发、不残留该单占用。
- 符合本类型足量或缺量条件并确认后，出库单置“已出库”。

#### OUT-FR-007 出库结果

- 需求、实发、未发数量、短拣、确认出库及交接信息可查询。上游指令生成的单据沿原来源回传OMS Mock；手工其他出库保留可查询结果及线下依据。
- 允许缺量的单据以“已完结且有未发量”表达结果，不把未发量改写为已发；后续需继续发货时由上游另发新单。

#### OUT-FR-008 取消与变更

- 尚未开始拣货且未确认出库时，可以接受取消并释放预占，也可以接受明细变更；需求与预占重新计算后一同更新，失败保留原单和原预占。
- 仓库、货主和业务类型等身份字段不得在原单上变更，须在允许取消时取消原单并重新下发。
- 已开始拣货后拒绝明细变更；未确认出库时仍可接受取消。取消按数量分段处理：未拣部分直接释放，已拣部分核对实物并回库后释放；回库不增加实际库存，其他订单或品质锁定仍保留。
- 模拟例：本单预占5件，已拣3件、未拣2件。取消时先释放未拣2件，回库核对后再释放已拣3件；本单共释放5件，实际库存不变。
- 确认出库后不允许取消或变更；后续撤销请求走上游其他业务，不回写已出库事实。

#### OUT-FR-009 缺货处理

- 单据分别记录需求、预占、实发、未发及缺货／短拣；建议货位无货先按 OUT-FR-004 换位，整仓无货上报异常。
- 五类普通出库的已接收缺货单，补货后由有权限的仓库人员人工重试预占与分配，库存增加本身不恢复；只补当前合法缺口，不重复占用。原拒收请求由上游重提，不良品其他出库仍核对指定实物。
- 缺货单按[确认出库](#out-fr-006-确认出库)判断完成资格；不满足时继续处理缺货或接受合法取消，保留原需求与差异。
- 分支条件、恢复节点与数量走查见[出库业务设计](../../04-业务分析和设计/03-出库业务设计.md#101-已接收缺货单人工恢复)及该文第九节（走查待执行，见[需求分析总览](../00-项目总览/02-需求分析总览.md#62-走查状态规则已确认)）。

#### OUT-FR-010 多货主归属与仓库权限

出库单、拣货与交接记录带货主维度并分别扣减对应货主库存；用户拥有仓库权限后可查看该仓全部货主出库数据，不能查看未授权仓库；具体操作还须具备相应动作权限，规则见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

#### OUT-FR-011 库存影响

预占、扣减、释放及流水的数量口径见[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)。

#### OUT-FR-012 基础波次

- B2C 包裹可选择按单拣货或进入基础波次。
- 管理端可从同一仓库、同一货主且处于可拣状态的 B2C 出库单中手工创建波次，系统生成波次拣货任务并汇总展示进度。
- 波次完成后各出库单仍分别复核、确认出库和回传结果。
- 平台仓转运、B2B、调拨、退回等非 B2C 类型按单摘果拣货，不进入波次。
- 具体分拣动作在应用设计中落实。

#### OUT-FR-013 退回出库

- 原入库单已经产生实收且上游要求退回时，不允许取消或冲销原入库记录。
- 货物必须先按商品配置完成必要的质检、上架并形成实际库存，再由 OMS Mock 发送独立退回出库指令；指令引用原入库单、货主、仓库、SKU、数量和退回原因，并分别保留原入库与退回出库记录。
- WMS 按普通出库完成预占、拣货、复核、确认出库和扣库。
- 未计入实收的暂存实物按线下安排处理，不生成WMS退回出库单。已实收但未上架的货物仍按上述入库步骤处理后退回。
- 不良品及过期转成的不良品实际移出仓库时通过 OUT-FR-014 其他出库处理；真实盘点差异按 INV-FR-006 核对调整。不纳入本条正常品退回，不将其改成正常品或释放为普通可用；未过期临期正品可以按本条退回。

#### OUT-FR-014 不良品其他出库

- 其他出库可由上游通知，一期用 OMS Mock 下发；也可在线下邮件通知仓库后，由有权限的仓库用户在 WMS 管理端手工创建。
- 两种来源都记录货主、仓库、SKU、品质、货位、批次／SN、通知来源、处置数量和原因；上游生成记录保留上游指令号，手工记录保留邮件等线下依据，不伪造上游指令号，也不建设自动收发邮件功能。
- 该路径允许选择实际在库的不良品，按单记录对应处置占用关系，不套用 OUT-FR-002 只从正常可用量预占的限制；已有品质锁定继续保留，锁定合计按不重复实物计量，同一实物不能同时给其他处置单或任务使用。
- 仓库核对指定实物、品质、批次／SN 和数量，确认出库后扣减对应实际库存及品质锁定、处置占用并生成流水，剩余不良品仍全量锁定、可用为 0；取消未执行的处置占用时保留品质锁定，不能将不良品恢复为普通可用。
- 该路径不先转换成正常品，不走正常品退回出库；核对指定在库实物后按实发扣减，同一实物不重复出库。
- 指定实物须足量确认；结果交接按[出库结果](#out-fr-007-出库结果)处理。

#### OUT-FR-015 出库单来源

- 五类普通出库单由 OMS Mock 指令生成，管理端不提供手工新建入口（退回出库亦由 Mock 下发并引用原入库）。
- 不良品其他出库可由 OMS Mock 下发，或由管理端在 OUT-FR-014 规则下手工创建。
- 演示基础资料可预置，出库单按上述来源生成。

#### OUT-FR-016 PDA 出库作业

- PDA 支持按出库单或波次拣货任务执行扫描拣货、按类型完成复核相关现场动作，并在授权下参与确认出库与交接登记（具体菜单与动作权限见公共能力与应用设计）。
- 与管理端共用业务记录与库存占用；重复提交不重复增加实发、不重复扣减库存。业务后果见《出库业务设计》第四节与第七节。

#### 履约时间

履约 48 小时起算、计时口径与展示规则以 [COM-FR-002](../07-公共能力/公共能力需求分析.md#com-fr-002-语言存储时间与业务时区) 为准；超时后仓库组织者跟进，上游决定后续处理，WMS 不自动取消或强制缺量。

## 三、调研诉求处理

[调研稿](出库业务需求调研.md)所列业务诉求纳入一期，具体规则见第二节。跨模块分工如下。

| 主题 | 处理结论 |
| --- | --- |
| 指令拒收、明细变更、出库取消与结果回传 | 出库模块判断是否允许接收、变更或取消；系统集成负责消息接收、去重和结果交接 |
| 可用量、预占、扣减、盘点阻断 | 出库模块确定占用、释放和扣减的业务时点；库存模块维护数量口径、流水和盘点限制 |
| 履约起算、截止展示与超时 | 由[公共能力需求分析](../07-公共能力/公共能力需求分析.md) 规定；超时不改变本模块拣发与确认资格 |
| 自动波次、派工、产能 | 不纳入一期 |

## 四、关联模块

| 关联模块 | 衔接说明 |
| --- | --- |
| [系统集成与对接](../06-系统集成与对接/系统集成与对接需求分析.md) | 接收 OMS Mock 出库指令及取消、变更消息；返回准入或执行结果；重发和结果回传不重复预占、扣库 |
| [基础资料](../01-基础资料/基础资料需求分析.md) | 接单校验仓库、货主、商品与物流渠道；拣货再校验货位和追溯信息 |
| [库存与库内业务](../04-库存与库内业务/库存与库内业务需求分析.md) | 读取可用量及盘点阻断范围，执行预占、货位分配、释放和扣减 |
| [公共能力](../07-公共能力/公共能力需求分析.md) | 仓库数据权限、动作授权及履约时间规则；交接、打印和重量使用一期模拟数据 |
| [入库业务](../02-入库业务/入库业务需求分析.md) | 退回出库引用原入库事实；已收未上架货物须先完成入库链再退回 |

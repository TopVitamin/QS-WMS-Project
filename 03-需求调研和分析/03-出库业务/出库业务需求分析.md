# 出库业务需求分析

> 本稿说明一期范围与系统需求。
> 业务背景与场景见[出库业务需求调研](出库业务需求调研.md)。

## 一、分析结论与模块边界

本模块覆盖[项目定位](../../01-全局背景信息/01-项目定位与范围.md)所列六类出库：接单预占 → 拣货（含 B2C 基础波次）→ 复核 → 确认出库 → 结果回传。完成与扣库以仓库**确认出库**为准，不以承运商揽收为前提；调拨不关联调入仓单据。对象、状态与系统交互见[出库模块宏观系统架构](../../01-全局背景信息/05-出库模块宏观系统架构.md)；现状与证据缺口见[调研稿](出库业务需求调研.md)；管理端与 PDA 共用记录。

**职责范围**

- 出库指令准入、预占、拣货分配、复核、确认出库、缺货／短拣、取消、退拣与返库上架及结果表达在本模块记录；数量扣减与流水口径见[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)。
- 出库指令与结果回传经[系统集成与对接需求分析](../06-系统集成与对接/系统集成与对接需求分析.md)；货主、商品、物流渠道资格见[基础资料需求分析](../01-基础资料/基础资料需求分析.md)。
- 已收正常品退回仓外走本模块退回出库；不良品移出走其他出库。

**不在本模块**

- 货从仓外退回本仓由[退货业务需求分析](../05-退货业务/退货业务需求分析.md)承接；本模块为派送失败建单提供原 B2C 出库单、运单与复核 SN 只读引用。报损／销毁及报损后非库存暂存跟踪；仓外运输、运单跟踪与渠道订单经营。
- 跨仓调拨主单、在途账与两端差异对账；人员派工、自动波次、产能调度与大促方案。
- 真实承运商面单、打印机与电子秤接入（一期使用 Mock 或手工数据）。
- 箱库存或托盘库存；作业容器仅作出库过程记录，不形成在库箱托维度。
- 独立的出库异常单据：货位缺货与短拣记在拣货任务上，退拣原因记在返库上架单上，账实差异由库存与库内盘点核实。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| OUT-FR-001 | 出库指令接收 | 先校验资料及类型准入，再接收并预占 |
| OUT-FR-002 | 库存校验与预占 | 按 SKU 库存的可用预占，暂存库位上的正常品也算；B2C 足量才接收，其他普通类型按可用部分预占 |
| OUT-FR-003 | 拣货任务 | 按单或波次分配库位并计入已分配，B2C 整单能分配足才生成；实拣可多次保存，整单提交时移到出库暂存库位 |
| OUT-FR-004 | 拣货校验与换位 | 错扫阻断；货位缺货自动换位，换不到记短拣 |
| OUT-FR-005 | 复核 | 六类都要复核，可随分拣或打包装箱；箱／托只作记录 |
| OUT-FR-006 | 确认出库 | 按类型判断足量或缺量资格，确认后扣库并结案 |
| OUT-FR-007 | 出库结果 | 需求、实发、未发及交接结果分别可查、可回传 |
| OUT-FR-008 | 取消与变更 | 生成拣货任务前可变更或取消；之后只受理取消，已拣自动退拣；已出库拒绝 |
| OUT-FR-009 | 缺货处理 | 缺货与短拣有明确处理结果；补货后由仓库人工重新分配，不静默改量 |
| OUT-FR-010 | 多货主归属与仓库权限 | 货主分别扣库，用户只访问已授权仓库 |
| OUT-FR-011 | 库存影响 | 预占、移库、扣减、释放与流水引用库存模块 |
| OUT-FR-012 | 基础波次 | 同仓同货主 B2C 可手工成波，非 B2C 按单拣货 |
| OUT-FR-013 | 退回出库 | 保留原入库事实，独立退回出库；货还在收货暂存库位的上架后才能拣货 |
| OUT-FR-014 | 不良品其他出库 | 支持上游或邮件依据手工创建，直接处置不良品 |
| OUT-FR-015 | 出库单来源 | 普通出库由 OMS Mock 生成；其他出库可 Mock 或管理端手工 |
| OUT-FR-016 | PDA 出库作业 | PDA 执行拣货、复核与返库上架等现场动作，与管理端共用记录 |
| OUT-FR-017 | 退拣与返库上架 | 取消时自动退拣，复核发现残损或少件时人工退拣；返库上架单规则同入库上架单 |

### 出库类型差异

| 出库类型 | 接单或占用方式 | 确认出库的数量条件 |
| --- | --- | --- |
| B2C包裹履约 | 所有SKU足量预占才接收；任一不足整单拒收，不保留本次请求占用 | 每项明细足量 |
| 平台仓转运、当地B2B批发 | 按需求与可用的较小值预占，不足部分保留为缺货 | 库存不足时允许缺量，至少一项明细实发大于0，一次确认整单完结 |
| 调拨出库、退回出库 | 按需求与可用的较小值预占，不足部分保留为缺货 | 每项明细足量 |
| 不良品其他出库 | 核对并指定在库不良品，计入这些库存明细的已分配 | 指定数量足量 |

接单时允许部分预占，不代表确认时允许缺量出库。各类型均须通过资料、盘点及相应作业校验。

#### OUT-FR-001 出库指令接收

- OMS Mock 推送 B2C 包裹履约、平台仓转运、B2B、调拨出库和退回出库指令，含货主、仓库、SKU 与数量、收货或交接信息。先校验资料和本类型预占要求，满足准入后生成可执行出库单并完成预占；失败返回拒收原因，不留下该请求的部分占用。
- 物流渠道与所属承运商均须启用，任一停用则拒收新单，新增交接引用同样校验；已有事实和历史快照保留。
- B2C 包裹复核打包后交承运商；平台仓转运和 B2B 按件复核，并按需记录箱／托容器；调拨出库按普通出库执行，不与调入仓记录关联；退回出库引用原入库单和退回原因。

#### OUT-FR-002 库存校验与预占

- 普通出库在所属仓库内按货主＋SKU 预占 **SKU 库存的可用**（正常品实际－订单占用），收货暂存、出库暂存库位上的正常品也算，不良品不算。接单阶段不锁定库位、不跨仓借量；货还在暂存的，接单后要等上架或返库上架才能分配、拣货（见 OUT-FR-003）。不良品其他出库按 OUT-FR-014 处理指定实物。
- 含盘点中 SKU 的出库请求照常接收并预占，不因盘点拒收；盘点完成前这张出库单只能取消，不能分配、组波、拣货、复核、确认出库或重新分配（见[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md) INV-FR-006）。
- 各类型的接单数量要求见[出库类型差异](#出库类型差异)。
- 示例：B2C 需求 5、可用 3 时整单拒收、不占这 3 件；日常 B2B 同样数据可接收，需求 5、预占 3、缺货 2 分别保留。
- 示例：美西仓该货主 SKU 在存储库位上正常品 10、收货暂存库位上正常品 4，已有订单占用 3，可用 11；新出库单需 5 后，订单占用变为 8、可用变为 6，实际库存仍为 14，美东仓库存不参与计算。这时能分配的只有存储库位上的 10 件，收货暂存的 4 件上架后才能分配。

#### OUT-FR-003 拣货任务

- 仓库组织者对待拣货的出库单生成拣货任务（按单或按波次，见 OUT-FR-012），系统在本单预占范围内分配库位、批次和数量，计入库存明细的已分配。只分存储、拣货库位上未被分配的正常品，收货暂存、出库暂存库位上的货要等上架或返库上架后再分；B2C 只有本单预占能全部分配到才生成拣货任务，分不全的留在待拣货；其他普通出库可以先拣分到的部分，剩下的按 OUT-FR-009 重新分配补拣。普通出库的效期商品排除过期或不良品批次，从未过期的正品中优先推荐有效期更早且可用的批次；临期正品允许参与推荐与出库，不设置最短出库剩余效期阻断，引用 INV-FR-011。
- 拣货任务分应拣明细与实拣明细：应拣由系统分配，拣货人员不能修改；实拣由 PDA 扫描库位、SKU、批次及配置要求的 SN 填写，可多次保存，保存不动库存。
- 每条应拣行拣足或已上报缺货后整单提交，按实拣一次性把库存从来源库位移到出库暂存库位，仍计实际库存并保持本单预占，来源库位上的已分配随之清掉。出库暂存库位每仓配置，与收货暂存库位分开，允许多货主混放，不参与出库分配。
- 生成拣货任务即视为出库单开始拣货。订单级预占仍记在 SKU 库存上，库存明细的已分配只表示当前拣货分配。

#### OUT-FR-004 拣货校验与换位

- 扫描库位、SKU、批次或 SN 不匹配时阻断并提示。
- 库位实物少于应拣（含发现残损不能拣）时，拣货人员在该应拣行上报缺货数量和原因；系统释放该行未拣部分的已分配，在本仓同货主的其他存储、拣货库位重新分配并追加应拣行，SKU 级预占总量不变。
- 存储区和拣货区都分配不到时，未拣部分在任务提交时记为该行短拣。短拣不改需求、不释放预占，按 OUT-FR-009 处理；不允许静默按实拣完成。
- 缺货上报与短拣留在拣货任务上，不另建出库异常单据；原库位的账实差异由拣货人员提交任务后对该 SKU 发起盘点，残损件由库存与库内做品质转换。
- 不良品其他出库按指定实物执行，不换位。

#### OUT-FR-005 复核

- 六类出库都要复核：按原单逐件核对 SKU、批次、SN 和数量，复核差异阻断确认出库。复核不单设工序，可以和分拣放在一起（如 B2C 波次按原单分拣时逐件扫描），也可以和打包装箱放在一起；结果记为复核记录，汇总数量对不能代替逐单核对。
- B2C 按包裹登记包裹号与模拟重量，并取承运商 Mock 模拟运单号；平台仓转运按箱／托记录所含各 SKU 数量；B2B、调拨出库、退回出库和不良品其他出库按件或按箱托核对，不用容器时容器为空。
- 复核发现已拣实物残损或少件时，由复核人员退拣该部分（OUT-FR-017）；残损件先由仓库主管核实转不良再退拣。本单预占保留，可重新分配补拣。已拣实物不做过期转换，照常复核、发出。
- 复核不动库存，确认出库前复核记录可删除重做；箱／托只作记录，不形成箱托库存。

#### OUT-FR-006 确认出库

- 所有出库类型均由仓库执行“确认出库”。
- 确认时可记录承运商 Mock、司机、客户自提等交接对象与凭证，也可确认后补登，补登不再扣库；承运商尚未揽收不阻止仓库确认。
- 实发取各行已复核数量，已拣的须全部复核后才能确认，并满足[出库类型差异](#出库类型差异)中的确认条件；不满足时拒绝确认，不扣库或完结。缺量只因库存不足（接单缺货或拣货短拣），已拣到的货不能少发，装车放不下等交接安排不算缺量。零实发单继续等待补货，也可接受合法取消。普通出库只能发正常品，复核发现残损的须先退拣；已拣实物不做过期转换，照常发出。
- 确认时按实发扣减出库暂存库位的实际库存与本单预占，同时释放本单剩余预占和库位分配。平台仓转运、B2B 缺量时一次确认即整单完结，原单不续发、不残留该单占用。
- 符合本类型足量或缺量条件并确认后，出库单置“已出库”。

#### OUT-FR-007 出库结果

- 需求、实发、未发数量、确认出库及交接信息可查询；缺货上报与短拣可在拣货任务追溯。上游指令生成的单据在出库单已出库时沿原来源回传 OMS Mock 一次，拣货、复核过程不回传进度；手工其他出库保留可查询结果及线下依据。
- 允许缺量的单据以“已完结且有未发量”表达结果，不把未发量改写为已发；后续需继续发货时由上游另发新单。

#### OUT-FR-008 取消与变更

- 生成拣货任务前（出库单待拣货），可以接受取消并释放预占，也可以接受明细变更；需求与预占重新计算后一同更新，B2C 仍须足量，失败保留原单和原预占。
- 仓库、货主和业务类型等身份字段不得在原单上变更，须在允许取消时取消原单并重新下发。
- 生成拣货任务后拒绝明细变更；确认出库前仍可接受取消。受理取消即转已取消，本单预占与库位分配一次释放：未提交的拣货任务关闭（波次任务只扣减本单份额），已拿出的实物放回原库位，不动库存；已进入出库暂存库位的实物自动退拣，经返库上架单回到存储、拣货库位后才能再被分配。释放不改变实际库存，其他订单的占用仍保留。
- 模拟例：本单预占 5 件，拣货任务已提交、3 件在出库暂存库位，另 2 件短拣待补。受理取消后出库单已取消，预占 5 一次释放，3 件自动退拣并生成返库上架单；实际库存始终不变，3 件返库上架前算可用、可被新单预占，但不能分配。
- 已拣后丢失或残损的，一期不在出库单上单独收口，按 OUT-FR-017 退拣处理。
- 确认出库后不允许取消或变更；后续撤销请求走上游其他业务，不回写已出库事实。

#### OUT-FR-009 缺货处理

- 单据分别记录需求、预占、已拣、实发和未发；缺货＝需求－预占，短拣记在拣货任务应拣行上；库位缺货先按 OUT-FR-004 换位。
- 五类普通出库的已接收缺货单或短拣单，补货或货上架后由有权限的仓库人员人工“重新分配”：先补预占缺口，已开始拣货的再为待拣数量分配库位并生成补拣任务；库存增加或上架本身不恢复，只补当前合法缺口，不重复占用。原拒收请求由上游重提；不良品其他出库按指定实物执行，不重新分配。
- 缺货单按[确认出库](#out-fr-006-确认出库)判断完成资格；不满足时继续处理缺货或接受合法取消，保留原需求与差异。
- 分支条件、恢复节点与数量走查见[出库业务设计](../../04-业务分析和设计/03-出库业务设计.md#74-已接收缺货单人工恢复)及该文第九节（走查待执行，见[需求分析总览](../00-项目总览/02-需求分析总览.md#62-走查状态规则已确认)）。

#### OUT-FR-010 多货主归属与仓库权限

出库单、拣货与交接记录带货主维度并分别扣减对应货主库存；用户拥有仓库权限后可查看该仓全部货主出库数据，不能查看未授权仓库；具体操作还须具备相应动作权限，规则见[公共能力需求分析](../07-公共能力/公共能力需求分析.md)。

#### OUT-FR-011 库存影响

预占、拣货与返库上架移库、扣减、释放及流水的数量口径见[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)。

#### OUT-FR-012 基础波次

- B2C 包裹可选择按单拣货或进入基础波次。
- 管理端可从同一仓库、同一货主、处于待拣货且整单能分配足的 B2C 出库单中手工创建波次，系统生成一张波次拣货任务，应拣按库位＋SKU＋批次汇总并展示进度；提交后按波次内顺序把实拣分回各单，短拣落在顺序靠后的单上。
- 生成波次拣货任务后成员单不能移出，只能取消。
- 波次完成后各出库单仍分别复核（可随分拣完成）、确认出库和回传结果。
- 平台仓转运、B2B、调拨、退回等非 B2C 类型按单摘果拣货，不进入波次。
- 分拣载体与扫描顺序在应用设计中落实。

#### OUT-FR-013 退回出库

- 原入库单已经产生实收且上游要求退回时，不允许取消或冲销原入库记录。
- 退回出库只退正常品，按普通出库的可用预占：货还在收货暂存库位的也能接单预占，上架后才能分配、拣货。OMS Mock 发送独立退回出库指令，引用原入库单、货主、仓库、SKU、数量和退回原因，并分别保留原入库与退回出库记录。
- WMS 按普通出库完成预占、拣货、复核、确认出库和扣库。
- 未计入实收的暂存实物按线下安排处理，不生成WMS退回出库单。
- 不良品及过期转成的不良品实际移出仓库时通过 OUT-FR-014 其他出库处理；真实盘点差异按 INV-FR-006 核对调整。不纳入本条正常品退回，不将其改成正常品或释放为普通可用；未过期临期正品可以按本条退回。

#### OUT-FR-014 不良品其他出库

- 新建其他出库（含邮件手工来源）同样适用盘点规则：含盘点中 SKU 的可以创建，但盘点完成前不能拣货和确认出库。
- 其他出库可由上游通知，一期用 OMS Mock 下发；也可在线下邮件通知仓库后，由有权限的仓库用户在 WMS 管理端手工创建。
- 两种来源都记录货主、仓库、SKU、品质、货位、批次／SN、通知来源、处置数量和原因；上游生成记录保留上游指令号，手工记录保留邮件等线下依据，不伪造上游指令号，也不建设自动收发邮件功能。
- 该路径允许选择已上架的在库不良品，在明细上记录指定的货位、批次／SN，不套用 OUT-FR-002 的可用预占，不加订单占用；指定数量计入这些库存明细的已分配，同一实物因此不能同时被其他处置单或任务指定。
- 拣货任务直接按指定实物生成，不换位、不重新分配；指定实物找不到时只能取消后重新指定。已拣实物取消时按 OUT-FR-017 退拣回不良隔离库位。
- 仓库复核指定实物、品质、批次／SN 和数量，确认出库后扣减对应不良品的实际库存并生成流水，剩余不良品仍不可用；取消时只解除指定、释放已分配，不良品仍不可用，不能恢复为普通可用。
- 该路径不先转换成正常品，不走正常品退回出库；核对指定在库实物后按实发扣减，同一实物不重复出库。
- 指定实物须足量确认；结果交接按[出库结果](#out-fr-007-出库结果)处理。

#### OUT-FR-015 出库单来源

- 五类普通出库单由 OMS Mock 指令生成，管理端不提供手工新建入口（退回出库亦由 Mock 下发并引用原入库）。
- 不良品其他出库可由 OMS Mock 下发，或由管理端在 OUT-FR-014 规则下手工创建。
- 演示基础资料可预置，出库单按上述来源生成。

#### OUT-FR-016 PDA 出库作业

- PDA 支持按出库单或波次拣货任务执行扫描拣货、复核（可随分拣或打包装箱）与返库上架，并在授权下参与确认出库与交接登记（具体菜单与动作权限见公共能力与应用设计）。
- 与管理端共用业务记录与库存占用；重复提交不重复移库、不重复增加实发、不重复扣减库存。业务后果见《出库业务设计》第四节与第七节。

#### OUT-FR-017 退拣与返库上架

- 退拣指已拣实物从本单退出，只有两种情况：受理取消时自动退拣出库暂存库位上的已拣实物；复核发现残损或少件时由复核人员人工退拣。
- 每次退拣生成一张返库上架单，记退拣原因并指回原出库单。结构与提交规则同入库上架单：应返库明细不能修改；实际返库可多次保存，不动库存；全部填完后提交，一次性把库存从出库暂存库位移到目标库位（正常品回存储、拣货库位，不良品回不良隔离库位），并校验库位启用、品质适配与货主占用。
- 取消退拣时本单预占已一并释放；复核退拣时本单预占保留，可按 OUT-FR-009 重新分配补拣，补不上时按类型缺量结案或等上游取消。
- 残损件先由仓库主管在出库暂存库位核实转不良，再退拣回不良隔离库位，不回到存储、拣货库位。
- 找不到的仍按应返库数量提交，再对该 SKU 发起盘点调整，不伪造实发。

#### 履约时间

履约 48 小时起算、计时口径与展示规则以 [COM-FR-002](../07-公共能力/公共能力需求分析.md#com-fr-002-语言存储时间与业务时区) 为准；超时后仓库组织者跟进，上游决定后续处理，WMS 不自动取消或强制缺量。

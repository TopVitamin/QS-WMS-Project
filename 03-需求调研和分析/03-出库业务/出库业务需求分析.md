# 出库业务需求分析

> 本稿说明一期范围与系统需求。业务背景见[调研稿](出库业务需求调研.md)。

## 一、分析结论

WMS执行B2C包裹履约、平台仓转运、当地B2B批发、调拨出库、退回出库，以及不良品其他出库。常规链路为接单预占、组织拣货、复核和确认出库。所有类型以仓库确认出库为完成及扣库节点，不以承运商实际揽收作为前提；调拨出库不关联调入仓单据。

## 二、功能需求

| 编号 | 功能 | 需求结论 |
| --- | --- | --- |
| OUT-FR-001 | 出库指令接收 | 先校验资料、盘点阻断及类型准入，再接收并预占 |
| OUT-FR-002 | 库存校验与预占 | B2C足量预占才接收；其他普通类型按可用量预占 |
| OUT-FR-012 | 基础波次 | 同仓同货主B2C可手工成波，B2B仍按单拣货 |
| OUT-FR-003 | 拣货任务 | 按单或波次锁定建议货位，按配置扫描追溯信息 |
| OUT-FR-004 | 拣货校验与换位 | 错扫阻断；货位无货可换位，整仓缺货留异常 |
| OUT-FR-005 | 复核打包 | 包裹复核SKU及数量，箱／托只记录作业容器 |
| OUT-FR-006 | 确认出库 | 按类型判断足量或缺量资格，确认后扣库并结案 |
| OUT-FR-007 | 出库结果 | 需求、实发、未发及交接结果分别可查、可回传 |
| OUT-FR-008 | 取消与变更 | 未拣可变更或取消；已拣取消先回库，已出库拒绝 |
| OUT-FR-009 | 缺货处理 | 缺货与短拣有明确处理结果；已接单补货后由仓库人工重试，不静默改量 |
| OUT-FR-013 | 退回出库 | 先保留原入库事实并形成库存，再独立退回出库 |
| OUT-FR-014 | 不良品其他出库 | 支持上游或邮件依据手工创建，直接处置不良品 |
| OUT-FR-010 | 多货主归属与仓库权限 | 货主分别扣库，用户只访问已授权仓库 |
| OUT-FR-011 | 库存影响 | 预占、扣减、释放与流水引用库存模块 |

### 接单与拣货组织

#### OUT-FR-001 出库指令接收

- OMS Mock推送B2C包裹履约、平台仓转运、B2B、调拨出库和退回出库指令，含货主、仓库、SKU与数量、收货或交接信息。先校验资料、盘点阻断和本类型预占要求，满足准入后生成可执行出库单并完成预占；失败返回拒收原因，不留下该请求的部分占用。
- B2C包裹出库单复核打包后交承运商；平台仓转运和B2B按件并辅以箱／托容器记录；调拨出库按普通出库执行，不与调入仓记录关联；退回出库引用原入库单和退回原因。

#### OUT-FR-002 库存校验与预占

- 普通出库在所属仓库内按货主＋SKU预占总可用，接单阶段不锁定货位、不跨仓借量；不良品其他出库按OUT-FR-014处理指定实物。
- 新出库请求命中盘点阻断时整单拒收，不预占、不生成可执行单或待受理单。盘点结束后由上游重提，不自动受理原拒收请求。
- B2C必须所有SKU足量预占才可有效接收；任一SKU不足，整单报错，其他SKU也不留下该请求的部分占用。
- 日常B2B、平台仓转运、调拨和退回出库按min（需求量，可用库存）预占，不足部分保留为缺货。接单时允许部分预占不代表可以缺量出库，确认资格按OUT-FR-006判断。
- 示例：B2C需求5、可用3时整单拒收、不占这3件；日常B2B同样数据可接收，需求5、预占3、缺货2分别保留。
- 示例：美西仓该货主SKU实际库存10、已预占3、可用7；新出库单需5后，预占变为8、可用变为2、实际库存仍为10，美东仓库存不参与计算。

#### OUT-FR-012 基础波次

- B2C包裹可选择按单拣货或进入基础波次。
- 管理端可从同一仓库、同一货主且处于可拣状态的B2C出库单中手工创建波次，系统生成波次拣货任务并汇总展示进度。
- 波次完成后各出库单仍分别复核、确认出库和回传结果。
- B2B按单摘果拣货，不进入波次。
- 一期不做自动波次规则、人员派工和产能计算；具体分拣动作在应用设计中落实。

#### OUT-FR-003 拣货任务

- 按出库单或波次生成拣货任务，列出并锁定建议货位、批次和数量；普通出库的效期商品排除过期或不良品批次，从未过期的正品中优先推荐有效期更早且可用的批次；临期正品允许参与推荐与出库，不设置最短出库剩余效期阻断，引用INV-FR-011。
- PDA扫描货位、SKU、批次及配置要求的SN确认拣货。
- 订单级预占仍按仓库＋货主＋SKU记录，货位锁定只表示当前拣货分配。

#### OUT-FR-004 拣货校验与换位

- 扫描货位、SKU、批次或SN不匹配时阻断并提示。
- 建议货位无货时，作业人员上报货位缺货；系统释放原货位锁定，重新推荐并锁定其他有货货位，SKU级预占总量不变。
- 若存储区和拣货区都无可拣库存，记录并上报整仓缺货异常；已有效接收的B2C等待补货后按OUT-FR-009人工恢复，或由OMS Mock取消；其他允许缺量出库的类型按OUT-FR-009收口。
- 取消后关闭异常并按实物环节释放对应预占。
- 实拣少于应拣时记录短拣数量，不允许静默按实拣完成。
- 已拣未确认出库数量仍属于实际库存并保持预占，其作业位置由拣货任务或暂存位置记录。

### 复核、出库与异常

#### OUT-FR-005 复核打包

- B2C包裹履约类出库单在确认出库前复核SKU、批次、SN和数量，登记包裹件数与模拟重量；复核差异阻断确认出库。
- 平台仓转运、B2B、调拨出库和退回出库可记录箱／托容器及其所含SKU数量，但不形成箱库存或托盘库存。

#### OUT-FR-006 确认出库

- 所有出库类型均由仓库执行“确认出库”。
- 确认时可记录承运商Mock、司机、客户自提等交接对象与凭证，但承运商尚未揽收也不阻止仓库确认。
- 平台仓转运与B2B支持缺量出库，一次确认即整单完结，不在原单继续履约；按实发数量同时扣减实际库存和对应订单预占。
- 未发量单独保留，未拣未发数量释放订单及货位锁定，已拣未发数量须先回库核对后释放，整单完结不残留该单锁定。
- B2C、调拨出库和退回出库不支持缺量，任一明细实发不足时确认出库报错、不得扣库或完结。
- 符合本类型足量或缺量条件并确认后，出库单置“已出库”。
- 打印机和电子秤使用模拟或手工数据。

#### OUT-FR-007 出库结果

- 需求、实发、未发数量、短拣、确认出库及交接信息可查询并回传OMS Mock。
- 允许缺量的单据以“已完结且有未发量”表达结果，不把未发量改写为已发；后续需继续发货时由上游另发新单。

#### OUT-FR-008 取消与变更

- 尚未开始拣货且未确认出库时，可以接受取消并释放预占，也可以接受明细变更；变更时原预占与新预占必须在同一事务内重新计算，失败则保留原单和原预占。
- 仓库、货主和业务类型等身份字段不得在原单上变更，须在允许取消时取消原单并重新下发。
- 已开始拣货后拒绝明细变更；已拣未确认出库的取消须先核对实物并完成回库，再释放对应预占和恢复可用，不能只改系统数量。
- 确认出库后不允许取消或变更；后续撤销请求走上游其他业务，不回写已出库事实。

#### OUT-FR-009 缺货处理

- 单据保留需求量、预占、实发、未发及缺货／短拣可查；建议货位无货先按 OUT-FR-004 换位，整仓无货上报缺货异常。
- **B2C**：接单不足按 OUT-FR-002 整单拒收；已接单不允许缺量发货，取消与回库按业务设计执行，补货后由有权限仓库人员**人工**重试预占与分配（2026-10-08 已确认），不静默改需求、不叠占。
- **平台／B2B**：允许缺量一次结案（OUT-FR-006）；**调拨、退回、其他出库**须足量确认，不足阻断。
- 分支条件、恢复节点与数量走查见[出库业务设计](../../04-业务分析和设计/03-出库业务设计.md#101-已接收缺货单人工恢复)及该文第九节（走查待执行，见[需求分析总览](../00-项目总览/02-需求分析总览.md#62-走查待执行规则已确认验收未做)）。

### 退回、不良品及共同约束

#### OUT-FR-013 退回出库

- 原入库单已经产生实收且上游要求退回时，不允许取消或冲销原入库记录。
- 货物必须先按商品配置完成必要的质检、上架并形成实际库存，再由OMS Mock发送独立退回出库指令；指令引用原入库单、货主、仓库、SKU、数量和退回原因，并分别保留原入库与退回出库记录。
- WMS按普通出库完成预占、拣货、复核、确认出库和扣库。
- 未进入库存的暂存实物在线下处理，不生成退回出库单；所有出库单都必须对应实际库存扣减。
- 不良品及过期转成的不良品通过其他出库或盘亏处理，不纳入本条正常品退回，不将其改成正常品或释放为普通可用；未过期临期正品可以按本条退回；不良品其他出库见OUT-FR-014，报损／销毁库存调减见INV-FR-012。

#### OUT-FR-014 不良品其他出库

- 其他出库可由上游通知，一期用OMS Mock下发；也可在线下邮件通知仓库后，由有权限的仓库用户在WMS管理端手工创建。
- 两种来源都记录货主、仓库、SKU、品质、库位、批次／SN、通知来源、处置数量和原因；上游生成记录保留上游指令号，手工记录保留邮件等线下依据，不伪造上游指令号，也不建设自动收发邮件功能。
- 该路径允许选择实际在库的不良品，按单记录对应处置占用关系，不套用OUT-FR-002只从正常可用量预占的限制；已有品质锁定继续保留，锁定合计按不重复实物计量，同一实物不能同时给其他处置单或任务使用。
- 仓库核对指定实物、品质、批次／SN和数量，确认出库后扣减对应实际库存及品质锁定、处置占用并生成流水，剩余不良品仍全量锁定、可用为0；取消未执行的处置占用时保留品质锁定，不能将不良品恢复为普通可用。
- 该路径不先转换成正常品，不走正常品退回出库；报损／销毁库存调减另由INV-FR-012承接，不重复扣库。
- 来源为上游的结果由INT交接，手工来源保留可查询结果；其他出库必须足量，当前验收使用指定数量足量完成的案例。

#### OUT-FR-010 多货主归属与仓库权限

出库单、拣货与交接记录带货主维度并分别扣减对应货主库存；用户拥有仓库权限后可查看该仓全部货主出库数据，不能查看未授权仓库，规则引用[COM分析稿](../07-公共能力/公共能力需求分析.md)。

#### OUT-FR-011 库存影响

预占、扣减与释放引用 INV-FR-003、INV-FR-004（[库存与库内业务需求分析](../04-库存与库内业务/库存与库内业务需求分析.md)）。

### 履约时间

履约 48 小时起算、计时口径与展示规则以 [COM-FR-002](../07-公共能力/公共能力需求分析.md#com-fr-002-语言存储时间与业务时区) 为准；超时后仓库组织者跟进，上游决定后续处理，WMS 不自动取消或强制缺量。

## 三、范围取舍与模块依赖

一期不包含：仓外运输与配送、客户退货入库及退货质检、渠道订单管理、人员派工、自动产能调度、大促产能方案、真实承运商面单服务与运单跟踪、真实打印机和电子秤接入。

| 依赖模块 | 依赖能力与使用约束 |
| --- | --- |
| INT | 接收OMS Mock指令并返回准入或执行结果；重发和结果回传不重复预占、扣库 |
| MD | 接单校验仓库、货主、商品；拣货再校验货位和追溯信息 |
| INV | 读取可用量及盘点阻断范围，执行预占、货位分配、释放和扣减 |
| COM | 执行仓库数据权限、动作授权及履约时间规则；交接、打印和重量使用一期模拟数据 |

## 四、应用设计输入与资料缺口

- 应用设计输入：按业务设计落实作业所需的处置记录、波次分拣页面与状态表达。
- 资料缺口：各渠道时效及超时原因样例，用于后续评估渠道差异；一期仍按上述统一参数执行。
- 人工重试入口、结果展示与操作留痕按OUT-FR-009落实；重复重试重新核当前缺口，不重复增加已有效占用，已取消或结案单不得恢复。

**业务验收示例（OUT-FR-002／003／009）：**B2B需求5，实际3且无其他锁定，接单占3、缺货2；合格库存新增2后为实际5、总预占3、可用2，原单尚未恢复。仓库人工重试后本单占5、缺货0，货位分配不另增预占；再次重试仍为5／5／0。补货不足时只按合法可用量补占并保留缺货；盘点阻断、已取消或已结案时不恢复。**文档逻辑走查已通过**（2026-10-08，见[需求分析总览§6.4](../00-项目总览/02-需求分析总览.md#64-文档逻辑走查记录2026-10-08)）；演示/PDA 实操待执行。

# 如何在领星OMS授权Genstore店铺


              
## 1 操作场景

**定义**：通过OMS系统的平台授权将Genstore店铺与OMS进行连接绑定，使OMS能够获取Genstore店铺相关数据和权限，从而实现对店铺订单等业务的统一管理。**作用**：将Genstore店铺后台订单同步至OMS进行管理，可以直接对订单进行审核、提交仓库处理等操作；同时可通过设置平台订单规则实现自动发货，提高订单处理效率，提升整体运营效能。本章将指导您如何在领星OMS授权Genstore店铺。
## 2 操作指引


### 2.1 获取授权信息

可参考官方说明：[https://help.genstore.ai/zh/docs/apps-type-custom](https://help.genstore.ai/zh/docs/apps-type-custom)1、创建自定义应用：
- 在 Genstore 商户后台，点击切换至 商店 页签。
- 点击 应用 -> 开发应用。
- 在新窗口中，点击 创建应用，并填写以下信息：应用名称：自定义应用名称；应用开发者：选择店主/有权限的员工账户.。
- 点击 创建应用。

2、配置 API 访问范围
- 在应用列表中，点击目标应用进入应用详情页。
- 在 概览 页签，点击 配置 API 访问范围。在随即打开的 应用配置 页面，点击 编辑。
- 勾选所需权限范围（如订单读取、产品管理等）。
- 点击 保存。

3、安装应用
- 在应用列表中，点击目标应用进入应用详情页。
- 点击 安装应用 按钮，确认安装。
- 系统将生成 API Access token，请立即保存该令牌。重要：`Access Token` 仅首次可见，请务必保存。

4、密钥管理
- 在应用列表中，点击目标应用进入应用详情页。


- 点击 管理 API 凭证 按钮或 API 凭证 页签，查看：API Key / API Secret / API Access token（仅首次安装可见，建议查看后保存）


### 2.2 登录领星OMS添加平台授权

路径：领星OMS - 系统设置 - 平台授权 - Genstore - 添加授权

### 2.3 设置产品映射配对（必需）

操作步骤：OMS系统设置 ＞ 产品配对 ＞ 新建/导入
- 产品配对前请确保OMS已创建对应的产品SKU；
- 平台订单模块内的平台 SKU 依据店铺后台的 sku 自动赋值，新建产品配对时手动填写的平台 SKU 需与其保持一致；
- 数量为平台SKU与系统SKU的换算系数（不是库存量），即买家下单购买1个平台SKU，卖家对应要发出的商品数量。如果是多种SKU的组合，可以点击加号继续添加；
- 产品映射关系是与平台店铺进行绑定，若授权了多个平台店铺，都需要重新进行产品映射。

  点击链接获取创建产品映射的详细教程：[使用OMS实现产品配对](https://help-oms.xlwms.com/aad8/bf28/ed20/e976)

### 2.4 领星OMS平台订单操作


- 首次授权后，系统会自动拉取店铺的创建时间3-5天内的订单，但平台订单不是实时自动同步的，后续会每间隔15分钟拉取2天内的订单。如果需要立刻看到最新的所有订单，需要点击【手动同步】按钮进行数据同步。

点击链接，查看详细操作步骤：[使用OMS平台订单实现发货](https://help-oms.xlwms.com/aad8/bf28/7080/de0f)
# 3.补充说明


### 3.1名词解释

OMS授权界面●店铺名称：支持自定义店铺名称，代表平台店铺在系统的名称，可以和平台店铺名称填写一致。●店铺代码：自定义店铺代码，店铺代码具有唯一性，方便管理用户授权的平台店铺。
# 4.常见问题


#### Q1：支持拉取哪些状态下的订单？

答案：支持拉取`financialStatus=paid` 及 `fulfillmentStatus=null/partial`（待发货 + 部分发货）状态的订单。
#### Q2：拉取订单后采用何种履约方式？

答案：支持客户自供面单并自动标发。

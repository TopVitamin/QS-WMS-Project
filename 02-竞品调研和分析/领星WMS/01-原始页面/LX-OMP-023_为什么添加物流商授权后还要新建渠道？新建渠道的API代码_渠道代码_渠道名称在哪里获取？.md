# 为什么添加物流商授权后还要新建渠道？新建渠道的API代码/渠道代码/渠道名称在哪里获取？


              物流商就相当于我们国内的顺丰、中通等快递服务商，渠道的话就是顺丰的半日达、标快等，所以实际使用中还需要建立物流渠道。
- 官方物流不需要填写API服务代码，只需要激活对应的渠道；物流渠道代码与物流渠道名称是自定义的，客户在OMS端可以看到您维护的这两个内容。
- 注意：物流渠道代码创建后不可修改，也不支持删除但可禁用。

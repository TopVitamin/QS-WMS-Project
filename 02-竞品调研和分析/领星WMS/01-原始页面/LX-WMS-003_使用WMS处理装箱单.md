# 使用WMS处理装箱单


              
## 一、功能背景



定义：在 Temu Y2 等直邮业务中，卖家会将多张直邮单包裹先发至物流服务商的国内仓，再由服务商在国内仓中将多个客户的包裹装在箱子中后，统一发空运到海外仓中扫描换单。

作用：




- WMS端新增完整的国内仓装箱流程。支持将多客户的小包裹装到箱子中，录入头程单号、重量、尺寸等信息，并支持打印箱唛（支持自定义）贴在箱子上

- 装箱单的头程单号会同步到每个关联直邮单，方便通过头程单号实现物流全流程追踪

- 海外仓可以在列表中看到每个箱子的面单率（即一个箱子内有多少直邮单已经有了尾程面单），优先拆那些面单率高的箱子扫描换单，大幅提高换单的操作效率




## 二、操作说明



### 4.1 装箱单主列表



适用场景：进入装箱单模块后，先通过主列表查看、筛选和管理各状态装箱单。国内仓主要用于创建和发运，海外仓主要用于按面单率查看待到港/在途箱件。

路径：WMS → 直邮 → 装箱单

特殊说明：仓库操作权限限制：目的仓对待发运的装箱单只保留打印箱唛和编辑按钮，且编辑按钮只能编辑基础信息



![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895566866/image.png)

### 4.2 【国内仓】新建装箱单

适用场景：国内仓签收直邮单后，需要将多张直邮单装入同一外箱发运。路径：装箱单列表 → 【新建装箱单】操作步骤：1. 先选择目的仓，按需填写头程单号、自定义箱号、箱唛重量、长宽高、备注（均为选填）
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895580922/dbf4c433)
2. 在【订单信息】区点击【添加订单】，勾选状态为「国内已收货」、且目的仓一致的直邮单（支持多客户混装），确定后提交装箱单
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895581083/1b427f26)
3. 返回列表后点击【打印箱唛】，将箱唛贴于外箱
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895696523/image.png)
4. 可以在管理后台-打印模板-装箱单箱唛中自定义配置模板
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895709102/image.png)

### 4.3 【国内仓】导入新建/更新装箱单与确认发运

适用场景：批量生成装箱单，或发运前补录装箱单的测量和头程单号等信息。导入新建：装箱单列表 → 【导入 ▾】→ 【导入新建装箱单】→ 上传 Excel。同一「装箱批次号」的多行直邮单会合并为一张装箱单，一次可生成多张「待发运」装箱单。导入更新：装箱单列表 → 【导入 ▾】→ 【导入更新装箱单】→ 按装箱单号批量补录箱唛重量、长宽高、头程单号、自定义箱号、备注。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895758464/image.png)
确认发运：
- 在「待发运」Tab 勾选装箱单，点击【确认发运】；或进入详情页点击【发运】
- 二次确认后，装箱单变为「已发运」，关联直邮单进入「待换单」
- 也可在「直邮单 - 国内已收货」列表批量【发货】——若某装箱单内全部未取消直邮单均已发运，该装箱单会自动变为「已发运」

注意：「待发运」状态可【取消】装箱单，取消后直邮单解除绑定并仍保持「国内已收货」。已发运后不可在装箱单维度撤回，需按直邮单规则逐单截单。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895805632/image.png)

### 4.4 【海外仓】查看面单率与换单出库

适用场景：箱件到港后，决定优先拆哪些外箱，再逐件换单出库。操作步骤： 1. 在主列表切换到「已发运」Tab，可以在列表中查看所有装箱单的面单率
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895831924/image.png)
2. 也可以点击装箱单号进入详情，查看直邮单总数、有面单数、无面单数、已出库数、面单率及直邮单清单
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895843589/image.png)
3. 线下拆箱后，进入 WMS → 直邮单 → 换单，扫中性条码 → 打印尾程面单 → 出库。箱内全部未取消直邮单完成出库后，装箱单自动变为「已完结」
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895857754/image.png)

### 4.5 【WMS】直邮单关联信息查看和头程单号同步


- WMS 直邮单列表/详情新增【所属装箱单号】【最早可获取面单时间】，支持按装箱单号搜索。点击装箱单号可跳转详情（需有权限）
- 头程单号同步：编辑、新建、导入更新装箱单的头程单号，会自动引发关联直邮单的头程单号变更，并会记录操作日志


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1782895887499/image.png)

## 五、常见问题 FAQ



**Q1：不走装箱单的直邮单，流程会变吗？**

不会。装箱单是可选作业层，未加入装箱单的直邮单仍按直邮单1期原流程走，计费口径也不变。

**Q2：箱唛重量、长宽高没填，能发运吗？**

可以。箱唛重量、长宽高均为选填，不填也不阻断确认发运和换单出库；录入后仅作头程费用线下核算参考，本期不参与系统自动计费。

**Q3：海外仓为什么看不到【确认发运】或【取消】？**

装箱单的创建、发运、取消由国内仓操作；海外仓主要查看面单率和直邮单清单，线下拆箱后按直邮单1期流程换单出库。

**Q4：面单率是怎么算的？**

面单率 = 有尾程面单的直邮单数 ÷ 关联直邮单总数。海外仓可据此判断优先拆哪些外箱。

**Q5：如何批量导入直邮单的头程单号**

建议使用装箱单功能，更新装箱单的头程单号时，会自动将头程单号更新到关联直邮单上

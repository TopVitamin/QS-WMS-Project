# 使用WMS进行入库认领


              
# 1.操作场景

**定义：** 当卖家的商品退回至海外仓，但未提前在系统（oms）中创建“退件/货预报单”时，仓库收货之后无法获取完整的退货信息，因此无法处理这批退货。此时，您需要创建入库认领单，以便客户进行认领，认领后可以正常进入退件流程。**目的：**借助入库认领单相关功能，卖家可以在系统（OMS）中主动查询并认领已到达仓库的未预报包裹，随后为其补建正式的退件单。通过这一流程，是仓库能够及时、准确地启动和执行退货处理流程，确保后续处理顺利进行。
# 2.操作指引

（1）仓库（WMS）-入库-到仓扫描，扫描退件包裹的物流单号，系统会自动校验该仓库已预报的单据内是否有对应的订单，若没有找到，则弹出提示【未找到此物流包裹】，此时，需要选择“创建认领单”，操作手动创建认领单，以便卖家可以直接在OMS里完成认领动作。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e686ce83-30f3-4a2e-9dfd-4df54c4eb61b/1784182377749/image.png)
（2）点击创建认领单之后，可以填写认领单信息。若选择不指定客户，选择【直接创建】，创建成功后所有OMS客户可见该认领单信息。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e686ce83-30f3-4a2e-9dfd-4df54c4eb61b/1784182689394/image.png)
未指定客户的情况下，拍照上传过程请注意不要拍到完整的跟踪号信息，以免误认领（3）如果仓库操作人员可以明确知道这个包裹属于哪个客户，可以选择【拆包清点】，创建后仅指定认领客户OMS端可见该认领单信息。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e686ce83-30f3-4a2e-9dfd-4df54c4eb61b/1784183172729/image.png)
（4）创建完认领单之后，WMS端可以在WMS-入库-入库认领模块，查询之前创建的认领单的认领进度。

# 3.补充说明


## 3.1 认领单各状态的释义

**待认领**：认领单创建成功，待OMS端客户操作认领。**已认领**：客户已经在OMS里操作认领完成，并且生成了对应的退件单/FBA退货入库单，可以切换这里查看关联单号。**已处理**：认领单完成认领并且生成的退件单/FBA退货入库单也完成上架，整个认领单的流程都走完了。**已取消**：认领单创建成功后，再待认领状态，又被WMS端操作人员操作取消了，取消后的认领单信息就会显示在这个模块。**已过期**：认领单创建之后，直到失效都没有客户操作认领过，则认领单状态显示为已过期状态，这个状态无法再次认领。
## 3.2 PDA支持创建认领单后，直接生成退件单

具体步骤可以参考文档：[通过PDA实现退件 | 领星WMS帮助中心](https://help.xlwms.com/12d0/d5f9/b3bb/b629)
# 4.常见问题

Q1:有没有办法能让包裹到了能够识别出是哪个客户的货呢？**答案：**可以跟客户约定在退件地址或收件人信息上加上他们的客户代码，这样仓库收到货即使没有退件/货单也能区分是哪个客户的货，并且指定客户创建认领单。Q2:入库认领单我能过一段时间就自动废弃掉吗？**答案：**可以在wms端口设置入库认领的失效时间，过了认领时间它就会进入已过期无法认领。创建认领单的时候，也可以直接选择失效日期。

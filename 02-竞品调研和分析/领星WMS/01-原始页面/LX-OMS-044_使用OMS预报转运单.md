# 使用OMS预报转运单


              
# 1.操作场景

**定义：** 转运，指货物从起运地发往卸货港 / 最终目的地的运输途中，完成中转换装、重装的物流操作；包含两种场景：同运输工具间中转搬运、不同运输方式（海运 / 空运 / 陆运）切换转运。**作用：**卖家在 OMS 系统左侧菜单栏进入【转运】模块，提前创建转运预报单，便于海外仓工作人员提前知晓货件信息、完成入库中转操作。 创建转运单时需完整填报目标入库仓库、提单号（B/L No）、柜号、客户订单号（SO）、客户信息、唛头、总箱数等核心资料，并可上传配套清关 / 货运附件；单据创建完成后，支持补充上传新附件、作废取消转运单。
# 2.操作指引


## 2.1 进入OMS系统

登录您的OMS管理后台，导航至转运模块。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773933/c5822650)

## 2.2 创建转运单


### 2.2.1手动创建

①在转运的菜单界面，点击新建按钮。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168774213/8afccad9)
②填写转运信息：进入新建转运的页面，填写对应的信息，包括仓库、B/LNo(提单号)、柜子号、唛头、箱数等。红色星号必填，其他选填即可。● 其中，转运列表信息可以选填FBA货件ID、FBA参考号、FBA仓库代码、派送方式、详细地址等。● 附件处可以选择需要上传交由仓库的BOL/物流面单/箱唛/托盘唛/POD。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773710/0c36c8b2)
③填写完成后，可以保存草稿或者直接提交。若点击保存草稿，转运单会为草稿状态；若点击提交，转运单会直接提交至WMS，状态流转至待收货。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773641/87113a8a)

### 2.2.2 批量导入创建

①在转运页面，点击导入按钮，下载对应导入模版。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773614/76d83f55)
②选择对应仓库，下载导入模板
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773688/99a5cc78)
③填写导入模版，根据导入模版内容填写对应转运信息，标黄的为必填项，其他选填即可，注意不要修改模版的字段和顺序，否则可能导致导入失败。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773610/7ca876f0)
④选择对应转运单文件，操作导入转运单。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773842/96f8a6b0)
⑤观察导入情况：可以点击右上角进入任务中心查看导入完成情况，若导入失败，可以操作下载失败文件，查看失败原因，修改后再导入。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773818/46ba6438)
⑥提交转运单：导入成功后，可以点击右侧单个提交或者点击上方批量提交，提交转运单后，转运单流转待收货状态，需要等待海外仓操作收货。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1784168773927/9492d1f3)

# 3.补充说明


## 3.1转运单状态

● 全部：展示所有状态的转运单。● 草稿：新建转运单的时候点击“保存草稿”，保存成功后即为草稿状态。草稿状态的转运单还未提交到仓库，支持修改，取消等操作。● 待收货：新建转运单的时候点击“提交”，或者将草稿状态的转运单提交至仓库，操作成功后即为待收货状态。待收货表示仓库还未收货，但可以在系统中查询到转运单。此时可以进行上传附件，取消等操作。● 已收货：表示仓库已经全部收货完成。● 部分转运：表示仓库已经将收到的货部分转运完成。● 已转运：表示仓库已将收到的所有货物转运完成。● 已取消：被取消作废的转运单。
## 3.2名词解释

● B/LNo(提单号)：提单（Bill of Lading，简称 B/L）是国际货物运输中最重要的单据之一（海运场景优先看 B/L No），由承运人（如船公司、航空公司）或其代理人出具，证明货物已被接收或装船，同时也是收货人提取货物的 “凭证”。而 “B/L No”（提单编号）就是这张提单的唯一标识代码，相当于货物运输的 “身份证号”，主要作用包括：①追踪货物：通过提单编号在承运人官网查询货物的运输状态（如是否装船、到港时间、清关进度等）。②单据关联：在报关单、商业发票、装箱单等外贸单据中，需填写提单编号以确保所有文件指向同一批货物。③提货核对：收货人提货时，需提供包含提单编号的单据，供承运人核对身份与货物信息。● 柜子号：“柜子号” 是物流（尤其是海运、集装箱运输）领域的通俗说法，全称通常是 “集装箱编号”（Container Number），也叫 “箱号”，是用于唯一标识每个集装箱的全球标准化代码，相当于集装箱的 “身份证号”。● 唛头：“唛头” 是外贸、物流领域的常用术语，英文对应 “Shipping Mark”，指印刷或粘贴在货物包装（如纸箱、木箱、托盘）上的标识符号或文字，核心作用是帮助各方快速识别货物、避免错发错运，是国际货物运输中不可或缺的 “货物名片”。● ETD：预计出发时间，指货物 / 运输工具（如船舶、飞机、货车）计划从出发地离开的时间，是运输流程的 “起点时间锚点”。● ETA：预计到达时间，指货物 / 运输工具计划抵达目的地（如港口、机场、仓库）的时间，是运输流程的 “终点时间锚点”。
# 4.常见问题

Q1:转运单会生产箱唛吗？**答案：系统目前不会对转运单生成箱唛。**Q2:转运单可以关联柜号吗？**答案：转运单无法关联柜号，如有需要可以填写在备注里，方便后期对账确认。**

# 使用WMS处理转运


              
# 1.操作场景

**定义：**WMS端转运处理是指仓库基于 OMS 推送的转运单，通过领星WMS的转运模块，完成 “待收货→已收货→已转运” 全流程的实物核对、收货、转运交接操作，是OMS转运预报的落地执行环节。**作用：**通过WMS端操作，实现对OMS转运单的实物履约，完成货物入库、与承运方交接，确保转运货物高效流转。
# 2.操作指引


### 2.1进入wms系统

登录WMS系统，导航至转运模块。

在页面点击收货，核对箱数填写实收，有托盘的可以填写对应托盘数，如果需要到仓暂存多个库位可以点击增加。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1778230235011/4adf61da)

也可以点击转运单据详情查看核对转运信息，并在右上角点击收货，如果需要到仓暂存可以对应选择暂存库位，对应填写实收箱数等信息后点击确认收货。

### 2.3确认出库或者拆单

核对信息无误可以点击确认出库，确认出库后单据将会流转已转运状态。

# 3.补充说明

转运单状态● 全部：展示所有状态的转运单。● 草稿：新建转运单的时候点击“保存草稿”，保存成功后即为草稿状态。草稿状态的转运单还未提交到仓库，支持修改，取消等操作。● 待收货：新建转运单的时候点击“提交”，或者将草稿状态的转运单提交至仓库，操作成功后即为待收货状态。待收货表示仓库还未收货，但可以在系统中查询到转运单。此时可以进行上传附件，取消等操作。● 已收货：表示仓库已经全部收货完成。● 部分转运：表示仓库已经将收到的货部分转运完成。● 已转运：表示仓库已将收到的所有货物转运完成。● 已取消：被取消作废的转运单。
# 4.常见问题

Q1:转运单是否会生成费用单据？**A1：转运是快进快出业务，不会生成费用单据，如果需要收取费用建议在OMP-业务费用新建业务流水补录。**Q2：转运是否会生成仓租？**A2：不会的，转运是快进快出业务，不涉及库存存放，所以不收取仓租。**

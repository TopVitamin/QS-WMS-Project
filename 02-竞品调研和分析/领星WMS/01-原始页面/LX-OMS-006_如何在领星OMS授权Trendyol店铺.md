# 如何在领星OMS授权Trendyol店铺


              
## 1 操作场景

**定义**：通过OMS系统的平台授权将Trendyol店铺与OMS进行连接绑定，使OMS能够获取Trendyol店铺相关数据和权限，从而实现对店铺订单等业务的统一管理。**作用**：将Trendyol店铺后台订单同步至OMS进行管理，可以直接对订单进行审核、提交仓库处理等操作；同时可通过设置平台订单规则实现自动发货，提高订单处理效率，提升整体运营效能。本章将指导您如何在领星OMS授权Trendyol店铺。
## 2 操作指引


### 2.1 获取授权信息


- 登录后台：必须使用店铺的主账号（Master User），登录Trendyol后台：[https://partner.trendyol.com/auth/logout?redirect=%2F](https://partner.trendyol.com/auth/logout?redirect=%2F)
- 进入账户设置：点击页面右上角的“公司/店铺名称”（Firma Adı / Mağaza Adı）。
- 选择基本信息：在下拉菜单中点击 “Account Details”（账户信息 / 对应土耳其语：Hesap Bilgilerim）。
- 提取集成参数：在左侧或顶部标签页中找到 “Integration Details”（集成信息 / 对应土耳其语：Entegrasyon Bilgileri）。

在该页面中，系统会展示对外对接所需的三个核心身份令牌：
- Supplier ID / Seller ID
- API Key
- API Secret Key


### 2.2 登录领星OMS添加平台授权

路径：领星OMS - 系统设置 - 平台授权 - Trendyol - 添加授权
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1779864211084/9a0a6f9e)

### 2.3 设置产品映射配对（必需）

操作步骤：OMS系统设置 ＞ 产品配对 ＞ 新建/导入
- 产品配对前请确保OMS已创建对应的产品SKU；
- 平台订单模块内的平台 SKU 依据店铺后台的 **barcode** 自动赋值，新建产品配对时手动填写的平台 SKU 需与其保持一致；
- 数量为平台SKU与系统SKU的换算系数（不是库存量），即买家下单购买1个平台SKU，卖家对应要发出的商品数量。如果是多种SKU的组合，可以点击加号继续添加；
- 产品映射关系是与平台店铺进行绑定，若授权了多个平台店铺，都需要重新进行产品映射。

  点击链接获取创建产品映射的详细教程：[使用OMS实现产品配对](https://help-oms.xlwms.com/aad8/bf28/ed20/e976)

### 2.4 领星OMS平台订单操作


- 首次授权后，系统会自动拉取店铺的创建时间3-5天内的订单，但平台订单不是实时自动同步的，后续会每间隔15分钟拉取2天内的订单。如果需要立刻看到最新的所有订单，需要点击【手动同步】按钮进行数据同步。

点击链接，查看详细操作步骤：[使用OMS平台订单实现发货](https://help-oms.xlwms.com/aad8/bf28/7080/de0f)
# 3.补充说明


### 3.1名词解释

OMS授权界面●店铺名称：支持自定义店铺名称，代表平台店铺在系统的名称，可以和平台店铺名称填写一致。●店铺代码：自定义店铺代码，店铺代码具有唯一性，方便管理用户授权的平台店铺。
# 4.常见问题


#### Q1：支持拉取哪些状态下的订单？

答案：支持拉取`Created`（待处理）状态的订单。
#### Q2：拉取订单后采用何种履约方式？

答案：支持客户自供面单并自动标发。

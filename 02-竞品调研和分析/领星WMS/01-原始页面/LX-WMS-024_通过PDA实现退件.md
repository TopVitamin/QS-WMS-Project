# 通过PDA实现退件


              
# 1.操作场景

**定义：**使用PDA进行退件操作，是指仓库人员借助手持移动终端（PDA）设备处理客户退回的货物。通过PDA可实时扫描运单、录入货物信息、匹配退件预报，并更新库存状态，实现高效、准确的退货入库流程。**作用：**通过扫描运单号或条形码可实时获取货物信息，准确匹配至对应客户的退件预报单，直接在PDA上完成信息录入、状态更新和库存同步，省去手工记录和电脑二次录入环节。
# 2.操作指引


## 2.1退件接收

退件分为OMS有预报退件单和没有预报退件单的情况，以下将分两种情况描述：
### 2.1.1OMS已预报退件单

（1）登录您的PDA设备：进入操作界面，选择退件-退件接收，扫描Barcode/跟踪号/退件单号；
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127367/34bd183f)
（2）扫描跟踪后，对于包裹会标记已勾选，代表已到仓，按需填写包裹尺寸重量、备注，清点完毕后点提交；
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127374/fccd6d88)

### 2.2.2OMS未预报退件单

（1）扫描跟踪号，没有预报的退件单，将提示“未找到物流包裹，选择创建入库认领单/退件单”，若明确包裹所属客户，且OMP端给该客户开启了“扫描包裹找不到退件单时，指定客户直接创建退件单”，可指定客户创建退件单；若不清楚包裹所属客户，可以直接创建认领单，此时包裹将进入待认领状态。该系统内所有客户均可查看该认领信息，物流跟踪号后四位由星号代替以确保信息安全。

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127275/edbcca7f)
a.PDA选择指定客户创建退件单后，OMS端可以在【退件—处理中】看到对应单据
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127357/1d3bbe5d)
b.PDA不选择指定客户创建，该系统内所有客户均可查看该认领信息，物流跟踪号后四位由星号代替以确保信息安全，OMS端需要在【仓储服务—入库认领—待认领】操作认领创建退件单

## 2.2退件处理

（1）PDA首页—退件—退件处理，扫描已清点完的退件单；
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127381/adee60d0)
（2）扫描Barcode，若退件单内的产品既有正品和次品，处理正品库存时，选择上架，扫描对应库位，填写上架数量 ，点确认提交即可；
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127394/c45fc24d)
（3）处理次品时，需选择是上架还是销毁，上架操作同上，销毁时可填写销毁数量，还需填写单个处理重量，然后点确认提交即可；
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785229127970/dc19bd30)

# 3.补充说明

**退件预报单：**客户在将货物退回海外仓之前，预先在系统中提交的电子通知单据。其中包含退回商品的详细信息、数量、退回原因及物流单号等，用于协助仓库提前识别、验收和跟踪退件，确保退货流程高效、准确。**PDA：**PDA（便携式数据终端）是一种手持式智能设备，广泛应用于仓储、物流和零售等领域，主要用于快速采集、处理及传输数据。在海外仓退件管理中，PDA可实现扫描条码、录入货物信息、实时更新库存状态等操作，显著提升作业效率和准确性。
# 4.常见问题

Q1:次品处理可以实现自动计费吗？**答案：是的，需要在OMP端的操作费设置中，将单据类型选为“退件”，并在条件变量中选择所需的处理方式，系统即可自动完成费用计算。**Q2:如果在次品处理时选择销毁会对现有库存产生影响吗？**答案：不会，因为此时要退件的次品还没上架，选择销毁不会对您原有库存产生影响。**

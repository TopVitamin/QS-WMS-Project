# 使用OMP创建账号


              
# 1.操作场景

**定义：**OMP 创建的账号指创建供 OMP/WMS 端使用的账号，创建流程为先创建角色以及角色权限，然后创建账号并绑定角色。**作用：**（1）满足不同岗位人员使用系统需求 ：OMP 主要为运营端使用，WMS 是仓库人员使用的端口。创建不同账号并分配相应角色权限，可以实现不同岗位的工作人员，只有自己需要操作的功能的权限，如仓库管理员、操作员等能通过各自账号登录系统进行相关操作。（2）实现系统功能的安全访问和操作 ：通过创建账号并设置角色权限，可对系统功能的访问进行控制。不同角色的账号只能访问和操作其被授权的功能模块，保障系统数据安全和业务流程的正常运行。（3）便于企业进行人员管理和业务管理 ：企业可通过 OMP 系统对创建的账号进行管理，包括账号的创建、修改、删除等操作。同时，根据业务需求为不同账号分配不同的仓库、客户等资源，实现对人员和业务的有效管理。
# 2.操作指引

（1）登录您的的OMP管理后台，导航至账号权限列表。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642671/8b555619)
（2）新建角色：定位至角色管理模块，点击新建角色。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643197/c41a24b7)
（3）创建角色：填写角色名称，分配角色权限并保存。角色可以理解为公司的不同岗位，如运营人员、拣货员等，每个岗位的职责不同，所需要的系统权限也不一样，可以根据岗位职责分配该角色需要的权限。需要注意的是，OMP系统和WMS系统的权限均在此配置，即需要OMP端为仓库的员工分配账号。关于角色管理详情可以参考该文档：[使用OMP管理角色 | 领星WMS帮助中心](https://help.xlwms.com/2f8e/a8f8/2327/05df)
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643100/1e23f93b)
（4）创建账号：导航至账号列表页面，点击新建账号进入创建详情页。 
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643251/ea48f3db)

- 姓名、账号、密码等信息可以自定义填写，标星号的为必填项，其中账号是全系统唯一的，如果您创建后提示此账号已存在，是因为对应账号被其他使用领星系统的用户创建了，建议您更换账号或者添加后缀创建再保存。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642852/79be6f1a)

- 绑定角色：请至少绑定一个角色，绑定角色后该账号就有角色对应的权限，一个账号可以绑定多个角色。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643005/f786453f)

- 绑定仓库：此处需要为对应账号绑定WMS可见仓库和OMP可见仓库，其中，WMS可见仓库关乎账号是否可以跳转对应仓库，以及登录WMS是否可以看见对应仓库；OMP可见仓库可以控制该账号看到哪些仓库下的订单、库存、费用等数据（包括页面数据和导出数据），需要对应账号在这个位置勾选绑定下对应OMP可见仓库，才能在OMP看到该仓库下单据。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643159/5d4c422c)

- 绑定客户：此处绑定客户后，对应账号在OMP中仅能查看已选择的客户（绑定物流渠道/渠道组黑白名单客户、全局设置前置计费除外，即上述操作中仍可选择全部客户）；WMS不限制。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643063/204bb713)
（5）批量设置账号安全保护：为了防止单一账密登录存在账号密码被盗刷、异地 / 陌生设备无拦截等风险，您可以为对应子账号开启账号安全保护，开启后，对应账号登录会触发安全校验，提示“设置MFA设备”。可以点击右侧单个为账号操作，或者点击上方批量设置。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642865/e10f4317)
（6）相关操作①修改密码：如果对应子账号由于多次输入密码错误导致被锁定/忘记了密码，可以操作为其修改下密码。
- 点击右侧操作按钮，点击修改密码。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642967/ea0c4688)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642898/1cd50ab7)
②停用账号：如果对应子账号暂时不需要使用，可以操作下停用账号。
- 点击右侧操作按钮，操作停用账号，对应子账号为停用状态。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643142/ac5db237)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642937/b809a355)
③删除账号：如果对应子账号不再使用，需要删除，可以操作删除账号。
- 点击右侧操作按钮，再点击删除账号，对应账号删除。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643226/2bfed21d)

# 3.补充说明

（1）名词解释：MFA设备：是用户绑定的手机号或邮箱，用于账号安全校验。主要应用于两个场景：
- 当账号安全保护开启时，用户在新设备登录需进行二步验证。
- OMP超级管理账号忘记密码时，可通过已验证的MFA设备完成身份核验自行找回密码。


# 4.常见问题

Q1：创建OMP的子账号提示重复是为什么？
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642492/612c8c7d)
**答案：OMP登录账号是领星全系统的校验，全系统内不能重复的，可以在后面加几个数字作为区分。******Q2：WMS子账号没有【快捷出库】的按钮，应该要开什么权限呢？**答案：在OMP管理后台-账号权限-角色管理，找到对应子账号绑定的角色，勾选WMS-一件代发出库里的【WMS直接发货】权限。**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233642672/5c195b61)
Q3：OMP子账号没有对应的仓库权限，为什么配置客户可用仓还是会显示全部的？**答案：只要在角色管理--OMP权限开启了“配置客户可用仓库”权限即可看到全部的仓库。**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785233643285/6b7cec74)

# 使用WMS实现新品维护


              
# 1.操作场景

**定义：**对新进入仓库的产品进行尺寸、重量的测量，并将数据录入系统的操作。**作用：**仓库端人员测量实物信息后进行新品维护，若仓库和卖家之间涉及仓租、物流费、操作费等计费，将以仓库端实际测量的尺寸重量数据作为计费依据。
# 2.操作指引

（1）进入WMS系统：登录您的WMS管理后台，导航至入库模块。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332491/f03faaed)
（2）进入新品维护菜单：点击新品维护按钮，进入新品维护页面。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332513/ea9a414d)
（2）维护新品尺寸重量：在新品维护页面可看到未测量产品数据，点击测量按钮进行维护。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332374/8aaf1e2d)
（3）填写实物尺寸重量：按照实物尺寸重量填写WMS规格信息（如果尺寸重量与客户维护的OMS规格信息一致，可点击引用OMS数据），点击公制英制按钮可以切换单位。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332586/a145dca9)
（4）确认数据：数据维护好之后点击确定按钮确认数据。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332676/5dee550d)

# 3.补充说明


## 3.1注意事项


- 单仓库场景：新品首次到仓收货时执行新品维护，仅需维护一次。
- 多仓库场景：新品在任意一个仓库首次收货时完成新品维护；后续该产品再入仓至其他仓库，无需重复维护。
- 特殊并发场景：若多个仓库同时发起同一商品新品维护，以先提交的仓库维护的数据为准。
- 若卖家对仓库测试的尺寸重量数据有异议，在与卖家商量妥帖后，可在OMP内的产品审核模块或者是WMS内的基础数据产品模块修改产品的WMS尺寸重量。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332546/b64e6dcc)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785140332323/a55b5c53)

- 新品数据会作为后续计费的基础数据，若仓库和卖家之间涉及到计费，请务必准确填写。

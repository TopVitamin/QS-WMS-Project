# 使用WMS处理退件


              
# 1.操作场景

**定义：**退件是指因各种原因从下游退回至上游节点（如从客户退回至商家，从销售端退回至仓库）的货物或物品，在我们系统中退件会形成产品库存。**作用：**对退件进行质检分级后，按其状态（可售、需翻包、需处理）采取相应措施，以实现资产价值最大化。
# 2.操作指引

（1）oms形成退件单，wms在退件待入库选择退件单去清点：由于是退件，所接收到的产品质量参差不齐，所以我们首先进行清点查看货物状态以及货物数量和客户预报是否一致。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1758796726177/a43ca244)
（2）选择清点：会有两个操作类型，到仓清点和到仓暂存。不管是到仓清点还是到仓暂存,都要开启到仓状态。这是对于货物到仓的一个记录，如果您设置按包裹数量计费，也是您收费的依据。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766732483108/image.png)
      1）选择到仓清点。那么就是对这个退件进行清点，看收到货物的sku种类和数量以及货物的质量状态。如果没问题可以正常上架出库的产品，我们就填写收到的正品；如果有问题的话，我们就填写收到的次品。实际收到的产品数量和种类可能和退件单上的不一致，我们实际进行填写以及添加新的产品sku，最终计费都以我们仓库实收的产品和sku数量为准 。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766732529668/image.png)
      2）选择到仓暂存。勾选到仓状态并选择暂存的库位，代表这个货物暂时先不进行清点上架，而是先暂时存放在仓库的某个库位。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766732597922/image.png)
（3）进行收货备注。比如说收到三个次品，在收货备注里填写、我们也可以把次品拍照上传，至于拍照费用跟客户协商讨论。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766732628782/image.png)
（4）清点之后就可以进行处理。如果是价值不高的或者质量严重有问题无法翻新的那么选择就地销毁。如果是价值比较高的可以维修的可以选择次品上架，次品上架形成次品库存，然后进行次品处理。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766732742269/image.png)
（5）使用PDA扫描未预报包裹时，可以直接创建退件单，无需客户认领流程。      1）在OMP-全局设置中配置可以直接在仓库创建退件单的客户。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1781252679631/image.png)
      2）扫描包裹物流跟踪号进入认领页面，可以直接选择客户，也可以拆包清点扫描SKU后自动定位到客户。若客户开启了上述权限，则进入退件单创建页面直接清点产品；若客户未开启上述权限，则仍进入创建认领单页面。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766659594125/image.png)

# 3.补充说明

（1）清点：主要是为了进行责任转移，要确定到的货是否和提单一致，以及箱子里是否有产品，产品是否有损坏等。（2）omp应收报价里的入库退件类型选择退件，处理方式可以选择上架或者销毁。所以首先您在收到退件之后一定要勾选到仓状态才能计费；其次上架销毁我们可以设置为自动计费，不一定要设增值费。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/c1757e46-f14b-4f1c-8be6-3037669274ac/1766732823922/image.png)

# 4.常见问题

Q1：wms端在处理退件的时候能修改退件类型吗？**答案：退件类型是由oms客户在下退件单时决定的，wms端不能进行修改。**Q2：我能选择让哪一类退件优先出库吗？**答案：可以的，在wms的设置这里去选择让哪种类型退件优先出库。**

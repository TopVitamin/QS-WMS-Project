# 如何设置分销商品的专属库存


              
## 1.操作场景

定义： 专属库存分配是 OMP 统一维护"分销商品指定客户可使用库存量"的能力，按「商品 + 仓库 + 客户」维度，把分销商品的部分库存定向分配给指定客户（货主或分销商）。作用： 默认情况下，分销商品库存由已认领商品的分销商共同使用，仓库无法把部分库存固定分配给指定客户。设置专属库存后，指定库存仅对应客户可使用，未设置的客户继续使用公共库存。适用场景：
- 分销商认领商品后，需要先支付定金或货款，仓库确认后再为其分配库存。
- 部分商品需要优先保障指定货主或分销商使用，剩余库存再由其他已认领客户共享。

库存关系速览：公共库存按当前库存实时计算：公共库存 = 仓库总库存 − 全部客户专属库存。
## 2.操作指引


### 2.1 添加专属仓库

登录 OMP 系统，进入【产品管理】→【分销产品】页面，找到目标分销商品，点击进入专属库存页面。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1788744455686/6565bfba)
点击【添加专属仓库】按钮，在弹窗内为指定客户分配专属可用库存量。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1788744455271/6087163b)
添加成功的已配置仓库，更新至专属库存页面内显示。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1788744455310/45f1da64)

### 2.2 导入专属库存

支持通过表格模板批量导入，增量更新仓库专属库存配置，适用于多仓库、多分销商的批量调整场景。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1788744455730/6d484800)

### 2.3 解除专属

针对不再需要专属库存的分销商，可执行【解除专属】操作；解除后该分销商将恢复使用公共库存。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1788744455465/0e9e9db2)

### 2.4 库存调整记录

专属库存的历史调整情况，可通过库存调整记录界面进行查看。

## 3.补充说明


### （1）名词解释


- 货主：商品库存的所属客户。货主与分销商均可设置专属库存，库存使用规则一致。
- 分销商：认领货主分销商品并使用库存进行销售的客户。
- 仓库可用库存：当前仓库中可用于出库及库存分配的库存量（SKU 实时可用库存量）。
- 锁定库存：已被订单占用、暂不可再次使用的库存。已设置专属库存的客户，OMS 仅展示自身订单产生的锁定库存。
- 专属库存：OMP 指定给某一客户独立使用的库存。客户拥有专属库存后，不再使用公共库存。
- 专属可用库存：当前客户剩余可下单使用的专属库存量，不包含已被订单锁定的库存。
- 专属客户：已在指定商品、指定仓库下建立专属库存关系的货主或分销商。专属库存为 0 时，仍属于专属客户。
- 公共库存：当前未分配为专属库存、可由未设置专属库存的已认领客户共同使用的库存。
- 公共库存客户：已认领商品，但尚未设置专属库存的客户，可直接使用当前公共库存。
- 待补充：客户已建立专属库存关系，但当前专属可用库存为 0，需 OMP 再次分配库存。
- 解除专属：取消客户当前的专属库存关系。解除后，剩余专属可用库存回到公共库存，客户恢复使用公共库存。
- 分销占用：货主 OMS 中表示当前被分销业务占用的库存。


## 4.常见问题

Q1：设置了专属库存的客户，还能用公共库存吗？答案：不能。客户拥有专属库存后，不再使用公共库存，仅使用自己的专属可用库存。即使专属库存用完（进入「待补充」状态），也不会自动恢复使用公共库存，需 OMP 再次分配或解除专属。Q2：如何让新认领商品的分销商暂时无法使用库存？答案：可将当前全部可用库存设为货主专属（此时公共库存为 0，分销商无库存可用）。待分销商付款后，再从货主专属库存中调整部分库存给对应分销商。Q3：调整专属库存时提示"专属库存合计不能超过仓库可用库存"怎么办？答案：说明调整后的专属库存总量超过了当前仓库可用库存。请减少调整数量，或先补充仓库实际库存，再重新调整。Q4：专属库存页面里为什么看不到某些仓库？答案：专属库存页面仅展示当前 SKU 已建立专属库存关系的仓库。仓库内所有客户均解除专属后，该仓库不再展示；可通过【添加专属仓库】重新配置（需该仓库当前 SKU 可用库存大于 0 且未配置专属关系）。Q5：添加客户时，为什么有些客户搜不到？答案：添加客户列表仅显示"已认领当前商品，且当前仓库内暂未分配专属可用库存的客户"。未认领该商品、或已在当前仓库分配了专属库存的客户，不会出现在添加列表中。Q6：WMS端是否支持调整专属库存？答案：暂不支持。WMS端管理的是仓库线下库存，如果线下库存实际低于已分配的专属库存量，需要先在OMP专属库存界面内手动重新分配。

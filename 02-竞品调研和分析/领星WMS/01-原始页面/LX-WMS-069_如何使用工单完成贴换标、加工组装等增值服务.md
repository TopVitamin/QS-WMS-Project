# 如何使用工单完成贴换标、加工组装等增值服务


              
# 1.操作场景

**定义：**当客户有库内加工的需求时（例如产品组装、拆分、翻新或贴标签），可以通过创建“关联库存工单”通知仓库。仓库人员完成工单后，系统将根据实际操作结果，自动更新库存数量，确保库存数据的准确性。**作用：**工单的完成状态是触发系统自动更新库存、生成财务记录等后续流程的关键信号。它确保了线下实际操作与线上数据记录实时同步，保证了数据的准确性。
# 2.操作指引

（1）进入WMS系统：登录您的WMS后台，导航至工单菜单。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607486/0eb37e22)
（2）维护工单类型：导航至工单菜单，点击工单类型管理。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607366/01685a76)
（3）创建工单类型：如果您需要创建的工单和库存是没有关联的，比如拍照、清点等，是否关联库存选“否”；如果您需要创建的工单和库存是有关联的，比如组装、产品调整等，是否关联库存选“是”。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607581/b07d5235)
（4）客户登陆oms下工单：选择“关联库存”工单类型后，首先会由客户提出具体的产品调整需求。待客户提交工单，相关SKU的库存将即刻被锁定，等待仓库处理。客户选择对应的增值服务，前提是已经在oms维护好单据类型为“工单”的增值服务。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607479/d8819e8d)
（5）审核工单：登录您的WMS后台，导航至工单-待审核状态，点击审核，再点击审核通过。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607263/77ac13b1)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607336/a7d3f608)
（6）处理工单：导航至工单-已审核状态，点击处理。客户预报的调整数量仅供参考，仓库可根据实物情况，在工单中填写实际拣货数量以及对应的增值服务，最终库存实际调整数量和工单计费以仓库实际调整为准。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607559/dbcb2445)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607682/23746c42)
（7）结算工单：导航至工单-处理完成状态，点击详情进入到详情页内，点击结算完成，工单即可自动计费。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607645/6550c79b)
在详情页内可点击到费用查看当前费用情况，如需修改可点击调整费用进行修改。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607052/6cb76786)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607362/41998d68)
（8）处理完成之后，点击库内-产品库存-库存流水，可以看到产品sku发生对应变化。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141606865/35b6de65)

# 3.补充说明

（1）组装：电商卖家将一套产品的多个零配件先运到海外仓库存放；当有顾客下单购买这套产品时，海外仓库的工作人员会根据指令，将这些零配件组装成一个完整的成品，然后再发给最终客户。（2）工单自动计费：如果您想要实现工单自动计费，需要先在应收报价操作费里，把单据类型为工单的增值服务维护进来，您oms客户在下工单的时候选择该增值服务即可实现自动计费。
# 4.常见问题

Q1：工单可以计算成本吗？**答案：可以的，只要您把单据类型为工单的增值服务维护进来，并填写了“应付计费变量”就可以。工单填写“应付计费变量”操作路径：登录您的OMP管理后台-报价设置-操作费设置-增值服务-应付计费变量和单价填写，可参考下图：**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607349/4abbc946)
Q2：我已经添加了增值服务，为什么客户下工单选增值服务时还是空白呢？**答案：您需要确认您的增值服务单据类型是否是工单，以及是否勾选了“OMS客户下单时，是否可勾选该增值服务”。**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785141607403/b6642cdc)

# 通过PDA实现盘点


              
# 1.操作场景

**定义：**仓库盘点是按计划对仓库内货品的数量、规格、质量、存放位置等信息实地核查，比对实际库存与系统库存记录，明确差异并记录的标准化操作。WMS端相关操作见使用WMS进行盘点**作用：**仓库盘点可精准修正库存数据误差，确保账实完全相符，为补货、出库、库存优化及成本核算提供可靠依据，同时防范货品丢失、损坏或积压问题。
# 2.操作指引

1. PDA-库存-新增盘点入口，点击后进入盘点列表页，可以看到待盘点和盘点中的单
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1789550257550/image.png)
2. 扫描和输入盘点单号后，会进入盘点单页，可以看到按库位排序后的SKU清单和对应的盘点状态
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1789550271157/image.png)
3. PDA提交盘点时，系统也会校验是否有锁定的库位库存，如果有，会显示【库存锁定】
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1789550282882/image.png)
4. 盘点操作页，会按照库位排序推荐拣货顺序，会展示目标库位上的待盘点产品，也可以更换当前库位。实盘库存支持扫描技术和手动填写数量。支持按库位提交
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1789550298108/image.png)
5. 当所有待盘点的SKU都盘点好后，点击提交，即可完成盘点单
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1789550316744/image.png)

# 如何给客户绑定销售代表、客服代表业务角色？


              
# 1.业务场景

许多公司中存在销售、客服等业务角色，他们负责客户拉新拓展、日常维护等工作，因此需要在系统中把客户和业务角色进行关联，方便在客户需要维护时及时找到负责业务人员，以及为相关人员核算绩效等作用。
# 2.操作指引

（1）创建业务角色：在OMP-权限&账号-创建角色（先创建角色、再创建账号）客服代表 权限可选择OMP权限：客户管理、产品审核、全局订单、工具模块等（可参考，具体权限的配置由您决定，第一次配置可以先将权限适当放大，后续再取消勾选不必要的权限）销售代表 权限可选择OMP权限：客户管理、全局订单等
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044415640/a19b5032)
（2）创建业务员账号：OMP-权限&账号-账号列表处进行创建姓名、账号（全局唯一，如出现重复提示可加字符、字母、数字等作区分）、密码等信息皆为自定义，并勾选上该业务员的角色。对应仓库、客户权限可做对应设置，如销售代表在客户权限中仅可见其负责的客户。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044415712/7bbfde47)

（3）客户绑定对应销售代表、客服代表a.OMP-客户管理-客户列表处，编辑或新建时，可对应添加上销售代表、客服代表
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044415945/59c30af3)
b.批量导入，批量创建客户时，可填入销售代表账号、客服代表账号
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044415852/3524b188)
c.已创建的客户，批量调整业务员进行批量绑定

# 3.补充说明

1.OMP-客户管理-客户列表处，可以通过销售代表、客服代表进行条件进行筛选，便于定位公司内业务员所负责的客户信息。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044416018/a780b9d5)
2.OMP-应收结算-业务费用处，也可作为条件项进行筛选，以快速找到该业务员下所属客户的业务费用单据。注意：您可在该页面中看到“历史销售代表”、“当前销售代表”、“历史客服代表”和“当前客服代表”；这里区别在于，例如历史销售代表为生成费用单据时客户绑定的销售代表；当前销售代表则为该单据所属客户当前所绑定的销售代表。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044415760/4b92e3e9)
3.OMP-应收结算-成本对账处，也可作为条件项进行筛选，以快速找到该业务员下所属客户的成本费用单据。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759044415806/e450e66b)

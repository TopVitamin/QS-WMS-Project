# 使用WMS处理直邮单


              
## 一、功能背景



跨境电商平台（如 Temu）的部分订单被标记为 **Y2 类型**，要求卖家将货物先发往国内仓库，由国内仓揽收后转运至海外仓，再由海外仓完成尾程换单出库，最终完成向买家的交付。

**直邮单**功能作为独立单据模块，完整覆盖从国内仓收货到海外仓换单出库的全链路，实现卖家和物流服务商的高效履约




## 二、核心价值



| 角色 | 核心价值 |
| --- | --- |
| 卖家 | 在 OMS 中一键将 Temu Y2 订单转为直邮单，全程可视化追踪国内段和海外段状态，无需手动跟进 |
| 国内仓 | 通过扫码完成签收、称重、发货，操作简单、状态清晰 |
| 海外仓 | 扫中性条码自动匹配直邮换单，打印尾程面单后一步换单出库 |
| 财务 | 系统自动触发两阶段计费，按报价方案精准结算，减少人工对账 |




## 三、全流程说明



### 3.1 前置条件


仅当租户在管理后台-全局设置中开启了直邮单设置，才会展示直邮单的相关操作本文章仅涉及直邮单（小包）的流程，如您还需要使用国内仓的小包装箱功能，也可前往查看[使用WMS处理装箱单](https://help.xlwms.com/12d0/d5f9/0c77/7ca9)
### 3.2 单据状态流转



直邮单共有以下状态，按操作节点依次流转：



| 状态 | 含义 | 触发条件 |
| --- | --- | --- |
| 待贴标 | 单据已生成，等待卖家打印中性条码 | 转单或导入成功后自动进入 |
| 待收货 | 卖家已送仓，等待国内仓签收 | 卖家点击【送仓】 |
| 国内已收货 | 国内仓已签收，等待确认发货 | 国内仓扫码签收 |
| 待换单 | 国内仓已发货，等待海外仓换单 | 国内仓确认发货（触发前置扣费） |
| 国外已出库 | 全部包裹完成换单出库（终态） | 海外仓全部包裹完成换单 |
| 已取消 | 单据已取消（终态） | OMS 取消或 WMS 截单 |



## 四、功能操作说明



### 4.1 【卖家端 OMS】生成直邮单



#### 4.1.1 路径1：平台订单手动转单



适用场景：卖家在 OMS 平台订单列表中，选中 Y2 订单后手动发起转单。



**操作步骤：**




- 进入 OMS → 平台订单列表

- 勾选需要处理的 Y2 订单（仅 Y2 标记的订单显示此按钮）

- 点击批量操作栏中的【转直邮单】按钮

- 在弹窗中填写：


- **发货仓库**（国内仓）：必填，从已绑定仓列表中选择

- **目的仓库**（海外仓）：必填，从已绑定仓列表中选择

- **物流渠道**：必填，仅展示支持上传面单的渠道

- 确认后系统执行校验，通过后自动生成直邮单




**注意事项：**




- 仅有授权Temu店铺的才会展示该按钮

- 所选订单必须全部为 Y2 类型

- 本期不支持分销 SKU，如含分销 SKU 将提示手动处理




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929134449/image.png)

#### 4.1.2 路径1：平台订单规则自动转单



适用场景：通过规则引擎，对命中条件（如订单标记 = Y2）的订单自动完成转单，无需人工逐单操作。



**设置步骤：**




- 进入 OMS → 系统设置 → 平台订单规则 → 新建/编辑规则

- 动作侧：选择新增的动作类型【转直邮单】，并配置发货仓、目的仓、物流渠道

- 规则生效后，命中条件的订单将自动生成直邮单




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929329444/image.png)

#### 4.1.3 路径2：手动导入直邮单



适用场景：卖家通过 Excel 模板批量导入直邮单，适用于平台外订单或需要手动管控的场景。



**操作步骤：**




- 进入 OMS → 直邮单 → 点击【导入直邮单】

- 下载导入模板，按要求填写

- 上传填好的 Excel 文件

- 导入成功后，系统生成直邮单，状态"待贴标"




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929392845/image.png)

### 4.2 【卖家端 】打印中性条码 & 送仓



直邮单生成后，卖家需要打印中性条码贴到包裹上，再点击送仓。



**操作步骤：**




- 在直邮单列表或详情页，勾选"待贴标"状态的单据

- 点击【打印中性条码】，在弹窗中选择编码类型（支持参考单号、直邮单号等），可附加发货仓、目的仓信息。可以在列表的【打印状态】查看单据是否已经打印中性条码

- 打印条码后将其粘贴到对应包裹上

- 确认无误后，点击【送仓】，单据状态变为"待收货"




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929423556/image.png)

### 4.3 【发货仓+目的仓】直邮单列表签收



列表页位于 WMS → 直邮→ 直邮单，以及管理后台-全局订单-直邮单

单据关联的【发货仓库】和【目的仓库】，在WMS中都可看到该单据

可以手动勾选签收，即变更单据状态为【国内已收货】



![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929519413/image.png)

### 4.4 【发货仓】签收称重



当卖家完成送仓后，国内仓操作员通过扫码完成签收，可选同步录入重量。



**操作步骤：**




- 进入 WMS → 直邮单 → 签收称重

- 国内仓扫描包裹上的中性条码（支持直邮单号、平台单号、参考单号、物流跟踪号等）

- 系统展示单据基本信息（直邮单号、平台单号、客户、目的仓、重量）

- 如已开启"签收后立即称重"，扫码后光标自动跳至重量输入框，录入重量后完成签收

- 单据状态变为"国内已收货"




**设置说明（齿轮图标）：**



| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 签收后立即称重 | 开启 | 扫码后自动跳至重量输入框 |
| 签收后立即发货 | 关闭 | 开启后签收即自动进入"待换单"状态 |




如平台订单已取消，扫码时系统将弹窗强提示，操作员可选择继续、前往处理或取消。




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929576137/image.png)

### 4.5 【发货仓】确认发货



签收完成后，国内仓操作员确认发货，系统触发前置扣费。



**操作步骤：**




- 进入 WMS → 直邮单列表，筛选"国内已收货"状态的单据

- 勾选需要发货的单据，点击【确认发货】

- 单据状态变为"待换单"，系统自动触发前置扣费





也可在签收称重操作页开启"签收后立即发货"，签收时即自动进入待换单状态。




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776929595207/image.png)

### 4.6 【发货仓 WMS】导入更新包裹后发货



操作步骤：




- 进入 WMS → 直邮单列表

- 点击【导入更新包裹】

- 如勾选【导入后自动发货】，即可自动发货




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1781256492330/image.png)

### 4.7 【目的仓】换单出库



包裹到达海外仓后，操作员通过扫码完成换单出库，打印尾程面单。



**操作步骤：**




- 进入 WMS → 直邮单 → 换单出库

- 目的仓扫描包裹上的中性条码

- 系统仅可匹配"待换单"状态的直邮单：

- 全部包裹换单出库后，单据状态自动变为"国外已出库"，系统自动结算扣费，并生成费用单据





换单界面同时支持扫描一件代发出库单和直邮单的单号，系统自动区分单据类型。




![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/36e61c34-115d-4aa0-be3f-486a0640abad/1776930526146/image.png)

### 4.8 取消与截单



#### 4.8.1 WMS 端截单（适用"待收货 / 国内已收货 / 待换单"状态）




- 在 WMS → 直邮单列表 → 操作 → 点击【取消】

- 二次确认后提交

- 单据状态变为"已取消"，关联平台订单同步取消

- **费用处理**：


- 待收货 / 国内已收货状态截单：未产生费用，无需额外处理

- 待换单状态截单：已冻结的前置扣费由系统自动返还至客户余额




#### 4.8.2 平台取消自动拦截



当 Temu 等平台买家取消订单时，系统联动处理如下：



| 直邮单当前状态 | 系统处理方式 |
| --- | --- |
| 待贴标 | 自动取消，操作人记录为"平台自动取消" |
| 待收货 / 国内已收货 / 待换单 | 不自动取消，在列表和详情中显示 ⚠️ 预警图标，提示操作员手动处理 |
| 国外已出库 / 已取消 | 终态，不作额外处理 |



### 4.9 计费说明



直邮单采用**两阶段计费**模式，报价方案按**发货仓（国内仓）+ 客户**维度匹配。

单据状态从【国内已出库】变更为【待换单】时，系统将自动根据单据详情（例如根据包裹重量）前置扣费，单据完结后最终结算并生成费用单据。



**报价方案配置入口**：OMP → 应收报价 → 报价方案 → 操作费 → 出库操作费 → 出库类型 → 新增"直邮单"选项




注意：直邮单虽然有发货仓和目的仓两个仓库，但报价方案仅锚定**发货仓（国内仓）**进行匹配。

## 五、常见问题



**Q1：转直邮单时提示"仅Y2订单支持该操作"？**

A1：请检查所选订单中是否混入了非 Y2 标记的订单，需确保勾选的全部为 Y2 订单后再操作。



**Q2：海外仓扫码后提示"面单待获取"？**

A2：尾程面单尚未从平台获取到系统，通常需要等待一段时间（Temu Y2 约需6天），获取后系统将自动更新，届时重新扫码即可。



**Q3：直邮单取消后，客户余额什么时候会返还？**

A3：在"待换单"状态截单后，已冻结的前置扣费由系统自动返还至客户余额，无需人工处理。



**Q4：同一个客户既有 Y2 也有非 Y2 订单，会互相影响吗？**

A4：不会。直邮单和一件代发出库单是完全独立的单据链路，通过 OMP 租户级开关控制功能可见性，同一订单不可同时生成两种单据。



**Q5：我的面单购买错误，想重新下单怎么办**

A5：在【待贴标】状态下可以自己取消订单，其他状态下可以联系仓库取消订单。取消订单后，平台订单状态会进入【已取消】，在已取消下转【待处理】重新下单即可

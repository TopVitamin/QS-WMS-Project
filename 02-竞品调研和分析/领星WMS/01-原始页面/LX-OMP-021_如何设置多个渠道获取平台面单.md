# 如何设置多个渠道获取平台面单


              
# 1.操作场景

定义：上传物流面单，一般指使用平台面单或者客户自供面单，无需配置物流费（物流费指快递的费用，不包括库内操作费和出库费），可用于获取平台面单或手动上传面单，是贴在包裹上的信息标签，包含收发货人、地址和物流单号等关键信息，方便快递公司准确分拣和派送包裹。作用：目前领星WMS系统中，存在一条系统默认渠道名为“上传物流面单”（Upload_Shipping_Label）是可以自动获取平台面单的渠道，但是如果仓库希望在面单水印设置时，根据不同的承运商进行区分，就需要设置多个渠道。目前支持拉取平台面单的平台有：Temu, Tiktok, Shein, Mercado, Shopee, Lazada, Wayfair。
# 2.操作指引

（1）创建一个虚拟的物流商：OMP-物流管理-物流商账号-添加授权-自定义物流商-点击下一步。（2）账户名称：可自定义，仅用于区分物流商账号。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759041930314/c6f8bf76)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/870e52cb-ae00-4da1-a5f0-30a966e55a43/1759041930575/38f2b1a5)
（3）新建物流渠道：可在物流商账号右侧操作-下拉新建渠道；或是新建物流渠道（白色按钮）进行创建。（4）新建物流渠道中，选择刚刚创建的物流商，注意物流渠道代码和物流渠道名称，客户在OMS下单时可以看到，且物流渠道代码创建时不可修改。建议物流渠道代码和物流渠道名称体现承运商信息，如upload-usps等。

# 3.补充说明

客户在OMS下单时选择该渠道，将不需要再选择承运商。

# 4.常见问题

Q1：物流渠道创建好后，客户无法在平台订单-分配仓库&物流时，无法选到新创建的物流渠道是为什么？答案：该物流渠道，没有绑定仓库，或是该物流渠道对该客户设置不可见。在OMP-物流管理-物流渠道列表内进行编辑，检查绑定仓库、绑定客户。Q2：选择新建的物流渠道后，无法获取到平台面单是为什么？答案：1.客户是否已经在平台上购买物流面单，让客户在平台上进行确认。目前支持拉取平台面单的平台有：Temu, Tiktok, Shein, Mercado, Shopee, Lazada, Wayfair，其他平台暂不支持获取。2.检查新建的物流渠道内，是否开启校验面单，平台面单获取的按钮。

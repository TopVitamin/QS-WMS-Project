# Temu美区联运面单在系统如何设置对应渠道进行区分？


              
# 1.操作场景

定义：Temu 美区联运面单，是 Temu 美国站点（美区）针对 USPS 尾程渠道推出的特殊物流标签，面单带有0024专属标记，实行 “指定揽收商中转 + USPS 尾程派送” 的联运模式，需根据仓库地址邮编交给指定揽收商（SpeedX 或 SwiftX），再转 USPS 尾程派送，不可直接交 USPS 揽收。作用：本文档将说明多种来源的Temu订单应当怎么设置对应渠道让客户选择，以便仓库能够通过渠道区分Temu联运订单，以及仓库如何去筛选对应订单，避免交货错误。
# 2.操作指引

### （2）做Temu物流渠道映射

将上一步创建好的自定义渠道点击编辑，进行Temu物流渠道映射，和平台的USPS 0024渠道做好映射。Temu智能推单或合作仓推单的方式都可以通过Temu渠道映射，针对Temu渠道直接配对一个系统的自定义渠道，配置后Temu订单使用对应的渠道推单到OMS，会直接使用配对好的系统渠道。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1778232230276/d35147de)

### （3）WMS按渠道筛选订单进行处理发货

仓库的WMS端处理订单时，筛选单独设置的使用联运面单的自定义渠道，针对这部分订单单独处理并交付给仓库所在邮编对应的揽收商，避免交付错误。

## 2.2 普通平台拉单模式


### 设置波次规则

通过设置波次规则区分Temu使用USPS的订单进行单独生成波次拣货交付。（注意：此方案只是建议方案，非完全适配）OMS客户无法百分百分配准确的渠道去获取对应的USPS0024面单，仓库端处理时可以根据销售平台和跟踪号开头去创建波次规则并生成波次，对应这部分订单操作拣货打印面单后确认是否有携带0024字样，有的就拣货出库后交付给对应的揽收商，没有的话需要正常交付给USPS。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1778232228976/7e60698c)
非完全适配原因：即使发货地址邮编在册的仓库，使用Temu的USPS官方面单，也不一定是USPS 0024渠道，可能有其他USPS渠道（正常交付给USPS的），所以如果走普通平台拉单的情况，只能通过【跟踪号和销售平台】规则区分出USPS的订单，并对应生成波次、操作拣货打印面单后确认面单是否有携带0024字样，从而判定该订单是否联运。
# 3.常见问题

Q1：Temu在OMS授权店铺后是否就可以直接在OMP做Temu渠道映射，让订单自动分配仓库设置了的联运渠道？答：目前只有Temu开启了智能推单并授权在OMS的店铺或者使用合作仓推单模式的店铺支持做Temu渠道映射，普通的授权拉单模式是不支持的，需要手动或者设置平台订单规则分配具体的渠道。Q2：普通拉单模式如何能够百分百准确对应交付？答：如果是美区半托管跨境店铺，建议直接走智能推单功能，不走普通拉单模式，比较能够确保准确。普通拉单模式目前暂时无法完全确认准确筛选。

# 使用OMS创建工单


              
# 1.操作场景

**定义：**工单是仓库端与 OMS 运营沟通的线上工具，替代微信线下沟通，通过规范流程传递需求、反馈问题。**作用：**用于仓库与 OMS 运营高效协同，涵盖业务咨询、异常反馈、需求提报等场景。本章将指导您如何通过 OMS 系统创建工单，实现标准化沟通。
# 2.操作指引

(1）进入OMS系统：登录您的OMS管理后台，导航至仓储服务菜单。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142695083/eb48823b)
(2)  新建工单：导航至工单菜单，点击新建工单。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142694959/911b87b4)
（3）填写基础信息：在新建页面，您可以自定义填写工单标题，选择执行仓库，并选取此次工单类型以及紧急程度（普通/紧急）。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142691942/4cfcb9f3)

### 常见工单类型

a. 关联库存的产品调整单：是您在需要修改产品相关信息时，需要提交的专项工单。比如您想改产品名称、更换产品SKU 、调整产品库存，都可以通过提交这份工单走流程处理，确保系统里的产品数据和您的实际需求保持一致。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142692130/a8e64fde)
b. 拍照（无需关联库存的工单类型）：是您有货物拍照需求时（比如想确认仓库里产品的外观、包装状态，或是需要产品细节图用于核对），提交给海外仓的专项工单。您提交后，仓库会按照您的具体要求（比如拍产品正面、包装标签等）完成拍照，之后将照片反馈给您，帮您直观确认货物的相关情况。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142692531/bdc613a7)
（4）提交工单：信息确认无误后，点击提交按钮，系统将根据您提交的信息，创建工单。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142692734/37a4bc26)
（5）工单进入待审核状态：工单创建成功后，系统将自动将其状态更新为待审核。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142695017/bd9035a2)
（6）提交后操作（可选）：提交后您可以对应查看工单详情，并且编辑/取消该工单。
- 工单在待审核、已审核状态支持在联系仓库处上传附件和内容，处理完成状态不支持，作废状态可二次编辑除执行仓库外的信息。
- 工单只有在待审核状态下支持编辑工单。


![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142694936/cdec08e5)

![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142693090/6b735cd3)
（7）状态更新跟踪：仓库操作会触发OMS状态自动流转，可自行追踪工单执行情况。已审核：仓库已审核该工单。处理完成：仓库已处理该工单，工单处于完结状态。作废：该工单由于仓库拒绝或者您主动取消，处于作废状态。（8）查看仓库反馈&回复沟通：点击工单进入详情页后，在页面下方可查看仓库回复记录、附件、您选择的增值服务、相关费用及历史操作记录。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142691466/4dd54e9b)

# 3.补充说明


### 3.1名词解释

工单状态全部：汇总展示所有创建的工单及其状态（用于筛选查询）。待审核：工单已提交但未进入处理环节，需审核人员确认工单信息是否合规、需求是否合理，审核通过后才会往下流转。已审核：工单经审核人员确认无误（信息合规、需求合理），已通过审核，将进入后续处理环节。处理完成：工单对应的需求 / 问题已全部解决（如任务执行完毕、故障修复、诉求响应到位），流程已收尾，无需进一步操作。作废：工单若存在信息错误（如重复提交、内容无效）、需求不合规 / 不合理被拒绝或需求取消，会被判定无需处理，流程直接终止且不进入后续环节。
# 4.常见问题

Q1:工单附件可以上传压缩包吗，文件不能超过多大？**答案：可以，不能超过10M。**Q2:工单附件支持视频吗？**答案：支持。**Q3:为什么在联系仓库那里上传了附件，仓库看不到？**答案：需要点击下方回复仓库才能看到。**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785142691661/5f132c90)
Q4:随时都可以在联系仓库上传附件吗？**答案：工单在待审核、已审核状态支持在联系仓库处上传附件和内容，处理完成状态不支持，作废状态可二次编辑除执行仓库外的信息。**

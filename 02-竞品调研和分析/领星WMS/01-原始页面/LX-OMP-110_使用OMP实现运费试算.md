# 使用OMP实现运费试算


              
# 1.操作场景

**定义：**OMP 中运费试算是在设置好报价方案之后，用以试算费用的。**作用：**可以快速判断已经设置的报价方案，是否有设置正确了，如果试算的费用跟仓库的报价方案不一致，可以及时的调整
# 2.操作指引

（1）进入OMP系统： 登录您的OMP管理后台，导航至工具模块菜单，点击费用试算。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785463544331/57ffc713)
（2）进行试算：填写对应的信息后点击试算，带星号的是必填项，不带星号的是非必填项。
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785463792788/image.png)

# 3.补充说明


### 3.1名词解释


- 住宅地址：住宅地址指的是快递包裹的最终投递地点为私人住宅、家庭住所或非商业性质的地址。


### 3.2注意事项


- 处理引用物流商报价的情况 ：引用物流商报价的，需要将对应的收件信息填写完整去试算，物流商需要完整的收件信息进行试算，且引用物流商报价的运费只会展示一个基础运费，不会分开展示运费和附加费。
- 检查分区信息匹配情况 ：若运费试算显示未检测到分区信息，就说明试算的时候，使用的地址跟已经设置的物流费里的分区信息不匹配，需要确认地址的正确性还有分区的设置是否规范。可以在OMP测试物流费分区查看确认，操作路径：登录OMP管理后台-工具模块-测试物流费分区-填写对应信息-点击搜索。

- 如果您是手动的选择SKU，需要填写数量之后，才可以进行试算

# 4.常见问题

Q1: 试算没有价格？**答案：试算失败的渠道，渠道前会显示一个橙色的感叹号，可以点击感叹号看到试算失败的原因。**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785463543853/70c34322)
Q2：试算的时候显示的计费重跟实际计费的时候，取值的计费重量不一致是为什么？**答案：物流费里有设置重量进位的，这种情况下，实际计费的时候，使用的计费重向上取整进位后的数值，费用试算里显示的是进位前的重量。**
![图片](https://saas.bk-cdn01.com/t/a7eea466-35ce-488d-ba1e-c9c1fe9a6db4/u/e5b7ee59-f680-481e-b0da-5daef37e6528/1785463543862/2a535eb0)
Q3:运费试算的时候，可以试算出附加费吗？**答案：可以的。**

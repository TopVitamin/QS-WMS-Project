# 如何授权通途ERP


              
## 1. 
    操作场景

定义：通途 ERP 当前仅支持通过 “启用第三方物流” 的方式实现订单同步至领星 OMS，因非 ERP 方主动对接领星 OMS 的 API 接口，暂无法像领星 ERP、聚水潭 ERP 等主动对接类 ERP 一样，实现入库单、一件代发出库单、退件单的直接推送以及渠道、产品、库存的自动同步。作用：同步通途 ERP 中已分配指定第三方物流的订单，以便在领星 OMS - 平台订单模块分配实际发货的仓库及物流，审核生成一件代发出库单并通知仓库完成出库作业，同时回传仓库提供的跟踪号。

### 2.2. 
     绑定物流渠道

如需将ERP的平台面单推送领星OMS，请补充【绑定物流渠道】，如果仅使用仓库面单，则跳过这一步。路径：基础设置 - 仓库设置，选择星链海外仓 - 选择邮寄方式（渠道） - 单击“绑定物流渠道”。

将平台物流渠道和该邮寄方式进行绑定。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1768903901848/MTMxMDI2OTk4ODg3NDc2MDI_624501_jqEvQ1AUfEBOoIbw_1768823927)
如果有多个平台物流渠道的面单需要推送领星OMS，请先操作“复制”邮寄方式，再对应绑定对应的平台物流渠道。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1768903901764/MTMxMDI2OTk4ODg3NDc2MDI_496996_BoCcqhd_eraFlSp__1768823927)

    分配库存

## 常见问题


#### Q1：通途ERP订单报错“上传失败：获取物流跟踪号超时，需重新获取“


![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1768903901853/MTMxMDI2OTk4ODg3NDc2MDI_491321_q3i-AihDEn-JQOQ6_1768823927)
答案：报错原因为通途ERP的订单在操作上传后，在规定的时间范围内，未能获取到领星OMS系统回传的跟踪号信息。①先确认，通途ERP订单是否有同步至领星OMS，如果未同步，需要检查领星OMS的授权信息与通途ERP后台的是否一致，确认一致后重新在通途操作上传；
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1768903901918/MTMxMDI2OTk4ODg3NDc2MDI_830386_Pj4WqnLYiuDn4u-s_1768823927)
②订单已同步至领星OMS后，确认当前OMS的订单状态，可以与领星海外仓人员确认仓库配置的标发节点，当前的订单状态如果不符合标发节点，则无法自动回传跟踪号。客户可以手动点击“标发”，确认通途店铺后台是否有更新上传状态。
![图片](https://saas.bk-cdn01.com/t/60d51478-7477-413d-a08c-4756ff2b94c3/u/7f819745-0ec5-4131-abe0-4c5cc7689a72/1768903901952/MTMxMDI2OTk4ODg3NDc2MDI_742391_f7rzavTgfRm3vhRz_1768823927)

#### Q2：领星OMS可以使用多个物流渠道，为什么通途ERP授权星链海外仓后只有一个物流渠道？

答案：当前的对接模式非通途 ERP 方主动对接领星 OMS 的 API 接口，暂无法像领星 ERP、聚水潭 ERP 等主动对接类 ERP 一样，实现OMS渠道/产品/库存等信息的同步。如需实现同步，请联系ERP方主动发起对接领星OMS的API接口，接口文档可参考：[查询渠道信息](https://apidoc-oms.xlwms.com/reference/getproductforpageusingpost)

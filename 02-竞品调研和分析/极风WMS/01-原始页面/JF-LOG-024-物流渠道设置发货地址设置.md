# 物流渠道设置发货地址设置

**一、定义**

有些物流商的物流渠道要求指定仓库地址才能使用，可以针对不同渠道设置发货地址，这样卖家在发货时选择这个物流渠道会对发货地址进行验证**。**

 **二、操作流程**

有三种方式可以**增加发货地址**，分别是在业务设置、物流商管理列表和物流商渠道管理列表。接下来就分别看一下：

**第一种：通过业务设置，设置发货地址**

**操作路径：设置-基础设置-发货地址**

**字段说明**

| 字段 | 说明 |
| --- | --- |
| 发件人(姓) | 必填，限制50字符 |
| 发件人（名） | 必填，限制50字符 |
| 电话 | 必填，入框限制输入50字符，如果填写至少6个数字，只允许数字和英文符号 |
| 邮箱 | 必填，限制50字符 |
| 公司名称 | 非必填，限制100字符 |
| 国家/地区 | 必填，下拉单选 |
| 省/州 | 非必填，下拉选择，选项与选择的国家对应，当选择的国家没有可匹配的省时，变为输入框 |
| 市/府 | 非必填，下拉选择，选项与选择的国家对应，当选择的国家没有可匹配的省时，变为输入框 |
| 区/县 | 非必填，下拉选择，选项与选择的国家对应，当选择的国家没有可匹配的省时，变为输入框 |
| 街道 | 非必填，限制100字符 |
| 门牌号 | 非必填，限制50字符 |
| 邮编 | 必填，限制50字符，且格式要正确xxx@xxx.xxx格式 |
| 地址1 | 必填，限制200字符 |
| 地址2 | 非必填，限制200字符 |

#### 
**第二种：物流商管理列表增加发货地址（针对这个物流商下所有渠道生效）**

![image.png](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260525122153/263956f5b26efcf0c792f7c88c7802c4.png)

![图片](https://download.jfwms.com/prod/static/back_help/img/74/20250603064353/c50b847d87633218cb2b127e7ea6c0d5.jpg)

（1）仓库选择：必选，下拉多选，下拉选项为有权限的仓库名称​

当所有有权限的仓库都设置过发货地址时，仓库下来选项为空​

（2）地址选择：必选，展示已在发货地址设置中添加的发货地址，若没有，则显示以下提示，点击“可前往发货地址设置页面添加”，

确定发货地址之后，该物流商下的所有物流渠道在该仓库下使用的时候，就使用该地址作为发货地址

即物流商可以针对不同仓库使用不同的发货地址，根据仓库去判断渠道用哪个地址

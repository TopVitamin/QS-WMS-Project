# 使用千易ERP的客户，如何对接极风WMS

# 1、获取**AccessId和SecretKey:**
打开极风OMS系统，前往：设置》ERP授权》千易，点击获取AccessId和SecretKey:

![image.png](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260603032654/cb4d2a88eaf6eaf91c8599e0a3b0d581.png)

![image.png](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260603032740/7f41a6519c63d45fb212afb6ce889f71.png)

# 在弹窗中复制AccessId和SecretKey:

![图片](https://download.jfwms.com/prod/static/back_help/img/3/20250410111151/6195f86d114cbe700a3139431f9dd08b.jpg)

#  2、打开千易ERP,在【系统】-【仓库管理】界面搜索“极风海外仓”

![图片](https://download.jfwms.com/prod/static/back_help/img/3/20241031125421/a8c653703c67d64ebd9c953cb64db17e.jpg)

## 2、点击[授权]按钮，输入AccessId和SecretKey:

![图片](https://download.jfwms.com/prod/static/back_help/img/3/20241031125422/ca7b698f73f20283dead5f80508b3b37.jpg)

![image.png](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/81/20260729060017/ab2bd49f5a1d8e5db04d6eccddcb29f8.png)

# 3、完成基础配置，仓库编码可以从极风WMS中查询

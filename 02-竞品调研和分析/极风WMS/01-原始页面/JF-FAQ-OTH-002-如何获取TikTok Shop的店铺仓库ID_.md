# 如何获取TikTok Shop的店铺仓库ID?

1、在授权TK店铺时，如需指定同步店铺内的部分订单，请选择&ldquo;指定店铺仓库订单&rdquo;。并确认店铺后台有设置发货仓库（店铺后台的仓库设置与OMS实际发货仓库无关，仅用于同个店铺授权多个不同OMS系统账号时分开同步订单）

![图片](https://download.jfwms.com/prod/static/back_help/img/3/20250226084927/2f73854b002d12d4deb47b4f0588ee1b.jpg)

 

2、店铺仓库ID以卖家中心的订单详情页内的为准。注意：如果填写错误，系统会默认同步所有订单！

![图片](https://download.jfwms.com/prod/static/back_help/img/3/20250226085200/b7a1543789d76ee88db969851096c648.jpg)

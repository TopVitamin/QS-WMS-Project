# MVP系统架构设计

本目录将已确认的需求与业务规则展开为系统对象、流程、状态、权限和消息设计。当前文档可供设计走查；字段清单已整理为六个模块的初稿，13列详细稿已归档、待字段取舍定稿后重建；完整研发交接还需细化字段样例、页面与演示数据，进度见[MVP入口](../README.md)。

**一期形态与演示边界**（课程沙盘、Mock 协作、非生产接口与设备、原型不反向覆盖已确认设计）见 [04-系统边界与上下游链路总览](04-系统边界与上下游链路总览.md) 第一节与第六节。业务目录 [上游协作与结果交接设计](../../../04-业务分析和设计/05-上游协作与结果交接设计.md) 管协作规则；本目录 [05-全局机制与权限配置](05-全局机制与权限配置.md) 管权限与公共机制。

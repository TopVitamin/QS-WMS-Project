## 二、时间口径（三层分开）

| 层 | 口径 | 系统落点 |
| --- | --- | --- |
| 存储 | 业务时间一律 UTC+0 | 业务时间字段、操作留痕、回传消息时间戳 |
| 业务判断 | 按**业务所属仓库**当地时区 | 履约 48 小时起算与截止；效期与临期/过期；盘点跨日过期转不良 |
| 展示与导出 | 用户所选展示时区，只改显示与导出 | 列表、详情、操作记录、导出文件标注时区；**不作为**业务判断依据 |

履约自**有效接收出库指令**起，按所属仓库当地业务时间加 48 小时（一期课程参数，非真实渠道承诺）。接收后的缺货、盘点等待计入；拒收不计时。超时不自动取消、释放或强制缺量。效期按当地业务日期判断；切换展示时区不改变截止或效期结果。

## 三、语言与展示

- 界面支持中文、英文，覆盖管理端与 PDA；术语中英对照与单号规则见全局背景《单据术语与生成规则》。
- 业务字段名、单据名与状态名保留项目口径，不随翻译变形。
- 库位编码、SN、批次号等标识符原样存储与展示。

## 四、权限点与默认角色矩阵

一期两层分开：**数据范围**按仓库授权（授权仓内可见全部货主，不做货主级账号隔离）；**动作**按角色控制菜单与操作。

| 配置项 | 内容 |
| --- | --- |
| 仓库数据范围 | 用户可授权多仓；未授权仓不可见 |
| 菜单与目录 | 一级、二级菜单按角色显隐；菜单基线见《系统与模块地图》附录 |
| 动作权限 | 无权限则入口不展示或不可执行，服务端同样校验 |
| 无主货可见范围 | WMS 内仅所在仓库授权用户可见登记记录 |

**默认矩阵（可按环境调整角色名，不按岗位名称硬编码）：** 关键确认集中于「仓库主管」；作业与常规收发确认独立配置。

| 权限点 | 所在端 | 关联动作 | 岗位配置 |
| --- | --- | --- | --- |
| 收货完结确认 | 管理端或 PDA | 入库单收货完结 | 常规收货确认，独立配置 |
| 新品维护（量方） | 管理端或 PDA | 首次到仓 SKU 写入仓内规格，阻断该 SKU 首次收货 | 入库作业权限，独立配置 |
| 收货执行 | 管理端收货作业台或PDA | 拒收数量与原因、实收数量、实收内良品/不良；追溯采集；两端共用同一收货记录与权限校验 | 入库作业权限，独立配置 |
| 在库受损品质确认 | 管理端或 PDA | 含上架前发现的未登记残损（先按原品质上架，再在目标库位转不良）和复核发现的已拣残损（在出库暂存库位转不良后再退拣）；盘点中的 SKU 不能转换 | 仓库主管 |
| 缺货单重新分配 | 管理端或 PDA | 对已接收有效单补预占缺口，已开始拣货的生成补拣任务 | 出库作业权限，独立配置 |
| 上架／移库执行 | 上架：PDA 或管理端 Web 端上架页；移库：PDA | 保存／删除未提交上架明细、整单提交移库；移库一次提交 | 作业权限，独立配置 |
| 拣货、复核与返库上架 | PDA | 拣货、复核与退拣、返库上架 | 作业权限，独立配置 |
| 确认出库 | 管理端或 PDA | 上游来源出库确认 | 常规出库确认，独立配置 |
| 无主货登记 | 管理端或PDA | 登记线索，不认领、不建入库单 | 入库登记权限；一期无认领权限；入库取消由上游消息受理，不设 WMS 手工取消入库 |
| 手工其他出库创建 | 管理端 | 依据线下邮件创建 | 创建权限，独立配置 |
| 手工其他出库确认 | 管理端 | 指定实物足量确认扣库 | 仓库主管；**不**被普通确认出库权限自动覆盖 |
| 盘点发起／实盘录入 | 管理端按计划创建，PDA 发现账实不符后发起；PDA 实盘 | 选 SKU、清点或扫 SN | 盘点作业权限，分别配置 |
| 盘点差异确认与取消 | 管理端 | 核实差异后直接调账；建错或盘不了时取消 | 仓库主管 |
| 波次创建 | 管理端 | 同仓同货主 B2C 基础波次 | 出库组织权限，独立配置 |

- 有权限仍须满足状态、数量、归属、品质、效期等业务校验。
- 一期不配置认领权限；入库取消仅接受上游消息（零实收），WMS 不提供手工取消入库或零实收完成结案。
- 角色可兼任；关键确认不引入审批流或双人复核。

用户、角色、操作记录字段见「字段清单合集·公共能力」。权限点字典一期只读；角色菜单/动作与用户仓库授权可配置，变更挂操作记录。

## 五、操作留痕清单

关键动作记录操作者、UTC 时间、原单与结果；与业务事实记录并存，**不可编辑**（见《单据与状态流转》现场记录规则）。

| 动作 | 留什么 | 位置 |
| --- | --- | --- |
| 收货提交 | 拒收与实收、实收内良品/不良、容器与追溯、操作者与时间 | 收货记录 |
| 上架保存与提交 | 应上架行、目标库位、数量及SN归属；保存占位不动库存，提交移库 | 上架单、操作记录；提交时库存流水 |
| 盘点差异确认（含暂存丢失盘亏） | 快照、实盘、差异依据 | 盘点单与库存流水 |
| 在库受损品质确认 | 原品质、位置、原因、新品质、通知结果 | 库存流水与操作记录 |
| 缺货单重新分配 | 原单、缺口、预占与分配变化、结果 | 出库单与操作记录 |
| 新品维护 | 实测规格、操作者与时间 | 新品维护记录与商品仓内规格 |
| 无主货登记 | 仓库、位置、线索、登记人与时间 | 无主货登记记录 |
| 出库取消（接受/拒绝） | 结论、原因；已拣时生成的返库上架单 | 出库单、返库上架单与操作记录 |
| 手工其他出库创建与确认 | 邮件依据、指定实物、确认人时间 | 出库单（手工来源） |
| 发起盘点 | 来源、发现环节、库位、差异依据、发起人；差异待核对关联原业务记录，主管确认盘点完成时解除 | 盘点单与原业务记录 |
| 退拣与返库上架 | 原出库单、退拣原因（取消、残损、少件）、应返库与实际返库 | 返库上架单与库存流水 |
| 收货完结与入库取消 | 完结确认人时间；取消消息、受理时间及原因 | 入库单、上游消息记录与操作记录 |
| 上游请求处理 | 每条消息的接受/拒绝/冲突结论 | 上游消息记录 |
| 确认出库 | 确认人、时间、交接对象与凭证 | 出库单与出库交接 |

查询入口：系统设置「操作记录」及各单据详情。

## 六、重复提交与结果重交

管理端与 PDA 对同一动作、同一确认重复提交，只返回已有结果，不重复扣库或改账。

上游消息去重、冲突与送达失败只重交已有结果，语义见《接口与 OMS Mock 消息设计》。

## 七、业务校验不能由权限绕过

动作权限不能替代状态、归属、品质、效期、数量、盘点等校验。数量与不重复记账见《实体对象关系》一致性约束；资料停用与变更见基础资料规则。一期不提供「直接改库存」的授权入口。

## 八、参数项清单

| 参数 | 性质 | 一期 |
| --- | --- | --- |
| 履约时限 | 48 小时，自有效接收出库指令起算 | 技术配置；后续可按渠道扩展 |
| 效期三天数 | 商品级：允许入库≥临期≥过期 | 商品资料，按仓库当地日期判断 |
| SN 唯一身份 | 货主＋SKU＋SN，四仓共用 | 库存维度规则 |
| Mock 重试间隔 | 技术参数；不改变单次生效语义 | 见消息设计篇 |
| 系统参数页 | 不提供业务维护页 | 菜单后置，走技术配置 |

仓库业务时区使用支持夏令时的时区标识，预置值随四仓仓库资料与演示地点校验，不用固定 UTC 偏移代替当地业务日。

## 出库页面权限承接

组织者分配／组波，现场人员拣货确认／复核／返库，主管确认出库／手工其他出库／品质转换／盘点确认，按钮与共用动作均按本篇角色校验。应用行为见[出库单主PRD第7.8节](../需求文档PRD/3-出库管理/出库单/出库单主PRD.md#78-其他出库权限与时间)。各次扫描确认使用现有业务记录和库存流水记录操作人与UTC时间，任务提交信息只表示结束任务。

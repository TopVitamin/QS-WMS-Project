## 二、时间口径（三层分开）

| 层 | 口径 | 系统落点 |
| --- | --- | --- |
| 存储 | 业务时间一律 UTC+0 | 业务时间字段、操作留痕、回传消息时间戳 |
| 业务判断 | 按**业务所属仓库**当地时区 | 履约 48 小时起算与截止；效期与临期/过期；盘点跨日过期转不良 |
| 展示与导出 | 用户所选展示时区，只改显示与导出 | 列表、详情、操作记录、导出文件标注时区；**不作为**业务判断依据 |

履约自**有效接收出库指令**起，按所属仓库当地业务时间加 48 小时（一期课程参数，非真实渠道承诺）。接收后的缺货、盘点等待计入；拒收不计时。超时不自动取消、释放或强制缺量。效期按当地业务日期判断；切换展示时区不改变截止或效期结果。

## 三、语言与展示

- 界面支持中文、英文，覆盖管理端与 PDA；术语中英对照与单号规则见全局背景《单据术语与生成规则》。
- 业务字段名、单据名与状态名保留项目口径，不随翻译变形。
- 库位编码、SN、批次号等标识符原样存储与展示。

## 四、演示可见性（不做角色权限）

一期 Demo 不提供登录、账号、角色、权限点或仓库授权校验。所有满足单据状态和业务规则的动作默认可见，不按角色裁剪菜单、按钮或操作。

| 配置项 | 一期做法 |
| --- | --- |
| 数据范围 | 顶栏当前仓库作为演示筛选；同仓全部货主可见，不做用户授权校验 |
| 菜单与目录 | 全部菜单默认可见；未实现页面显示占位 |
| 动作入口 | 只由单据状态、数量、归属、品质、效期、盘点等业务条件决定 |
| 操作记录 | 记录操作者、UTC 时间、原单与结果，用于追溯，不承担鉴权 |
| 无主货可见范围 | WMS 内按顶栏仓库展示，不做用户级可见性 |

- 不配置认领权限、角色菜单/动作、用户仓库授权或权限点字典。
- 入库取消仅接受上游消息（零实收），WMS 不提供手工取消入库或零实收完成结案。
- 关键确认不引入审批流或双人复核；操作者只作为留痕字段。

## 五、操作留痕清单

关键动作记录操作者、UTC 时间、原单与结果；与业务事实记录并存，**不可编辑**（见《单据与状态流转》现场记录规则）。

| 动作 | 留什么 | 位置 |
| --- | --- | --- |
| 收货提交 | 拒收与实收、实收内良品/不良、容器与追溯、操作者与时间 | 收货记录 |
| 上架保存与提交 | 应上架行、目标库位、数量及SN归属；保存占位不动库存，提交移库 | 上架单、操作记录；提交时库存流水 |
| 盘点差异确认（含暂存丢失盘亏） | 快照、实盘、差异依据 | 盘点单与库存流水 |
| 在库受损品质确认 | 原品质、位置、原因、新品质、通知结果 | 库存流水与操作记录 |
| 缺货单重新分配 | 原单、缺口、预占与分配变化、结果 | 出库单与操作记录 |
| 新品维护 | 实测规格、操作者与时间 | 新品维护记录与商品仓内规格 |
| 无主货登记 | 仓库、位置、线索、登记人与时间 | 无主货登记记录 |
| 出库取消（接受/拒绝） | 结论、原因；已拣时生成的返库上架单 | 出库单、返库上架单与操作记录 |
| 手工其他出库创建与确认 | 邮件依据、指定实物、确认人时间 | 出库单（手工来源） |
| 发起盘点 | 来源、发现环节、库位、差异依据、发起人；差异待核对关联原业务记录，盘点确认完成时解除 | 盘点单与原业务记录 |
| 退拣与返库上架 | 原出库单、退拣原因（取消、残损、少件）、应返库与实际返库 | 返库上架单与库存流水 |
| 收货完结与入库取消 | 完结确认人时间；取消消息、受理时间及原因 | 入库单、上游消息记录与操作记录 |
| 上游请求处理 | 每条消息的接受/拒绝/冲突结论 | 上游消息记录 |
| 确认出库 | 确认人、时间、交接对象与凭证 | 出库单与出库交接 |

查询入口：系统设置「操作记录」及各单据详情。

## 六、重复提交与结果重交

管理端与 PDA 对同一动作、同一确认重复提交，只返回已有结果，不重复扣库或改账。

上游消息去重、冲突与送达失败只重交已有结果，语义见《接口与 OMS Mock 消息设计》。

## 七、业务校验与动作可见性

动作是否展示、是否可执行只由状态、归属、品质、效期、数量、盘点等业务校验决定。数量与不重复记账见《实体对象关系》一致性约束；资料停用与变更见基础资料规则。一期不提供「直接改库存」的授权入口。

## 八、参数项清单

| 参数 | 性质 | 一期 |
| --- | --- | --- |
| 履约时限 | 48 小时，自有效接收出库指令起算 | 技术配置；后续可按渠道扩展 |
| 效期三天数 | 商品级：允许入库≥临期≥过期 | 商品资料，按仓库当地日期判断 |
| SN 唯一身份 | 货主＋SKU＋SN，四仓共用 | 库存维度规则 |
| Mock 重试间隔 | 技术参数；不改变单次生效语义 | 见消息设计篇 |
| 系统参数页 | 不提供业务维护页 | 菜单后置，走技术配置 |

仓库业务时区使用支持夏令时的时区标识，预置值随四仓仓库资料与演示地点校验，不用固定 UTC 偏移代替当地业务日。

## 出库页面动作承接

分配／组波、拣货确认／复核／返库、确认出库、手工其他出库、品质转换与盘点确认等入口默认展示，只看单据状态与业务规则，不按角色裁剪。应用行为见[出库单主PRD第7.8节](../需求文档PRD/3-出库管理/出库单/出库单主PRD.md#78-其他出库动作与时间)。各次扫描确认使用现有业务记录和库存流水记录操作人与UTC时间，任务提交信息只表示结束任务。

## 一、共同机制的维护位置

系统组成与范围见[00](00-系统与模块地图.md)及[04](04-系统边界与上下游链路总览.md)，对象与数量见[02](02-实体对象关系.md)，状态操作见[03](03-单据与状态流转.md)，上游消息与结果重交见[06](06-接口与OMS Mock消息设计.md)。本文只展开时间、语言、权限、留痕和配置，不重复模块功能。

## 二、时间口径（三层分开）

| 层 | 口径 | 系统落点 |
| --- | --- | --- |
| 存储 | 业务时间一律UTC+0 | 全部业务时间字段、操作留痕时间、回传消息时间戳 |
| 业务判断 | 按业务所属仓库的当地时区计算 | 履约48小时起算与截止；效期剩余保质期计算与临期／过期等级；盘点跨日过期转换 |
| 展示与导出 | 右上角切换时区，只改显示与导出 | 列表、详情、操作记录、导出文件按当前所选时区展示并标注时区；导出后不再是业务判断依据 |

履约自有效接收指令起，按所属仓库当地业务时间加48小时；接收后的缺货、盘点等待计入，拒收不计时。超时不自动取消、释放或强制缺量。效期按当地业务日期判断；切换展示时区不改变截止时间或效期结果（COM-FR-002）。

## 三、语言与展示

- 界面支持中文、英文切换（COM-FR-002），覆盖管理端与PDA；术语随语言版本取`../字段清单合集`定义的中英对照。
- 业务字段名、单据名与状态名保留项目口径（入库单、出库单、确认出库等）不随翻译变形；导出文件按发起导出时所选时区转换并标注。
- 货位编码、SN文本、批次号这类标识符原样存、原样显，不做本地化改写。

## 四、权限配置

一期权限两层分开：数据范围按仓库授权（货主不单独授权），动作按RBAC菜单与操作授权（COM-FR-001）。

| 配置项 | 内容 | 依据 |
| --- | --- | --- |
| 仓库数据范围 | 用户可被授权一个或多个仓库；授权仓内可看全部货主的资料、库存与单据；未授权仓不可见，不提供货主级权限 | COM-FR-001、MD-FR-008 |
| 菜单与目录授权 | 一级、二级菜单按角色显隐；附录菜单基线见[00](00-系统与模块地图.md) | COM-FR-001 |
| 动作权限 | 角色持有动作权限才可执行查看之外的动作；下表动作分别配置；无权限则入口不展示或不可执行，服务端同样校验 | COM-FR-001 |
| 待认领可见范围 | 无主件待认领记录仅其所在仓库的授权用户可见 | COM-FR-001 |

一期权限配置基线：关键确认权限集中于“仓库主管”角色，作业与常规收发确认分别配置。下表是默认角色矩阵；系统按账号的仓库授权及RBAC权限判断，不按岗位名称硬编码。

| 权限点 | 所在端 | 关联动作 | 岗位配置 |
| --- | --- | --- | --- |
| 收货完结确认 | 管理端或PDA | 入库单收货完结 | 常规收货确认权限，独立配置 |
| 质检执行／质检确认 | PDA（管理端可查） | 需检任务正常／不良判定 | 质检作业权限，独立配置 |
| 免检残损登记与品质判定 | 管理端或PDA（同一记录） | 已收未上架免检实物直接登记判定，不生成质检任务 | 入库作业权限，独立配置 |
| 已收未上架丢失异常确认 | 管理端（剩余实物落位在PDA） | 核实原实收、现场剩余、损失及依据，关联结转与盘亏同次生效 | 仓库主管 |
| 在库受损品质确认 | 管理端或PDA（同一记录） | 确认在库实物转不良并通知货主；不得绕过实盘冻结 | 仓库主管 |
| 缺货单人工重试 | 管理端或PDA（入口随应用设计定） | 对仍有效且未进入取消或结案的已接收单据补预占与分配 | 出库作业权限，独立配置 |
| 上架／移库执行 | PDA | 实物落位与库内移库 | 作业权限，独立配置 |
| 拣货与回库执行 | PDA | 拣货、取消回库 | 作业权限，独立配置 |
| 确认出库 | 管理端或PDA（同一记录） | 上游指令来源的出库确认；手工其他出库确认另见下行 | 常规出库确认权限，独立配置 |
| 无主件归属确认 | 管理端 | 确认归属，生成关联入库记录 | 仓库主管 |
| 手工其他出库创建 | 管理端 | 依据线下邮件登记指定实物与处置要求 | 创建权限，独立配置 |
| 手工其他出库确认 | 管理端 | 核实指定实物与实发，足量确认扣库 | 仓库主管；须另有该确认权限，普通确认出库权限不自动覆盖 |
| 盘点创建／实盘录入 | 管理端创建，PDA实盘 | 选择范围、清点或扫SN | 盘点作业权限，分别配置 |
| 盘点差异确认 | 管理端 | 核实差异、有效占用与调整结果 | 仓库主管 |
| 报损／销毁处置确认 | 管理端 | 核实处置实物及完成条件，确认扣库 | 仓库主管 |
| 波次创建 | 管理端 | 同仓同货主B2C基础波次 | 出库组织权限，独立配置 |

- 权限不替代业务校验：状态、数量、归属、品质与效期资格仍按业务规则判断；无权限只是入口不展示。
- 角色可以兼任，仓库主管账号仍须有对应仓库授权。关键确认不增加提交、审核或双人审批；创建、登记、实盘及常规收发确认不会因关键确认角色而自动合并授权。

## 五、操作留痕清单

各动作记录原单、操作者、UTC时间与结果；下表列出额外业务依据（COM-FR-003及各域追溯要求）：

| 动作 | 留什么 | 位置 |
| --- | --- | --- |
| 收货差异确认 | 操作者、时间、原单、处理结果 | 收货记录 |
| 已收未上架丢失异常确认 | 原实收、现场剩余、损失身份与依据、实际落位、异常账面结转及关联盘亏 | 入库异常记录与两类关联流水 |
| 在库受损品质确认 | 原品质、受损实物与位置、原因、新品质、通知结果 | 品质记录与流水 |
| 免检残损登记与品质判定 | 原入库与实收、对应实物、数量、原因、品质、操作者和时间 | 入库品质／差异记录 |
| 缺货单人工重试 | 原单、操作者、时间、当前缺口、已有与新增预占、分配及重试结果 | 出库作业记录 |
| 质检 | 检验结果（正常/不良）、原因、操作者 | 质检任务与结果记录 |
| 无主件认领 | 归属确认依据、确认人 | 待认领记录 |
| 出库取消（接受/拒绝） | 结论、原因、回库结果 | 出库单操作记录 |
| 其他出库手工创建与确认 | 邮件依据、指定实物、确认人时间 | 出库单（手工来源） |
| 盘点调整 | 快照、实盘、差异、确认人 | 盘点单 |
| 报损/销毁 | 原因、指定实物、处置量、确认人时间、暂存去向 | 处置记录 |
| 上游请求处理 | 每条消息的接受/拒绝/冲突结论 | 指令与结果记录（06） |
| 确认出库 | 确认人、时间、交接对象与凭证 | 出库单与交接登记 |

留痕是事实记录的一部分，不可编辑（03第四节）；查询入口在「系统设置-操作记录」与各单据详情。

## 六、重复提交与结果重交

管理端与PDA对同一动作重复提交、同一确认重复提交，只返回已有结果，不重复生效或扣库（COM-FR-004、INV-FR-001）。上游消息去重、冲突与结果送达失败只重交已有结果，统一见[06第二、五节](06-接口与OMS Mock消息设计.md)。

## 七、业务校验不能由权限绕过

有动作权限仍须满足状态、归属、品质、效期、数量、盘点冻结及追溯配置校验。数量与不重复记账约束集中见[02第七节](02-实体对象关系.md)，资料切换与停用按MD-FR-006／007执行，不提供直接改库存的授权入口。

## 八、参数项清单

| 参数 | 性质 | 系统 |
| --- | --- | --- |
| 履约时限 | 统一48小时，自有效接收出库指令起算（缺货与盘点等待计入；被拒收的请求不计时） | 一期随技术配置；后续可按渠道区分 |
| 三天数（允许入库/临期/过期） | 这是商品级配置，不是全局参数；须满足允许入库≥临期≥过期，允许相等 | 商品资料（按商品配置），按仓库当地日期判断 |
| SN唯一身份 | 货主＋SKU＋SN，四仓共用判断 | 库存维度规则，非参数 |
| Mock重试 | 重试间隔等属于技术参数；只重交已有结果 | 送达状态见06第五节；消息顺序语义见06第二节，不作为可随意调整的参数 |
| 系统参数页 | 一期不提供页面维护 | 「系统设置-系统参数」菜单后置；参数走技术配置 |

改变履约、效期等业务判断的配置须有业务确认依据；重试间隔等技术参数由技术设计选择，不能改变单次生效与结果重交语义。仓库业务时区采用能处理当地夏令时的时区标识，具体预置值随仓库资料与演示地点校验，不使用固定UTC偏移代替。

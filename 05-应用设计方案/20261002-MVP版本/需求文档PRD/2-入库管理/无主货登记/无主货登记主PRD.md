## 一、定位与适用范围

无主货登记（UG）只记一件事：仓库收到一批实物，对不上任何入库单或退货预报，也认不出是哪个货主的。登记保留识别线索和存放位置，等OMS上线后由客户认领。

| 情况 | 处理 |
| --- | --- |
| 认不出货主，也对不上单 | 登记无主货，实物放无主货暂存位置 |
| 能确定货主，但实物错SKU、缺单、超收或未预报 | 仓库线下暂存，联系货主补报或安排退回；WMS不记录、不增加库存，也**不**登记无主货 |
| 能对上入库单，但现场判定不收 | 收货时录拒收，生成入库异常 |
| 经核实属于退货、退件 | 交退货流程按预报收货 |

一期只有登记和查询。不认领、不指定货主、不转入库、不手工入库、不记线下处置；OMS认领链路尚未建设，不算一期已实现能力。

## 二、登记规则

1. 操作人从当前仓库上下文进入无主货登记，管理端或PDA均可登记；一期不配置登录、角色或仓库授权。
2. 每批同来源实物登记一条：同一运单、同一柜或同一次到件的一批外箱合并为一条，不按箱拆。
3. 仓库取操作人当前仓库，登记后不可改。
4. 不选库位：无主货统一放在本仓无主货暂存区域（异常处理库区内的无主货暂存位，见[库存宏观架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)），登记只记到仓，不记到具体库位，实物不与已识别货主的货混放。
5. 运单号、箱唛号、柜号至少填一项；运单号、箱唛号可填多个，每行一个，去首尾空格、去空行。
6. 箱数必填，正整数，只表示外箱或包裹数，不代表箱内件数，也不据此生成SKU数量。
7. 实物描述、照片选填；一期不接附件服务，照片只做本地预览与文件名留底，不校大小与张数，正式上限待公共能力定义。
8. 提交时记录登记人与UTC时间，生成UG号（单号规则见[单据术语与生成规则](../../../../../01-全局背景信息/08-单据术语与生成规则.md)），状态为「暂存中」。
9. 同一次提交重复到达返回原UG号，不重复登记。登记后所有字段只读，不更正、不删除；录错的线索在新登记的实物描述中说明，不改原记录。

## 三、登记结果

登记成功只生成UG记录。不生成入库单、退货单、收货记录、上架单、入库异常、库存或库存流水，也不影响任何货主的库存、入库进度和回传结果。无主货暂存区域里的实物不计库存，也不占用任何库位的货主归属。

## 四、页面与查询

| 端 | 入口 | 内容 |
| --- | --- | --- |
| 管理端 | 入库管理 → 无主货登记 | 列表查询、详情查看、页头「登记无主货」 |
| PDA | 首页入库作业 | 扫运单或箱唛登记；交互见[PDA无主货登记前端Demo版PRD](../../7-PDA作业端/无主货登记作业/PDA无主货登记前端Demo版PRD.md)，规则同本文 |

查询范围只限所在仓库：列表按顶栏当前仓库过滤，其他仓的登记不可见。可按登记号、运单号、箱唛号、柜号、登记时间查询，列表展示识别线索摘要、箱数、登记人与时间。

页面不出现指定货主、认领、转入库、转库存或处置按钮；状态只展示「暂存中」，不设状态页签。

## 五、后续能力边界

OMS上线后，WMS推送登记信息供客户在OMS认领，客户下发有效入库指令，WMS再按普通入库执行并关联原登记；届时启用「已转入库」「已线下处置」状态。一期Mock不代做认领，也不预留可点击的认领入口。

## 六、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| 到件3箱，面单运单号对不上任何单、认不出货主 | 生成一条UG记录，状态暂存中；实物按现场规矩放无主货暂存区域；各货主库存、库存流水不变 |
| 运单、箱唛、柜号都不填 | 阻断提交，提示至少填一项 |
| 箱数填0 | 阻断提交 |
| 已知货主ANKR缺单的5箱 | 页面提示能确定货主的不在此登记；按线下补单处理，不生成UG |
| 美西仓登记后，顶栏切换到美东仓查询 | 不显示美西仓记录 |
| 同一次提交重复点击 | 只生成一个UG号 |
| 登记后打开详情 | 所有字段只读，无认领、指定货主、转入库按钮 |

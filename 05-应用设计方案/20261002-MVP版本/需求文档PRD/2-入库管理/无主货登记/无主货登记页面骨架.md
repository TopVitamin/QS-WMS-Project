# 无主货登记页面骨架

> 文档版本：WMS-V0.1｜日期：2026-10-15｜状态：初稿，待评审。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；动作条件以[《无主货登记主PRD》](无主货登记主PRD.md)为准；字段以[《无主货登记（详细稿）》](../../../字段清单合集/02-入库管理/无主货登记/无主货登记（详细稿）.tsv)为准；交互见[《无主货登记前端Demo版PRD》](无主货登记前端Demo版PRD.md)。本文只画管理端；PDA登记屏见[《PDA无主货登记页面骨架》](../../7-PDA作业端/无主货登记作业/PDA无主货登记页面骨架.md)。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 无主货登记列表 | `/wms/inbound/unclaimed` | 入库管理 → 无主货登记 | 查询本仓登记记录，页头发起登记 |
| 登记 Dialog | 列表页头「登记无主货」 | 录入暂存库位与识别线索并提交 |  — |
| 记录详情 Sheet | 列表点击登记号 | 只读查看线索、照片与登记信息 |  — |

**本期不提供**：编辑、删除、认领、指定货主、转入库、线下处置；状态页签；行勾选与批量操作；导入。

容器选型：登记字段约8个 → **Dialog**；记录只读且无子表 → **Sheet**。

## 绘制约定

- 列表查询区 `FilterBar` 6 列栅格，见[需求文档 PRD / AGENTS.md](../../AGENTS.md)。
- 多个运单号或箱唛号在列表只显示第一个，其余以「+N」提示，悬停看全部。
- 示例值为虚构。

## 列表页

- **用途**：查本仓有哪些无主货、放在哪、凭什么线索识别。
- **关键要素**：页头「登记无主货」（primary）+「导出」；无状态页签；状态列固定「暂存中」；无操作列。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库 US-LA-01) ------------------------------------------------+
| PageContainer fill                                                                           |
|  无主货登记                                                [+ 登记无主货]  [导出]            |
| +-- Panel (筛选) ------------------------------------------------------------------------------+|
| | FilterBar · 6 列                                                                            ||
| | 登记号            | 运单号            | 箱唛号            | 柜号              | 登记时间    ||
| | [请输入登记号]    | [请输入运单号]    | [请输入箱唛号]    | [请输入柜号]      | [不限 范围] ||
| |                                                                         [查询] [重置]      ||
| +---------------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) -----------------------------------------------------------------------+|
| | DataTable 工具区: [列设置]                                                                    ||
| | +------------------------------------------------------------------------------------------+||
| | | 登记号(链)   | 状态   | 运单号          | 箱唛号        | 柜号        | 箱数 | 暂存库位  ||
| | | UG-…-0002    | 暂存中 | 1Z999AA1… +1    | FBA15XYZ…     | —           | 3    | EX-01-01  ||
| | | 实物描述(截断)           | 登记人 | 登记时间          |                                 ||
| | | 白色纸箱，无发件人…       | 赵六   | 2026-10-08 15:40  |                                 ||
| | +------------------------------------------------------------------------------------------+||

| +---------------------------------------------------------------------------------------------+|

```

**补充说明**：

- 数据范围：只显示顶栏当前仓库的记录；切仓后列表随之变化。
- 筛选共5项，查询/重置紧跟第5列，不出现「展开」。

## 登记 Dialog

```text
+-- Dialog: 登记无主货 ----------------------------------------------------------+
| (i) 仅登记认不出货主、对不上单的实物；能确定货主的请线下联系补单，不在此登记。 |
| 仓库        US-LA-01 美西仓（只读）                                             |
| 暂存库位 *  [请选择异常处理库位 v]                                              |
| -- 识别线索（运单号、箱唛号、柜号至少填一项） --                                |
| 运单号      [                                    ]  每行一个                    |
|             [                                    ]                              |
| 箱唛号      [                                    ]  每行一个                    |
| 柜号        [            ]          箱数 *  [    ]  外箱或包裹数               |
| 实物描述    [                                              ]                    |
| 照片        [+ 上传]  (Mock，选填)                                              |
|                                                         [取消]  [提交登记]     |
+--------------------------------------------------------------------------------+
```

**补充说明**：

- 暂存库位下拉只列本仓启用的异常处理库区下的启用库位；没有可选库位时下拉为空并提示先在基础资料维护。
- 三项线索都空时，在识别线索分组标题下显示错误，不逐个字段标红。
- 提交成功关闭弹窗、列表刷新并高亮新记录。

# 上架单页面骨架

> 文档版本：WMS-V0.3｜日期：2026-10-15｜状态：演示已走查（2026-10-15）。V0.2：列表与详情只展示应上架与已上架，不展示「已录」。V0.3：详情改为与入库单相同的「概览卡 + 多页签」，新增 Web 端上架录入页。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；动作条件以[《上架单主PRD》](上架单主PRD.md)为准；字段以[《上架单（详细稿）》](../../../字段清单合集/02-入库管理/上架单/上架单（详细稿）.tsv)为准；交互见[《上架单前端Demo版PRD》](上架单前端Demo版PRD.md)。PDA保存与提交的线框见[PDA上架页面骨架](../../7-PDA作业端/上架作业/PDA上架页面骨架.md)，本文只画管理端（含 Web 端上架录入页）。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 上架单列表 | `/wms/inbound/putaway` | 入库管理 → 上架单 | 状态页签、查询、进入详情、进入 Web 端上架或跳转PDA上架 |
| 上架单详情 | `/wms/inbound/putaway/:putawayNo` | 列表点击上架单号；入库单详情上架单页签点单号 | 基本信息、上架进度、应上架与实际上架明细、操作日志 |
| Web 端上架 | `/wms/inbound/putaway/:putawayNo/entry` | 详情页头、列表行操作（未完成单） | 补录落位、撤销未提交行、整单提交 |
| 序列号 Sheet | 详情实际上架页签行内「序列号」 | 只读查看该落位行关联的SN |  — |

**本期不提供**：管理端新建、编辑、删除上架单；更正、作废、重新打开已完成单；行勾选与批量操作；批量导入落位。保存与提交在 PDA 或 Web 端上架页完成，规则相同。

容器选型：上架单有单头、两张子表和日志，且要从入库单详情跳入 → **独立路由详情页**（概览卡 + 多页签）；补录需要边看明细边录 → **独立路由录入页**；SN明细字段少 → **Sheet**。入库单详情内原有的上架单 Sheet 保持只读快览，单号可跳本详情页。

## 绘制约定

- 列表查询区：`FilterBar` 6 列栅格（常显最多 5 项 + 第 6 列查询/重置；筛选项 >5 时其余进 `advanced`），见[需求文档 PRD / AGENTS.md](../../AGENTS.md)。
- 详情：与入库单相同的业务单据详情版式——上方 `DetailOverview`（左「基本信息」`Descriptions columns={3}`，右 320px 汇总卡），下方 `DetailTabs`（带条数，写入 URL）；货主、仓库展示为 `{编码} {名称}`；示例值为虚构。
- 列表与详情只展示「应上架」与「已上架」：「已上架」只在整单提交后等于应上架；保存进度（已录／剩余）只在作业页（PDA、Web 端上架页）。

## 列表页

- **用途**：按当前仓库查看上架进度，查找某容器、某来源单的上架单，进入详情或转到PDA作业。
- **关键要素**：页头仅「导出」；`StatusTabs` 带数量；`FilterBar` 6 列；`DataTable` 无勾选；单号链详情；行内「Web 端上架」「PDA上架」仅未完成单出现。

- 无容器收货合并单的容器号显示「无容器收货」。

## 详情页（独立路由）

- **用途**：核对一张上架单应上架了什么、录到了哪些库位、是否已提交、谁在什么时候做了什么，以及追到来源收货行。
- **关键要素**：版式同入库单详情。页头标题 + 状态；右侧 `返回列表`、`Web 端上架`、`PDA上架`（后两个仅未完成时）。上方左「基本信息」卡、右「上架进度」汇总卡；下方页签：应上架明细、实际上架明细、操作日志。

## Web 端上架（录入页）

- **用途**：现场已按纸单或口头完成搬运、没用 PDA 时，由文员把落位结果补录进上架单并提交；规则与 PDA 相同。
- **关键要素**：版式同详情：上方左「基本信息」+「录入落位」表单，右「录入进度」卡（提交按钮在卡片底部）；下方页签：应上架明细（带已录、剩余、「录入」）、已录落位（带「撤销」）。管理端密度，键盘录入、回车保存。

```text
+-----------------------------------------------------------------------------------------------+
| PageContainer                                                                                 |
|  上架录入 · PA-20261005-0001  [上架中]                                         [返回详情]     |
| +-- Section: 基本信息 (3列) ---------------------------------------+ +-- SummaryCard 320px ---+|
| | 品质 良品      | 来源单号 RK-…-0004  | 货主 ANKR 安客创新        | | 录入进度                ||
| | 作业容器 C-B02 | 暂存库位 STAGE-IN-01 | 收货记录号 RC-…-0001     | | 保存只记落位，不动库存  ||
| +------------------------------------------------------------------+ | 已录               38%  ||
| +-- Section: 录入落位 (FormGrid 4列) ------------------------------+ | [=====-------] 300/800  ||
| | 应上架行 *                        | 目标库位 *     | 上架数量 *  | | ----------------------- ||
| | [#1 · CABLE-01 · BATCH-A · 剩余200 v] | [A-01-01    ] | [200     ] | | 应上架             800  ||
| |                                   | 推荐 A-01-01，点此填入 | 剩余 200 | | 已录               300  ||
| | (SN 商品) 序列号 * [每行一个                                    ] | | 剩余               500  ||
| | 错误提示(红字)                                      [保存落位]  | | 落位行数             1  ||
| +------------------------------------------------------------------+ | [提交上架（1 条落位）]  ||
|                                                                      | 还有 500 件未落位       ||
|                                                                      +-------------------------+|
| +-- DetailTabs ------------------------------------------------------------------------------+|
| | (应上架明细 2)  (已录落位 1)                                                                ||
| | 行号 | SKU                 | 批次号       | 失效日期 | 应上架 | 已录 | 剩余 | 操作          ||
| | 1    | CABLE-01 USB 数据线 | BATCH-2026-A | -        | 500    | 300  | 200  | 录入          ||
| | 2    | CABLE-01 USB 数据线 | BATCH-2026-B | -        | 300    | 0    | 300  | 录入          ||
| | 【已录落位】 行号 | 应上架行号 | SKU | 目标库位 | 上架数量 | 序列号 | 操作「撤销」           ||
| +---------------------------------------------------------------------------------------------+|
+-----------------------------------------------------------------------------------------------+
```

**补充说明**：

- 只列剩余 > 0 的应上架行；选行后预填推荐库位与剩余数量，可改。
- 每次「保存落位」即写入上架单（不动库存）；本行没录满就留在本行，录满后自动切到下一行。
- 「撤销」只对未提交的落位，二次确认；提交按钮在每行录满前不可用，提交确认后回到详情。
- 与 PDA 交替录同一张单时，两边看到的是同一份已保存明细。

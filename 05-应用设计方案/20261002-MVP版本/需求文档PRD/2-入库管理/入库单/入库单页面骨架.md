# 入库单页面骨架

> 文档版本：WMS-V0.8｜日期：2026-10-15｜状态：演示已走查。V0.8：详情改为「基本信息 + 作业进度」概览卡 + 多页签（明细、收货记录、上架单、入库异常、操作日志），与 qs-wms-demo 现状一致。
> 线框画法遵循 [《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；组件与分区对齐 [《QS-WMS 前端设计与开发规范》](../../../../../09-产品原型/qs-wms-demo/docs/02-设计规范.md)。
> 动作条件以[《入库单主PRD》](入库单主PRD.md)为准；字段以[《入库单（详细稿）》](../../../字段清单合集/02-入库管理/入库单/入库单（详细稿）.tsv)及收货记录、上架单、入库异常初稿为准；交互见[前端Demo版PRD](前端Demo版PRD/)（列表/详情/收货与双端/弹窗分册）。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 入库单列表 | `/wms/inbound/orders` | 入库管理 → 入库单（`menu.inboundOrders`） | 状态页签、查询、行内确认收货完结、导出 Mock |
| 入库单详情 | `/wms/inbound/orders/:inboundNo` | 列表点击入库单号 | 基本信息 + 作业进度卡、页头收货（F07）与确认完结；入库明细/收货记录/上架单/入库异常/操作日志页签 |
| 收货记录 Sheet | 详情「收货记录」页签行内「查看」 | 只读展开一次收货的明细与序列号 |  — |
| 上架单 Sheet | 详情「上架单」页签行内「查看」 | 只读应上架/实际上架两个子页签 |  — |
| 收货作业台 | `/wms/inbound/orders/:inboundNo/receive` | 容器绑定 + 多行录入表；列表/详情「Web 端收货」进入 |  — |
| 确认收货完结 Dialog | 列表行内 / 详情页头 | 二次确认，列出未收明细 |  — |
| 模拟推送入库指令 Dialog | 列表页头（仅 Demo） | 按指令字段造待收货单 |  — |

**本期不提供**：管理端新建/编辑入库单页、行勾选、列表内直接收货（仅入口跳转收货作业台）、在入库单详情里保存或提交上架（上架单在本页只读，单号可跳[上架单详情](../上架单/上架单页面骨架.md)；上架走 PDA 或上架单的 Web 端上架页）。

容器选型：详情含多类子记录 → **独立路由详情页**（概览卡 + 多页签）；Web 收货 → **独立路由作业台**（容器绑定 + 多行录入表；交互特殊，不套用普通列表/表单模板）；单次收货/上架单字段多 → **Sheet** 只读；确认与 Mock 推送 → **Dialog**。

## 绘制约定

- 列表查询区：`FilterBar` **6 列栅格**（常显最多 5 项 + 第 6 列查询/重置；筛选项 >5 时其余进 `advanced`），见 [需求文档 PRD / AGENTS.md](../../AGENTS.md)。
- 详情：上方 `DetailOverview` 两栏（左「基本信息」`Descriptions columns={3}`，右 320px `SummaryCard`），下方 `DetailTabs`；标签在上、值在下；长字段（备注、运单号）可 `multiline` 或跨列。
- 货主、仓库展示为 `{编码} {名称}`；示例值为虚构。
- 单据状态、明细状态用语义色标签，不手工改状态。
- 进度：列表进度条旁只写「已完成件数/分母件数」（如 `600/1100`）；详情汇总卡另显示取整百分比（口径见主 PRD R13）。

## 列表页

- **用途**：按当前顶栏仓库查看入库单进度，进入详情，在收货中且满足 R07 时办理确认收货完结。
- **关键要素**：页头「模拟推送入库指令（Demo）」+「导出」；`StatusTabs` 带数量（含已取消）；`FilterBar` 6 列；`DataTable` **无行勾选**；入库单号链至详情；行内提供 Web 端收货、PDA 收货与「确认收货完结」（按条件出现）。

**补充说明**：

- **图中省略**：列拖拽、排序、空态、默认排序（创建时间降序）见 Demo PRD；页头**无新增、无导入、无审核、无批量操作**（AC01）。
- 列表数据范围：顶栏**当前仓库**内全部货主（主 PRD R12）；一期不按用户账号或角色裁剪。
- 单号列点击进入**详情路由**；行内不设「查看」。
- 「确认收货完结」仅在收货中且 R07 满足时出现；待收货、上架中、已完成、已取消不渲染（不用 disabled）。
- 已取消单（一期纳入，仅限零实收）只保留查看，行内无操作。
- 状态页签数量基于**当前筛选结果**再按推导状态计数（AC20）。

## 详情页（独立路由）

- **关键要素**：页头左侧「入库单 · 单号 [状态]」；右侧 `返回列表` 固定最前，其次「Web 端收货」「PDA 收货」（F07）、再「确认收货完结」（R07，主按钮）。上方左「基本信息」卡、右「作业进度」汇总卡（两栏等高，窄屏堆叠）；下方一张多页签卡：入库明细、收货记录、上架单、入库异常、操作日志，页签带条数并写入 URL（`?tab=`）。

```text

|  入库单 · RK-20261002-0005  [已完成]                              [返回列表]                  |
```

**补充说明**：

- 单号与状态只在标题出现，基本信息不重复；收货完结已确认时在「收货完结」字段后附确认人、确认时间。
- 汇总卡进度条：收货 blue、上架 green；数量清单按状态色（实收 blue、拒收 red、未收>0 orange、已上架 green）；拒收为 0 时整行不显示。
- 明细「未收」在整单已完成且该行未收>0 时，单元格附加「短少」标签（AC10）；已完成单不再出现收货、完结按钮；已取消单明细随单收口为已取消，保留收货记录与入库异常。
- 页签内**无**新建、编辑、作废、提交入口（AC15）；表格列设置在页签栏右侧，不单占一行。
- 收货记录页签的「作业容器」由明细汇总：一次提交含多个容器时显示「BOX-A 等 2 个」，Sheet 内按容器分组列出（主 PRD R16）。
- 上架单页签单号跳上架单详情，行内「查看」开 Sheet 快览；上架单另有独立列表，两处引用同一数据（上架单主PRD与模块地图）。
- 操作日志含本单的收货、完结等记录，以及本单各上架单的保存、撤销、提交（PDA 与 Web 端上架都记）。

# 入库单前端Demo版PRD·详情页

> **版本**：WMS-V0.8  
> **更新时间**：2026-10-15  
> **定位**：供 AI / 研发实现**入库单详情独立路由页**。业务规则见[《入库单主PRD》](../入库单主PRD.md)（§6.4、§7.3～§7.4、R05、R08～R11、R13；F02、F03、F07）。  
> **本文件只写详情呈现**；收货见[收货与双端分册](入库单前端Demo版PRD_收货与双端.md)；确认收货完结见[弹窗与 Mock §3](入库单前端Demo版PRD_弹窗与Mock.md)；共用约定见[公共分册](入库单前端Demo版PRD_公共与技术约定.md)。  
> **V0.8**：由多块分区 Panel 改为「概览卡 + 多页签」：基本信息与作业进度并排，明细与四类子记录（含操作日志）收进页签；与 qs-wms-demo 现状一致。

关联：[《入库单页面骨架》](../入库单页面骨架.md) 详情区。

**布局与占位须符合 [需求文档 PRD / AGENTS.md](../../../AGENTS.md) 「布局硬规则」一节**（业务单据详情用概览卡 + 多页签，见该节第 3 条）。

**实现参照**：`inbound-order-detail-page.tsx` 本身即业务单据详情样板（《02-设计规范》§5.2）；上架单详情 `putaway-detail-page.tsx` 照此实现。

## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 入库单详情页 |
| 路由 | `/wms/inbound/orders/:inboundNo`；当前页签写入 `?tab=`（`items` 默认不写） |
| 入口 | 列表点击入库单号 |
| 目标 | 只读查看单头、进度与明细；追溯收货记录/上架单/异常/日志；**收货（F07）**与确认收货完结 |
| 版式 | 页头 → `DetailOverview`（左基本信息、右作业进度）→ `DetailTabs`（入库明细、收货记录、上架单、入库异常、操作日志） |

| 模式 | 说明 |
| --- | --- |
| 容器 | **独立路由页**（不用 880px 主详情 Sheet） |
| 返回 | `返回列表`，保留列表 query（`state.listSearch`）；切页签保留该 state |

> **本期边界**  
> - 无编辑、删除；上架保存/提交不在本页（AC15），走 PDA 或上架单 Web 端上架页。  
> - 收货走**独立收货作业台路由**（页头「Web 端收货」入口），规则与 PDA 一致（R15）。  
> - 子对象页签无新建/提交入口。  
> - 上架单页签「已上架」仅计**已提交**量（AC09）。

## 2. 页头

### 2.1 标题与状态

`<DetailTitle title={t('inbound.detailTitle')} code={inboundNo} status={inboundOrderStatusMeta[status]} />`，渲染为「入库单 · RK-… [状态]」。单号与状态不再在基本信息里重复。

### 2.2 页头按钮矩阵

`返回列表` **始终第一**（outline）。

| 按钮 | 待收货 | 收货中 | 上架中 | 已完成 | 样式 |
| --- | :---: | :---: | :---: | :---: | --- |
| 返回列表 | ✅ | ✅ | ✅ | ✅ | outline |
| Web 端收货（F07） | ✅* | ✅* | ❌ | ❌ | outline |
| PDA 收货 | ✅* | ✅* | ❌ | ❌ | outline |
| 确认收货完结 | ❌ | R07 ✅ | ❌ | ❌ | primary（页头唯一主按钮） |

\* 须 `receiptCloseFlag=未确认` 且存在未收>0 的行（与 §6.4 一致）。全部拒收等零实收单走上游取消，受理后整单与明细为已取消，页头不渲染收货/完结按钮。

「Web 端收货」→ [收货与双端 §3](入库单前端Demo版PRD_收货与双端.md)；成功刷新详情（AC21）。「确认收货完结」→ [弹窗 PRD §3](入库单前端Demo版PRD_弹窗与Mock.md)。

### 2.3 二次确认与刷新

1. 点击「确认收货完结」→ 打开弹窗分册 §3。  
2. 确认成功 → `toast.success(inbound.receiptCloseSuccess)`，详情随 `useDb` 订阅刷新。  
3. 失败 → `toast.error`；列表进入详情时若单已变状态，页头按钮应已随 `recompute` 消失。

## 3. 概览（`DetailOverview`）

两栏：左 `minmax(0,1fr)`，右固定 320px；`lg` 以下堆叠。

### 3.1 基本信息（左）

`<Section title="基本信息">` + `<Descriptions columns={3}>`，字段顺序：

| 行 | 字段 |
| --- | --- |
| 1 | 货主（`CodeName`）、上游单号、业务类型（`TagLabel`） |
| 2 | 仓库（`CodeName`）、到货方式、柜号 |
| 3 | 预计到仓（日期）、首次到货、运单号（`multiline`，多行） |
| 4 | 创建时间、完成时间、收货完结（未确认 / 已确认 · 确认人 确认时间） |
| 5 | 备注（`col-span-3`，`multiline`） |

空值统一 `<Empty />`。

### 3.2 作业进度（右）

`<SummaryCard title="作业进度" description={inbound.progressHint}>`：

| 元素 | 规格 |
| --- | --- |
| 收货进度 | `SummaryProgress` blue，`receiptProgress(order)`：实收 / 预计 |
| 上架进度 | `SummaryProgress` green，`putawayProgress(order)`：已上架 / 实收；实收为 0 显示 `-` |
| 数量清单 | `SummaryMetrics`：SKU 种类、预计数量、实收数量（blue）、拒收数量（red，0 时隐藏）、未收数量（>0 时 orange）、已上架（green） |

进度显示取整百分比 + `done / total`（R13 详情汇总卡口径）。

## 4. 页签（`DetailTabs param="tab"`）

页签带条数；表格贴卡片左右边、与页签栏留 `pt-3`；列设置在页签栏右侧。空表文案 `inbound.tabs.empty.*`。

### 4.1 入库明细（`items`，默认页签）

列：行号、商品编码、**条码**、名称、明细状态、预计、实收、拒收、未收、**实收良品数量**、**实收不良品数量**、**已上架数量**（已提交上架单累计）。不展示待上架数量列。

- 数字列 `<Num>`，`meta.align: 'right'`。  
- 单状态已完成且未收>0：未收旁 `TagLabel` `inbound.shortage`（AC10）。  
- 已取消单的明细状态为**已取消**（主 PRD §7.4）。

### 4.2 收货记录（`receipts`）

| 列 | 展示 | 说明 |
| --- | --- | --- |
| 收货记录号 | `<DocNo>` | 开 §5.1 Sheet；不另设「查看」列 |
| 收货时间 | `<DateTime>` | 倒序 |
| 收货人 | 文本 | — |
| 作业容器 | 一个容器显示容器号；多个显示「首个容器号 等 N 个」；只有无容器收货显示「无容器收货」 | `receiptContainerLabel()`（R16） |
| 暂存库位 | 库位编码 | — |
| 实收合计 / 拒收合计 | `<Num>` | 本记录明细汇总 |

### 4.3 上架单（`putaway`）

| 列 | 展示 | 说明 |
| --- | --- | --- |
| 上架单号 | `<DocNo>` | 跳上架单详情 `/wms/inbound/putaway/:putawayNo` |
| 作业容器 | 空显示「无容器收货」 | AC19 |
| 品质 | `TagLabel` | — |
| 单据状态 | `<StatusBadge>` | 上架单三态 |
| 应上架总数量 | `<Num>` | — |
| 已上架数量 | `<Num>` | **仅已提交**上架单（AC09） |
| 操作 | 「查看」 | 开 §5.2 Sheet 快览 |

### 4.4 入库异常（`exceptions`）

列：异常记录号、异常类型（拒收）、商品编码、名称、异常数量、异常原因、收货记录号、登记时间。

### 4.5 操作日志（`logs`）

列：操作时间、操作、操作人、说明（`audit-log-columns.tsx`，与上架单详情共用）。数据取 `refType='INBOUND'` 且 `refNo=本单` 的记录，加上本单各上架单（`refType='PUTAWAY'`）的保存、撤销、提交记录；后者说明前带上架单号。按时间倒序。

## 5. Sheet

### 5.1 收货记录 Sheet

宽 `880px`（《02-设计规范》§5.4）。标题为收货记录号；单头 `Descriptions columns={4}`：收货时间、收货人、暂存库位、作业容器（列出本次提交的全部容器，含无容器收货）。明细：商品编码、名称、作业容器、实收、拒收、拒收原因、良品、不良品、批次、生产日期、失效日期；按容器分组排列。

### 5.2 上架单 Sheet

`inbound-putaway-sheet.tsx`，只读快览。标题「上架单号 [状态] [品质]」；单头 `Descriptions columns={4}`：作业容器（空为「无容器收货」，AC19）、来源收货记录号、应上架、已上架。内层 `DetailTabs`（不写 URL）：**应上架明细** / **实际上架明细**，列与上架单详情共用 `putaway-line-columns.tsx`；SN 列在抽屉里只显示条数，查看 SN 去上架单详情。

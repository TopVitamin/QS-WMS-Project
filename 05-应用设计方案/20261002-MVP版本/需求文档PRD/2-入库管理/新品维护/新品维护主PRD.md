## 一、定位与边界

新品维护记录（NS）是某货主某SKU在本仓网第一次量方的结果。它同时承担两件事：给商品写入仓内规格，作为该SKU可以收货的准入凭证。

| 做 | 不做 |
| --- | --- |
| 首次收货前量长宽高、毛重，生成一条NS记录并写入商品仓内规格 | 待维护单、审核、入库单上的新品状态 |
| 管理端与PDA共用同一提交规则 | 形成库存、改变入库数量 |
| 展示上游预报尺寸供对照 | 改写货主、商品身份，或自动回写上游 |
| 按货主、SKU、来源入库单查询已有记录 | 更正、删除、重新量方；后续规格变化走商品资料维护 |

一期量方、称重和拍照都用手工或模拟数据，不集成电子秤、DWS。

## 二、新品判断与收货准入

1. 同一货主＋SKU没有提交成功的NS记录，就是新品。判断只看NS记录，不看上游“需维护”标记，也不看商品上是否已有预报尺寸。
2. 同编码不同货主分别判断；同货主SKU在任一仓维护成功后，四仓共用，其他仓不再量方。
3. 新品在任何仓、任何入库单的收货提交都被阻断，提示先完成新品维护。阻断只针对该SKU，同单其他SKU可以照常收货。
4. 完成维护后立即可收；维护本身不产生实收、库存或入库进度。

## 三、量方录入

| 项 | 规则 |
| --- | --- |
| 货主、SKU | 从收货作业台或PDA收货进入时带出，不可改；独立维护时手工选择启用货主及其下启用SKU，下拉只列尚无NS记录的SKU |
| 维护仓库 | 操作人当前仓库，只读；决定录入单位 |
| 来源入库单号 | 从收货环节进入时带入；独立维护为空 |
| 长、宽、高 | 必填，大于0，最多2位小数；按维护仓库长度单位（cm或inch）录入 |
| 毛重 | 必填，大于0，最多3位小数；按维护仓库重量单位（kg或lb）录入 |
| 照片 | 选填，商品、外箱、标签；一期不接附件服务，只做本地预览与文件名留底，不校大小与张数，正式上限待公共能力定义 |
| 备注 | 选填，如与预报尺寸的差异说明 |
| 对照信息 | 只读展示商品条码、名称及上游预报长宽高、毛重；没有预报显示“—” |

保存时统一换算：inch×2.54得cm，lb×0.45359237得kg；cm保留2位小数、kg保留3位小数，四舍五入。展示时按查看仓库单位反向换算，保留同样位数，因此任一仓看到的值都能从cm、kg复算。

## 四、提交校验与结果

1. 操作人从当前仓库上下文进入新品维护；一期不配置用户账号、角色或仓库授权。
2. 提交时重新检查：货主、商品均启用；该货主＋SKU仍无NS记录。已有记录时阻断，并展示已有记录号、维护仓库、维护人与时间。
3. 多仓并发提交同一货主SKU，以先提交成功者为准，后提交者按上一条阻断。
4. 同一次提交重复到达（重复点击、网络重试）返回原NS记录，不新建第二条。
5. 成功后生成NS号（单号规则见[单据术语与生成规则](../../../../../01-全局背景信息/08-单据术语与生成规则.md)），记维护人与UTC时间，并把长宽高、毛重写入该货主商品的仓内规格；商品资料上这次写入按商品PRD留痕。
6. 记录生成后只读：不更正、不删除。量错了按商品资料维护修改仓内规格，NS记录保留首次量方事实。

## 五、页面与入口

| 端 | 入口 | 内容 |
| --- | --- | --- |
| 管理端 | 入库管理 → 新品维护 | 记录列表、记录详情、页头「新品量方」独立维护 |
| 管理端 | 收货作业台中新品行的阻断提示 | 「去量方」打开同一量方弹窗，带出货主、SKU、来源入库单；提交后回到作业台继续收货 |
| PDA | 收货时扫到新品 | 自动进入量方屏，提交后回到收货；PDA不设独立量方入口。交互见[PDA新品量方前端Demo版PRD](../../7-PDA作业端/新品量方作业/PDA新品量方前端Demo版PRD.md)，规则同本文 |

列表数据范围：NS记录属于货主＋SKU、四仓共用，列表不按顶栏仓库过滤，默认显示全部记录，可按维护仓库筛选。新品量方的提交仍只能在当前仓库发生。

## 六、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| 货主A的SKU-X无NS记录，在公制仓（cm、kg）收货 | 收货提交被阻断，提示先做新品维护；同单其他SKU可收 |
| 在收货作业台点「去量方」，录 30×20×10 cm、1.25 kg 提交 | 生成NS记录，来源入库单号为当前单；回到作业台后SKU-X可收；库存与入库数量不变 |
| 货主A的SKU-X到英制仓（inch、lb）收货 | 不再要求量方；在该仓查看记录显示 11.81×7.87×3.94 inch、2.756 lb |
| 货主B也有编码SKU-X | 仍按新品阻断，需单独量方 |
| 两仓同时提交货主A的SKU-Y | 只生成一条记录；后提交者看到已有记录号 |
| 同一次提交重复点击 | 返回同一NS号 |
| 商品已停用时提交 | 阻断，不生成记录 |
| 长或毛重填0、负数或超出小数位 | 阻断保存，字段内提示 |

以上为文档验收要求；管理端量方弹窗与 PDA 量方屏已按本文实现并演示通过（2026-10-15）。

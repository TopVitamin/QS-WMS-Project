# 新品维护页面骨架

> 文档版本：WMS-V0.2｜日期：2026-10-15｜状态：演示已走查（2026-10-15）。V0.2：详情抽屉标题与分组卡片对齐入库单详情写法。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；动作条件以[《新品维护主PRD》](新品维护主PRD.md)为准；字段以[《新品维护（详细稿）》](../../../字段清单合集/02-入库管理/新品维护/新品维护（详细稿）.tsv)为准；交互见[《新品维护前端Demo版PRD》](新品维护前端Demo版PRD.md)。本文只画管理端；PDA量方屏见[《PDA新品量方页面骨架》](../../7-PDA作业端/新品量方作业/PDA新品量方页面骨架.md)。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 新品维护列表 | `/wms/inbound/new-sku` | 入库管理 → 新品维护 | 查询NS记录，页头发起独立量方 |
| 记录详情 Sheet | 列表点击维护记录号 | 只读查看实测规格、照片与留底信息 |  — |
| 新品量方 Dialog | 列表页头「新品量方」；收货作业台新品行「去量方」 | 录入长宽高、毛重并提交 |  — |

**本期不提供**：编辑、删除、重新量方、审核；导入；行勾选与批量操作。

容器选型：记录字段约15个、无子表 → 详情用 **Sheet**；量方字段少、需从收货作业台原地弹出后回到作业 → **Dialog**。

## 绘制约定

- 列表查询区 `FilterBar` 6 列栅格，见[需求文档 PRD / AGENTS.md](../../AGENTS.md)。
- 尺寸、重量一律按**顶栏当前仓库**单位展示，列头带单位，如「长×宽×高(inch)」「毛重(lb)」。
- 货主展示 `{编码} {名称}`；示例值为虚构。

## 列表页

- **用途**：查某货主某SKU是否已量方、在哪个仓量的、量了多少；需要时先行量方。
- **关键要素**：页头「新品量方」（primary）+「导出」；无状态页签（记录只有提交成功一种）；数据不按顶栏仓库过滤。

## 新品量方 Dialog

- **从收货作业台进入**：货主、商品只读带出，显示来源入库单号；提交成功关闭弹窗并回到作业台，该行解除阻断。
- **从列表页头进入**：先选货主，再选商品（下拉只列该货主启用且无NS记录的SKU）；来源入库单号为空。

```text
+-- Dialog: 新品量方 ------------------------------------------------------------+
| 维护仓库 US-LA-01 美西仓（inch / lb）       来源入库单号 IB-20261002-0003      |
| 货主 *        [ANKR 安客创新 v]            商品 *   [LAMP-02 台灯 v]          |
| 商品条码 6901234567892                                                          |
| -- 预报规格（对照，只读） --                                                    |
| 长×宽×高 12.00×8.00×3.00 inch    毛重 2.50 lb      (无预报显示 —)              |
| -- 实测规格 --                                                                  |
| 长度(inch) * [      ]  宽度(inch) * [      ]  高度(inch) * [      ]            |
| 毛重(lb) *   [      ]                                                           |
| 照片          [+ 上传]  (Mock，选填)                                            |
| 备注          [                                              ]                  |
|                                                         [取消]  [提交量方]     |
+--------------------------------------------------------------------------------+
```

**补充说明**：

- 提交时若发现该货主SKU已被其他仓维护，弹窗内 `Alert` 显示已有记录号、维护仓库、维护人与时间，「提交量方」变为「关闭」，不覆盖已有结果。
- 提交按钮在请求中置 loading，重复点击不产生第二条记录。

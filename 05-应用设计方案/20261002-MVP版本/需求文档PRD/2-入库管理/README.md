# 入库管理

一期按[入库宏观架构](../../../../01-全局背景信息/04-入库模块宏观系统架构.md)执行：正常／调拨入库由上游指令建单，收货实收内录品质，收货确认入暂存库存，上架整单提交移库。零实收可受理上游取消，无主货只登记；不设质检任务、损失确认或手工入库。

字段详细稿维护完整定义；同名初稿只保留五列投影，与详细稿同步生成。收货行按容器、SKU、批次／效期拆分；上架行按应上架行关联，不能只按SKU合并，避免不同批次串账。SN商品收货逐件采集，上架时将这些SN关联到具体落位行，提交才更新SN位置；不修改库存模块字段清单。

入库单、上架单、新品维护、无主货登记均已有管理端三件制（2026-10-15补齐后三者）；PDA收货、上架、[新品量方](../7-PDA作业端/新品量方作业/PDA新品量方前端Demo版PRD.md)、[无主货登记](../7-PDA作业端/无主货登记作业/PDA无主货登记前端Demo版PRD.md)已有骨架与Demo PRD（后两者2026-10-15补齐），规则以对应主PRD为准。

2026-10-15 走查后，四套件的页面均已实现并通过演示走查：上架单列表与详情、新品维护列表／量方弹窗／详情、无主货登记列表／登记弹窗／详情、入库单详情上架单页签跳转，以及 PDA 新品量方屏、无主货登记屏与按应上架行的 PDA 上架落位。上架单的应上架行按收货明细行区分，同SKU不同批次不再串行；管理端只展示应上架与已上架，「已录」不进页面（保存进度只在 PDA 作业页）；无主货登记只记线索与箱数，实物统一放本仓无主货暂存区域（异常处理库位 `EX-01-*`），不选库位。

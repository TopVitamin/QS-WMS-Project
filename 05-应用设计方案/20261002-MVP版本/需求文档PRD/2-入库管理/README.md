# 入库管理

一期按[入库宏观架构](../../../../01-全局背景信息/04-入库模块宏观系统架构.md)执行：正常／调拨入库由上游指令建单，收货实收内录品质，收货确认入暂存库存，上架整单提交移库。零实收可受理上游取消，无主货只登记；不设质检任务、损失确认或手工入库。

字段详细稿维护完整定义；同名初稿只保留五列投影，与详细稿同步生成。收货行按容器、SKU、批次／效期拆分；上架行按应上架行关联，不能只按SKU合并，避免不同批次串账。SN商品收货逐件采集，上架时将这些SN关联到具体落位行，提交才更新SN位置；不修改库存模块字段清单。

入库单、上架单、新品维护、无主货登记均已有管理端三件制（2026-10-15补齐后三者）；PDA收货、上架、[新品量方](../7-PDA作业端/新品量方作业/PDA新品量方前端Demo版PRD.md)、[无主货登记](../7-PDA作业端/无主货登记作业/PDA无主货登记前端Demo版PRD.md)已有骨架与Demo PRD（后两者2026-10-15补齐），规则以对应主PRD为准。上架单、新品维护、无主货的管理端页面及PDA量方、登记屏尚未实现，不把文档补齐说成页面已经实现。

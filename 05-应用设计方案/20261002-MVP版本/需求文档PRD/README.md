# MVP需求文档PRD

本目录维护WMS一期的系统行为、页面结构和Demo实现要求。规则以上位[全局背景信息](../../../01-全局背景信息/)为准，需求分析和业务设计展开同一规则；现有原型只表示实现进度。主PRD、页面骨架、Demo PRD分别维护规则、布局和交互，不各写一套业务结论。

| 模块 | 当前文档 | 字段定义 |
| --- | --- | --- |
| 基础资料 | [转换与阅读说明](1-基础资料/WMS基础资料PRD转换说明.md)；货主、商品、仓库、库区、库位、承运商和渠道的三件制 | 基础资料各对象详细稿 |
| 入库管理 | [入库管理入口](2-入库管理/README.md)；入库单、上架单、新品维护、无主货登记三件制 | 入库六类对象详细稿；初稿为五列投影 |
| PDA作业端 | [设计规范](7-PDA作业端/PDA作业端设计规范.md)、收货与上架页面骨架及Demo PRD | 复用入库对象字段，不另建PDA字段账 |
| 出库、库存与库内 | 当前未形成独立PRD套件；行为见[系统架构](../系统架构设计/README.md) | 现有字段清单本轮保留原文件，不代表已与全部架构细节校验一致 |
| 退货 | 架构已覆盖三类来源，独立PRD、退货字段清单及页面尚待补齐 | 共用上架单可区分入库／退货来源；退货单、收货及异常字段尚未形成 |
| 系统集成、公共能力 | 规则与权限见系统架构对应篇，独立页面PRD待补 | 集成字段映射和JSON当前仅占位，不能作为可联调样例 |

ERP采购订单套件已移至[参考归档](../../../00-草稿对话/ERP采购PRD参考/README.md)，不属于WMS一期需求。

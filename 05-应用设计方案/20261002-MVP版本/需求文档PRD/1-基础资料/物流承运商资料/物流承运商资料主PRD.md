## 一、文档概要

需求类型：基础资料 — 物流承运商（与物流渠道分层维护，各占独立菜单）。

上游：[《基础资料需求分析》](../../../../03-需求调研和分析/01-基础资料/基础资料需求分析.md)（MD-FR-009、MD-FR-010）、[《基础资料业务设计》](../../../../04-业务分析和设计/01-基础资料业务设计.md)第五节、第七节、[《系统与模块地图》](../../系统架构设计/00-系统与模块地图.md)。

## 二、需求背景与范围

物流承运商表示与仓库协作的承运企业身份。出库业务引用**物流渠道**（归属承运商），单据与交接展示时可衍生承运商名称；一期由管理端维护最小档案，不接真实承运商生产打单服务。香港、美西、美东、德国四仓**共用一套**承运商与渠道档案，渠道不按仓库或货主单独绑定。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 物流承运商 | 承运企业档案；其下挂物流渠道 | 管理端维护或演示预置 | 具备资料维护权限的管理端用户 | 物流渠道的归属；出库单、出库交接展示衍生承运商信息 |

**本期做**：物流承运商列表与详情、弹窗新增与编辑、使用状态启停、详情页下属物流渠道子表（维护入口与渠道模块共用弹窗形态）、外部物流承运商代码占位。

**本期不做**：提交与审核流、批量文件导入、物理删除、销售发货或「由仓库指定」物流、运费结算、真实 API 授权与打单、按仓或按货主拆分承运商档案。

**设计边界（原交付清单收口）**：

- 独占菜单「基础资料 → 物流承运商」（命名以模块地图为准）；与物流渠道列表不设对象切换页签。
- 仅**使用状态**，无审核页签；新建默认启用；列表页头无导入。
- 列表默认列以详细稿「列表展示=是」为准：编码、名称、简称、使用状态；系统维护最后修改人、最后修改时间见 Demo PRD。
- 承运商停用：先处理下属仍启用渠道，或确认无未完结出库/交接引用；停用不级联修改渠道状态，但阻断新业务引用。
- 渠道子表字段、对接方式、启停与出库引用以物流渠道套件为准；本子表承担入口与默认所属承运商带入。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与防重 | 物流承运商编码全系统唯一，保存前去首尾空格并校验重复；一经保存不可修改 | 名称、简称不做全局唯一校验（以详细稿为准） |
| R02 | 状态与审核 | 仅维护使用状态（启用/停用）；不设草稿、提交、审核；新建保存后默认启用 | 启停直接生效 |
| R03 | 与渠道归属 | 每个物流渠道必须归属一个承运商；**新增渠道**时所属承运商须为启用状态 | 既有渠道保留归属；父承运商停用后见 R06 |
| R04 | 引用与变更 | 名称、简称、联系信息变更不回写历史出库单与交接已固化的快照 | 快照字段见出库相关 PRD 与字段清单 |
| R05 | 权限与范围 | 资料访问受仓库授权约束；维护动作须具备物流承运商资料维护权限；四仓共用档案，列表不按仓过滤 | 细则见公共能力需求分析 |
| R06 | 停用与级联 | 承运商停用前：其下物流渠道须均已停用，**或**不存在仍被未完结出库/交接引用的启用渠道；不满足则拒绝停用并提示依据 | 停用成功后不强制改写渠道使用状态；但其下所有渠道均不得用于新出库接单或新增交接引用，即使渠道仍为启用。恢复承运商后仍须渠道自身为启用 |
| R07 | 删除 | 一期不提供物理删除入口；历史保留 | 与全局转换说明一致 |
| R08 | 导入 | 一期不做批量文件导入；列表页头不出现导入 | 导出可按 Demo 需要保留为 Mock |

### 4.2 F01 物流承运商档案维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 引入新承运企业，或更新联系人与备注。 |
| 操作与处理 | 在物流承运商列表查询、新增或编辑；列表按物流承运商编码、名称、使用状态筛选；默认列与可选列见 Demo PRD。编码在编辑弹窗只读。 |
| 功能规则 | 必填项以详细稿为准；外部物流承运商代码为对接占位，可空；联系人电话按文本保存，一期不做 E.164 强校验；邮箱可做基础格式校验。 |
| 成功结果 | 生成或更新一条承运商记录；启用状态下可供新增渠道选择所属承运商。 |
| 异常与恢复 | 校验失败阻止保存并定位字段，已填内容保留。 |

### 4.3 F02 启用与停用

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 暂停或恢复与某承运企业的协作。 |
| 操作与处理 | 列表或详情页头执行启用/停用；停用前二次确认。 |
| 功能规则 | 停用条件见 R06；启用无额外前置（不因下属渠道状态自动启用渠道）。 |
| 成功结果 | 停用后立即阻断新出库与新交接对该承运商下渠道的引用资格（结合渠道自身状态）；历史单据与交接保留快照。 |
| 异常与恢复 | 条件不满足时阻止停用并说明：仍存在启用渠道，或存在未完结引用。 |

### 4.4 F03 详情页物流渠道子表

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 在承运商视角查看并维护下属渠道。 |
| 操作与处理 | 列表点击编码进入详情；子表展示当前承运商下渠道，列与渠道列表对齐（不含「所属物流承运商」列）；行内查看、编辑、启停；页头「新增渠道」在承运商为启用时可用，默认带入当前承运商。 |
| 功能规则 | 渠道字段校验、启停与出库引用规则以[《物流渠道资料主PRD》](../物流渠道资料/物流渠道资料主PRD.md)为准；子表与渠道列表共用 `ChannelFormDialog`（见物流渠道 Demo PRD）。 |
| 成功结果 | 子表与渠道列表数据一致；保存后刷新子表。 |
| 异常与恢复 | 承运商停用时不隐藏既有渠道行，但不可用于新业务引用。 |

### 4.5 状态与动作

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可供新增渠道选择所属承运商 | 新建保存或人工启用 | 否 |
| 停用 | 停止新业务对其下渠道的引用资格（结合渠道规则） | 人工停用且通过 R06 校验 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果与业务影响 | 失败处理 |
| --- | --- | --- | --- | --- |
| 无（新建） | 保存 | 必填与 R01 通过 | 建档成功，默认启用 | 校验失败阻止保存 |
| 启用 | 停用 | R06 满足 | 新出库接单与新交接不得再选用其下渠道 | R06 不满足则阻止并提示 |
| 停用 | 启用 | 无 | 恢复新增渠道可选；新出库/交接仍须渠道自身启用且满足渠道侧规则 | 无 |

## 五、上下游影响与协同

| 关联模块 | 变化与交接内容 | 验收要点 |

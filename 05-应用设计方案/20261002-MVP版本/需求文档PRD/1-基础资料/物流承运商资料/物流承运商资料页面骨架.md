## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 物流承运商列表 | 基础资料 → 物流承运商 | 查询承运企业，进入详情或弹窗维护 |
| 物流承运商详情 | 列表点击承运商编码 | 只读主档 + 下属渠道子表（独立路由） |
| 承运商 Dialog | 列表/详情「新增」「编辑」 | 新建或修改单条承运商 |
| 物流渠道 Dialog | 详情子表或渠道菜单 | `ChannelFormDialog`（规则见物流渠道套件） |
| 确认 Dialog | 停用承运商、放弃未保存 | 二次确认 |

**本期不提供**：导入、审核页签、独立路由编辑承运商；无 `StatusTabs`、无行勾选。

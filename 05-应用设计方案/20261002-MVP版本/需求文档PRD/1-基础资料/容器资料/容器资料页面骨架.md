# 容器资料页面骨架

> 文档版本：WMS-V1.0｜日期：2026-10-27｜状态：待评审。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；动作条件以[《容器资料主PRD》](容器资料主PRD.md)为准；字段以[《容器（详细稿）》](../../../字段清单合集/01-基础资料/容器/容器（详细稿）.tsv)为准；交互见[《容器资料前端Demo版PRD》](容器资料前端Demo版PRD.md)。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 容器列表 | `/wms/master/containers` | 基础资料 → 容器管理 | 查询、进入详情、新增内部容器、停用/启用 |
| 容器详情 | `/wms/master/containers/:containerNo` | 列表点容器号；收货/上架/复核/库存引用 | 查看基本信息、容量、内容、关联单据、操作记录 |
| 新增容器 Dialog | 列表「新增容器」 | 管理端建立内部容器 | 录入容器号、类型、货主、容量、备注 |
| 编辑容器 Dialog | 详情/列表「编辑」 | 修改容量、父容器、备注 | 容器号只读 |
| 停用/启用确认 Dialog | 列表/详情 | 状态动作 | 二次确认并显示引用阻断 |

**本期不提供**：容器类型字典维护页、跨仓调拨、清洗维修报废、批量导入、按容器预占/盘点的独立入口。

## 列表页

- **用途**：按当前仓库查询容器，进入详情或新增内部容器。
- **关键要素**：页头「新增容器」「导出」；FilterBar 6 列；5 个筛选项常显；表格列：容器号、类型、货主、状态、当前库位、内容、最近扫描时间、操作。

```text
+-- PageContainer fill -------------------------------------------------------------------------+
| 容器管理                                                          [+ 新增容器] [导出]        |
| +-- Panel (筛选) -----------------------------------------------------------------------------+|
| | FilterBar · columns={6}                                                                     ||
| | 容器号            | 容器类型       | 货主           | 状态           | 当前库位          | 查询 重置 ||
| | [扫描或输入箱唛]  | [全部 v]       | [全部 v]       | [全部 v]       | [请输入]          |          ||
| +---------------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) ----------------------------------------------------------------------+|
| | 容器号(链) | 容器类型 | 货主 | 状态 | 当前库位 | 内容 | 最近扫描时间 | 操作              ||
| | C-M01      | 箱       | ANKR | 上架中 | -      | 3 SKU·9件 | 2026-10-11 | 详情 停用       ||
| | C-B07      | 箱       | ANKR | 在库   | B-01-01 | 1 SKU·20件 | 2026-10-08 | 详情           ||
| +---------------------------------------------------------------------------------------------+|
| | 共 N 条  每页 20 [20 v]                                              < 1 2 3 >             ||
+------------------------------------------------------------------------------------------------+
```

**补充说明**：

- 容器号可点进详情；行内不设「查看」。
- 状态由作业驱动，列表不提供手工改状态；仅停用/启用。
- 当前库位为空显示 `-`；内容为 0 时显示 `-`。
- 已停用容器行灰色显示，仍可查历史。

## 详情页

- **用途**：查看容器身份、容量、内容、关联单据和操作记录。
- **关键要素**：`DetailTitle`「作业容器 · 容器号 [状态]」；右侧「返回容器列表」「编辑」「停用/启用」；基本信息 3 列 + 320px 内容汇总卡；页签：容器内容、关联单据、操作记录。

```text
+-- PageContainer -------------------------------------------------------------------------------+
| 作业容器 · C-M01 [上架中]                              [返回容器列表] [编辑] [停用]          |
| +-- Section 基本信息 (3列) ------------------------------+ +-- SummaryCard 320px -----------+|
| | 容器号 C-M01        | 容器类型 箱     | 来源 内部       | | 容器内容                       ||
| | 货主 ANKR           | 当前仓库 US-LA  | 当前库位 -      | | SKU 种类 3                     ||
| | 父容器号 -          | 最近扫描时间 …  | 最近扫描人 …    | | 件数 9                         ||
| +---------------------------------------------------------+ | 未设置容量上限                 ||
| +-- Section 容量与备注 (3列) -----------------------------+ +--------------------------------+|
| | 最大件数 - | 最大重量 - | 最大体积 - | 备注 -                                              ||
| +---------------------------------------------------------------------------------------------+|
| +-- DetailTabs ?tab= --------------------------------------------------------------------------+|
| | (容器内容 3) (关联单据 2) (操作记录 1)                                                       ||
| | SKU | 批次 | 生产日期 | 品质 | 当前库位 | 件数 | SN数 | 来源                                ||
+------------------------------------------------------------------------------------------------+
```

**补充说明**：

- 状态只在标题显示；基本信息不重复。
- 内容页签按 SKU/批次/品质/当前库位拆行；容器内容不手工编辑。
- 关联单据页签只读，单号可跳转；空态「暂无关联单据」。
- 停用/启用按状态显示；有库存或未完结引用时阻断并列出对象。

## 新增/编辑 Dialog

```text
+--------------------------------------------------------------+
| 新增作业容器                                              [×] |
|--------------------------------------------------------------|
| 容器号*        [扫描或输入箱唛/托唛                         ] |
| 容器类型*      [箱 v]        所属货主* [请选择 v]           |
| 当前仓库       [US-LA-01 美西仓]（只读）                     |
| 最大件数       [      ]      最大重量(kg) [      ]          |
| 最大体积(m³)   [      ]      父容器号     [请选择 v]        |
| 备注           [多行文本                                  ] |
|--------------------------------------------------------------|
|                                      [取消] [保存]          |
+--------------------------------------------------------------+
```

**补充说明**：

- 编辑时容器号只读；当前仓库、货主只读。
- 容量为空表示不限制；需为正数/非负数。
- 父容器必须同仓同货主；最多一层。
- 保存成功 Toast「容器已保存」；重复容器号字段下提示。

## 停用/启用 Dialog

```text
+--------------------------------------------------+
| 停用容器 C-M01                                [×] |
|--------------------------------------------------|
| 停用后不再参与新收货、上架、复核或出库作业；       |
| 历史记录保留。                                     |
| 当前引用：库存 1 行 / 上架单 1 张（如有）          |
|--------------------------------------------------|
|                          [取消] [确认停用]        |
+--------------------------------------------------+
```

**补充说明**：

- 有库存或未完结引用时不展示确认按钮，直接列出阻断对象。
- 启用只恢复档案可用，不自动恢复原作业状态。

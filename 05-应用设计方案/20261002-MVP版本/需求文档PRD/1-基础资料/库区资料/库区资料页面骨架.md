## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 库区列表 | 基础资料 → 库区管理 | 查询、新增、启停 |
| 新增库区 | 列表「+ 新增」 | `/zones/new` |
| 库区详情 | 列表点击库区编码 | 只读 + 维护信息 |
| 编辑库区 | 列表/详情「编辑」 | 独立路由表单 |
| 确认 Dialog | 停用、放弃未保存 | 二次确认 |

**本期不提供**：导入、审核、物理删除。

## 列表页

- **关键要素**：`PageContainer fill`；「导出 Mock」「+ 新增」；双 `Panel`；`FilterBar` **6 列**（4个字段，操作紧随其后，不展示展开）；`DataTable` 无勾选、无 `StatusTabs`。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库仅影响业务单，列表展示授权内全部库区) ----+
| PageContainer fill                                                                 |
|  库区管理                                              [导出 Mock]  [+ 新增]         |
| +-- Panel (筛选) ------------------------------------------------------------------+|
| | FilterBar · 6 列（4个字段＋操作列）                                              ||
| | 所属仓库 | 库区编码 | 库区名称 | 使用状态 | [查询][重置]               ||
| +----------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) -----------------------------------------------------------+|
| | 所属仓库 | 库区编码(链) | 名称 | 类型 | 状态 | 最后修改 | 修改人 | 操作          ||
| | 共 N 条   每页 20                                              < 1 >              ||
| +----------------------------------------------------------------------------------+|
```

编码进详情路由（须带仓库上下文，见 Demo PRD）。

## 详情页（独立路由）

```text
|  查看库区详情  [StatusBadge]  Z-PICK          [返回列表]  [编辑]  [停用/启用]       |
| +-- Panel: 基础信息 — Descriptions 4 列 -------------------------------------------+|
| | 所属仓库 | 编码 | 名称 | 类型 | 状态 | 备注(跨列)                                  ||
| +-- Panel: 维护信息 — 最后修改人 | 最后修改时间 -------------------------------------+|
```

## 新增/编辑页（独立路由）

```text
| 新增库区 / 编辑库区                                    [取消]  [保存]              |
| +-- Panel: 基础信息 — 所属仓库* | 编码* | 名称* | 类型* | 备注(跨列) -----+|
```

有占用时所属仓库只读（R04）。取消有改动 →「放弃修改？」Dialog。

停用：「确认停用库区？」— 说明 R08（不级联库位、限制新建与推荐落位）。文案见 Demo PRD。

## 一、文档概要

需求类型：基础资料 → 仓库资料。

上游：[《基础资料需求分析》](../../../../../03-需求调研和分析/01-基础资料/基础资料需求分析.md)（MD-FR-003、006、007、008）、[《基础资料业务设计》](../../../../../04-业务分析和设计/01-基础资料业务设计.md)。

## 二、需求背景与范围

仓库是权限范围、业务指令、库存与单据的共同锚点。一期默认预置香港、美西、美东、德国四仓；一期不提供业务侧新增，具备权限的人员维护名称、时区、币别、单位、结构化地址、联系人、暂存库位及默认收货方式。

| 对象 | 用途 | 数据来源 | 维护方 | 引用方 |
| --- | --- | --- | --- | --- |
| 仓库 | 身份、地址、时区币别；权限与指令仓库维度 | 系统预置四仓 | 具备仓库资料维护权限的用户 | 入出库、库存、库区库位、数据权限 |

**本期做**：四仓种子；编码保存后不可改；列表查询与详情；编辑可维护字段；使用状态只读展示，四仓默认启用，不开放新增和启停入口；变更留痕；导出仅 Demo Mock（非一期业务能力）。

**本期不做**：复制；实体仓／逻辑仓；审核流；批量导入；对接与第三方映射；物理删除；汇率主数据。列表不出现 ERP 版运营类型、对接方式、审核状态等列。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 预置与建仓 | 初始化四仓；一期无新增入口；编码全系统唯一、预置后不可修改；无复制、导入 | 既有原型新增能力须移除，不能作为一期范围 |
| R02 | 时区与币别 | IANA 时区；ISO 4217 币别 | 业务日期按所属仓时区 |
| R03 | 地址与联系 | 结构化地址 + 只读「地址完整展示」；联系人选填 | 国家/地区用字典；一期不强校验邮编 |
| R04 | 状态 | 仅启用／停用，无审核 | 四仓默认启用，状态只读；一期无用户启停入口 |
| R05 | 引用与变更 | 资料变更不回写历史单据 | MD-FR-007 |
| R06 | 删除与导入 | 无物理删除、无导入入口 | 全局一致 |
| R07 | 权限 | 仅授权仓库范围；维护须权限点 | 见公共能力 |

### 4.2 F01 列表与详情

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 核对四仓资料或查看地址、时区。 |
| 操作与处理 | 按编码、名称、状态、国家/地区等查询；点击编码进详情；分区展示基础、地址、联系、维护信息。 |
| 功能规则 | 投影以详细稿「列表展示」「详情展示」为准；编码、地址完整展示、系统字段只读。 |
| 成功结果 | 授权范围内当前资料可见。 |
| 异常与恢复 | 无授权则空列表；无匹配则空状态。 |

### 4.3 F02 编辑维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 地址/联系人变更或纠正时区、币别。 |
| 操作与处理 | 从列表／详情进入编辑，无新增仓库路由和入口；保存更新维护人、维护时间。 |
| 功能规则 | 编码只读。维护字段见详细稿；名称、时区、币别、国家／地区、城市、地址1等按既有要求校验。收货暂存与出库暂存须为本仓启用暂存库位且不同；默认收货方式可按仓配置；单位统一cm／kg存储。 |
| 成功结果 | 新业务读最新值；历史快照不变。 |
| 异常与恢复 | 校验失败阻止保存。 |

### 4.4 F03 使用状态

四仓预置为启用；一期列表、详情只读显示状态，不提供业务侧新增与启停。已存在的原型按钮和新增路由属于待修实现，不回写为一期能力。

### 4.5 F04 变更留痕

创建人/时间、最后修改人/时间只读；关键展示字段变更不回写历史单据。

### 4.6 F05 数据权限

列表与详情仅返回授权仓库；维护还须动作权限。

### 4.7 状态与动作

| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| 启用 | 可作新业务仓库引用 | 系统预置，默认启用 |
| 停用 | 不可作新业务引用 | 「停用」且通过 MD-FR-006 |

| 当前状态 | 动作 | 结果 |
| --- | --- | --- |
| 启用 | 编辑保存 | 更新可维护字段 |
| * | 导出（Demo） | Mock 提示，非真实导出 |

## 五、上下游影响

入库校验仓库启用；库存按仓库维度；库区库位归属仓库不可通过改资料变更；一期不在仓库主档维护 OMS 映射。

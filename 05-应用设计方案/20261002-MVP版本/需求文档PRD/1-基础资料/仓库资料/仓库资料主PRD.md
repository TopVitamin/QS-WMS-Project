上游：[《基础资料需求分析》](../../../../../03-需求调研和分析/01-基础资料/基础资料需求分析.md)（MD-FR-003、006、007、008）、[《基础资料业务设计》](../../../../../04-业务分析和设计/01-基础资料业务设计.md)。

## 二、需求背景与范围

仓库是权限范围、业务指令、库存与单据的共同锚点。一期默认预置香港、美西、美东、德国四仓；有权限人员可**新增**仓库（唯一编码）或维护名称、时区、币别、结构化地址、联系人与备注。

| 对象 | 用途 | 数据来源 | 维护方 | 引用方 |
| --- | --- | --- | --- | --- |
| 仓库 | 身份、地址、时区币别；权限与指令仓库维度 | 预置四仓 + 管理端新增 | 具备仓库资料维护权限的用户 | 入出库、库存、库区货位、数据权限 |

**本期做**：四仓种子与手动新增；编码保存后不可改；列表查询与详情；编辑可维护字段；**启用／停用**（详情页头与列表操作列，新增/编辑表单不出现状态）；变更留痕；导出仅 Demo Mock（非一期业务能力）。

**本期不做**：复制；实体仓／逻辑仓；审核流；批量导入；对接与第三方映射；物理删除；汇率主数据。列表不出现 ERP 版运营类型、对接方式、审核状态等列。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 预置与建仓 | 初始化四仓；可新增第 5 个及以后仓；编码全系统唯一、**保存后不可改**；无复制、导入 | Demo 新增写入本地 Mock |
| R02 | 时区与币别 | IANA 时区；ISO 4217 币别 | 业务日期按所属仓时区 |
| R03 | 地址与联系 | 结构化地址 + 只读「地址完整展示」；联系人选填 | 国家/地区用字典；一期不强校验邮编 |
| R04 | 状态 | 仅启用／停用，无审核 | 新增默认启用；状态在列表/详情维护，**不在新增/编辑表单**；停用落实 MD-FR-006 |
| R05 | 引用与变更 | 资料变更不回写历史单据 | MD-FR-007 |
| R06 | 删除与导入 | 无物理删除、无导入入口 | 全局一致 |
| R07 | 权限 | 仅授权仓库范围；维护须权限点 | 见公共能力 |

### 4.2 F01 列表与详情

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 核对四仓资料或查看地址、时区。 |
| 操作与处理 | 按编码、名称、状态、国家/地区等查询；点击编码进详情；分区展示基础、地址、联系、维护信息。 |
| 功能规则 | 投影以详细稿「列表展示」「详情展示」为准；编码、地址完整展示、系统字段只读。 |
| 成功结果 | 授权范围内当前资料可见。 |
| 异常与恢复 | 无授权则空列表；无匹配则空状态。 |

### 4.3 F02 编辑维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 地址/联系人变更或纠正时区、币别。 |
| 操作与处理 | 页头新增，或列表/详情进编辑；保存更新维护人、维护时间。 |
| 功能规则 | 新增可录编码（必填、唯一）；编辑编码只读。可编辑项见详细稿。必填：编码（新增）、名称、时区、币别、国家/地区、城市、地址1 等；邮箱格式校验。 |
| 成功结果 | 新业务读最新值；历史快照不变。 |
| 异常与恢复 | 校验失败阻止保存。 |

### 4.4 F03 使用状态

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 暂停或恢复某仓接新指令。 |
| 操作与处理 | **详情页头**或**列表操作列**启停；二次确认；新增保存后默认启用。 |
| 功能规则 | 停用后新业务不得引用；停用前 MD-FR-006 校验与入出库/库存对齐。Demo 可确认框 + Mock；完整校验联调补齐。 |
| 成功结果 | 列表筛选与状态展示同步。 |
| 异常与恢复 | 校验失败保持原状态。 |

### 4.5 F04 变更留痕

创建人/时间、最后修改人/时间只读；关键展示字段变更不回写历史单据。

### 4.6 F05 数据权限

列表与详情仅返回授权仓库；维护还须动作权限。

### 4.7 状态与动作

| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| 启用 | 可作新业务仓库引用 | 预置、新增默认或执行「启用」 |
| 停用 | 不可作新业务引用 | 「停用」且通过 MD-FR-006 |

| 当前状态 | 动作 | 结果 |
| --- | --- | --- |
| 启用 | 编辑保存 | 更新可维护字段 |
| 启用 | 停用 | 变为停用 |
| 停用 | 启用 | 变为启用 |
| * | 导出（Demo） | Mock 提示，非真实导出 |

## 五、上下游影响

入库校验仓库启用；库存按仓库维度；库区货位归属仓库不可通过改资料变更；一期不在仓库主档维护 OMS 映射。

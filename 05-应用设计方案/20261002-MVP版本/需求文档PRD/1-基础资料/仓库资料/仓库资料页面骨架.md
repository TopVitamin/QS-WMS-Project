## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 仓库列表 | 基础资料 → 仓库资料 | 查询授权仓库、进入详情或编辑 |
| 仓库详情 | 列表点击仓库编码 | 分组只读（独立路由） |
| 仓库新增 | 列表「+ 新增」 | `/warehouses/new` |
| 仓库编辑 | 列表/详情「编辑」 | 独立路由 |
| 确认 Dialog | 新增/编辑取消或返回且有改动 | 放弃未保存修改 |

**本期不提供**：导入、审核页签、Sheet 抽屉详情。

## 列表页

- **关键要素**：`PageContainer fill`；页头「+ 新增」「导出 Mock」；双 `Panel`；`FilterBar` **6 列**（5 字段 + 查询/重置）；`DataTable` 无勾选、无 `StatusTabs`；编码链详情；行内编辑 + 启停。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库仅影响业务单，列表仍展示授权内全部仓库) ------------+
| PageContainer fill                                                                 |
|  仓库管理                                              [+ 新增]  [导出 Mock]      |
| +-- Panel (筛选) ------------------------------------------------------------------+|
| | FilterBar · 6 列（5 字段 + 操作列）                                              ||
| | 仓库编码     | 仓库名称     | 使用状态   | 国家/地区  | 最后修改时间      | 操作列 ||
| | [编码]       | [名称]       | [状态 v]   | [国家 v]   | [选择日期范围]    |[查询][重置]||
| +----------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) -----------------------------------------------------------+|
| | DataTable 工具区: [列设置]                                                        ||
| | | 仓库编码(链) | 名称 | 时区 | 状态 | 地址摘要 | 最后修改 | 操作(编辑+启停) |     ||
| | 共 N 条   每页 20                                              < 1 >              ||
| +----------------------------------------------------------------------------------+|
+------------------------------------------------------------------------------------+
```

## 详情页（独立路由）

```text
+------------------------------------------------------------------------------------+
|  查看仓库详情 · US-LA-01 [StatusBadge]    [返回列表]  [停用/启用]  [编辑]         |
| +-- Panel: 基础信息（Descriptions 4 列） ------------------------------------------+|
| | 编码 | 名称 | 时区 | 币别 | 状态 | 备注(跨列)                                      ||
| +-- Panel: 地址信息 ---------------------------------------------------------------+|
| | 国家/地区 … 地址完整展示(只读,整行)                                                ||
| +-- Panel: 联系信息 ---------------------------------------------------------------+|
| +-- Panel: 维护信息（最后修改人、最后修改时间） ------------------------------------+|
+------------------------------------------------------------------------------------+
```

无删除、审核；启停二次确认；状态不在新增/编辑表单。

## 编辑页 / 新增页（独立路由）

```text
| 编辑仓库 / 新增仓库                                    [取消]  [保存]              |
| +-- Panel: 基础信息 — 编码*(新增可录/编辑只读) | 名称* | 时区* | 币别* | 备注(跨列) ||
| +-- Panel: 地址信息 — 国家/地区* … | 地址完整展示(只读，保存后刷新)                 ||
| +-- Panel: 联系信息 — 姓名 | 电话 | 邮箱                                            ||
```

## Dialog（放弃修改）

```text
+-------------------------------------+
| 放弃修改？                       [×] |
| 当前编辑尚未保存，确定离开吗？       |
|                  [继续编辑] [放弃]   |
+-------------------------------------+
```

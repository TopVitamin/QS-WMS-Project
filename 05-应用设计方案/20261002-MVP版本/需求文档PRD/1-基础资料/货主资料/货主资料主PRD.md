## 一、文档概要

需求类型：基础资料 → 货主资料。

上游：[《基础资料需求分析》](../../../../03-需求调研和分析/01-基础资料/基础资料需求分析.md)（MD-FR-001、006、007、008、009、011）、[《基础资料业务设计》](../../../../04-业务分析和设计/01-基础资料业务设计.md)。

## 二、需求背景与范围

货主是库存、作业单据与指令的归属主体。一期由 OMS Mock 推送外部货主身份，系统预置自营货主；WMS 保留上游货主标识，并在管理端补充联系地址与作业控制。货主联系地址用于通知与导出，**不是**出库收件地址。

| 对象 | 用途 | 数据来源 | 维护方 | 引用方 |
| --- | --- | --- | --- | --- |
| 货主 | 身份、作业配置、联系地址 | 预置自营 + OMS Mock 推送 | 身份由预置/上游写入；可编辑字段由有权限用户维护 | 入出库、库存指令货主；商品按货主建档 |

**本期做**：列表查询与详情；同页编辑可改字段；**启用／停用**（列表操作列与详情页头，**不在编辑表单**）；上游货主标识与最近资料同步时间展示；推送创建/更新可变更字段。

**本期不做**：管理端新增货主；复制；审核流；批量导入；物理删除；货主级用户数据授权（一期有仓权限可见全部货主）；收费/自助门户；出库收件地址。列表无审核状态列；页头无「新增」、无导入（导出仅 Demo Mock）。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与身份 | 货主编码全系统唯一，管理端不可改；与上游货主标识并存 | 外部货主编码与推送一致；自营预置 |
| R02 | 来源与建档 | 无管理端「新增货主」；记录仅预置自营或推送成功创建/更新 | 拒收见系统集成需求分析 |
| R03 | 维护与同步 | 再次推送按集成约定更新可变更字段；冲突拒收 | 货主备注仅 WMS 本地维护 |
| R04 | 自营货主 | 预置、不可删除、不可改为外部 | 外部类型只读 |
| R05 | 引用与快照 | 资料变更不回写历史单据 | MD-FR-007 |
| R06 | 停用校验 | 停用前校验库存、过程量、预占、盘点锁定等 | 细则见需求分析 MD-FR-006 |
| R07 | 删除与导入 | 无物理删除、无导入入口 | 全局一致 |
| R08 | 作业控制 | 「上架库位推荐时机」仅影响推荐时机与默认值 | 三选一；外部货主默认「上架扫描时再推荐」 |

### 4.2 F01 列表与详情

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 核对身份、地址、作业配置并进入维护。 |
| 操作与处理 | 按编码、名称、类型、状态、国家/地区、上游货主标识查询；点击编码进详情；分区展示基础、作业控制、上游对接、地址、联系、维护信息。 |
| 功能规则 | 投影以详细稿为准；列表摘要用只读「地址完整展示」。 |
| 成功结果 | 授权范围内货主可见。 |
| 异常与恢复 | 无匹配则空状态。 |

### 4.3 F02 编辑可改字段

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 校对名称与地址；配置上架库位推荐时机；补充备注。 |
| 操作与处理 | 详情 `?edit=1` 或页内进入编辑；保存更新维护人、维护时间。 |
| 功能规则 | 编码、类型、上游标识、最近同步时间、地址完整展示只读。**使用状态不在编辑表单**（F03）。可编辑：名称、备注、推荐时机、结构化地址与联系人。上架库位推荐时机必填；邮箱可做格式校验。 |
| 成功结果 | 新业务读最新值；历史快照不变。 |
| 异常与恢复 | 校验失败阻止保存。 |

### 4.4 F03 使用状态

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 暂停或恢复接新指令。 |
| 操作与处理 | **详情页头**或**列表操作列**启停；停用前 R06。 |
| 功能规则 | 仅启用／停用。已停用不得作新业务指令货主（MD-FR-011）。 |
| 成功结果 | 列表与详情状态一致。 |
| 异常与恢复 | 停用校验失败保持启用。 |

### 4.5 F04 上游同步展示

详情「上游对接」只读展示上游货主标识、最近资料同步时间；列表可按上游标识筛选。成功接收/更新后系统刷新同步时间（UTC 存库，展示按用户时区）。

### 4.6 状态与动作

| 状态 | 含义 | 进入条件 |
| --- | --- | --- |
| 启用 | 可作新业务指令货主 | 预置、推送默认或「启用」 |
| 停用 | 不可作新业务指令货主 | 「停用」且通过 R06 |

| 当前状态 | 动作 | 结果 |
| --- | --- | --- |
| 启用 | 编辑保存 | 更新可维护字段 |
| 启用 | 停用 | 变为停用（R06） |
| 停用 | 启用 | 变为启用 |
| * | 导出（Demo） | Mock 提示 |

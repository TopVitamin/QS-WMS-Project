## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 货主列表 | 基础资料 → **货主管理** | 查询货主，进入详情或行内启停 |
| 货主详情 | 列表点击货主编码 | 分组只读查看；同路由 `?edit=1` 编辑 |
| 确认 Dialog | 停用、离开未保存编辑 | 二次确认 |

**本期不提供**：新增货主页、独立 `/edit` 路由、导入、审核页签、Sheet 抽屉详情。

## 列表页

- **关键要素**：`PageContainer fill`；`title` 对齐菜单「货主管理」；页头**仅**「导出 Mock」（**无**「+ 新增」）；双 `Panel`；`FilterBar` **6 列**（5 字段 + 查询/重置/展开）；`DataTable` 无勾选、无 `StatusTabs`。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库，列表展示全部货主) --------------------------------+
| PageContainer fill                                                                 |
|  货主管理                                                         [导出 Mock]        |
| +-- Panel (筛选) ------------------------------------------------------------------+|
| | FilterBar · 6 列（5 字段 + 操作列）                                              ||
| | 货主编码 | 货主名称 | 货主类型 | 使用状态 | 国家/地区 | [查询][重置][展开]       ||
| | (展开) 上游货主标识 [请输入]                                                      ||
| +----------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) -----------------------------------------------------------+|
| | DataTable 工具区: [列设置]                                                        ||
| | +------------------------------------------------------------------------------+||
| | | 货主编码(链) | 名称 | 类型 | 状态 | 地址完整展示 | 最后修改时间 | 操作        |||
| | | OWNER-SELF   | …    | 自营 | 启用 | 中国…        | …            | 编辑 停用   |||

```

- 路由：`/wms/master/customers`。编码链 `/wms/master/customers/:code`；行内「编辑」→ 同 path + `?edit=1`。
- 停用：先 R06 预校验，失败 toast；通过后再确认 Dialog。
- 列设置可选扩展须符合 Demo PRD；**维护列默认仅最后修改人、最后修改时间**（不默认创建人/创建时间）。

## 详情页（`/customers/:code` · 查看 / `?edit=1` 编辑）

- **关键要素**：`PageContainer` + 多 `Panel`；view 用 `Descriptions columns={4}`；edit 用表单控件同区替换。

**只读模式页头**：`返回列表`、`编辑`（primary）、`停用`/`启用`。

**编辑模式页头**：`返回列表`、`取消`、`保存`。

```text
+------------------------------------------------------------------------------------+
| PageContainer                                                                      |
|  货主管理 · OWNER-B  [启用]              [返回列表]  [编辑]  [停用]                  |
|  (?edit=1 时 actions: [返回列表] [取消] [保存])                                     |
| +-- Panel: 基础信息 ----------------------------------------------------------------+|
| | 货主编码 | 货主名称 | 货主类型 | 使用状态（view 只读，edit 仍只读展示 Badge 旁）  ||
| | 货主备注（整行）                                                                  ||
| +------------------------------------------------------------------------------------+|
| +-- Panel: 作业控制 — 上架库位推荐时机 ----------------------------------------------+|
| +-- Panel: 上游对接 — 上游货主标识 | 最近资料同步时间 -------------------------------+|
| +-- Panel: 地址信息 — 国家/地区 … | 地址完整展示(整行) ------------------------------+|
| +-- Panel: 联系信息 ----------------------------------------------------------------+|
| +-- Panel: 维护信息 — 最后修改人 | 最后修改时间 （MasterAuditPanel，无创建人/时间）  ||
+------------------------------------------------------------------------------------+
```

- 分区顺序：基础信息 → 作业控制 → 上游对接 → 地址信息 → 联系信息 → 维护信息。
- 编码、类型、上游标识、最近同步时间、地址完整展示始终只读；**启停不在编辑表单改状态**。
- 无删除、无审核按钮。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 商品列表 | `/wms/master/skus` | 基础资料 → 商品 SKU（`menu.skus`） | 按货主与编码查询，进入详情或编辑 |
| 商品详情 | `/wms/master/skus/:ownerCode/:skuCode` | 列表点击商品编码 | 只读主档、条码子表、维护信息（独立路由页） |
| 商品编辑 | `/wms/master/skus/:ownerCode/:skuCode/edit` | 列表/详情「编辑」 | 维护可编辑字段含追溯配置（独立路由页；不含条码子表） |
| 条码 Dialog | 详情子表「新增条码」或行内编辑 | 维护条码行（小表单） |  — |
| 确认 Dialog | 停用商品、放弃编辑 | 有后果操作二次确认 |  — |

**本期不提供**：手工新建 SKU 主档页、导入、审核页签、Sheet 抽屉详情（含子表，用路由页）。

容器选型：主档字段多 + 条码子表 → **独立路由**详情/编辑；条码行 **Dialog**（≤4 字段，对齐规范 §4.3）。

## 列表页

- **用途**：查询 OMS 推送的全部商品，进入详情或编辑。
- **关键要素**：仅导出 Mock；`FilterBar` **6 列**栅格（常显筛选项 + 第 6 列查询/重置/展开）；`DataTable` 无勾选、无状态页签；商品编码链至详情；列表默认含最后修改时间、最后修改人。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库 US-LA-01，商品列表展示全部货主商品) ------------------+
| PageContainer fill                                                                   |
|  商品 SKU                                                           [导出 Mock]        |
| +-- Panel (筛选) ----------------------------------------------------------------------+|
| | FilterBar · 6 列                                                                    ||
| | 所属货主          | 商品编码          | 商品名称          | 使用状态 [全部 v]      ||
| | [全部货主 v]      | [请输入编码]      | [请输入名称]      | [查询][重置][展开]     ||
| | (展开) 主条码 [输入] | 商品形态 [全部 v] | 是否启用 SN [全部 v] | 最后修改时间 [范围] ||
| +--------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) ----------------------------------------------------------------+|
| | DataTable 工具区: [列设置]                                                            ||
| | +----------------------------------------------------------------------------------+||
| | | 货主     | 商品编码(链) | 商品名称   | 主条码       | 单位 | 形态 | 状态 | 修改时间 | 修改人 | 操作 ||
| | | 自营     | CABLE-01     | USB数据线  | 690000000001 | 件   | 轻小 | 启用 | …        | 编辑 ||
| | | 外部货主A| CABLE-01     | 同名样例   | 690000000002 | 件   | 轻小 | 启用 | …        | 编辑 ||
| | +----------------------------------------------------------------------------------+||
| | 共 N 条   每页 20 [20 v]                                        < 1 2 3 >            ||
| +--------------------------------------------------------------------------------------+|
+----------------------------------------------------------------------------------------+
```

**补充说明**：

- **图中省略**：列拖拽、排序、空态见 Demo PRD；页头**无「新增 SKU」、无导入**。
- 数据范围：商品列表展示全部货主的商品；一期不提供登录、角色或用户仓库授权校验，仍展示货主列。
- 行内「编辑」进编辑路由；编码点击进入**详情路由**；启用/停用可收进「更多」或页头详情操作（见 Demo PRD）。

## 编辑页（独立路由）

- **用途**：保存可编辑主档字段（含**追溯配置**、尺重）；身份字段只读；条码仍在详情子表维护（编辑页不嵌子表，或子表只读提示「请保存后于详情维护条码」——Demo 采用**编辑页不含子表**，保存后回详情）。
- **关键要素**：页头 **取消**、**保存**；追溯区含 SN/批次/效期及效期天数；条件显示见 Demo PRD。

```text
+----------------------------------------------------------------------------------------+
| 编辑商品 · 自营 / CABLE-01                                 [取消]  [保存]            |
| +-- Panel: 基础信息 --------------------------------------------------------------------+|
| | 所属货主(只读)    | 商品编码(只读)    | 商品名称*         | 商品名称(英文)    ||
| | 自营              | CABLE-01          | [USB 数据线]      | [输入]            ||
| | 计量单位* [件 v]  | 使用状态 [启用 v] | 商品备注 [多行…………]（占 2～3 列）       ||
| | 上游商品标识(只读) OMS-SKU-xxx                                                        ||
| +----------------------------------------------------------------------------------------+|
| +-- Panel: 识别摘要（只读） ------------------------------------------------------------+|
| | 主条码  690000000001（在详情条码子表维护）                                            ||
| +----------------------------------------------------------------------------------------+|
| +-- Panel: 形态与属性 ------------------------------------------------------------------+|
| | 商品形态* [轻小件 v]  | 是否带电 [否 v]                                              ||
| +----------------------------------------------------------------------------------------+|
| +-- Panel: 追溯配置 --------------------------------------------------------------------+|
| | 是否启用 SN* [否 v]   | SN 格式校验 [输入]（SN=是 时显示）                           ||
| | 是否启用批次* [否 v]  | 是否启用效期* [否 v]                                         ||
| | 保质期天数*           | 允许入库天数*     | 临期天数*         | 过期天数*         ||
| | [正整数]              | [正整数]          | [正整数]          | [正整数]          ||
| | (效期=是 时上述天数必填；保存校验 允许入库≥临期≥过期)                                 ||
| +----------------------------------------------------------------------------------------+|
| +-- Panel: 尺重信息 --------------------------------------------------------------------+|
| | 毛重 [输入] | 净重 [输入] | 长 [输入] | 宽 [输入] | 高 [输入]                      ||
| +----------------------------------------------------------------------------------------+|
+----------------------------------------------------------------------------------------+
```

**补充说明**：

- 取消或浏览器返回：有改动时 `Dialog`「放弃修改？」（同仓库资料）。
- 保存成功：`toast` 后返回详情（或列表，记录 `from`）。

## 骨架检查

- [x] 双 Panel 列表 + FilterBar 6 列；路由 `/wms/master/skus` 及 `…/:ownerCode/:skuCode`（含 `/edit`）
- [x] 无 StatusTabs / 无行勾选 / 无导入 / 无手工新建 SKU
- [x] 详情与编辑为独立路由；详情含条码 `DataTable` 子表
- [x] 编辑页含追溯配置分组，字段与商品详细稿一致
- [x] 条码维护用 Dialog，非独立路由

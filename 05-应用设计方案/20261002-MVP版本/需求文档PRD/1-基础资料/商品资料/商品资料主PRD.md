> 用途：定义 QS-WMS 一期货主维度商品档案的接收、查看、维护、条码子表、启停与追溯配置规则，作为研发实现和测试验收的依据。
> 定位：应用设计层**业务真源**。业务规则以[《基础资料需求分析》](../../../../../03-需求调研和分析/01-基础资料/基础资料需求分析.md)（MD-FR-002、MD-FR-007、MD-FR-009）为准；字段以[《商品（详细稿）》](../../../字段清单合集/01-基础资料/商品/商品（详细稿）.tsv)、[《商品条码（详细稿）》](../../../字段清单合集/01-基础资料/商品/商品条码（详细稿）.tsv)为准；全局约定见[《WMS基础资料PRD转换说明》](../WMS基础资料PRD转换说明.md)。生成或改动 `qs-wms-demo` 见下文「原型阅读路径」。
> 不写什么：不写采购价、销售价、价目表与调价（原 ERP）；不写批量导入、主数据审核、SKU 分发至外部 ERP／WMS、外部平台映射页；不写入出库采集批次／SN 的执行细则，见入库与库存需求分析。

## 二、需求背景与范围

商品是入库、出库、库存与指令匹配的核心对象。每个货主独立建档，业务匹配键为**货主编码 + 商品编码**；商品名称允许重复，同货主内商品编码唯一，不同货主可使用相同编码文本。商品条码在**全系统**唯一，重复不能保存。一期商品身份由 OMS Mock 推送生成，管理端不提供手工新建 SKU 入口；WMS 可维护名称、仓内形态、追溯开关、效期阈值、尺重及条码子表，不得静默改写上游身份字段。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 商品（SKU） | 指令匹配、作业配置、列表查询 | OMS Mock 推送；部分字段管理端补充 | 推送接收 + 管理端编辑 | 入库、出库、库存、PDA 扫描 |
| 商品条码 | 扫描解析到唯一商品 | 推送或详情子表维护 | 商品详情「条码」子表 | 收货、上架、拣货等扫描场景 |

本期做：商品列表与详情；编辑可维护字段；条码子表新增行（保存后条码文本不可改，须停用后新建）；启用／停用及停用校验；效期天数不等式校验；追溯开关切换限制；变更留痕；上游商品标识只读展示。

本期不做：管理端手工新建商品主档；采购价、销售价、初始供应商；商品分类三级树、品牌经营、图片附件位（除非字段稿后续扩展）；批量文件导入；审核流；向 ERP／聚水潭／领星分发 SKU；外部平台店铺映射；包装层次与独立批次属性字典；带电属性的仓内合规硬校验。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 身份与匹配 | 货主编码、商品编码、上游商品标识由推送写入，管理端只读；匹配与更新键为货主编码+商品编码；同货主商品编码唯一 | 身份冲突或无法匹配时拒收并记录原因，不另建身份（MD-FR-009） |
| R02 | 名称与条码 | 商品名称允许重复；条码文本全系统唯一（含子表各行）；同一商品建议仅一条主条码 | 主条码只读汇总展示在商品主档「主条码」字段 |
| R03 | 效期配置 | 启用效期管理时，保质期、允许入库、临期、过期天数必填；须满足允许入库≥临期≥过期（可相等） | 收货准入、在库等级由入库与库存域执行 |
| R04 | 追溯配置 | SN 启用后按 SN 管理库存；批次／效期启用后在作业采集 | 带电仅资料表达，一期不单独触发仓内校验；入库不设质检任务，品质在收货实收内录入 |
| R05 | 尺重 | 毛重、净重、长宽高可由推送或管理端或入库新品维护回写；不得改写上游身份字段 | 沿用字段口径：长宽高统一cm、重量统一kg存储；按仓库长度／重量单位换算录入与展示 |
| R06 | 状态口径 | 仅使用状态（启用／停用），无审核 | 与 WMS 全局规则一致 |
| R07 | 引用与快照 | 商品名称等变更不回写历史单据；单据保留当时快照 | MD-FR-007 |
| R08 | 停用与删除 | 不提供物理删除；停用前校验实际库存、已确认出库待交接、入库过程量、未完结业务等（MD-FR-006） | 拒绝时提示数量或单据定位 |
| R09 | 开关切换 | SN、批次、效期开关在该货主商品任一仓库有实际库存或已开始作业入库时禁止切换 | 仅有预报未作业且无库存不阻断 |
| R10 | 导入与价格 | 不提供批量导入；不维护采购价、销售价 | 转换说明全局规则 |

### 4.2 F01 档案查看与编辑

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 核对 OMS 推送结果，补充形态、追溯与尺重。 |
| 操作与处理 | 列表按货主、商品编码、名称、主条码、形态、追溯开关、使用状态等查询；编码或链接进详情；**独立路由**编辑页维护详细稿「编辑页=可编辑」字段（条码仅在详情子表维护）。列表默认展示最后修改时间、最后修改人；详情「维护信息」仅上述两项（不展示创建信息）。 |
| 功能规则 | 不提供新增商品主档页面。保存时执行 R03 效期不等式等。 |
| 成功结果 | 配置对后续新业务指令与作业生效；历史单据不变。 |
| 异常与恢复 | 校验失败保留已填内容并定位字段。 |

### 4.3 F02 OMS Mock 推送接收

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 新货主商品接入或上游字段更新。 |
| 操作与处理 | 集成层接收消息，按货主编码+商品编码匹配；存在则更新约定可变更字段，不存在则新建启用记录。 |
| 功能规则 | 保留上游商品标识；货主须已存在且启用；不得静默改货主内商品编码。冲突拒收并记原因。 |
| 成功结果 | 管理端可见新商品或更新后的字段。 |
| 异常与恢复 | 拒收原因可查，不创建第二套身份。 |

### 4.4 F03 条码子表

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 一品多码、换标、辅码扫描。 |
| 操作与处理 | 在商品详情「条码」子表新增行，填写条码、是否主条码、使用状态；保存后条码文本只读，调整须停用该行再新建。 |
| 功能规则 | 条码全系统唯一（R02）；扫描任一条启用条码命中同一商品；设主条码时更新主档主条码展示。 |
| 成功结果 | 子表与主档展示一致。 |
| 异常与恢复 | 重复条码阻止保存并提示占用关系。 |

### 4.5 F04 形态、追溯、效期、尺重

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 按品类配置上架推荐、SN／批次／效期与尺重。 |
| 操作与处理 | 编辑页分组维护：商品形态、是否带电；是否 SN／批次／效期及 SN 格式校验；效期天数；毛净重与长宽高。 |
| 功能规则 | R03、R04、R05；未启用 SN 时 SN 格式校验隐藏或只读；未启用效期时效期天数非必填。 |
| 成功结果 | 入库、库存、PDA 按配置执行（各域验收）。 |
| 异常与恢复 | 开关切换受 R09 约束时阻止并说明库存或作业单。 |

### 4.6 F05 变更留痕

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 商品改名、改形态后的审计与历史单据一致性。 |
| 操作与处理 | 记录最后修改人时间；关键字段变更可扩展变更历史（实现可选，至少满足维护信息展示）。 |
| 功能规则 | R07、R09。 |
| 成功结果 | 历史单据名称快照不变。 |
| 异常与恢复 | 开关切换失败保留原配置。 |

### 4.7 F06 启用与停用

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 货主停售某 SKU 或错误推送后停用。 |
| 操作与处理 | 列表或详情单条启用／停用；一期可不提供批量启停（若 Demo 需要可 Mock，规则同单条）。 |
| 功能规则 | R08；停用后新业务指令不得引用；商品停用时其条码一并不可用。 |
| 成功结果 | 新单选不到该 SKU，历史保留。 |
| 异常与恢复 | 有库存或未完结业务时拒绝停用并提示依据。 |

### 4.8 状态与动作

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可作为新业务 SKU 引用 | 推送建档或人工启用 | 否 |
| 停用 | 停止新业务引用 | 人工停用 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果 | 失败处理 |
| --- | --- | --- | --- | --- |
| — | OMS 推送建档/更新 | 匹配成功、货主有效 | 启用商品或更新字段 | 拒收记原因 |
| 启用 | 编辑保存 | 字段校验、R09 | 配置更新 | 校验失败 |
| 启用 | 停用 | 通过 R08 校验 | 新单不可选 | 提示库存/单据 |
| 停用 | 启用 | 无 | 恢复可选 | — |
| 子表条码 | 新增行 | 条码不重复 | 可扫描 | 重复阻止 |

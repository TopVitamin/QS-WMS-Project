## 一、文档概要

需求类型：基础资料 → **物流渠道**（归属[《物流承运商资料主PRD》](../物流承运商资料/物流承运商资料主PRD.md)所定义的承运商；菜单独立，Demo 规划 `menu.channels`，列表 path `/wms/master/channels`）。

上游：[《基础资料需求分析》](../../../../03-需求调研和分析/01-基础资料/基础资料需求分析.md)（MD-FR-010、MD-FR-011）、[《基础资料业务设计》](../../../../04-业务分析和设计/01-基础资料业务设计.md)第五节、第七节。

## 二、需求背景与范围

物流渠道是出库侧可选的物流服务标识。上游出库指令、WMS 出库单与出库交接引用**渠道编码**，展示时可带出所属物流承运商。渠道类型仅作分类筛选，不驱动打单与计费；**物流对接方式**与**外部服务产品代码**为一期占位，演示 Mock 渠道一般选「线下交接」。四仓共用一套渠道档案，不按仓库或货主绑定；一期不建设物流产品层，不接真实承运商生产打单服务。

| 对象 | 用途 | 数据来源 | 由哪里维护 | 被哪些业务引用 |
| --- | --- | --- | --- | --- |
| 物流渠道 | 出库可选的物流方式；归属一个承运商 | 管理端维护或演示预置 | 具备资料维护权限的管理端用户 | 出库单、出库交接；上游出库指令匹配 |

**本期做**：独立菜单「基础资料 → 物流渠道」；列表查询；弹窗新增/编辑/查看（`ChannelFormDialog`）；使用状态启停；对接方式与外部产品代码占位；所属承运商变更规则；承运商详情子表与列表共用同一弹窗与 Mock 源。

**本期不做**：审核、批量导入、物理删除、独立路由详情页、销售发货与「由仓库指定」、渠道按仓绑定、默认交接方式字段、真实 API 打单；列表不设与承运商的对象切换页签。

## 四、功能需求说明

### 4.1 共用规则

| 规则编号 | 主题 | 规则 | 边界或例外 |
| --- | --- | --- | --- |
| R01 | 编码与防重 | 渠道编码全系统唯一，保存前去首尾空格并校验重复；一经保存不可修改 | 名称不做全局唯一校验 |
| R02 | 状态与审核 | 仅使用状态；新建默认启用；无审核 | 启停直接生效 |
| R03 | 所属承运商 | 必填；**新增**时仅可选启用中的物流承运商 | 无出库/交接引用时可改所属承运商；有引用时所属只读 |
| R04 | 渠道类型 | 快递｜卡派｜自提｜其他；仅分类与筛选，不驱动打单 | 与竞品运输方式展示类似，一期无产品层 |
| R05 | 引用与变更 | 名称、类型、对接占位变更不回写历史单据与交接快照 | 渠道编码为业务匹配键 |
| R06 | 对接占位 | 物流对接方式必填：系统 API 对接（预留）｜线下交接；外部服务产品代码选填，对接方式为预留时建议填写 | 一期不接生产服务 |
| R07 | 停用 | 停用后新出库接单与新交接登记不得再选用；若仍有未完结出库或交接引用该渠道，拒绝停用直至业务合法收口 | 不因停用自动取消已接单出库或已登记交接 |
| R08 | 承运商停用叠加 | 所属物流承运商已停用时，本渠道即使仍为启用，也不得用于新出库接单或新增交接引用 | 恢复承运商后仍须本渠道为启用 |
| R09 | 删除与导入 | 无物理删除；无批量文件导入 | 见转换说明 |
| R10 | 仓网范围 | 四仓共用一套渠道，渠道资料无「所属仓库」字段 | 演示覆盖按一期交付标准 |

### 4.2 F01 物流渠道档案维护

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 为承运商配置可被选用的快递/卡派/自提等渠道，供出库与 OMS 指令匹配。 |
| 操作与处理 | 在物流渠道列表或承运商详情子表新增/编辑/查看；列表按渠道编码、名称、所属承运商、渠道类型、使用状态、物流对接方式查询；编码列打开查看弹窗，非独立详情路由。 |
| 功能规则 | 必填与取值见详细稿；演示数据宜选「线下交接」。 |
| 成功结果 | 启用且引用资格满足时，可被新出库指令接单与新交接登记选用。 |
| 异常与恢复 | 无启用承运商时列表「新增」不可用并提示；校验失败保留输入。 |

### 4.3 F02 启用与停用

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 暂停某物流方式或恢复选用。 |
| 操作与处理 | 列表、承运商详情子表或查看弹窗入口执行启停；停用前二次确认。 |
| 功能规则 | R07、R08；与承运商停用规则叠加判断。 |
| 成功结果 | 停用后新业务不可选；历史保留渠道快照。 |
| 异常与恢复 | 存在未完结引用时阻止停用并提示关联单据类型（口径 Q02）。 |

### 4.4 F03 出库与交接引用边界

| 内容 | 说明 |
| --- | --- |
| 使用场景 | 出库单携带渠道；交接登记引用渠道并选择交接方式。 |
| 操作与处理 | 业务侧在出库接单、交接登记环节选择渠道；本模块只维护档案与资格。 |
| 功能规则 | 出库单引用渠道；交接登记在**出库交接**由作业选择交接方式，**不在渠道上预置默认**。选用资格：渠道启用、所属承运商未处于「阻断新业务引用」状态（承运商停用即阻断，见承运商主 PRD R06）。 |
| 成功结果 | 指令与单据可展示渠道及衍生承运商信息。 |
| 异常与恢复 | 资料缺失或停用按分节点准入记录拒收或作业异常（MD-FR-011）。 |

### 4.5 状态与动作

| 状态 | 含义 | 进入条件 | 是否终态 |
| --- | --- | --- | --- |
| 启用 | 可被新出库/新交接选用（须叠加承运商资格） | 新建或人工启用 | 否 |
| 停用 | 关闭后续引用资格 | 人工停用且通过 R07 | 否 |

| 当前状态 | 动作/事件 | 前置条件 | 结果 | 失败处理 |
| --- | --- | --- | --- | --- |
| 无（新建） | 保存 | R01、R03 等通过 | 默认启用 | 校验失败 |
| 启用 | 停用 | 无未完结引用（R07） | 新单不可选 | 有引用则阻止 |
| 停用 | 启用 | 无 | 恢复可选（仍受 R08 约束） | 无 |

## 六、验收标准与待确认事项

### 6.1 验收标准

| 编号 | 条件与操作 | 预期结果 |
| --- | --- | --- |
| AC01 | 在启用承运商下新建渠道，类型「快递」，对接「线下交接」 | 保存成功，列表可见 |
| AC02 | 编辑无引用的渠道，更换所属承运商（目标为启用） | 保存成功；有引用时所属只读 |
| AC03 | 所属承运商停用后，渠道仍为启用，尝试新出库接单 | 不可选用该渠道 |
| AC04 | 渠道停用后新建出库/交接 | 不可选用；进行中单据不受影响 |
| AC05 | 修改渠道名称后查看历史出库单 | 历史仍为快照名称 |
| AC06 | 渠道存在未完结出库或交接时申请停用 | 拒绝并提示 |
| AC07 | 对接方式为「系统 API 对接（预留）」保存，外部代码为空 | 允许保存；建议性提示可展示 |

## 页面与弹窗清单

| 页面/容器 | 入口 | 用途 |
| --- | --- | --- |
| 物流渠道列表 | 基础资料 → 物流渠道（`/wms/master/channels`） | 查询渠道；Dialog 新增/编辑/查看 |
| `ChannelFormDialog` | 列表「新增」/编辑/编码链；承运商详情子表 | 新建、修改、只读查看渠道 |
| 确认 Dialog | 停用渠道、放弃未保存 | 二次确认 |

**本期不提供**：独立路由详情页（查看走 **`ChannelFormDialog`**）、导入、审核页签、`:code/edit` 路由。

容器选型：单列表路由 + 弹窗维护（与 **`CarrierFormDialog`** 承运商维护形态对称）；编码列点击 → **查看 Dialog**。

## 列表页

- **用途**：按承运商、类型、对接方式查询渠道；编码链打开查看 Dialog。
- **关键要素**：页头主按钮文案 **新增**（`masterChannel.create`）；create 弹窗标题 **新增物流渠道**；`FilterBar` **六列** + 展开（与主数据列表统一）；所属承运商链至承运商详情路由。

```text
|                                              [+ 新增]  [导出 Mock]                           |

| +----------------------------------------------------------------------------------------------+|

```

**补充说明**：

- **图中省略**：空态、排序见 Demo PRD；无行勾选。
- **渠道编码(链)**：点击打开 **`ChannelFormDialog` view**（只读），非跳转路由。
- **所属承运商(链)**：点击进入承运商**详情路由** `/wms/master/carriers/:code`。
- 父承运商停用不隐藏渠道行；仅影响新业务可选性。

## ChannelFormDialog（新增 / 编辑 / 查看）

```text
+------------------------------------------+
| 新增物流渠道 / 编辑物流渠道 / 物流渠道详情 [×] |
|------------------------------------------|
| 所属物流承运商*  [CAR-UPS 演示UPS v]  (有引用时只读) |
| 渠道编码*        [CH-MOCK-01]         (编辑/查看只读) |
| 渠道名称*        [输入]                             |
| 渠道类型*        [快递 v]                           |
| (create/edit 无使用状态；view 只读 StatusBadge)       |
| 渠道备注         [多行]                             |
| 物流对接方式*    [线下交接 v]                       |
| 外部服务产品代码 [输入] (对接方式为 API 预留时提示) |
| -- 查看模式附加 --                                  |
| 创建人 / 创建时间 / 最后修改人 / 最后修改时间       |
|------------------------------------------|
| 查看: [关闭]     编辑/新增: [取消] [保存]           |
+------------------------------------------+
```

**补充说明**：

- 列表页头 **新增** 打开本弹窗，标题固定为 **新增物流渠道**（i18n `masterChannel.createTitle`）。
- 从承运商详情「新增渠道」进入：所属承运商默认当前且可改（无引用时）。
- 新增前置：存在 ≥1 **启用**承运商，否则页头新增置灰并提示。

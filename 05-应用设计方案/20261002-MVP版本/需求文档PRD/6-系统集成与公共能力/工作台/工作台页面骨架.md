## 工作台

- **用途**：一屏查看当前仓关键待办和近期动态，进入对应列表/详情。
- **关键要素**：欢迎语与仓库时间；5 个 KPI 卡；近 7 天入库趋势 + 出库状态分布；最新入库单 + 演示闭环入口。

```text
+-- PageContainer -------------------------------------------------------------------------------+
| Lily Chen，你好                                                                               |
| US-LA-01 美西仓 · 仓库当地时间 2026-10-26 20:40                                               |
| +-- KPI 5 列 --------------------------------------------------------------------------------+|
| | 待收货入库单 3 | 待上架件数 909 | 待处理出库单 10 | 今日已出库 0 | 待复核出库单 2 |          ||
| +---------------------------------------------------------------------------------------------+|
| +-- 近7天入库单量 (2/3) ---------------------------+ +-- 出库单状态分布 (1/3) ----------------+|
| | 近 7 天暂无入库单；当前演示数据早于今天。          | | 总数 21；待处理 10 / 待拣货 5 / ...    ||
| | 或柱状图 7 天                                     | | 状态色条 + 图例                        ||
| +---------------------------------------------------+ +---------------------------------------+|
| +-- 最新入库单 (2/3) -------------------------------+ +-- 演示闭环 (1/3) ----------------------+|
| | 单号 | 货主 | SKU·件数 | 状态 | 创建时间           | | PDA 收货 / PDA 上架                    ||
| | ...                                               | | 入库单 / 库存查询                      ||
| +---------------------------------------------------+ +---------------------------------------+|
+------------------------------------------------------------------------------------------------+
```

**补充说明**：

- KPI 卡可点，分别带状态进入入库单/出库单列表。
- 趋势无数据时显示空态，不画 0 柱。
- 出库状态分布按当前仓；状态色与列表一致。
- 最新入库单 6 条，点击进详情。
- 演示入口不改变业务规则。

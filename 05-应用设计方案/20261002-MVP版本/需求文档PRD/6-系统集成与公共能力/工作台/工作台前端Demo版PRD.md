# 工作台前端Demo版PRD

> 用途：在 `qs-wms-demo` 实现[《工作台主PRD》](工作台主PRD.md)；说明路由、KPI、趋势、分布、最新单、反馈与 Mock。不重复业务规则。
> 布局真源：[《工作台页面骨架》](工作台页面骨架.md)。
> 版本：WMS-V1.0｜日期：2026-10-27｜状态：待评审。

**样式与组件**：布局与占位符合[需求文档 PRD / AGENTS.md](../../AGENTS.md)「布局硬规则」；页面参照 `dashboard-page.tsx`。

## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 路由 | `/wms/dashboard` |
| 入口 | 工作台菜单/登录后首页 |
| 目标 | 当前仓关键待办、趋势、出库分布、最新入库单、演示入口 |
| 页面边界 | 只读；不下单、不改状态、不跨仓 |

## 2. KPI 卡

| KPI | 数据 | 点击去向 |
| --- | --- | --- |
| 待收货入库单 | 入库单待收货数量 | `/wms/inbound/orders?status=PENDING_RECEIVE` |
| 待上架件数 | 当前仓未完成上架单待上架件数合计 | `/wms/inbound/putaway?status=PENDING` |
| 待处理出库单 | 出库单待处理数量 | `/wms/outbound/orders?status=PENDING_HANDLE` |
| 今日已出库 | 当前仓当地日期已出库单数 | `/wms/outbound/orders?status=SHIPPED` |
| 待复核出库单 | 出库单待复核数量 | `/wms/outbound/orders?status=PENDING_VERIFY` |

## 3. 近 7 天入库趋势

- 7 个自然日含今天，按当前仓、创建时间计数。
- 有数据：柱状图 + 数量/日期。
- 全 0：空态「近 7 天暂无入库单；当前演示数据早于今天。」，不画 0 柱。
- 不做下钻/导出。

## 4. 出库状态分布

- 当前仓出库单按状态计数；总数=各状态之和。
- 状态色条 + 图例；状态与出库单列表一致。
- 0 状态保留图例但不画色段。

## 5. 最新入库单

- 当前仓按创建时间倒序取 6 条。
- 列：单号、货主、SKU/件数、状态、创建时间。
- 单号进详情；「查看全部」进入入库单列表。

## 6. 演示闭环入口

| 入口 | 去向 |
| --- | --- |
| PDA · 收货 | `/pda/receive` |
| PDA · 上架 | `/pda/putaway` |
| 入库单 | `/wms/inbound/orders` |
| 库存查询 | `/wms/inventory/stock` |

## 7. 反馈

| 场景 | 反馈 |
| --- | --- |
| 无数据 | KPI 0；趋势空态；最新单空态 |
| 加载失败 | 页面错误态，可重试 |
| 切换仓库 | 立即重算，无需 Toast |

## 8. Mock 覆盖

- 当前仓至少 3 张待收货、若干待上架、10 张待处理、2 张待复核、1 张已出库；
- 趋势至少一组有数据场景和一组全 0 场景（可用不同仓/种子日期）；
- 出库状态覆盖待处理、待拣货、待复核、待出库、已出库、已取消；
- 最新入库单至少 6 条。

## 9. 演示验收

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 打开工作台 | 5 个 KPI、趋势、分布、最新单、入口齐全 |
| 2 | 点击待收货 KPI | 进入入库单列表并带状态 |
| 3 | 切换仓库 | 所有数字/列表按新仓 |
| 4 | 种子日期早于今天 | 趋势显示空态，不显示 0 柱 |
| 5 | 点击最新入库单 | 进入详情 |
| 6 | 点击 PDA 收货/上架 | 进入对应 PDA 页面 |

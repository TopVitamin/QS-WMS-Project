# 工作台主PRD

> 用途：定义 WMS 管理端工作台的 KPI、近 7 天入库趋势、出库状态分布、最新入库单和演示入口，作为研发实现与验收依据。
> 定位：应用设计层工作台页面真源。数据口径以入库、出库、上架主 PRD 为准；页面见[《工作台页面骨架》](工作台页面骨架.md)，交互见[《工作台前端Demo版PRD》](工作台前端Demo版PRD.md)。
> 不写什么：不新造业务规则；不写报表平台、权限配置、实时消息推送；不写生产性能指标。

## 2. 背景与目标

仓库主管每天先看“有多少待收货、待上架、待处理出库、今日已出库、待复核”，再看近期入库趋势和最新入库单。工作台是入口和概览，不替代列表与详情，不提供业务动作。

目标：一屏看到当前仓库的关键待办；所有数字可追溯到对应列表；无数据时明确空态；切换仓库后数据同步切换。

## 3. 范围

| 功能 | 内容 |
| --- | --- |
| F01 KPI | 待收货入库单、待上架件数、待处理出库单、今日已出库、待复核出库单 |
| F02 近 7 天入库趋势 | 当前仓库按自然日统计入库单量；无数据时显示空态 |
| F03 出库状态分布 | 当前仓库出库单按状态计数与占比条 |
| F04 最新入库单 | 当前仓库最近 6 张入库单，可跳详情 |
| F05 演示入口 | PDA 收货/上架、入库单、库存查询快捷入口 |

非本期：自定义看板、导出、图表下钻、跨仓汇总、消息推送、角色权限。

## 4. 对象定位与边界

| 项目 | 内容 |
| --- | --- |
| 对象层级 | 管理端首页概览 |
| 核心职责 | 汇总待办与近期动态，提供入口 |

## 6. 状态与操作

工作台没有业务状态，所有卡片只读。

| 动作 | 允许 |
| --- | --- |
| 查看 KPI/趋势/分布/最新单 | ✅ |
| 点击 KPI 进入对应列表 | ✅ |
| 点击最新入库单进详情 | ✅ |
| 在工作台直接改单据 | ❌ |

## 7. 核心规则

| 编号 | 主题 | 规则 | 边界 |
| --- | --- | --- | --- |
| R01 | 仓库范围 | 所有数字按顶栏当前仓库过滤，不跨仓汇总 | 切换仓库立即重算 |
| R02 | 待收货 | 入库单状态=待收货的数量 | 与入库单列表状态页签一致 |
| R03 | 待上架 | 当前仓未完成上架单的待上架件数合计 | 与上架单列表口径一致 |
| R04 | 待处理/待复核 | 出库单对应状态计数 | 与出库单列表一致 |
| R05 | 今日已出库 | 已出库且确认出库时间在当前仓库当地日期今日的单数 | 按仓库时区，不按浏览器时区 |
| R06 | 近 7 天趋势 | 含今天在内 7 个自然日，按入库单创建时间计数 | 全 0 时显示空态，不显示一排 0 |
| R07 | 出库状态分布 | 当前仓出库单按状态计数；总数=各状态之和 | 不混入其他仓 |
| R08 | 最新入库单 | 当前仓按创建时间倒序取 6 条 | 点击进详情 |
| R09 | 数据范围 | 一期不校验账号/角色/仓库授权 | 只按顶栏仓库 |

## 11. 异常与一致性

| 场景 | 处理 |
| --- | --- |
| 当前仓无数据 | KPI 显示 0；趋势显示空态；最新单空态 |
| 切换仓库 | 所有数字与列表重算 |
| 种子日期早于今天 | 趋势显示“近 7 天暂无入库单”空态，不伪造成今天 |
| 状态被其他动作改变 | 重新进入或刷新后按最新数据展示 |

## 12. 验收

| 编号 | 条件与操作 | 预期 |
| --- | --- | --- |
| AC01 | 打开工作台 | 5 个 KPI、趋势、分布、最新单、入口齐全 |
| AC02 | 切换仓库 | 所有数字与最新单按新仓 |
| AC03 | 种子日期早于今天 | 趋势显示空态，不显示一排 0 |
| AC04 | 点击 KPI | 进入对应列表并带状态筛选 |
| AC05 | 点击最新入库单 | 进入入库单详情 |
| AC06 | 当前仓无数据 | KPI 0、趋势空态、最新单空态 |

# 系统集成与指令结果主PRD

> 用途：定义 WMS 管理端“系统集成 → 指令与结果”页面如何查看上游 OMS Mock 指令、入库/出库/退货/基础资料消息留痕和回传结果，以及结果重交的边界。
> 定位：应用设计层系统集成页面真源。消息与字段以[《接口与OMS Mock消息设计》](../../../系统架构设计/06-接口与OMS Mock消息设计.md)及[《上游消息记录（详细稿）》](../../../字段清单合集/05-系统集成与对接/上游消息记录/上游消息记录（详细稿）.tsv)、[《回传记录（详细稿）》](../../../字段清单合集/05-系统集成与对接/回传记录/回传记录（详细稿）.tsv)为准；页面见[页面骨架](系统集成与指令结果页面骨架.md)，交互见[Demo PRD](系统集成与指令结果前端Demo版PRD.md)。
> 不写什么：不写真实 OMS 协议、网络重试、签名、鉴权；不写各业务单据内部状态机。

## 2. 背景与目标

一期 WMS 的上游建单、变更、取消和结果回传均通过 OMS Mock 完成。页面需要把“收到什么、是否受理、生成了哪张单、回传是否成功”放在同一入口，便于演示和排查。页面不替代各业务单据状态，只做集成留痕与结果重交。

## 3. 范围

### 3.1 本期范围

- 上游消息视图：入库、出库、基础资料推送三类消息；
- 回传结果视图：入库结果、出库结果、退货结果；
- 按时间倒序展示；结果失败可重交；入库/退货结果按原序号重交；
- 消息与结果只读，不手工修改报文。

### 3.2 功能清单

| 编号 | 功能/位置 | 本次内容 |
| --- | --- | --- |
| F01 | 上游消息 | 汇总入库/出库/基础资料消息，显示动作、状态、对象、错误 |
| F02 | 回传结果 | 汇总入库/出库/退货结果，显示状态、次数、明细 |
| F03 | 结果重交 | 失败结果重交原结果；已接收不重复 |
| F04 | 对象跳转 | 消息/结果跳对应单据 |

### 3.3 非本期范围

- 真实 OMS 连接、签名、证书、网络重试策略；
- 手工编辑/补发报文；
- 消息归档、批量导出、告警；
- 账号/角色/权限校验。

## 4. 对象定位与边界

| 项目 | 内容 |
| --- | --- |
| 对象层级 | 集成留痕与结果操作 |
| 核心职责 | 证明收到什么、是否受理、生成了什么、回传结果如何 |
| 数据来源 | OMS Mock 推送与 WMS 回传动作 |
| 不负责 | 不改变业务单据事实；不替代业务状态机；不保存库存 |

## 5. 场景索引

| 场景 | 说明 |
| --- | --- |
| S01 | 上游新建指令被接收并生成单据 |
| S02 | 上游变更/取消被接受或拒绝 |
| S03 | 入库/出库/退货完成，生成回传结果 |
| S04 | 回传失败，重新提交原结果 |
| S05 | 按对象回到原单核对 |

## 6. 状态与操作

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 消息状态 | 已接收、已拒绝 | 拒绝需原因 |
| 结果状态 | 已发送、失败 | 失败可重交 |
| 重交 | 只允许失败结果；已发送不重复 | 沿用原结果序号 |

## 7. 核心规则

| 编号 | 主题 | 规则 | 边界 |
| --- | --- | --- | --- |
| R01 | 消息留痕 | 每个上游消息写一条；同一消息标识重发返回原结论，不重复建单 | 内容变更按版本/指纹拒绝 |
| R02 | 消息动作 | 新建、变更、取消、基础资料推送 | 动作与业务单据对应 |
| R03 | 结果生成 | 入库/出库/退货完成时生成一次；序号按对象递增 | 过程不回传进度 |
| R04 | 结果状态 | 已发送/失败；失败保留原因与尝试次数 | 失败不影响业务事实 |
| R05 | 重交 | 只重交失败结果，沿用原序号；已发送返回“无需重交” | 不生成第二条结果 |
| R06 | 跳转 | 消息/结果可跳原单；跨仓/不存在不展示详情 | 只读 |
| R07 | 数据范围 | 顶栏当前仓库过滤；一期不校验账号/角色/仓库授权 | 系统级基础资料消息按全局 |

## 11. 异常与一致性

| 场景 | 处理 |
| --- | --- |
| 重复消息 | 返回原结论，不重复建单 |
| 结果重交失败 | 保留失败状态与次数 |
| 已发送重交 | 提示无需重交 |
| 原单跨仓/删除 | 结果保留，跳转置灰/普通文本 |
| 消息版本不符 | 拒绝并记录原因 |

## 12. 验收

| 编号 | 条件与操作 | 预期 |
| --- | --- | --- |
| AC01 | 新建入库/出库消息 | 消息列表出现，状态已接收，对象单号可跳 |
| AC02 | 重复同一消息标识 | 不新增消息/单据 |
| AC03 | 变更/取消被拒绝 | 消息状态已拒绝，含原因 |
| AC04 | 完成入库/出库/退货 | 结果列表出现对应结果 |
| AC05 | 失败结果重交 | 沿用原序号，状态更新；不新增第二条 |
| AC06 | 已发送结果重交 | 提示无需重交 |
| AC07 | 切换仓库 | 列表按当前仓过滤；跨仓对象不展示详情 |

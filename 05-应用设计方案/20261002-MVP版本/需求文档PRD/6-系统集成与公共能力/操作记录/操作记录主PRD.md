# 操作记录主PRD

> 用途：定义 WMS 管理端操作记录（审计留痕）的查询、字段、筛选、追溯与保留边界，作为研发实现和验收依据。
> 定位：应用设计层公共能力真源。记录范围以[《全局机制与操作留痕》](../../../系统架构设计/05-全局机制与权限配置.md)为准；字段以[《操作记录（详细稿）》](../../../字段清单合集/06-公共能力/操作记录/操作记录（详细稿）.tsv)为准；页面见[《操作记录页面骨架》](操作记录页面骨架.md)，交互见[《操作记录前端Demo版PRD》](操作记录前端Demo版PRD.md)。
> 不写什么：不写各业务动作内部规则；不写日志存储/检索实现；不写账号、角色、权限配置。

## 2. 背景与目标

入库、出库、库存、退货、基础资料和系统集成动作分散在多个页面，问题追溯需要统一的只读留痕。操作记录不是业务单据，不改变业务状态；它回答“谁在什么时间、对哪个对象、做了什么、结果如何”。

目标：统一对象/动作/结果/操作者/终端口径；可按仓库、对象、动作、操作者、时间查询；可从记录跳回原单；已发生记录不可编辑、删除或补写。

## 3. 范围

### 3.1 本期范围

- 只读列表、筛选、导出 Mock；
- 记录对象：入库单、出库单、波次、拣货任务、返库上架单、退货单、盘点单、移库作业、库存/品质转换、基础资料、系统集成；
- 动作留痕：创建/变更/取消/确认/提交/审核类关键动作，以及与上游协作结论；
- 详情抽屉展示变更前后摘要、结果说明、终端、仓库、货主、关联作业号。

### 3.2 功能清单

| 编号 | 功能/位置 | 本次内容 |
| --- | --- | --- |
| F01 | 操作记录列表 | 按业务单号、对象类型、动作、操作者、时间查询 |
| F02 | 记录详情 | 只读展示对象、动作、结果、变更摘要、操作者/终端/时间 |
| F03 | 原单追溯 | 业务对象单号/关联作业号跳原单 |
| F04 | 导出 | 页头导出 Mock |

### 3.3 非本期范围

- 手工新增、编辑、删除、补写记录；
- 全量字段级版本历史页；
- 日志归档、冷热存储、外部审计平台；
- 账号/角色/用户仓库授权校验。

## 4. 对象定位与边界

| 项目 | 内容 |
| --- | --- |
| 对象层级 | 公共能力——只读审计记录 |
| 核心职责 | 记录关键动作的事实、结果和操作者 |
| 数据来源 | 各业务动作成功/拒绝时由系统写入 |
| 不负责 | 不替代业务单据；不保存库存余额；不做业务回滚 |

## 5. 场景索引

| 场景 | 说明 |
| --- | --- |
| S01 | 按业务单号查某张单的全部操作 |
| S02 | 按对象/动作筛某类操作 |
| S03 | 从记录跳回原单或关联作业 |
| S04 | 导出当前筛选结果（Mock） |

## 6. 状态与操作

操作记录没有业务状态；记录一经写入即“已生效”，只读。

| 动作 | 允许 |
| --- | --- |
| 查看列表/详情 | ✅ |
| 按条件筛选 | ✅ |
| 跳转原单 | ✅（对象存在且同仓） |
| 新增/编辑/删除/冲销 | ❌ |

## 7. 核心规则

| 编号 | 主题 | 规则 | 边界 |
| --- | --- | --- | --- |
| R01 | 写入时机 | 业务动作成功或拒绝时写一条；同一请求重试不重复写 | 业务事务失败不写成功记录 |
| R02 | 对象 | 必须有业务模块、对象类型、对象单号；无对象动作不写伪类型 | 系统任务可用 SYSTEM |
| R03 | 结果 | 成功/拒绝/部分完成；拒绝记录原因摘要 | 不写空结果 |
| R04 | 操作者/终端 | 管理端取当前操作人，PDA 取作业人，系统任务为 SYSTEM；终端 WEB/PDA/SYSTEM | 一期无登录，操作人取全局设置 |
| R05 | 仓库/货主 | 从原对象带入；资料类操作货主可空 | 跨仓对象不展示详情 |
| R06 | 变更摘要 | 资料/数量/状态变化时记录前后值摘要 | 非必填 |
| R07 | 只读 | 不提供编辑、删除、手工补写 | 误操作恢复走原业务规则 |
| R08 | 数据范围 | 顶栏当前仓库限定；一期不校验账号/角色/仓库授权 | 系统级记录按全局展示 |

## 11. 异常与一致性

| 场景 | 处理 |
| --- | --- |
| 原单删除/跨仓 | 记录保留；单号显示普通文本，不展示详情 |
| 重复请求 | 只保留一条记录 |
| 记录写入失败 | 不影响业务结果；由技术补偿，不向用户伪造成功 |
| 同一动作多次执行 | 按实际动作各写一条，不合并 |

## 12. 验收

| 编号 | 条件与操作 | 预期 |
| --- | --- | --- |
| AC01 | 完成一次出库确认 | 操作记录出现该出库单记录，结果成功 |
| AC02 | 上游拒绝一次指令 | 出现拒绝记录，含原因摘要 |
| AC03 | 按业务单号/对象/动作/操作者筛选 | 结果与条件一致 |
| AC04 | 点击对象单号 | 跳原单；跨仓/不存在不展示详情 |
| AC05 | 查找编辑/删除入口 | 均不存在 |
| AC06 | 重复重试同一请求 | 不新增重复记录 |

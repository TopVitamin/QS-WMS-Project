## 页面与容器清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 操作记录列表 | `/wms/system/logs` | 系统设置 → 操作记录 | 查询关键动作留痕，进入记录详情 |
| 记录详情抽屉 | 列表行「查看」/业务单号 | 只读查看对象、动作、结果、变更摘要、操作者与终端 |

**本期不提供**：新增、编辑、删除、补写、全量字段版本页、独立归档页。

## 列表页

- **用途**：按当前仓库、业务单号、对象、动作、操作者和时间查询留痕。
- **关键要素**：页头「导出」；FilterBar 6 列；表格列：创建时间、动作、对象类型、业务单号、操作者、说明；行可打开详情抽屉。

```text
+-- PageContainer fill -------------------------------------------------------------------------+
| 操作记录                                                              [导出]                 |
| +-- Panel (筛选) -----------------------------------------------------------------------------+|
| | FilterBar · columns={6}                                                                     ||
| | 业务单号          | 对象类型       | 操作           | 操作人         | 创建时间          | 查询 重置 ||
| | [请输入]          | [全部 v]       | [全部 v]       | [全部 v]       | [日期范围]        |          ||
| +---------------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) ----------------------------------------------------------------------+|
| | 创建时间          | 操作         | 对象类型 | 业务单号      | 操作人      | 说明             ||
| | 2026-10-27 10:00  | 确认出库     | 出库单   | OB-...0007    | Lily Chen   | ...              ||
| +---------------------------------------------------------------------------------------------+|
| | 共 N 条  每页 20 [20 v]                                              < 1 2 3 >             ||
+------------------------------------------------------------------------------------------------+
```

**补充说明**：

- 业务单号可点开记录详情；原单跳转在详情抽屉内提供，跨仓/不存在显示普通文本。
- 无勾选、无批量操作；列表默认创建时间倒序。
- 动作列显示动作名称或对象命令；说明为空显示 `-`。

## 记录详情抽屉

```text
+-- DetailSheet 880px ---------------------------------------------------------------------------+
| 操作记录 · AUD-...                                                            [×]            |
| 对象：出库单 OB-20261015-0007   动作：确认出库   结果：成功   终端：WEB                  |
| 操作人：Lily Chen   时间：2026-10-27 10:00   仓库：US-LA-01   货主：ANKR                  |
| 变更摘要：状态 待出库 → 已出库；实发 1 件                                                |
| 关联作业：拣货任务 PK-... / 复核记录 VR-...                                              |
| 说明：...                                                                                  |
| [打开原单]                                                                                 |
+------------------------------------------------------------------------------------------------+
```

**补充说明**：

- 详情只读；不提供编辑、删除、补写。
- 变更前后摘要与说明可为空；对象/动作/结果必填。
- 跨仓或对象不存在时隐藏「打开原单」。

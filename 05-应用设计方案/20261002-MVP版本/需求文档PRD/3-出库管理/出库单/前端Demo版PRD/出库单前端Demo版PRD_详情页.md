# 出库单前端Demo版PRD·详情页

> **版本**：WMS-V0.2  
> **更新时间**：2026-10-15  
> **定位**：供 AI / 研发实现**出库单详情独立路由页**。业务规则见[《出库单主PRD》](../出库单主PRD.md)（§6.4、§7.3～§7.4、R08～R14；F02～F09）。  
> **本文件只写详情呈现与入口**；弹窗正文见[弹窗与 Mock](出库单前端Demo版PRD_弹窗与Mock.md)；共用约定见[公共分册](出库单前端Demo版PRD_公共与技术约定.md)。

## 1. 页面概述

| 项 | 内容 |
| --- | --- |
| 路由 | `/wms/outbound/orders/:outboundNo` |
| 文件 | `order-detail-page.tsx`，样板 `inbound-order-detail-page.tsx` |
| 版式 | `DetailTitle` + `DetailOverview`（基本信息 / 数量进度）+ `DetailTabs` |
| 找不到 | 单号不存在或不属当前仓：空态「未找到出库单」+「返回列表」 |

> **本期边界**  
> - 无编辑、删除；状态不可手改。  
> - 复核在 PDA 完成，本页只给入口与记录维护。  
> - 子对象（任务、返库单）在本页只读，点单号进各自详情。

## 2. 页头

### 2.1 标题

`<DetailTitle title={t('outbound.ui.orderTitle')} code={no} status={outboundStatusMeta[status]} />`，渲染为「出库单 · OB-… [状态]」。

### 2.2 页头按钮矩阵

按钮全部来自 `orderActions(order, db)`（公共分册 §3.3），不满足条件的不渲染。

| 按钮 | 条件（摘自主PRD §6.4） | 样式 | 行为 |
| --- | --- | --- | --- |
| 返回列表 | 始终，最左 | outline | 回列表并带回 `listSearch` |
| 按单生成拣货任务 | 待处理 | primary | `run({type:'ALLOCATE'})`；与列表工具栏「按单生成拣货任务」同义；成功 toast 任务号，停留本页，拣货任务页签 +1 |
| 重新分配 | 待拣货或待复核；有缺货或待拣 | outline | 同一 `ALLOCATE` 命令；返回已存在任务时 toast「已有未完成任务 PK-…」 |
| 去复核 | 待拣货、待复核；已拣＞已复核 | outline 下拉 | 「复核工作台」打开 `/wms/outbound/verify-station?no=`；「PDA 复核」打开 `/pda/verify?no=`（见[复核工作台 Demo PRD](../../复核工作台/复核工作台前端Demo版PRD.md)） |
| 确认出库 | 待出库 | primary | 打开确认出库弹窗（弹窗分册 §2） |
| 补登交接 | 已出库 | outline | 打开登记交接弹窗 |
| 更多 | 有任一低频动作时 | outline 下拉 | 见下表 |

| 「更多」菜单项 | 条件 | 行为 |
| --- | --- | --- |
| 退拣 | 待拣货、待复核；有有效实拣 | 退拣弹窗 |
| 模拟变更 | 待拣货；OMS 来源；非其他出库 | OMS Mock 弹窗锁定变更模式 |
| 模拟取消 | 未出库未取消；OMS 来源 | OMS Mock 弹窗锁定取消模式（destructive 文字） |
| 取消出库单 | 未出库未取消；手工来源 | `useConfirm` destructive 后 `run({type:'CANCEL'})` |
| 模拟回传失败 | 已出库；有出库结果 | `run({type:'RETRY_RESULT', simulateFailure:true})` |
| 重交出库结果 | 已出库；结果状态为失败 | `run({type:'RETRY_RESULT'})` |

同一时刻 primary 至多一个（待处理为「按单生成拣货任务」，待出库为「确认出库」）。待处理 B2C 单也可回列表勾选多张后「组波批量拣货」。

## 3. 概览（`DetailOverview`）

### 3.1 基本信息（左，`Section` + `Descriptions columns={3}`）

| 字段 | 展示 | 出现条件 |
| --- | --- | --- |
| 业务类型 | `TagLabel` | 始终 |
| 货主 | `CodeName` | 始终 |
| 仓库 | `CodeName`（编码 + 仓库名） | 始终 |
| 订单来源 | 文本 | 始终 |
| 上游指令号 | `BizCode` | OMS 来源 |
| 上游消息标识 | `BizCode` | OMS 来源 |
| 线下依据摘要 | 文本，`col-span-3`，`multiline` | 手工其他出库 |
| 引用原入库单号 | `BizCode` | 采购退货出库 |
| 物流渠道 | `CodeName` | 始终（空为 `-`） |
| 物流承运商 | 文本，由渠道带出 | 始终（空为 `-`） |
| 创建时间 | `DateTime` | 始终 |
| 收货人 | 文本 | 始终 |
| 收货联系电话 | 文本 | 始终 |
| 收货地址 | 文本，`col-span-3` | 始终 |
| 确认出库时间 / 确认出库操作者 | `DateTime` / 文本 | 已出库 |

| 出库单备注 | 文本，`col-span-3` | 始终 |

单号、状态已在标题，不重复；不展示对象版本。

### 3.2 数量进度（右，`SummaryCard` 320px）

- `SummaryProgress`：标签「拣货进度」，`done=已拣`、`total=需求`（其他出库为指定数量），显示件数与取整百分比；已出库时改为「实发」`实发/需求`，tone green。
- `SummaryMetrics`：需求、本单预占（其他出库隐藏）、缺货（orange，为 0 或其他出库时隐藏）、已拣、已复核、实发（未出库显示 `-`）、未发（只在已出库时出现，orange）。

## 4. 页签（`DetailTabs param="tab"`，带条数）

列用 `createDataColumns<T>()`，行数据为领域对象，数字列右对齐。

### 4.1 商品明细（`items`，默认）

行号、商品（`CodeName` 编码 + 名称）、需求、本单预占、缺货、已拣、待拣、已复核、实发、未发。值取 `lineQty`；其他出库预占、缺货显示 `-`；实发、未发未出库时显示 `-`。

### 4.2 指定实物（`specified`，仅其他出库）

出库单行号、商品、库位、批次号、品质（`TagLabel`）、指定数量、序列号（多个用逗号，空为 `-`）。

### 4.3 拣货任务（`tasks`）

任务号（`DocNo` → 拣货任务详情）、任务来源、状态（`StatusBadge`）、应拣、实拣、短拣、创建时间。波次任务只计本单份额（`taskQtyForOrder`）。不放「去拣货」按钮，进任务详情后操作。

### 4.4 复核记录（`reviews`）

复核记录号（`DocNo` 打开复核记录 Sheet）、复核方式、容器类型、容器号、模拟运单号、复核数量、有效数量、复核人、复核时间、操作。

- 已删除记录整行 `text-muted-foreground`，操作列显示 `TagLabel`「已删除」；
- 行操作 `RowActions`：「补包裹信息」（B2C、未出库、未删除）、「删除」（未出库、未删除，danger，`useConfirm` 后 `DELETE_VERIFY`）。

### 4.5 交接记录（`handovers`）

交接记录号、交接方式、交接对象、物流渠道、运单号或面单号、包裹或箱托数、交接时间、登记人、交接凭证附件（文件名，空为 `-`）、交接备注（默认隐藏）。只读。

### 4.6 返库上架单（`putbacks`）

返库上架单号（`DocNo` → 返库上架单详情）、退拣原因、状态、应返库、已返库（已提交才计）、创建时间。已取消单页签标题照常带数。

### 4.7 出库结果（`results`，仅 OMS 来源）

页签内容顶部一行 `Descriptions columns={4}`：结果状态（`StatusBadge`）、结果序号、提交次数、生成时间；下方表格：商品、实发、未发。重交与模拟失败入口在页头「更多」。

### 4.8 操作日志（`logs`，最后一个）

`outboundLogColumns`：操作时间、操作（`outbound.actions.<命令>`）、操作人、说明。取本单 `refNo` 的记录，并合并本单相关拣货任务、返库上架单的记录，说明前带对象单号；按时间倒序。

## 5. 复核记录 Sheet

`verification-sheet.tsx`，样板 `inbound-receipt-sheet.tsx`。`DetailSheet` 标题「复核记录 · VR-…」（已删除时带灰色「已删除」标签）；上方 `Descriptions columns={4}`：复核方式、容器类型、容器号、模拟运单号、包裹模拟重量（B2C）、复核人、复核时间、复核备注；下方表格：出库单行号、商品、批次号、序列号、复核数量、有效复核数量。不放业务按钮。

## 6. 详情页自检

1. 各状态页头按钮与 §2.2 一致：待拣货无「确认出库」「去复核」（AC06）；已取消只有「返回列表」。
2. 基本信息按类型增减字段，无对象版本、无含义不清的「时间」。
3. 汇总卡未出库时未发不出现；已出库实发＋未发＝需求。
4. 八个页签顺序固定，操作日志最后；其他出库才有指定实物页签；出库结果只在 OMS 来源出现。
5. 复核记录号打开 Sheet，可看到 SKU、批次、SN 与有效量。
6. 动作失败 toast 写明原因；成功后对应页签条数与汇总卡同步变化。

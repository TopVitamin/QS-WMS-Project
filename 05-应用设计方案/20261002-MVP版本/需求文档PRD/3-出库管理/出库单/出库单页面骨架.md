# 出库单页面骨架

> 文档版本：WMS-V0.2｜日期：2026-10-15｜状态：文档修订，待演示验收。V0.2：由《出库管理页面骨架》拆出，补全列表、详情、复核记录 Sheet 与五个弹窗线框。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；组件与分区对齐[《QS-WMS 前端设计与开发规范》](../../../../../09-产品原型/qs-wms-demo/docs/02-设计规范.md)。
> 动作条件以[《出库单主PRD》](出库单主PRD.md) §6.4 为准；字段以[《出库单（详细稿）》](../../../字段清单合集/03-出库管理/出库单/出库单（详细稿）.tsv)及复核记录、出库交接详细稿为准；交互见[前端Demo版PRD](前端Demo版PRD/)。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 出库单列表 | `/wms/outbound/orders` | 出库管理 → 出库单（`menu.outboundOrders`） | 状态页签、查询、勾选 B2C 单组波、Mock 与手工其他出库入口、导出 |
| 出库单详情 | `/wms/outbound/orders/:outboundNo` | 列表点单号；波次、拣货任务、返库上架单详情里点原单号 | 基本信息 + 数量进度卡；页头按状态出按钮；明细与五类子记录、操作日志页签 |
| 复核记录 Sheet | 详情「复核记录」页签点复核记录号 | 只读查看一次复核的商品、批次、SN 与有效量 | — |
| 确认出库 Dialog | 详情页头（待出库） | 逐行校验结果、二次确认、可同时登记交接 | — |
| 登记交接 Dialog | 详情页头（已出库）「补登交接」 | 补登交接，与确认出库内交接区字段相同 | — |
| 退拣 Dialog | 详情页头「更多」→ 退拣 | 选实拣归属、数量、原因、SN | — |
| 包裹信息 Dialog | 复核记录页签行内「补包裹信息」（B2C） | 补包裹号与模拟重量，生成 Mock 运单 | — |
| OMS Mock Dialog | 列表页头「OMS Mock」；详情「更多」→ 模拟变更／模拟取消 | 新建、变更、取消三种模式 | — |
| 创建其他出库 Dialog | 列表页头 | 邮件依据 + 指定不良品库存 | — |
| 指令处理记录 Dialog | 列表页头 | 查看处理结论、版本与失败原因，按原消息重发 | — |

**本期不提供**：普通出库新建／编辑页；行内「查看」按钮；复核、交接独立列表；列表直接确认出库；批量操作（组波除外）。

容器选型：详情含多类子记录 → **独立路由详情页**（概览卡 + 多页签）；复核记录字段少 → **Sheet**；确认、交接、退拣、Mock → **Dialog**。

## 绘制约定

- 列表查询区：`FilterBar` 6 列栅格（常显最多 5 项 + 第 6 列查询/重置；>5 项其余进 `advanced`），见[需求文档 PRD / AGENTS.md](../../AGENTS.md)。
- 列表按顶栏当前仓库过滤，不设仓库筛选与仓库列；状态用 `StatusTabs`，不在筛选区重复。
- 详情：上方 `DetailOverview` 两栏（左「基本信息」`Descriptions columns={3}`，右 320px `SummaryCard`），下方 `DetailTabs`，页签带条数并写入 URL。
- 货主、仓库、渠道展示 `{编码} {名称}`；示例值为虚构。
- 页头：「返回列表」在最左；状态允许的次要动作 outline；本状态主动作一个 primary；低频动作收进「更多」。

**页头按钮（按状态）**：

| 状态 | 页头按钮（左→右） | 更多 |
| --- | --- | --- |
| 待处理 | 返回列表、按单生成拣货任务（primary） | 模拟变更（普通出库）、模拟取消（OMS）或取消出库单（手工其他出库）；列表亦可组波批量拣货 |
| 待拣货 | 返回列表、去复核下拉（已拣＞已复核时）、重新分配（有缺货或待拣时） | 退拣、模拟取消或取消出库单 |
| 待复核 | 返回列表、去复核下拉、重新分配（有缺货或待拣时） | 退拣、模拟取消或取消出库单 |
| 待出库 | 返回列表、确认出库（primary） | 模拟取消或取消出库单 |
| 已出库 | 返回列表、补登交接 | 模拟回传失败、重交结果（OMS 来源） |
| 已取消 | 返回列表 | — |

**基本信息按类型增减**：采购退货出库加「引用原入库单号」；手工其他出库加「线下依据摘要」，不显示上游指令号与消息标识；已出库加「确认出库操作者」；已取消加「取消原因」。不展示对象版本。

**页签**：

| 页签 | 列 | 说明 |
| --- | --- | --- |
| 商品明细 | 行号、商品（编码 名称）、需求、预占、缺货、已拣、待拣、已复核、实发、未发 | 其他出库预占、缺货显示「-」；未发只在已出库时有值 |
| 指定实物 | 出库单行号、商品、库位、批次、品质、指定数量、序列号 | 仅其他出库出现 |
| 拣货任务 | 任务号(链)、任务来源、状态、应拣、实拣、短拣、创建时间 | 波次任务的应拣只计本单份额 |
| 复核记录 | 复核记录号(开 Sheet)、复核方式、容器类型、容器号、模拟运单号、复核数量、有效数量、复核人、复核时间、操作 | 已删除行灰显并标「已删除」；操作：补包裹信息（B2C）、删除 |
| 交接记录 | 交接记录号、交接方式、交接对象、物流渠道、运单号或面单号、包裹或箱托数、交接时间、登记人、附件 | 只读 |
| 返库上架单 | 返库上架单号(链)、退拣原因、状态、应返库、已返库、创建时间 | 已取消单仍展示未完成返库 |
| 出库结果 | 商品、实发、未发；页签顶部一行：结果状态、序号、提交次数、生成时间 | 仅 OMS 来源已出库后有数据 |
| 操作日志 | 操作时间、操作、操作人、说明 | 本单及其任务、返库单相关动作 |

# 出库管理

一期按[出库宏观架构](../../../../01-全局背景信息/05-出库模块宏观系统架构.md)执行：六类出库共用出库单，接单预占，生成拣货任务或组波时分配库位，扫描确认即下架，按原单复核后由主管确认出库；取消或退拣的货经返库上架单回到库位。不设出库异常单。

打包台电脑上的复核用[复核工作台](复核工作台/复核工作台前端Demo版PRD.md)。现场作业见PDA[拣货](../7-PDA作业端/拣货作业/PDA拣货前端Demo版PRD.md)、[复核](../7-PDA作业端/复核作业/PDA复核前端Demo版PRD.md)、[返库上架](../7-PDA作业端/返库上架作业/PDA返库上架前端Demo版PRD.md)，规则以上表各主PRD为准，两端共用业务记录与库存。

三项现场作业在管理端各有不用 PDA 时的入口：拣货用「Web 端拣货」录入页、返库用「Web 端返库」录入页（版式同上架单「Web 端上架」，按纸单补录）；复核用复核工作台（扫码枪作业台）。PDA 拣货与返库按库位逐站作业：扫库位到站、扫商品计数、数满自动确认、做完一个库位自动跳到下一个（2026-10-18 起）。

阅读顺序：先读出库单主PRD（状态—功能矩阵与数量口径），再按要实现的页面读对应套件。字段详细稿维护完整定义，初稿为五列投影。

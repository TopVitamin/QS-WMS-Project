> 文档版本：WMS-V0.3｜日期：2026-10-18｜状态：演示已走查（2026-10-18）。由《出库管理页面骨架》拆出。V0.3：新增「Web 端拣货」录入页，列表与详情加 Web 端拣货、PDA拣货两个入口。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)；动作条件以[《拣货任务主PRD》](拣货任务主PRD.md)为准；字段以[《拣货任务（详细稿）》](../../../字段清单合集/03-出库管理/拣货任务/拣货任务（详细稿）.tsv)为准；交互见[《拣货任务前端Demo版PRD》](拣货任务前端Demo版PRD.md)。PDA 线框见[PDA拣货页面骨架](../../7-PDA作业端/拣货作业/PDA拣货页面骨架.md)。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 拣货任务列表 | `/wms/outbound/pick-tasks` | 出库管理 → 拣货任务 | 状态页签、查询、进入详情、Web 端拣货或跳转 PDA拣货 |
| 拣货任务详情 | `/wms/outbound/pick-tasks/:taskNo` | 列表点任务号；出库单、波次详情点任务号 | 应拣明细、实拣归属、原单份额、操作日志 |
| Web 端拣货 | `/wms/outbound/pick-tasks/:taskNo/entry` | 详情页头、列表行操作、波次详情页头（未完成任务） | 按纸质拣货单逐行录入实拣与缺货、提交任务 |

**本期不提供**：管理端关闭任务、修改应拣行；Web 端扫码作业台（不用 PDA 时走录入页）。

容器选型：补录要边看待拣明细边录 → **独立路由录入页**，版式同上架单「Web 端上架」（概览卡 + 多页签），管理端密度。

- 「所属单据」按来源显示出库单或波次链接；补拣任务同按单。
- 「Web 端拣货」「PDA拣货」仅待拣货、拣货中出现；PDA拣货直接进入该任务的按库位作业页。
- 已退拣的归属行有效数量小于归属实拣，退拣差额不另列。

## Web 端拣货（录入页）

- **关键要素**：版式同详情。上方左「基本信息」+「录入拣货结果」表单，右「录入进度」卡（提交按钮在卡片底部）；下方页签：待拣明细（按拣货路径排序，带剩余与「录入」）、实拣记录。管理端密度，键盘录入、回车保存。

```text
+-----------------------------------------------------------------------------------------------+
|  拣货录入 · PK-20261015-0019 [待拣货]                                          [返回详情]     |
| +-- Section: 基本信息 (3列) ------------------------------------+ +-- SummaryCard 320px -----+|
```

- 进入页面默认选中路径上第一条还有剩余的应拣行，实拣数量带出剩余；保存后本行处理完自动切到下一条，没处理完留在本行。
- 保存按钮写明本次实拣与缺货件数；错误红字写在表单底部左侧，不弹层。
- 已完成或已关闭的任务打开录入页直接回到详情；提交成功后同样回到详情。

# 复核工作台页面骨架

> 文档版本：WMS-V0.1｜日期：2026-10-15｜状态：新增，待演示验收。
> 线框画法遵循[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)，作业台版式遵循原型[《作业台设计规范》](../../../../../09-产品原型/qs-wms-demo/docs/04-作业台设计规范.md)。复核规则以[《出库单主PRD》第7.5节](../出库单/出库单主PRD.md#75-复核)为准，交互见[《复核工作台前端Demo版PRD》](复核工作台前端Demo版PRD.md)。

## 定位

复核工作台是管理端给打包台作业员用的复核页面：电脑接扫描枪和秤，按原单逐件扫商品或序列号，装进包裹、箱或托，提交后形成一条复核记录。它和 [PDA 复核](../../7-PDA作业端/复核作业/PDA复核页面骨架.md)是同一件事的两种作业形态，共用复核记录与数量口径，不新增单据或状态。

| 场景 | 推荐入口 |
| --- | --- |
| B2C 包裹在打包台装箱、称重、贴面单 | 复核工作台 |
| 暂存区随分拣核对、托盘边走边扫 | PDA 复核 |

**本期不提供**：播种墙与二次分拣（一期不设，见[出库业务设计](../../../../../04-业务分析和设计/03-出库业务设计.md)）；打印面单；真实电子秤接入（重量手工录入模拟）；在工作台删除或修改已提交的复核记录（仍在出库单详情「复核记录」页签处理）。

## 页面与入口

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 复核工作台 | `/wms/outbound/verify-station` | 出库管理 → 复核工作台；出库单详情「去复核 → 复核工作台」 | 扫原单号定位，逐件复核，选容器后提交 |
| 带单打开 | `/wms/outbound/verify-station?no=OB-…` | 出库单详情「去复核」 | 直接进入该单 |

- 列表只列本仓、未出库未取消、已拣多于已复核的单，点行等同扫码。

## 第二步：逐件复核并装箱

```text

| | 商品             | 批次 | 待复核 | 本次      | 序列号    |  | | 提交后待复核    1         | |
| | CABLE-01         | -    | 3      | [ 2 ]     | -         | ×| | ------------------------- | |
| | 数据线 · 69012…  |      |        |           |           |  | | [ 提交复核（2 件） ]      | |
| | SN-DEMO-01       | -    | 1      | 1         | SN0000…01 | ×| |   清空本次                | |
| |                                                               | +---------------------------+ |
| | 装箱                                                          |                               |
| | 复核方式 (随分拣)(随打包装箱●)  容器 (无)(包裹●)(箱)(托)        |                               |
| | 包裹号 [PKG-OB-…0001]   模拟重量 kg [ 0.45 ]                  |                               |
| +---------------------------------------------------------------+                               |
+--------------------------------------------------------------------------------------------------+
```

**分区说明**：

| 分区 | 内容 | 说明 |
| --- | --- | --- |
| 上下文一行 | 货主、业务类型、待复核件数 | 只放作业要用的三项；收货人、地址去详情看 |
| 提示条 | 现在该做什么／刚才发生了什么 | 一条两句话；结果停留到下一次操作 |
| 扫码框 | 一个框：没定位单时扫单号，定位后扫商品或序列号 | 每次操作后焦点回到扫码框 |
| 复核明细 | 本单每条有效实拣一行：商品、批次、待复核、本次、已扫序列号 | 普通商品「本次」可直接改数；序列号商品只能逐件扫；点行设为当前行，同一商品多批次时扫商品记到当前行 |
| 装箱 | 复核方式、容器类型、容器号、模拟重量 | B2C 默认随打包装箱＋包裹，包裹号预填、重量必填；其他类型默认随分拣＋无 |
| 右侧汇总 | 本单各商品已拣／已复核／本次，合计与提交按钮 | 主按钮写明件数；「清空本次」二次确认 |

**页头按钮**：

| 按钮 | 条件 | 行为 |
| --- | --- | --- |
| 出库单详情 | 已定位单据 | 打开出库单详情，本次录入保留 |
| 换一单 | 已定位单据 | 本次有录入时二次确认后清空；回到第一步 |

## 提交后

- 成功：提示条变绿，写复核记录号、件数、容器号与 Mock 运单号；本次清空。本单还有待复核量时停留本单，继续装下一个包裹或箱；已全部复核时回到第一步扫下一张单。
- 被拒（如期间被退拣、取消或已出库）：弹「知道了」窗写明原因，本次录入保留，作业员调整后重交。

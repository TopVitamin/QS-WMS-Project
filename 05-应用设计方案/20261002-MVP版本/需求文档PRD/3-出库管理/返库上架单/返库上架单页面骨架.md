> 文档版本：WMS-V0.3｜日期：2026-10-18｜状态：演示已走查（2026-10-18）。由《出库管理页面骨架》拆出。V0.3：新增「Web 端返库」录入页，列表与详情加 Web 端返库、PDA返库上架两个入口。

## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 返库上架单列表 | `/wms/outbound/return-putaway` | 出库管理 → 返库上架单 | 状态页签、查询、进入详情、Web 端返库或跳转 PDA 返库 |
| 返库上架单详情 | `/wms/outbound/return-putaway/:putbackNo` | 列表点单号；出库单详情返库页签点单号 | 应返库与实际返库明细、操作日志 |
| Web 端返库 | `/wms/outbound/return-putaway/:putbackNo/entry` | 详情页头、列表行操作（未完成单） | 补录落位、重录本行、整单提交 |

**本期不提供**：管理端新建、编辑、作废；Web 端扫码作业台。

- 返库进度只认整单提交（0% 或 100%）；保存进度只在作业页（PDA、Web 端返库）显示。

- 已完成单隐藏「Web 端返库」「PDA返库上架」。

## Web 端返库（录入页）

- **关键要素**：版式同上架单「Web 端上架」。上方左「基本信息」+「录入落位」表单，右「录入进度」卡（提交按钮在卡片底部）；下方页签：应返库明细（带已保存、剩余、「录入」）、已保存落位（带「重录本行落位」）。

```text
+-----------------------------------------------------------------------------------------------+
|  返库录入 · PB-20261015-0001 [待上架]                                          [返回详情]     |
| +-- Section: 基本信息 (3列) ------------------------------------+ +-- SummaryCard 320px -----+|
| | 退拣原因 取消 | 原出库单号 OB-…-0008(链) | 货主 ANKR …          | | 录入进度                 ||
| | 来源库位 STAGE-OUT-01                                         | | 保存只记落位，不动库存…  ||
| +---------------------------------------------------------------+ | 已保存 [-----]  0 / 2    ||
| +-- Section: 录入落位 (FormGrid 4列) ---------------------------+ | 应返库              2    ||
| | 应返库行 *（跨2列）                 | 目标库位 *  | 本次数量 * | | 已保存              0    ||
| | [#1 · CABLE-01 · 良品 · 剩余2 v]    | [A-01-01]   | [2]        | | 剩余                2    ||
| |                                     | 建议…点此填入| 剩余 2    | | 落位                0    ||
| | 序列号 *（SN 商品，整行，默认带出本行还没落位的 SN）          | | [提交返库上架（0 处）]   ||
| | 保存只记落位、不动库存，可重录…                  [保存落位]   | | 还有 2 件没保存落位      ||
| +---------------------------------------------------------------+ +--------------------------+|
| +-- DetailTabs (?tab=) ----------------------------------------------------------------------+|
| | (应返库明细 1) (已保存落位 0)                                                               ||
| | 【应返库明细】 行号 | 商品 | 品质 | 批次号 | 建议库位 | 应返库 | 已保存 | 剩余 | 操作         ||
| | 【已保存落位】 应返库行号 | 商品 | 目标库位 | 返库数量 | 序列号 | 操作（重录本行落位）       ||
| +---------------------------------------------------------------------------------------------+|
+-----------------------------------------------------------------------------------------------+
```

- 目标库位与建议库位不同时，字段下方出现「建议 X，点此填入」。
- 保存后本行没录满就留在本行，录满切到下一条；全部录满后提交按钮可点，提交成功页面回到详情。
- 「重录本行落位」危险操作，二次确认写明会清掉的件数与库位；不动库存。

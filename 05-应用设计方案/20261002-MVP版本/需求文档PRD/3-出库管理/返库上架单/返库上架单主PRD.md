## 一、生成与关联

每次退拣自动生成一张，不允许手工建单：

| 退拣原因 | 触发 | 本单预占 |
| --- | --- | --- |
| 取消 | 出库单受理取消时，已确认实拣按原单归属自动退拣 | 随取消释放 |
| 少件 | 复核时人工退拣；同时把该 SKU 标记待核对 | 保留，可重新分配补拣 |
| 残损 | 复核时人工退拣；须先把实物转不良 | 保留，可重新分配补拣 |

单头指回原出库单，来源库位为出库暂存库位；应返库明细按实拣归属生成，保留商品、品质、批次与 SN，不可修改。每行带建议库位（原拣货库位）。

## 二、状态与操作

| 状态 | 允许操作 | 生效结果 |
| --- | --- | --- |
| 待上架 | 查询、保存落位（PDA 扫描或 Web 端录入）、录满直接提交 | 首次保存进入上架中 |
| 上架中 | 继续保存、重录未提交的行、整单提交 | 保存不动库存 |
| 已完成 | 查询与追溯 | 不更正、不作废、不重复移库 |

保存、重录、提交有两个入口，规则相同、写同一张返库上架单，可交替使用：

| 入口 | 适用 | 做法 |
| --- | --- | --- |
| PDA 返库上架 | 现场有 PDA | 按建议库位逐站：扫目标库位，逐件扫商品（SN 商品扫 SN）计数，一行数满自动保存，一个库位放完自动跳到下一个 |
| Web 端返库 | 现场按纸单或口头放回、没有使用 PDA | 有返库执行权限的人员在管理端逐行录入目标库位、数量（SN 商品录序列号），录满后整单提交 |

管理端不提供新建、作废入口。原出库单已取消不影响本单继续完成。

## 三、保存与提交校验

1. 目标库位启用、属于本仓，不能是收货暂存、出库暂存或异常处理库位；正常品回存储或拣货库位，不良品回不良隔离库位；目标位已有库存或占用须为同货主。
2. 每行可分次保存到不同库位；行内已保存不超过应返库数量；SN 商品每次落位的 SN 须来自本行还没落位的 SN，且不重复。PDA 按实际扫到的 SN 记录；不指定时按应返库清单顺序取。
3. 提交时每行已保存＝应返库；通过后一次把库存从出库暂存移到各目标库位，更新 SN 位置，记录提交人与提交时间。保存不搬库存，重复提交不再搬。
4. 少件仍按应返库数量填满提交，再对该 SKU 发起盘点扣减实物差异；该 SKU 待核对期间不参与新分配。

## 四、数量口径

| 数量 | 关系 |
| --- | --- |
| 应返库 | 各应返库行之和，生成后不变 |
| 已保存（作业进度） | 只在作业页（PDA 返库上架、Web 端返库）展示 |
| 已返库 | 已完成时等于应返库，否则为 0；管理端列表与详情只展示应返库与已返库 |

## 五、管理端页面

| 页面 | 内容 |
| --- | --- |
| 列表 | 状态页签（全部、待上架、上架中、已完成）；筛选返库上架单号、原出库单号、退拣原因、货主；列：单号、状态、退拣原因、原出库单、货主、应返库、已返库、创建时间、提交时间；未完成单行内「Web 端返库」「PDA返库上架」 |
| 详情 | 基本信息（退拣原因、原出库单、货主、仓库、来源库位、创建时间、提交人、提交时间、备注）；返库进度卡；页签：应返库明细、实际返库明细、操作日志；未完成单页头「Web 端返库」「PDA返库上架」 |
| Web 端返库（录入页） | 基本信息；录入落位表单（应返库行按建议库位排序，目标库位默认带出建议库位并可一键还原，数量默认本行剩余，SN 商品默认带出本行还没落位的序列号）；录入进度卡（已保存/应返库，提交按钮写明落位处数）；页签：应返库明细（带已保存、剩余与「录入」）、已保存落位（带「重录本行落位」） |

## 六、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| 已拣 2 的 B2C 单被取消 | 自动生成返库上架单 1 张，原因取消，应返库 2，状态待上架 |
| PDA 保存 1 件到 A-01-01、刷新后再保存 1 件到 A-01-02 | 状态上架中；管理端已返库仍为 0；暂存库存不变 |
| 提交 | 已完成；A-01-01、A-01-02 各加 1，暂存减 2；提交人与时间写入；再次提交不再移库 |
| 目标库位填出库暂存库位或他货主占用的库位 | 阻断，提示原因，不保存 |
| 复核时退拣少件 1 | 生成原因少件的返库单；该 SKU 待核对；提交后盘点才解除 |
| 返库单两行，建议库位分别为 L1、L2；PDA 扫 L1、扫商品数满 | 自动保存到 L1，并跳到 L2 提示扫库位 |
| PDA 在 L2 扫了另一个合法库位 L3 再扫商品 | 改放到 L3（页面写明建议 L2），保存校验照常 |
| SN 商品应返库 SN1、SN2，PDA 先扫 SN2 保存 1 件 | 落位记 SN2；再保存 SN1 时记 SN1；重复扫 SN2 阻断 |
| 不用 PDA：Web 端返库录 A-01-01 × 1、A-01-02 × 1 后提交 | 与 PDA 提交结果相同；提交人为录入人 |
| 管理端打开已完成单 | 页头无「Web 端返库」「PDA返库上架」；实际返库明细显示目标库位与数量 |

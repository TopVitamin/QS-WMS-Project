## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 波次列表页、波次详情页 |
| 路由 | 列表 `/wms/outbound/waves`；详情 `/wms/outbound/waves/:waveNo` |
| 入口 | 列表：出库管理 → 波次管理；详情：列表点波次号、组波成功跳转、拣货任务详情点所属波次 |
| 目标 | 按状态与条件查询本仓波次；查看成员、商品明细、拣货进度与日志；进入未完成的波次拣货任务 |
| 适用状态 | 已下发任务、已完成、已取消（已取消为终态） |
| 版式 | 列表 `PageContainer fill` + 筛选 `Panel` + 表格 `Panel`；详情 `DetailTitle` + `DetailOverview` + `DetailTabs` |
| 页面边界 | 不提供新建、编辑、删除、移出成员、下发任务、手工完成、整波取消、行勾选与批量操作 |

> **本期边界**
> - 组波入口在[出库单列表](../出库单/前端Demo版PRD/出库单前端Demo版PRD_列表页.md)，本页不重复。
> - 波次状态由波次拣货任务终态派生，页面不提供状态维护入口。
> - 管理端不展示拣货任务内部进度，只展示应拣/实拣汇总；现场进度见拣货任务列表。
> - 一期不校验用户权限与角色；数据范围只由顶栏当前仓库限定。

## 2. 查询区

`FilterBar columns={6}`；`draft` / `filters` 双 state；点「查询」写入 `filters` 并回第一页；「重置」清空两者。筛选与页签写入 URL（`?no=&orderNo=&customerId=&status=`），刷新与从详情返回时保留。

| 字段 | 位置 | 控件 | 匹配 | placeholder |
| --- | --- | --- | --- | --- |
| 波次号 | 常显第 1 列 | `Input` | 包含；空格分词，任一分词命中即可（不区分大小写） | `outbound.ui.waveNoPlaceholder`（请输入波次号） |
| 出库单号 | 常显第 2 列 | `Input` | 任一成员出库单号包含任一分词；空格分词同上 | `outbound.ui.noPlaceholder`（请输入出库单号） |
| 货主 | 常显第 3 列 | `OptionSelect allOption` | 精确匹配 | `common.selectPlaceholder`；「全部」选项值为 `FILTER_ALL` |
| （第 4～6 列） | — | 查询、重置（无「展开」） | — | — |

- 筛选项共 3 个，全部常显，不出现 `advanced` 与「展开/收起」；查询/重置紧跟第 3 项，不空列。
- 空条件查询返回当前仓库全部波次，按创建时间倒序。
- 顶栏切换仓库后，保留筛选条件并按新仓库重新过滤；无数据时显示空态。

## 4. StatusTabs

| key | 中文 | 计数口径 | 颜色 |
| --- | --- | --- | --- |
| `ALL` | 全部 | 当前筛选后的波次数 | — |
| `RELEASED` | 已下发任务 | 当前筛选后派生状态为已下发任务的波次数 | blue |
| `COMPLETED` | 已完成 | 当前筛选后派生状态为已完成的波次数 | green |
| `CANCELLED` | 已取消 | 当前筛选后派生状态为已取消的波次数 | gray |

- 页签顺序固定为「全部、已下发任务、已完成、已取消」；URL `?status=`，默认 `ALL`。
- 各页签计数之和等于「全部」；切换页签不重置筛选区，查询后回到第一页。
- 一期不产生「已分配」波次，因此不设该页签；状态文案来自 `status.wave.*`，与列表、详情共用同一映射。

## 10. 派生/计算

只列页面用到的公式，业务规则见[《波次主PRD》](波次主PRD.md) §6～§7。

| 名称 | 公式 | 用于 |
| --- | --- | --- |
| 波次状态 | 波次头已取消 → 已取消；存在任务且全部为已完成/已关闭 → 已完成；否则已下发任务；一期不产生「已分配」 | 列表状态、页签计数、详情标题、页头按钮 |
| 出库单数 | 成员出库单号数组长度 | 列表、汇总卡 |
| 应拣 | 波次拣货任务全部应拣行 `plannedQty` 之和 | 列表、汇总卡、进度 |
| 实拣 | 波次拣货任务全部应拣行 `pickedQty` 之和 | 列表、汇总卡、进度 |
| 拣货进度 | 应拣 > 0 时 `round(实拣 / 应拣 × 100)`，否则显示 `-` | 汇总卡 |
| 已取消单 | 成员出库单状态为已取消的数量 | 汇总卡（为 0 隐藏） |
| 成员波次状态 | 成员出库单已取消 → 已取消；否则在波次内 | 出库单页签 |
| 原单份额 | 该成员在该应拣行的 `shares[].qty` 之和 | 出库单页签 |
| 页签计数 | 当前 `filters` 结果按派生状态分组计数；总数 = `filters` 结果数 | StatusTabs |

- 不新增预占、需求或份额计算；波次不改变成员单的预占与需求。

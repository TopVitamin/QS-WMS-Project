## 页面与弹窗清单

| 页面/容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 波次列表 | `/wms/outbound/waves` | 出库管理 → 波次管理（菜单） | 按状态页签与条件查询波次，进入详情 |
| 波次详情 | `/wms/outbound/waves/:waveNo` | 列表点波次号；出库单列表组波成功后跳转；拣货任务详情点所属波次 | 看出库单、商品明细、拣货进度与操作日志 |

**本期不提供**：

| 入口 | 原因 |
| --- | --- |
| 新建/编辑/删除波次 | 组波只在出库单列表勾选后生成；波次不可手工维护 |
| 移出成员、调整成员份额 | 成员与份额在组波时确定，归属后不重排 |
| 【下发任务】 | 远期能力；一期组波即下发，不停留在「已分配」 |
| 【完成波次】 | 波次状态由任务终态推导，不设人工完成 |
| 整波取消 | 远期能力；一期成员取消只扣该单份额，全部成员取消时波次转「已取消」 |
| 行勾选与批量操作 | 波次之间无批量业务动作 |

容器选型：列表为 `PageContainer fill` + 双 `Panel`（筛选 / 表格）；详情为独立路由页，采用 `DetailTitle` + `DetailOverview` + `DetailTabs`，与[《02-设计规范》](../../../../../09-产品原型/qs-wms-demo/docs/02-设计规范.md) §5.2 业务单据详情一致。本期无 Dialog、Sheet。

## 文档说明与绘制约定

- **与主 PRD 的分工**：组波条件、状态判断、成员取消后果、验收见[《波次主PRD》](波次主PRD.md)；骨架只回答「画在哪、叫什么」。
- **与字段的分工**：波次头字段与「波次明细」以[《波次（详细稿）》](../../../字段清单合集/03-出库管理/波次/波次（详细稿）.tsv)为准；商品明细来自波次拣货任务的应拣行与成员份额，不新增波次字段。
- 仓库由顶栏当前仓库限定，列表不设「仓库」列或仓库筛选；货主显示「编码 名称」。
- 状态统一用 `StatusBadge`；成员状态「在波次内／已取消」用 `TagLabel`，与波次状态区分。
- 线框中的波次号、任务号、单号、数量均为虚构示例。

## 列表页

- **用途**：按状态与条件查询本仓波次，进入波次详情或任务详情。
- **关键要素**：页头仅「导出」；`FilterBar` 3 个常显条件、无展开；4 个状态页签；8 列只读表格，无操作列、无勾选。

```text
+-- WmsLayout: 侧栏 | 顶栏（当前仓库 US-LA-01） ------------------------------------+
| PageContainer fill                                                               |
|  波次管理                                                             [导出]      |
| +-- Panel (筛选) ---------------------------------------------------------------+|
| | FilterBar · columns={6}（3 个常显，无「展开」）                                ||
| | 波次号            | 出库单号           | 货主              | [查询] [重置]     ||
| | [请输入波次号]    | [请输入出库单号]   | [全部货主     v]  |                   ||
| +-------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) --------------------------------------------------------+|
| | (全部 3) (已下发任务 2) (已完成 1) (已取消 0)                     [列设置]   ||
| | 波次号              | 状态       | 货主             | 波次拣货任务       | 出库单数 | 应拣 | 实拣 | 创建时间          ||
| | WV-20261015-0001链接 | 已下发任务 | C10028 Anker 示例 | PK-20261015-0001链接 | 2        | 2    | 0    | 2026-10-15 08:30  ||
| | WV-20261015-0002    | 已完成     | C10028 Anker 示例 | PK-20261015-0002    | 2        | 2    | 2    | 2026-10-14 09:00  ||
| | （其余列无；无操作列）                                                          ||
| +-------------------------------------------------------------------------------+|
| | 共 3 条   每页 20 [20 v]                                      < 1 2 3 >       ||
| +-------------------------------------------------------------------------------+|
+---------------------------------------------------------------------------------+
```

**补充说明**：

- **重点突出**：页头只有「导出」；筛选 3 项全部常显，查询/重置紧跟第 3 项；状态页签带计数；表格无勾选列、无操作列，进入详情只点波次号或任务号。
- **列取舍**：主 PRD 写作「波次拣货任务数」；本期一期固定 1 张，线框以任务号链接同时承载数量与入口。若后续拆多任务，该列显示首张任务号 + 「+N」，不新增数字列。
- **图中省略**：排序、列设置、空态、计数口径见 Demo PRD §4～§5。
- **条件差异**：已完成、已取消波次不显示拣货入口；一期不产生「已分配」波次，不设该页签。

## 详情页

- **用途**：查看波次全貌、成员与商品明细，追溯操作，进入未完成的波次拣货任务。
- **关键要素**：`DetailTitle`「波次 · 波次号 [状态]」；页头「返回列表」固定最前；「Web 端拣货」「PDA拣货」只在已下发任务且存在未关闭任务时出现；基本信息 3 列 + 右侧 320px 拣货进度卡；`DetailTabs` 三个页签带条数。

```text
+---------------------------------------------------------------------------------+
| PageContainer                                                                   |
|  波次 · WV-20261015-0001 [已下发任务]          [返回列表] [Web 端拣货] [PDA拣货] |
| +-- DetailOverview -------------------------------------------------------------+|
| | Section「基本信息」Descriptions columns={3}        | SummaryCard 320px         ||
| | 货主             | 仓库               | 波次拣货任务       | 拣货进度              ||
| | C10028 Anker 示例 | US-LA-01 美西仓    | PK-20261015-0001   | [----------] 0 / 2   ||
| | 出库单数         | 创建时间           | （空）             | 出库单数       2     ||
| | 2                | 2026-10-15 08:30   |                    | 应拣 2 / 实拣 0      ||
| | 波次备注（跨 3 列）                                                    | 已取消单 0（为 0 隐藏） ||
| | 示例补货波次                                                          |                      ||
| +-------------------------------------------------------------------------------+|
| +-- DetailTabs param="tab" -----------------------------------------------------+|
| | (出库单 2) (商品明细 2) (操作日志 1)                                          ||
| | 序号 | 出库单号          | 波次状态 | 出库单状态 | 需求 | 原单份额 | 已拣 | 已复核 | 组波时间         ||
| | 1    | OB-20261015-0009链接 | 在波次内 | 待拣货   | 1    | 1        | 0    | 0      | 2026-10-15 08:30 ||
| | 2    | OB-20261015-0010链接 | 在波次内 | 待拣货   | 1    | 1        | 0    | 0      | 2026-10-15 08:30 ||
| +-------------------------------------------------------------------------------+|
+---------------------------------------------------------------------------------+
```

**补充说明**：

- **重点突出**：状态只出现在 `DetailTitle`，基本信息不重复「波次状态」；基本信息 6 个字段（货主、仓库、波次拣货任务、出库单数、创建时间、波次备注）；汇总卡展示实拣/应拣进度与四项数量。
- **页头按钮按状态互斥**：

| 波次状态 | 页头按钮（`返回列表` 之后） |
| --- | --- |
| 已下发任务，存在未关闭任务 | `[Web 端拣货] [PDA拣货]` |
| 已下发任务，任务都已关闭或完成 | 无 |
| 已完成 | 无 |
| 已取消 | 无 |

- **已取消成员**：出库单页签中该行整行灰显，「波次状态」列显示「已取消」；波次头状态不因单个成员取消而改变。
- **其余页签**：
  - 「商品明细」一行 = 一条应拣行 × 一张成员单的份额；列见 Demo PRD §7.2。
  - 「操作日志」按时间倒序，列=时间、动作、操作者、说明。
- **空态**：当前页签无记录时显示该页签专属空文案，不整页空白。
- **未找到**：非当前仓或不存在的波次显示「未找到波次」+「返回列表」，不展示缓存数据。

# 退货单页面骨架

> 文档版本：WMS-V0.3｜日期：2026-10-25｜状态：已同步六项退货规则确认；动态作业验收未做。
> 线框只表达管理端页面结构和入口位置；业务条件以[退货单主 PRD](退货单主PRD.md)为准；字段以[退货字段详细稿](../../../字段清单合集/05-退货管理/)为准；交互以[前端 Demo 分册](前端Demo版PRD/)和[PDA 退货收货分册](../../7-PDA作业端/退货收货作业/)为准。

## 一、页面与容器清单

| 页面／容器 | 确认路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 退货单列表 | `/wms/returns/orders` | 退货管理 → 退货单 | 状态页签、条件查询、进入详情、进入收货 |
| 退货单详情 | `/wms/returns/orders/:returnNo` | 列表点退货单号；收货、上架页签点单号 | 查看来源、数量、明细、收货记录、异常与上架 |
| Web 退货收货作业台 | `/wms/returns/orders/:returnNo/receive` | 列表或详情页头 | 管理端录入退货收货；与 PDA 共用提交记录 |
| PDA 退货收货 | `/pda/return-receive` | PDA 作业入口或退货单详情页头 | 扫码定位退货单并收货；页面名称沿用“退货收货” |
| 派送失败建单 Dialog | 由列表页头或收货入口打开 | 输入原 B2C 运单号 | 定位原出库并生成派送失败退货单 |
| 退货预报 Mock Dialog | 列表页头“OMS Mock” | Demo／演示专用 | 模拟接收客户退货、平台仓退件预报 |
| 系统集成：指令与结果 | `/wms/system/instructions-results` | 系统集成菜单 | 查看退货结案结果；失败时重交原结果 |
| 收货记录 Sheet | 退货单详情“退货收货记录”页签 | 点击 RR 号 | 只读查看一次收货事实 |
| 退货异常 Sheet | 退货单详情“退货异常”页签 | 点击 RX 号 | 只读查看拒收事实与 SN 核对依据 |

本期不提供：客户退货／平台仓退件的管理端手工新建、退货收货记录手工新建、退货异常手工新建、已发生事实更正或作废、独立质检页面、FBA 退仓处理页面。

```text
+-- PageContainer fill ----------------------------------------------------------------------+
|  退货单                                                        [OMS Mock] [派送失败建单] [导出] |
| +-- Panel（筛选，FilterBar columns={6}） -----------------------------------------------+ |

| | [请输入单号]  | [全部 v]      | [全部 v]      | [请输入运单号] | [日期范围]     |          |
| | （advanced）上游退货预报号 | 原出库单号 | 原出库运单号 | 平台侧退货单号 | 完成时间       |          |
| +---------------------------------------------------------------------------------------+ |
| +-- Panel flex-1（表格） ---------------------------------------------------------------+ |
| | StatusTabs：(全部) (待收货) (收货中) (上架中) (已完成) (已取消)                       |
| | 退货单号 | 状态 | 来源 | 货主 | 关联线索 | 预计 | 实收 | 拒收 | 已上架 | 创建时间 | 操作 |
| | RT-…     | 待收货 | 客户退货 | … | 退货运单… | 2 | 0 | 0 | 0 | … | 收货 |
| +---------------------------------------------------------------------------------------+ |
+-----------------------------------------------------------------------------------------+
```

- 退货单号是详情入口，不另放“查看”按钮。
- 当前仓库由顶栏确定；列表显示该仓库的退货单，不按用户角色裁剪。
- 状态页签使用五态，计数在当前筛选条件之后重新统计。
- “派送失败建单”只定位原 B2C 运单，不提供任意字段新建；“OMS Mock”属于演示输入，不代表真实 OMS 客户端。

```text
| +-- DetailTabs (?tab=) ---------------------------------------------------------------+ |

| |                                                                                     |
| | 退货明细：行号 | 商品 | 原出库行 | 预计 | 实收 | 拒收 | 未收 | 良品 | 不良品 | 已上架 |
| +-------------------------------------------------------------------------------------+

```

退货单、退货收货记录和退货异常均不提供编辑表单。退货单由上游推送或派送失败建单生成，状态允许的业务操作只在页头显示：

- 待收货、收货中：Web 端收货、PDA 收货；派送失败建单入口可在列表或 PDA 起始页使用。
- 收货中：满足条件时显示“确认收货完结”；确认只关闭继续收货，不直接把未上架货物当作已完成。
- 上架中：保留进入共用上架单详情或 PDA／Web 上架入口。
- 已完成、已取消：只读追溯；已完成可从系统集成入口重交结果，不在退货详情重复扣库。

## 四、Web 退货收货作业台

```text
+-- PageContainer fill ----------------------------------------------------------------------+
| 退货收货作业 · RT-… [状态]                                  [返回详情] [返回列表]          |
| +-- Panel：单头摘要 --------------------------------------------------------------------+ |
| | 来源 | 货主 | 仓库 | 退货运单／原运单 | 预计 | 已实收 | 拒收 | 当前剩余                       |
| +----------------------------------------------------------------------------------------+ |
| +-- 双栏 -------------------------------------------------------------------------------+ |
| | 左：当前容器与录入表                              | 右：本次收货                          |
| | [绑定容器] [无容器收货]                            | 容器列表、各容器件数、拒收数           |
| | 扫码商品／选择商品                                 | 本次良品／不良品／拒收合计              |
| | 商品、批次、效期、SN核对状态                       | [清空本次] [提交退货收货（N个容器）]   |
| | 本次良品 | 本次不良品 | 本次拒收 | 固定枚举原因／SN系统固定原因         |                                      |
| +----------------------------------------------------------------------------------------+
```

- 页面固定展示退货来源和关联线索，避免把客户退货、派送失败和平台仓退件混淆。
- 当前容器、本次录入、本次汇总和提交入口按此线框排布；控件校验与提交结果见[收货与双端分册](前端Demo版PRD/退货单前端Demo版PRD_收货与双端.md)。
- 实收只读展示为良品与不良品之和；SN 核对结果在当前行附近展示，具体处理见主 PRD 和[PDA 退货收货 Demo PRD](../../7-PDA作业端/退货收货作业/PDA退货收货前端Demo版PRD.md)。

## 五、详情页 Sheet

### 5.1 退货收货记录 Sheet

标题“退货收货记录号 [收货时间]”，上方展示退货单号、收货人、收货暂存库位、收货时间、容器集合和备注；下方按收货明细展示商品、容器、实收、拒收、品质、批次／效期、SN核对结果和序列号。只读，无业务按钮。

### 5.2 退货异常 Sheet

标题“退货异常记录号 [拒收]”，展示退货单、RR 号、收货行号、商品、异常数量、异常原因、扫描 SN、核对依据、登记人和登记时间。只读，无确认、编辑和关闭按钮。

### 5.3 上架单 Sheet

复用上架单详情的只读快览，单号可跳转共用上架单详情；必须展示来源业务“退货”和来源 RR 号。上架保存进度与提交规则不在本文件重复维护。

## 六、页面自检

- [ ] 列表 `FilterBar columns={6}`，最多 5 项常显，其他筛选进入 advanced。
- [ ] 退货单详情使用“概览卡 + 多页签”，不把收货记录、异常和上架明细全部堆在一个长页面。
- [ ] 收货作业台不是普通编辑表单；本次录入与已提交事实分开显示。
- [ ] 退货单、退货收货记录和退货异常均没有手工编辑入口。
- [ ] 退货上架入口指向共用上架单，不新建“退货上架单”对象。
- [ ] 已取消和已完成单不显示收货、变更、取消操作。

## 2. 已确认路由与页面

| 路由 | 页面 | 页面职责 |
| --- | --- | --- |
| `/wms/returns/orders` | 退货单列表 | 当前仓库内查询、状态页签、进入详情和进入收货 |
| `/wms/returns/orders/:returnNo` | 退货单详情 | 基本信息、数量、退货明细、RR／上架／RX／日志页签 |
| `/wms/returns/orders/:returnNo/receive` | Web 退货收货 | 按容器录入本次收货，提交生成 RR |
| `/pda/return-receive` | PDA 退货收货 | 扫码定位、派送失败建单、按单收货 |
| `/wms/system/instructions-results` | 系统集成：指令与结果 | 查看完成结果；重交失败的原结果 |

Web 与 PDA 退货收货页面名称统一为“退货收货”；对应路由已经注册。退货详情对失败结果提供系统集成页跳转。详情返回列表时保留列表筛选和状态页签；切换当前仓库后，非当前仓单据应提示并返回列表。

## 3. 领域状态与派生

| 概念 | 建议存储值 | 页面口径 |
| --- | --- | --- |
| 退货来源 | `FAILED_DELIVERY` / `CUSTOMER_RETURN` / `PLATFORM_RETURN` | 中文显示“派送失败退回／客户退货／平台仓退件” |
| 单据状态 | `PENDING_RECEIPT` / `RECEIVING` / `PUTTING_AWAY` / `COMPLETED` / `CANCELLED` | 与全局状态枚举一致，禁止页面手工改写 |
| 收货完结 | `NOT_CONFIRMED` / `CONFIRMED` | 只表示是否关闭继续收货，不代替主状态 |
| SN 核对结果 | `MATCHED` / `NO_REFERENCE` / `MISMATCH_REJECTED` | “无可对核原单”不是“核对一致” |
| 退货异常类型 | `REJECTED` | 一期仅拒收；枚举原因由退货字段稿维护 |

状态和数量均读取主 PRD §4 的派生口径；页面不直接维护单头累计数量，也不在本文重复维护公式。

## 4. 两端共用动作约定

| 动作名称（建议） | 触发端 | 结果 |
| --- | --- | --- |
| `createReturnFromOutboundTracking` | 管理端／PDA | 以原 B2C 运单定位并生成 RT；重复未完结单返回原结论 |
| `submitReturnReceipt` | Web／PDA | 一次提交生成一条 RR；按容器、退货预计行、SKU、批次／效期和 SN 写入；自动生成 RX、上架单并更新暂存库存 |
| `confirmReturnReceiptClose` | 管理端；是否开放 PDA 待确认 | 记录收货完结人／时间，定型最终短少 |
| `acceptReturnCancellation` | OMS Mock 消息入口 | 仅零实收接受；已受理后状态为已取消 |
| `resendReturnResult` | 系统集成入口 | 重交原结果，不重复业务事实 |

动作名只是跨页面协作约定，不是接口协议；真实接口由系统集成文档维护。

## 5. 页面字段映射

| 区域 | 主要字段 |
| --- | --- |
| 列表 | 退货单号、状态、来源、货主、预报／原出库／运单线索、预计、实收、拒收、已上架、创建时间 |
| 详情基本信息 | 退货来源、仓库、货主、退货预报号、退货运单号、原出库单／运单、平台侧退货单号、建单方式、创建／完成／取消时间、备注 |
| 退货明细 | 行号、原包裹（派送失败来源）、商品、原出库行、预计、实收、拒收、未收、良品、不良品、已上架 |
| RR Sheet | RR号、退货单号、收货暂存库位、收货人／时间、容器、明细、SN核对 |
| RX Sheet | RX号、RR号、收货行、商品、拒收量、原因、扫描 SN、核对依据、登记人／时间 |

拒收原因固定为“外包装严重破损”和“SN核对不一致”。操作员只能选择“外包装严重破损”；SN不一致由系统固定记录，并保留扫描SN与核对依据。照片、附件和破损等级不作为必填项。

## 6. 跨端走查路径

1. OMS Mock 预报 → 列表出现待收货 RT → 进入详情。
2. 通过 Web 收货或 PDA 定位 RT → 录入容器、商品、良品／不良品／拒收、批次／效期／SN → 提交 RR。
3. 查看详情 RR、RX 和按容器×品质生成的共用上架单。
4. 按共用 PDA／Web 上架规则保存落位，确认保存不动库存；整单提交后核对暂存与目标库位。
5. 退货单收货完结、全部上架 → 已完成 → 查看结果交接记录。
6. 另走派送失败扫原运单、SN 不一致、无预报、FBA 特征和重复提交场景。

# 退货单前端Demo版PRD·详情页

> 本文只写退货单详情页的呈现与跳转；业务规则见[退货单主 PRD](../退货单主PRD.md)；收货交互见[收货与双端分册](退货单前端Demo版PRD_收货与双端.md)；字段见退货字段详细稿。

**布局与占位须符合[需求文档 PRD / AGENTS.md](../../../AGENTS.md)「业务单据详情」约定**：`DetailOverview` + `SummaryCard` + URL 页签。

## 1. 路由与页头

| 项目 | 约定 |
| --- | --- |
| 建议路由 | `/wms/returns/orders/:returnNo` |
| 标题 | `退货单 · {退货单号} [{状态}]` |
| 返回 | 返回列表并保留列表筛选条件 |
| 收货入口 | 待收货／收货中显示“Web 端收货”“PDA 收货” |
| 完结入口 | 收货中且满足主 PRD §5 条件时显示“确认收货完结” |
| 取消／编辑 | 不提供；由 OMS Mock 消息入口处理 |

## 2. 概览区

### 2.1 基本信息

使用 `Descriptions columns={3}`，字段按来源条件展示：

| 分组 | 字段 |
| --- | --- |
| 来源 | 退货来源、建单方式、退货预报号、平台侧退货单号 |
| 归属 | 退货单号、仓库、货主 |
| 运输线索 | 退货运单号、原出库单号、原出库运单号；无值不显示空标签 |
| 时间 | 创建时间、首次收货时间、收货完结确认人／时间、完成时间、取消受理时间 |
| 备注 | 上游备注、到件识别备注；是否允许上传图片待确认 |

单号、仓库、货主、原出库单号、退货预报号均只读；不能通过详情页改写来源和归属。

### 2.2 汇总卡

右侧 320px `SummaryCard`：

- 收货进度：`实收＋拒收 / 预计`；未收在收货完结后显示为最终短少。
- 上架进度：`已上架 / 实收`；实收为 0 时显示“—”。
- 数量清单：预计、实收、拒收、未收、良品、不良品、已上架。
- 状态为已取消时保留取消原因和取消时间，不显示“完成结果”。

## 3. 页签

页签使用 `DetailTabs param="tab"`，带条数；默认进入退货明细。

### 3.1 退货明细

列：行号、商品编码／名称、原出库单行号（有则显示）、预计、实收、拒收、未收、良品、不良品、已上架、行状态（页面派生）。

不要把拒收件的扫描 SN 当作实收 SN 展示在退货明细中；拒收 SN 去退货异常 Sheet 查看。

### 3.2 退货收货记录

列表列：RR号、收货时间、收货人、容器数、实收、拒收、良品、不良品、暂存库位。点击 RR 号打开只读 Sheet。

RR Sheet：

- 单头：RR号、退货单号、暂存库位、收货人、收货时间、备注、容器集合；
- 明细：收货行号、退货单行号、容器、商品、实收、拒收、品质、批次／生产日期／失效日期；
- SN：序列号、品质、核对结果、核对依据、原出库 SN（有则显示）。

### 3.3 上架单

列表列：上架单号、状态、品质、容器、来源 RR 号、应上架、已上架、创建时间、提交时间。点击上架单号跳共用上架单详情，来源单号点击回退货单当前详情。

上架单列表不在退货页签内保存或提交；保存／提交入口遵循共用上架单 PRD和 PDA／Web 上架分册。

### 3.4 退货异常

列表列：RX号、异常类型、收货记录号、收货行号、商品、异常数量、异常原因、扫描 SN、核对依据、登记时间。只读，无“处理完成”按钮。

### 3.5 操作日志

展示退货单自身，以及本单 RR、RX、来源退货上架单和结果回传相关的关键操作。日志不能替代事实记录；数量和库存仍从业务对象读取。

## 4. 并发与空态

- 进入详情和打开页签时重新计算派生；提交收货、收货完结或取消消息并发发生时，以服务端最新事实校验，失败提示刷新。
- 没有 RR 时显示“尚未确认退货收货”，没有 RX 时显示“本单暂无拒收异常”，没有上架单时显示“收货确认后按容器与品质生成上架单”。
- 当前仓库不匹配时不展示其他仓数据；无权限时返回列表。
- 已完成和已取消单所有页签只读；结果重交从系统集成入口执行。

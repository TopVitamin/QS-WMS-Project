# PDA收货页面骨架

> 文档版本：WMS-V0.1｜日期：2026-10-14｜状态：初稿，待评审。  
> 线框按 360 宽、360×560 可用区域绘制，遵循[《PDA作业端设计规范》](../PDA作业端设计规范.md)第 2、3 节；组织方式参照[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)（用途 → 关键要素 → 线框 → 补充说明）。  
> 动作条件以[《入库单主PRD》](../../2-入库管理/入库单/入库单主PRD.md)（R03、R04、R15、R16、R17）为准；交互、校验与文案见[《PDA收货前端Demo版PRD》](PDA收货前端Demo版PRD.md)。

## 页面与弹层清单

| 页面/弹层 | 路由参数 | 入口 | 用途 |
| --- | --- | --- | --- |
| 选单 | `step=order`（默认） | 首页「收货」；管理端「PDA 收货」带单号直达扫容器 | 扫入库单号或柜号、从可收货列表点选；有未提交作业时先接续 |
| 扫容器 | `step=container` | 选单后；容器作业页「新增容器」 | 扫箱唛/托唛绑定容器，或选无容器收货；列出本次作业已有的容器 |
| 容器作业 | `step=box&box=<容器号>` | 绑定或点选容器后 | 在当前容器里扫商品逐行录入；新增容器、提交收货 |
| 本行录入 | `step=line&box=<容器号>&sku=<SKU>` | 扫到或点选商品 | 录入良品、不良品、拒收与拒收原因；加入本容器 |
| 提交收货 | `step=submit` | 容器作业页「提交收货」 | 勾选本次要提交的容器，一次提交 |
| 业务阻断 | 弹窗 | 校验不通过 | 写清原因与下一步，点「知道了」关闭 |
| 新品量方 | `step=measure&box=<容器号>&sku=<SKU>` | 容器作业扫到或点选新品时自动进入 | 先量方再收；线框见[《PDA新品量方页面骨架》](../新品量方作业/PDA新品量方页面骨架.md) |
| 二次确认 | 弹窗 | 放弃作业、移出明细 | 列出会丢掉的内容 |

无容器收货的 `box` 参数为 `BULK`。

## 绘制约定

- 每屏四段：标题栏（返回、收货、当前仓库编码）→ 上下文条 → 主区（可滚动）→ 底部操作区（固定）。
- 上下文条：入库单号（后 4 位加粗）、当前容器、本次作业的容器数与行数。
- `[扫]` 为扫码框，`[键盘]` 为手输切换（规范 §4.4）；「模拟扫码」只在 Demo 显示。
- 示例数据取固定种子 IB-20261002-0001（CABLE-01 预计 500，未收货）。

## 1. 选单（step=order）

- **用途**：确定本次收货的入库单；有未提交作业时先接续。
- **关键要素**：未提交作业卡片（有才显示）；提示语、扫码框、模拟扫码；可收货入库单列表，整行可点。

```text
+--------------------------------------+
| <  收货                     US-LA-01 |
+--------------------------------------+
| 未提交的收货作业                     |
| IB-20261002-0001                     |
| 2 个容器 · 2 行 · 10:32 暂存         |
| [放弃作业]               [继续作业]  |
+--------------------------------------+
| 请扫描入库单号或柜号                 |
| [扫] 等待扫描…               [键盘]  |
| 模拟扫码 [IB-…0001] [IB-…0003]       |
|                                      |
| 可收货入库单 (3)                     |
| IB-20261002-0001            待收货   |
| ANKR · 1 种商品 · 待收 500           |
| IB-20261002-0003            收货中   |
| ANKR · 2 种商品 · 待收 495           |
+--------------------------------------+
```

**补充说明**：

- 有未提交作业时，扫描或点选其他入库单会被阻断：先提交或放弃当前作业。
- 本屏没有底部操作区。

## 2. 扫容器（step=container）

- **用途**：绑定下一个作业容器，或选择无容器收货。
- **关键要素**：上下文条；提示语、扫码框、模拟扫码；本次作业已有容器（点击继续录入）；底部「无容器收货」「提交收货」。

```text
+--------------------------------------+
| <  收货                     US-LA-01 |
+--------------------------------------+
| IB-…0001 · 本次 1 个容器 · 1 行      |
+--------------------------------------+
| 请扫描箱唛或托唛                     |
| [扫] 等待扫描…               [键盘]  |
| 模拟扫码 [BOX-0001-02] [BOX-0001-03] |
|                                      |
| 本次作业的容器 (1)                   |
| BOX-0001-01        已暂存 · 1 行  >  |
|   良品 58 · 不良 2 · 拒收 0          |
+--------------------------------------+
| [无容器收货]          [提交收货 (1)] |
+--------------------------------------+
```

**补充说明**：

- 扫到本次作业已有的容器：直接打开它继续录入。
- 扫到本单已提交过的容器：业务阻断。扫到入库单号、柜号、商品条码、库位码：扫码错误，并说明扫到的是什么码。
- 本次作业还没有任何明细时，不显示「提交收货」。

## 3. 容器作业（step=box）

- **用途**：在当前容器里逐个扫商品；一个容器可装多个 SKU。
- **关键要素**：上下文条（当前容器）；提示语、扫码框、模拟扫码；本容器已录明细（点击修改）；待收明细（点击按本次可收预填）；底部「新增容器」「提交收货」。

```text
+--------------------------------------+
| <  收货                     US-LA-01 |
+--------------------------------------+
| IB-…0001 · 容器 BOX-0001-02 · 1 行   |
+--------------------------------------+
| 请扫描商品条码                       |
| [扫] 等待扫描…               [键盘]  |
| 模拟扫码 [690000000001 CABLE-01]     |
|                                      |
| 本容器已录 (1)                       |
| CABLE-01  USB 数据线             >   |
|   良品 28 · 不良 2 · 拒收 0          |
| 待收明细                             |
| CABLE-01  USB 数据线    本次可收 410 |
+--------------------------------------+
| [新增容器]               [提交收货]  |
+--------------------------------------+
```

**补充说明**：

- 「新增容器」：本容器有明细时先校验再暂存，然后进入扫容器；没有明细则直接回扫容器。
- 「提交收货」：先按同样规则校验并暂存本容器，再进入提交收货页。
- 无容器收货时上下文条显示「无容器收货」，其余相同。
- 扫到或点选新品（本单货主无维护记录）：阻断音后自动进入新品量方，不进本行录入；量方提交或返回后回到本屏。

## 4. 本行录入（step=line）

- **用途**：录入一个商品在本容器里的良品、不良品、拒收。
- **关键要素**：商品卡片（编码大号、名称最多两行、预计/已收/本次可收）；三个数量步进器；拒收原因大按钮（拒收大于 0 时出现）；合计；扫码提示；底部「返回」「加入本容器」。

```text
+--------------------------------------+
| <  收货                     US-LA-01 |
+--------------------------------------+
| IB-…0001 · 容器 BOX-0001-02          |
+--------------------------------------+
| CABLE-01                             |
| USB 数据线                           |
| 预计 500 · 已收 0 · 本次可收 440     |
|                                      |
| 良品        [ - ]    28    [ + ]     |
| 不良品      [ - ]     2    [ + ]     |
| 拒收        [ - ]     0    [ + ]     |
| [破损] [标签不符] [效期不符] [其他]  |
| 合计 30 / 本次可收 440               |
| 再扫同一商品，良品 +1                |
+--------------------------------------+
| [返回]                 [加入本容器]  |
+--------------------------------------+
```

**补充说明**：

- 拒收原因按钮只在拒收大于 0 时出现。
- 主按钮不可用时（合计为 0、拒收未选原因），原因写在底部操作区上方一行。
- 已加入的行再次进入：主按钮为「保存本行」，商品卡片右上角有「移出本容器」（小号、需确认）。

## 5. 提交收货（step=submit）

- **用途**：确认本次要提交的容器，可只提交一部分。
- **关键要素**：容器列表（复选，默认全选，显示行数与合计）；已选汇总；提示「生成 1 条收货记录」；底部「返回」「确认提交」。

```text
+--------------------------------------+
| <  提交收货                 US-LA-01 |
+--------------------------------------+
| IB-20261002-0001                     |
+--------------------------------------+
| [x] BOX-0001-01    1 行              |
|     良品 58 · 不良 2 · 拒收 0        |
| [x] BOX-0001-02    1 行              |
|     良品 28 · 不良 2 · 拒收 0        |
| [ ] 无容器收货     1 行              |
|     良品 0 · 不良 0 · 拒收 3         |
|                                      |
| 已选 2 个容器：实收 90，拒收 0       |
| 提交后生成 1 条收货记录，            |
| 未勾选的容器继续留在作业中           |
+--------------------------------------+
| [返回]             [确认提交 (2)]    |
+--------------------------------------+
```

**补充说明**：

- 提交前按最新数量整体校验；任一容器不通过则整次不提交，业务阻断并指出容器与商品。
- 成功后：入库单仍有未收 → 回扫容器；已全部收完 → 提示后回选单。

## 6. 弹层

```text
+------------------------------+   +------------------------------+
| 不能提交                     |   | 放弃本次收货作业？           |
| 容器 BOX-0001-01 在本单已    |   | 将删除 2 个容器、2 行未提交  |
| 确认收货，请更换作业容器     |   | 的录入；已提交的收货不受影响 |
|                    [知道了]  |   | [取消]           [放弃作业]  |
+------------------------------+   +------------------------------+
           业务阻断                          二次确认
```

## 骨架检查

- [ ] 每屏在 360×560 下主按钮、当前对象、关键数量可见
- [ ] 每个扫码屏有提示语与模拟扫码
- [ ] 容器作业页底部固定「新增容器」「提交收货」
- [ ] 提交收货页可只勾选部分容器
- [ ] 枚举选择用大按钮，不用下拉
- [ ] 扫到新品自动进入新品量方，不能跳过

批次／SN扩展区：按商品配置在本行展开批次、日期和序列号明细；上架时按应上架行选择SN并对应目标库位。主操作仍固定底部，扩展内容在主区滚动。盘点、库位停用或SN校验不通过时，显示具体阻断原因并保留已录内容；新品不在此处阻断，扫到即自动进入新品量方；这些属于一期规则，尚未通过页面实操验证。

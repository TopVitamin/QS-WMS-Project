## 页面与弹层清单

| 页面/弹层 | 路由参数 | 入口 | 用途 |
| --- | --- | --- | --- |
| 量方录入 | `/pda/receive?step=measure&box=<容器号>&sku=<SKU>` | PDA 收货容器作业扫到或点选新品时自动进入 | 录入长宽高、毛重，可拍照、备注，提交量方 |
| 已有记录阻断 | 弹窗 | 提交时发现已有维护记录 | 显示已有记录号、维护仓库、维护人与时间 |
| 放弃录入确认 | 弹窗 | 已填数值时返回 | 确认丢弃本次未提交的数值 |

PDA 首页不设「新品维护」宫格；独立量方只在管理端。

## 绘制约定

- 四段：标题栏 → 上下文条（入库单号后 4 位加粗、容器）→ 主区 → 底部操作区（固定）。
- 尺寸、重量按标题栏当前仓库的单位录入，字段名带单位。示例仓 US-LA-01 为英制（inch、lb）。
- 示例数据与管理端骨架一致：货主 ANKR 的 LAMP-02 台灯，预报 12.00×8.00×3.00 inch、2.50 lb，无维护记录。

## 量方录入（step=measure）

- **用途**：收货遇到新品时，先量方再收。
- **关键要素**：顶部橙色阻断提示；商品卡片（SKU 编码大号、名称最多两行、条码、货主）；预报规格（只读对照）；长、宽、高、毛重四个数字框（2×2 排列）；拍照、备注（低频，放主区下方）；底部「提交量方」及不可用原因。

```text
+--------------------------------------+
| <  新品量方                 US-LA-01 |
+--------------------------------------+
| IB-…0003 · 容器 BOX-0003-01          |
+--------------------------------------+
| ! LAMP-02 是新品，须先量方才能收货   |
| LAMP-02                              |
| 台灯                                 |
| ANKR 安客创新 · 6901234567892        |
| 预报 12.00×8.00×3.00 inch · 2.50 lb  |
|                                      |
| 长(inch) *         宽(inch) *        |
| [ 12.20      ]     [ 8.00       ]    |
| 高(inch) *         毛重(lb) *        |
| [ 3.10       ]     [            ]    |
|                                      |
| 照片  [拍照]  (选填)                 |
| 备注  [点按填写                ]     |
+--------------------------------------+
| 请填写毛重                           |
|                        [提交量方]    |
+--------------------------------------+
```

**补充说明**：

- 进入本屏自动聚焦「长」；回车依次跳到宽、高、毛重。
- 数字框点按弹出数字键盘；扫码内容不写入数字框（规范 §4.2）。
- 没有预报规格时显示「预报 —」。
- 提交成功或返回，都回到收货容器作业；返回后该商品再扫仍进入本屏。

## 页面与弹层清单

| 页面/弹层 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 登记表单 | `/pda/unclaimed`（单屏，无步骤） | 首页「无主货登记」 | 录入线索、箱数、暂存库位，拍照，提交登记 |
| 提交确认 | 弹窗 | 「提交登记」 | 提示提交后不能修改 |
| 放弃确认 | 弹窗 | 已填内容时返回 | 确认丢弃未提交的内容 |

**本期不提供**：查询、认领、指定货主、转入库；查询在管理端。

## 绘制约定

- 单屏：标题栏 → 主区（表单，可滚动）→ 底部操作区（固定）。没有上下文条。
- 字段顺序与管理端登记弹窗一致；线索框可手输，也可点中后扫码填入。
- 示例值为虚构，与管理端骨架一致：美西仓 US-LA-01，异常处理库位 EX-01-01。

## 登记表单

- **用途**：业务员现场记下这批货的信息和照片。
- **关键要素**：范围提示（一行）；运单号、箱唛号（每行一个）、柜号；箱数；暂存库位（可用库位大按钮组，也可扫库位码）；照片；实物描述；底部「提交登记」及不可用原因。

```text
+--------------------------------------+
| <  无主货登记               US-LA-01 |
+--------------------------------------+
| 认得出货主的不在此登记，请联系补单   |
| 运单号  每行一个                     |
| [1Z999AA10123456784              ]   |
| [1Z999AA10123456785              ]   |
| 箱唛号  每行一个                     |
| [FBA15XYZ0001                    ]   |
| 柜号    [                        ]   |
| 运单号、箱唛号、柜号至少填一项       |
|                                      |
| 箱数 *      [ - ]    3     [ + ]     |
| 暂存库位 *                           |
| [ EX-01-01 ]  [ EX-01-02 ]           |
| 照片    [拍照]  [缩略图][缩略图]     |
| 实物描述 [                       ]   |
+--------------------------------------+
| 请选择暂存库位                       |
|                        [提交登记]    |
+--------------------------------------+
```

**补充说明**：

- 暂存库位按钮只列本仓启用的异常处理库区下的启用库位；扫库位码也能选中。没有可用库位时显示「本仓没有可用的异常处理库位，请先在基础资料维护」。
- 主按钮不可用时（线索全空、箱数未填、未选库位），原因写在底部操作区上方一行。
- 提交成功后清空表单，留在本屏登记下一批。

## 弹层

```text
+------------------------------+   +------------------------------+
| 提交无主货登记？             |   | 放弃本次登记？               |
| 3 箱 · 暂存库位 EX-01-01     |   | 已填的内容和照片不会保存     |
| 提交后不能修改或删除         |   |                              |
| [取消]           [确认提交]  |   | [继续填写]         [放弃]    |
+------------------------------+   +------------------------------+
```

## 骨架检查

- [ ] 360×560 下「提交登记」始终可见；表单超出时只滚主区
- [ ] 暂存库位用大按钮组，不用下拉
- [ ] 提交前有确认，说明提交后不能修改
- [ ] 无认领、指定货主、转入库入口

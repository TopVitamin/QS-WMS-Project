# PDA移库前端Demo版PRD

版本：WMS-V0.2｜2026-10-21（按 Demo 实现回写）。规则见[移库作业主PRD](../../4-库存管理/移库作业/移库作业主PRD.md)，布局见[PDA移库页面骨架](PDA移库页面骨架.md)。

路由`/pda/move`，`step`允许`source`、`item`、`target`、`lines`、`confirm`、`done`。一次提交可含一行或多行，成功后形成一条移库作业；管理端只查询，不下发任务。

| 步骤 | 可识别的码 | 成功结果 | 校验与候选 |
| --- | --- | --- | --- |
| source | 本仓库位码 | 绑定源位，进入商品 | 启用、非暂存、有不在盘点中的可移库存；候选为本仓有可移库存的库位 |
| item | SKU、商品条码；SN商品可直接扫SN；另一个可作源位的库位 | 显示货主、批次、品质、实际、已分配、可移；扫到另一源位就换过去 | 必须存在源位；多批次或多品质时列表只留命中行让人点选；候选来自源位库存 |
| target | 本仓库位码；同一商品（+1）；SN商品扫SN | 显示目标位，确认搬到位后加入待提交清单 | 非源位、非暂存、启用、同货主或空位、品质适配；候选为合法目标位（先同货主同商品的库位，再空库位） |
| lines | 不接收扫码 | 查看、删除未提交行；继续添加或进入确认 | 至少1行；全部行须同仓库、同货主；同一源明细累计数量不超可移上限；同一SN不得重复 |
| confirm | 不接收扫码 | 整次提交后返回一个MV号 | 再校验全部行的数量、SN、盘点状态和目标占用；任一行失败时整次不生效 |
| done | 不接收扫码 | 显示MV号、各行源减和目标增 | 提供“继续移库” |

普通SKU默认数量1，可调到可移上限，再扫同一商品+1；SN商品可按数量盘点；实际采集SN时逐件核实，数量按SN数计，重复SN报错。源库存带容器引用时，可在目标步骤切换为散件模式，移出部分或全部可移数量；目标库存不绑定新容器，源位剩余数量保留原容器引用。也可从容器入口整容器移库。可移＝实际－已分配－清单已加。盘点中阻断；待核对不自动增加移库冻结，但页面提示核对实物。扫目标位时与提交时用同一套目标位校验。

扫描发现源位实物与账不符时，点低频红字“账实不符”，确认后调用共用的库内动作`REPORT_DISCREPANCY`（发现环节“移库时账实不符”）立即标记“待核对”，本行不移。若待提交清单已有其他行，页面要求先提交这些行，或确认实物已全部放回源位后放弃草稿；收尾后进入盘点发起页（[PDA盘点](../盘点作业/PDA盘点前端Demo版PRD.md)第二节），不直接发起无依据调整。

安卓返回逐步回退；当前行和待提交清单均进入本机草稿，刷新可继续或放弃。从清单继续添加时只清空当前行，保留已加行；后续行扫到其他货主库存时阻断。提交失败保留全部草稿，清单标出失败行（动作错误带行号）；放弃含已搬实物的草稿前，须二次确认实物已全部放回源位。提交成功后草稿清除，重复提交（同一请求号）返回原MV号。每个扫码步骤提供模拟候选；数量框接收到扫码字符时转给当前扫码步骤，不改数量。

## 动作与文案key

整次提交走与管理端共用的库内动作`SUBMIT_MOVE`。文案放在`pdaMove`分组（`pda.move`已是首页宫格名）。

| 业务动作／文案 | key | 中文 | 英文 |
| --- | --- | --- | --- |
| 加入待提交清单 | `pdaMove.addLine` | 加入清单 | Add Line |
| 继续添加 | `pdaMove.addAnother` | 继续添加 | Add Another |
| 删除未提交行 | `pdaMove.removeLine` | 删除本行 | Remove Line |
| 整次提交 | `pdaMove.submit` | 提交移库 | Submit Move |
| 上报账实不符并转盘点 | `pdaMove.mismatch`／`pdaMove.mismatchConfirm` | 账实不符／确认并去盘点 | Mismatch／Confirm |
| 整次失败 | `pdaMove.atomicFailed` | 存在失败行，本次移库未生效 | Move failed. No lines were applied. |
| 放弃草稿确认 | `pdaMove.confirmPhysicalRestored` | 将删除 n 行未提交的移库。请确认实物已全部放回源位。 | This removes n unsubmitted lines. Confirm all items were returned to source locations. |

走查：单行和多行移库、不同源／目标库位、批次、SN、后续行命中其他货主、暂存位、已分配上限、盘点中、待核对提示、重复提交、保存草稿后刷新、一行失败时整次不生效。验证每行源减目标增成对、SKU三量不变，管理端能立即查询同一MV记录。

# PDA移库页面骨架

版本：WMS-V0.1｜2026-10-15。规则见[移库作业主PRD](../../4-库存管理/移库作业/移库作业主PRD.md)，全局交互见[PDA作业端设计规范](../PDA作业端设计规范.md)。

```text
扫源位              扫商品／SN          数量与目标          待提交清单
┌────────────────┐  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐
│ ‹ 移库  US-LA-01│  │ ‹ 移库          │  │ ‹ 移库          │  │ ‹ 移库  已加2行 │
│ 请扫描源库位     │  │ A-01-01 源位    │  │ SKU-001 正常B1  │  │ A-01→B-02  SKU-1 │
│ [扫] 等待扫描…   │  │ 扫商品／SN      │  │ 可移7           │  │ 数量2       [删除]│
│ 模拟 A-01-01     │  │ [扫] …          │  │ 数量 [−] 2 [+]  │  │ C-01→D-02  SKU-2 │
│                  │  │ 模拟 SKU-001    │  │ 扫目标位 [    ] │  │ 数量3       [删除]│
│                  │  │                 │  │ 模拟 B-02       │  │ 共2行 合计5      │
│ [返回首页]        │  │ [返回]           │  │ [返回] [加入清单] │  │ [继续添加] [去提交]│
└────────────────┘  └────────────────┘  └────────────────┘  └────────────────┘

提交确认
┌────────────────┐
│ ‹ 确认移库      │
│ 共2行 合计5      │
│ 同仓库／同货主   │
│ 整次成功或整次失败│
│ [返回] [提交移库] │
└────────────────┘
```

源库存带容器引用时，第三屏提供“转为散件”入口；散件模式可输入移库数量，目标库存不绑定新容器。整容器入口仍按容器内全部明细移动。SN商品在第三屏改为逐件扫描清单，数量由SN数得出。待提交清单可删除未提交行；点击“继续添加”回到扫源位。底部始终只有一个主按钮；错误就近显示，业务阻断使用弹窗。提交成功显示MV号、各行源减和目标增结果，并提供“继续移库”。

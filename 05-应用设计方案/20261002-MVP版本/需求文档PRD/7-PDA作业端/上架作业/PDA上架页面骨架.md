# PDA上架页面骨架

> 文档版本：WMS-V0.2｜日期：2026-10-15｜状态：初稿，待评审。  
> 线框按 360 宽、360×560 可用区域绘制，遵循[《PDA作业端设计规范》](../PDA作业端设计规范.md)第 2、3 节；组织方式参照[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)。  
> 动作条件以[《上架单主PRD》](../../2-入库管理/上架单/上架单主PRD.md)（状态与操作、保存与提交校验）与[《入库业务设计》](../../../../../04-业务分析和设计/02-入库业务设计.md)第 6.3 节为准；入库单侧的只读口径见[《入库单主PRD》](../../2-入库管理/入库单/入库单主PRD.md) R09、R10；交互、校验与文案见[《PDA上架前端Demo版PRD》](PDA上架前端Demo版PRD.md)。

## 页面与弹层清单

| 页面/弹层 | 路由参数 | 入口 | 用途 |
| --- | --- | --- | --- |
| 选上架单 | `step=list`（默认） | 首页「上架」、首页「待上架」数字 | 扫上架单号、容器号或商品条码定位上架单；或从待上架列表点选 |
| 上架单作业 | `step=work&po=<上架单号>` | 选中上架单 | 看应上架与已录落位；扫目标库位；提交上架单 |
| 落位录入 | `step=place&po=<上架单号>&loc=<库位>` | 扫到目标库位 | 选商品、填数量，保存落位；或剩余全部放到此库位 |
| 提交确认 | 弹窗 | 上架单作业「提交上架单」 | 说明提交后库存移动、不能修改 |
| 撤销确认 | 弹窗 | 已录落位行「撤销」 | 确认删除一条未提交的落位 |

## 绘制约定

- 每屏四段：标题栏 → 上下文条 → 主区（可滚动）→ 底部操作区（固定）。
- 上下文条：上架单号（后 4 位加粗）、品质、容器号（无容器收货显示「无容器收货」）。
- 示例数据取固定种子：0004 的良品上架单 PA-20261005-0001（容器 C-B02，应上架 800，已保存 300 未提交）。

## 1. 选上架单（step=list）

- **用途**：找到要作业的上架单。
- **关键要素**：提示语、扫码框、模拟扫码；待上架列表（上架中排前，整行可点）。

```text
+--------------------------------------+
| <  上架                     US-LA-01 |
+--------------------------------------+
| 请扫描上架单号、容器号或商品条码     |
| [扫] 等待扫描…               [键盘]  |
| 模拟扫码 [PA-…0001] [C-A01]          |
|                                      |
| 待上架 (4)                           |
| PA-20261005-0001    良品    上架中   |
| 容器 C-B02 · IB-…0004 · 已录 300/800 |
| PA-20261004-0002    不良品  待上架   |
| 容器 C-A01 · IB-…0003 · 已录 0/10    |
| PA-20261009-0001    良品    待上架   |
| 无容器收货 · IB-…0008 · 已录 0/60    |
+--------------------------------------+
```

**补充说明**：

- 扫容器号或商品条码命中多张上架单时（如同一容器的良品单与不良品单），列表只保留命中的几张，提示点选。
- 本屏没有底部操作区。

## 2. 上架单作业（step=work）

- **用途**：逐个库位落位，全部落完后提交。
- **关键要素**：上下文条；提示语「请扫描目标库位」、扫码框、推荐库位（大号）、模拟扫码；应上架明细（已录/应上架）；已录落位（可撤销）；底部「提交上架单」及不可用原因。

```text
+--------------------------------------+
| <  上架                     US-LA-01 |
+--------------------------------------+
| PA-…0001 · 良品 · 容器 C-B02         |
+--------------------------------------+
| 请扫描目标库位                       |
| [扫] 等待扫描…               [键盘]  |
| 推荐库位  A-01-01                    |
| 模拟扫码 [A-01-01] [B-01-01]         |
|                                      |
| 应上架                               |
| CABLE-01  USB 数据线     已录 300/800|
| 已录落位                             |
| A-02-01   CABLE-01   300     [撤销]  |
+--------------------------------------+
| 还有 500 件未落位                    |
|                         [提交上架单] |
+--------------------------------------+
```

**补充说明**：

- 已录落位即「保存的实际上架明细」：只记进度，不动库存（R10）。离开再进入仍在。
- 全部落完（每行已录＝应上架）后「提交上架单」才可点。

## 3. 落位录入（step=place）

- **用途**：把某个商品放到刚扫的库位，记录数量。
- **关键要素**：上下文条；目标库位（大号）；商品列表（只列还有剩余的，单选，扫码或点选）；数量步进器（默认该行剩余）；底部「剩余全部放此」「保存落位」。

```text
+--------------------------------------+
| <  上架                     US-LA-01 |
+--------------------------------------+
| PA-…0001 · 良品 · 容器 C-B02         |
+--------------------------------------+
| 目标库位                             |
| B-01-01                              |
| 请扫描商品条码，或点选下方商品       |
| (o) CABLE-01  USB 数据线   剩余 500  |
|                                      |
| 上架数量     [ - ]   500   [ + ]     |
+--------------------------------------+
| [剩余全部放此]          [保存落位]   |
+--------------------------------------+
```

**补充说明**：

- 只剩一个商品有剩余时自动选中。
- 在本屏扫到另一个库位码：校验通过后切换目标库位。
- 「剩余全部放此」把本单所有剩余数量都记到当前库位（整箱落位）。

## 4. 弹层

```text
+------------------------------+   +------------------------------+
| 提交上架单 PA-…0001？        |   | 撤销这条落位？               |
| 共 2 条落位。提交后库存从    |   | A-02-01 CABLE-01 × 300       |
| 暂存库位移到目标库位，不能   |   |                              |
| 再修改                       |   |                              |
| [取消]          [确认提交]   |   | [取消]             [撤销]    |
+------------------------------+   +------------------------------+
```

## 骨架检查

- [ ] 每屏在 360×560 下主按钮、目标库位、关键数量可见
- [ ] 每个扫码屏有提示语与模拟扫码
- [ ] 保存与提交分开：保存只记进度，提交才动库存
- [ ] 提交按钮不可用时写明原因

批次／SN扩展区：按商品配置在本行展开批次、日期和序列号明细；上架时按应上架行选择SN并对应目标库位。主操作仍固定底部，扩展内容在主区滚动。新品维护、盘点、库位停用或SN校验不通过时，显示具体阻断原因并保留已录内容；这些属于一期规则，尚未通过页面实操验证。

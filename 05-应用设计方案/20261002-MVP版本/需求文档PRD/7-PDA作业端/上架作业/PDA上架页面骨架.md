# PDA上架页面骨架

> 文档版本：WMS-V0.3｜日期：2026-10-19｜状态：初稿，待评审。V0.3：按推荐库位逐站上架，与 PDA拣货、返库上架同一版式；取消「落位录入」屏与「剩余全部放此」。
> 线框按 360 宽、360×616 可用区域绘制，遵循[《PDA作业端设计规范》](../PDA作业端设计规范.md)第 2、3 节与 §4.6；组织方式参照[《页面骨架模板-WMS-V1》](../../../../../06-常用模板和方法论/页面骨架模板-WMS-V1.md)。
> 动作条件以[《上架单主PRD》](../../2-入库管理/上架单/上架单主PRD.md)（状态与操作、保存与提交校验）与[《入库业务设计》](../../../../../04-业务分析和设计/02-入库业务设计.md)第 6.3 节为准；入库单侧的只读口径见[《入库单主PRD》](../../2-入库管理/入库单/入库单主PRD.md) R09、R10；交互、校验与文案见[《PDA上架前端Demo版PRD》](PDA上架前端Demo版PRD.md)。

## 页面与弹层清单

| 页面/弹层 | 路由参数 | 入口 | 用途 |
| --- | --- | --- | --- |
| 选上架单 | `step=list`（默认） | 首页「上架」、首页「待上架」数字 | 扫上架单号、容器号或商品条码定位上架单；或从待上架列表点选 |
| 按库位上架 | `step=work&po=<上架单号>`；到站后加 `at=<推荐库位>&to=<目标库位>` | 选中上架单；管理端「PDA上架」 | 一屏一个推荐库位：扫库位到站，扫商品计数，数满自动保存，放完自动跳下一站 |
| 全部已录落位 | `step=done&po=<上架单号>` | 最后一行保存后自动进入 | 核对落位、撤销，提交上架单 |
| 提交确认 | 弹窗 | 汇总屏「提交上架单」 | 说明提交后库存移动、不能修改 |
| 撤销确认 | 弹窗 | 已录落位行「撤销」 | 确认删除一条未提交的落位 |
| 保存失败 | 阻断弹窗 | 保存被动作拒绝 | 写原因，点「知道了」；计数保留 |

## 绘制约定

- 每屏四段：标题栏 → 上下文条 → 主区（可滚动）→ 底部操作区（固定）。
- 上下文条：上架单号（后 4 位加粗）、品质、容器号（无容器收货显示「无容器收货」）、已录/应上架。
- 示例数据取固定种子：0011 的良品上架单 PA-20261011-0001（容器 C-M01：CABLE-01 × 2 推荐 A-01-01；ANKR-001 × 1、ANKR-002 × 6 推荐 B-01-03）。

## 1. 选上架单（step=list）

- **用途**：找到要作业的上架单。
- **关键要素**：提示语、扫码框、扫码结果行、模拟扫码；待上架列表（上架中排前，整行可点）。

```text
+--------------------------------------+
| <  上架                     US-LA-01 |
+--------------------------------------+
| 请扫描上架单号、容器号或商品条码     |
| [扫] 等待扫描…                       |
| 没有找到待上架的上架单：XYZ-404      |  ← 扫码结果行（红/蓝）
| 模拟扫码 [PA-…0001] [PA-…0002] [C-B02]|
|                                      |
| 待上架 (6)                           |
| PA-20261005-0001    良品    上架中   |
| C-B02 · IB-…0004        已录 300/800 |
| PA-20261004-0002    不良品  待上架   |
| C-A01 · IB-…0003           已录 0/10 |
| …                                    |
| PA-20261011-0001    良品    待上架   |
| C-M01 · IB-…0011            已录 0/9 |
+--------------------------------------+
```

**补充说明**：

- 扫容器号或商品条码命中多张上架单时（如同一容器的良品单与不良品单），列表只保留命中的几张，扫码框下蓝字提示点选。
- 本屏没有底部操作区。

## 2. 按库位上架（step=work）

- **用途**：按推荐库位一站一站放，本站放完自动跳下一站。
- **关键要素**：上下文条；当前站卡片（未到站主色「前往库位」，到站变绿「已到达库位」，右侧下一站）；提示语、扫码框、扫码结果行、模拟扫码；「本库位待放」行卡（编码、名称两行、批次，右侧大号待放数，计数中换成「已数 a/n」）；「已录落位」（可撤销）；底部：未到站写先扫库位，计数中出数量框与「保存落位（n 件）」。

```text
按库位上架 · 未到站                      按库位上架 · 已到站（计数中）
+------------------------------------+  +------------------------------------+
| <  上架                   US-LA-01 |  | <  上架                   US-LA-01 |
+------------------------------------+  +------------------------------------+
| PA-…0001 良品 · C-M01 · 已录 0/9   |  | PA-…0001 良品 · C-M01 · 已录 2/9   |
+------------------------------------+  +------------------------------------+
| ┃⌖ 前往库位              下一个    |  | ┃✓ 已到达库位                      |
| ┃  A-01-01               B-01-03   |  | ┃  B-01-03                         |
| 扫描库位 A-01-01，或其他可放的库位 |  | 扫描商品条码或序列号，每扫一件 +1  |
| [扫] 等待扫描…                     |  | [扫] 等待扫描…                     |
| 扫到的是商品 CABLE-01：请先扫描…   |  | ANKR-002 +1，已数 1/6              |
| 模拟扫码 [A-01-01 推荐][B-01-03]   |  | 模拟扫码 [6931…2143][6998…5524]    |
|          [A-01-02]                 |  |                                    |
| 本库位待放（1）                    |  | 本库位待放（2）                    |
| +--------------------------------+ |  | +--------------------------------+ |
| | CABLE-01                 待放  | |  | | ANKR-001                 待放  | |
| | USB 数据线                  2  | |  | | USB-C Charger 65W           1  | |
| | 应上架 2 · 已录 0              | |  | | 应上架 1 · 已录 0              | |
| +--------------------------------+ |  | +--------------------------------+ |
|                                    |  | ┃ ANKR-002                 已数 ┃ |
|                                    |  | ┃ Magnetic Power Bank       1/6 ┃ |
|                                    |  | 已录落位（1）                      |
|                                    |  | A-01-01  CABLE-01         2  撤销  |
+------------------------------------+  +------------------------------------+
| 先扫描库位 A-01-01；放到别处就扫那 |  | [ - ]  1  [ + ]  [保存落位（1 件）]|
| 个库位                             |  |                                    |
| [       保存落位（不可点）       ] |  |                                    |
+------------------------------------+  +------------------------------------+
```

**补充说明**：

- 改放：扫到不在路径上的合法库位，卡片标签变「改放库位（推荐 B-01-03）」，库位号显示实际库位；扫码结果行用蓝字写明。
- 无推荐库位的一站排最后：卡片写「无推荐库位 / 任一可用库位」，提示语「扫描任一可用库位作为目标」。
- 同一站同一商品多批次：行卡显示批次；扫商品码时蓝字提示点选行或扫批次号，选中的行主色描边。
- SN 行：行卡带 SN 标签，列出本次扫到的序列号，行卡下方红字小按钮「清空已扫」；底部不出数量框。
- 「撤销」为红字小按钮，在已录落位分组里，远离底部主按钮；撤销需二次确认。
- 本站放完换站时主区回到顶部，新库位卡在最上面；底部只有通栏主按钮，没有「返回」按钮（返回用标题栏或安卓返回键）。

## 3. 全部已录落位（step=done）

- **用途**：核对全部落位后整单提交。
- **关键要素**：完成卡（应上架、已录、落位处数）；已录落位（可撤销）；提交说明；底部「提交上架单」。

```text
+------------------------------------+
| <  上架                   US-LA-01 |
+------------------------------------+
| PA-…0001 良品 · C-M01 · 已录 9/9   |
+------------------------------------+
|                 ✓                  |
|            全部已录落位            |
|   应上架 9  |   已录 9   |  落位 3  |
| 已录落位（3）                      |
| A-01-01  CABLE-01         2  撤销  |
| B-02-01  ANKR-001         1  撤销  |
| B-01-03  ANKR-002         6  撤销  |
| 提交后库存才从收货暂存库位移到各目 |
| 标库位，提交后不能再改             |
+------------------------------------+
| [          提交上架单            ] |
+------------------------------------+
```

**补充说明**：

- 已录落位即「保存的实际上架明细」：只记进度，不动库存（R10）。离开再进入仍在。
- 在本屏撤销某条落位后剩余又大于 0，自动回到按库位上架。

## 4. 弹层

```text
+------------------------------+   +------------------------------+
| 提交上架单 PA-…0001？        |   | 撤销这条落位？               |
| 共 3 条落位。提交后库存从    |   | B-02-01 · ANKR-001 × 1       |
| 收货暂存库位移到目标库位，不 |   |                              |
| 能再修改                     |   |                              |
| [取消]        [提交上架单]   |   | [取消]             [撤销]    |
+------------------------------+   +------------------------------+
```

## 骨架检查

- [ ] 每屏在 360×616 下当前站卡片、扫码框、主按钮可见
- [ ] 每个扫码屏有提示语、扫码结果行与模拟扫码
- [ ] 保存与提交分开：保存只记进度，提交才动库存
- [ ] 主按钮不可用时写明原因（底部提示行）

批次／SN：同一站多批次时行卡显示批次，扫批次号或点选；SN 行逐件扫 SN。Demo 收货尚未采集 SN，校验按商品 SN 规则（见 Demo PRD §4.1）。新品维护、盘点、库位停用或SN校验不通过时，显示具体阻断原因并保留计数与已录内容。

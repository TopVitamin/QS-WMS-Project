> **版本**：WMS-V1.1｜**日期**：2026-10-27｜**定位**：供 AI/研发在 `qs-wms-demo` 实现管理端人工品质转换、自动过期转换展示与验收。本文件只写页面呈现与交互，不重复业务规则。

> **实现约定**：[《QS-WMS 前端设计与开发规范》](../../../../../09-产品原型/qs-wms-demo/docs/02-设计规范.md)、[需求文档 PRD 约定](../../AGENTS.md)。

关联资料：[《品质转换主PRD》](品质转换主PRD.md)、[《品质转换页面骨架》](品质转换页面骨架.md)、[《库存查询前端Demo版PRD》](../库存查询/库存查询前端Demo版PRD.md)、[《库存查询页面骨架》](../库存查询/库存查询页面骨架.md)、[《库存流水前端Demo版PRD》](../库存流水/库存流水前端Demo版PRD.md)、[《库存模块宏观系统架构》](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)。

## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 对象名称 | 品质转换（正常品 → 不良品） |
| 路由 | 无独立路由；承载页 `/wms/inventory/stock?view=balance&inventoryId={id}` |
| 入口 | 批次库存详情页头「品质转换」；批次行可转换数量 > 0 时显示 |
| 目标 | 在原库位、原批次把正常品转为不良品，记录原因、依据、通知结果与 SN，保证数量与流水一致 |
| 适用条件 | 所选库存行品质为正常品；库位用途为存储或拣货；SKU 未盘点；可转换数量 > 0。出库暂存仅限主 PRD §1「复核发现已拣残损」的例外，现有实现不支持，见 §13 |
| 版式 | `Dialog`，`sm:max-w-lg`，内容超出时 `max-h-[90vh] overflow-y-auto`；只读区两列，长文本与 SN 清单占整行 |
| 页面边界 | 不建单据、不编号、不搬实物、不改订单预占、不做不良转正常、不做不良品移库、不提供 PDA 入口、不配置角色权限 |

> **本期边界**
> - 一期 Demo 只实现管理端入口；PDA 入口延后。
> - 自动过期转换由系统执行，页面只展示「已转不良」或「待补做：原因」，不提供手工触发。
> - 转换只改同一库位、同一批次的品质数量；需要移到不良隔离库位时，转换完成后再走移库。
> - 转换不改变 SKU 实际总量、不改变订单预占；可用数量相应减少。
> - 一期不校验用户权限与角色。

## 2. 入口条件（本对象无查询区）

品质转换没有独立列表，因此**没有 FilterBar、查询/重置、StatusTabs**。入口由批次库存详情当前行决定，条件如下：

| 条件 | 取值 | 不满足时 |
| --- | --- | --- |
| 当前仓库 | 等于批次行 `warehouseCode`（顶栏当前仓） | 不展示按钮；深链显示「无权限或记录不存在」 |
| 视角 | 批次库存（`view=balance`，有 `inventoryId`） | 不展示入口 |
| 品质 | 正常品 | 不展示按钮；动作拒绝「只有正常品可以转换」 |
| 库位用途 | 存储或拣货 | 不展示按钮；动作拒绝「只有存储、拣货库位上的正常品可以人工转换」 |
| 盘点状态 | SKU 未盘点 | 不展示按钮；动作拒绝「{{sku}} 正在盘点（{{no}}），不能变动库存」 |
| 可转换数量 | `min(库存数量－已分配, SKU可用数量) > 0` | 不展示按钮 |
| 有效期 | 未启用效期或未过期 | 过期正常品仍可人工转换；自动转换另见 §7.3 |

- 入口所在批次库存列表的查询区见[《库存查询前端Demo版PRD》](../库存查询/库存查询前端Demo版PRD.md) §2.2。
- 不满足条件时整按钮不渲染，不用 disabled 占位，也不弹错误提示。
- 「暂停分配」不阻止人工转换；主 PRD 只要求盘点中暂停转换。

## 3. 页头与工具栏按钮

入口位于批次库存详情 `DetailSheet` 页头（`Section「身份与位置」` 的 `extra` 区域），不新增页面工具栏。

| 位置 | 按钮 | 显示条件 | 样式 | 行为 |
| --- | --- | --- | --- | --- |
| 批次详情页头 | 查看流水 | 始终 | `Button variant="outline" size="sm"` | 跳 `/wms/inventory/logs`，带 `customerId`、`sku`、`quality`、`location`、`batch` |
| 批次详情页头 | 品质转换 | 可转换数量 > 0 | `Button size="sm"`（主按钮） | 打开品质转换 Dialog |
| Dialog 底部 | 取消 | 始终 | `variant="outline"` | 有输入时先确认放弃；无输入直接关闭 |
| Dialog 底部 | 确认转换 | 始终可点 | `default`（主按钮） | 触发校验；通过后提交 |

- 一个区域只有一个主按钮；批次详情内「品质转换」为主按钮，「查看流水」为次级。
- Dialog 打开后不出现第二个业务按钮；不使用「保存」「提交」文案。

## 5. 列表/表格

### 5.1 列表

不适用。本对象不新增列表、不新增表格页签、不新增行操作列。

### 5.2 Dialog 只读字段

打开时由当前批次库存行带入，全部只读；不写 placeholder。

| # | 字段 | 来源 | 展示形式 | 空值/示例 |
| --- | --- | --- | --- | --- |
| 1 | 仓库 | 批次行 `warehouseCode` | 只读输入框 | `US-LA-01` |
| 2 | 货主 | 批次行 `customerId` | 只读，编码＋名称 | `C10028 Anker 示例` |
| 3 | 商品 | 批次行 `skuCode` | 只读，编码＋名称 | `CABLE-01 数据线` |
| 4 | 库位 | 批次行 `locationCode` | 只读 | `B-03-01` |
| 5 | 批次号 | 批次行 `batchNo` | 只读 | 非批次商品显示 `-` |
| 6 | 品质 | 固定为正常品 | 只读文案 | `正常品` |
| 7 | 库存数量 | 批次行 `onHandQty` | 只读 | `10` |
| 8 | 已分配 | 批次行 `allocatedQty` | 只读 | `3` |
| 9 | 可转换 | `min(库存数量－已分配, SKU可用数量)` | 只读，强调 | `7` |
| 10 | 原因 | 固定为在库受损 | 只读 | `在库受损` |

- 只读字段顺序固定；不在 Dialog 里展示仓库全名、库位用途、效期等级等非必要信息。
- 品质文案按主 PRD 用「正常品」；库存列表枚举显示「良品」，两处文案待统一（见 §13）。

### 5.3 SN 候选清单（仅 SN 商品）

SN 清单不是 `DataTable`，是两列、可滚动的复选框网格；只列本仓、本货主、本 SKU、当前品质的在库 SN。

| # | 元素 | 展示 | 可选条件 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 复选框 | `Checkbox` | 始终可勾选 | 勾选状态受控 |
| 2 | SN | 等宽数字文本 | — | 原样展示，不截断 |
| — | 空态 | 文案 | — | 无可选 SN 时显示「当前仓库没有可选的在库 SN」，仍可按数量转换 |

- 不展示 SN 的库位、批次或入库时间；不要求 SN 与库存行库位绑定。
- 已出库、已盘亏或已属于其他品质的 SN 不出现在候选清单。
- 不提供扫码框；主 PRD「选择或扫描」在本期以选择实现，扫描待后续（见 §13）。

### 5.4 转换后的两条流水（承载页展示）

转换成功后，批次详情顶部 `Alert` 列出本次动作生成的两条流水：

| # | 元素 | 展示 | 说明 |
| --- | --- | --- | --- |
| 1 | 提示 | 「本次转换已记录两条独立流水」 | 只在本次动作后显示 |
| 2 | 流水号 | `DocNo` 链接 → 库存流水详情 | 两条，按负数在前、正数在后 |
| 3 | 品质 | `TagLabel` | 正常品 / 不良品 |
| 4 | 变化量 | 带符号数量 | 正常品 `-N`、不良品 `+N`，颜色只辅助，符号始终保留 |

## 6. 操作矩阵

### 6.1 入口与行条件

| 条件 | 正常品·存储/拣货 | 正常品·出库暂存 | 不良品 | 正常品·盘点中 | 可转换 = 0 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 显示「品质转换」按钮 | ✅ | ❌（主 PRD 例外待实现，见 §13） | ❌ | ❌ | ❌ |
| 打开 Dialog | ✅ | ❌ | ❌ | ❌ | ❌ |
| 动作层可提交 | ✅ | ❌ | ❌ | ❌ | ❌ |

### 6.2 Dialog 内动作

| 操作 | 条件 | 结果 |
| --- | --- | --- |
| 勾选/取消 SN | SN 商品 | 只改选择，不校验数量；提交时校验个数 |
| 取消 | 无输入 | 直接关闭，不改数据 |
| 取消 / × / 遮罩 / Esc | 有输入 | 先弹「放弃本次录入？」；确认放弃才关闭 |
| 确认转换 | 表单校验通过 | 提交；成功后关闭并提示 |
| 确认转换 | 校验失败 | 字段红字；保留输入；不发请求 |
| 确认转换 | 动作层失败 | `toast.error(errorKey)`；保留输入与弹窗 |
| 重复确认 | 同一 `requestId` | 返回原结果，不生成第二组流水 |

- 确认按钮始终可点，不因表单未填而 disabled；点击后显示所有字段错误。
- 无二次确认弹窗；Dialog 本身就是确认容器。

## 7. 承载详情（转换涉及的区块）

承载页的完整字段与列见[《库存查询前端Demo版PRD》](../库存查询/库存查询前端Demo版PRD.md) §7.2；本节只写转换会用到的区块。

| 分组 | 字段 | 与转换的关系 |
| --- | --- | --- |
| 身份与位置 | 仓库、货主、商品、库位（含用途）、容器号、品质 | 决定 Dialog 只读上下文与入口是否显示 |
| 批次效期 | 批次号、生产日期、有效期至、效期等级 | 转换在原批次；过期影响自动转换 |
| 数量 | 库存数量、已分配、可分配 | 可转换上限 = min(库存数量－已分配, SKU可用数量) |
| 作业状态 | 可分配资格、盘点状态、作业提示、过期转换 | 盘点中禁用；过期转换展示见 §7.3 |
| 追溯 | 库存明细号、最后库存流水号、最后变动时间、创建时间 | 转换后流水回写 |
| SN（有则显示） | 已登记 SN 列表 | 转换会更新实际核实的 SN 品质 |

### 7.3 自动过期转换的展示

| 页面字段值 | 出现条件 | 不允许的操作 |
| --- | --- | --- |
| `-` | 未启用效期、未过期，或已无可转换数量 | — |
| 已转不良 | 不良品且效期等级为过期 | 不显示数量、不显示按钮 |
| 待补做：盘点中 | 正常品过期，SKU 在盘点 | 无「立即转换」 |
| 待补做：仍有已分配 | 正常品过期，本行仍有已分配 | 无「立即转换」 |
| 待补做：SKU可用不足 | 正常品过期，SKU 可用不足 | 无「立即转换」 |
| 待补做：待系统重试 | 正常品过期，原因已消除但未执行 | 无「立即转换」 |

- 自动过期流水操作者为「系统」，原因说明「效期过期」，每次生成两条独立流水。
- 页面不新增「过期转换状态」字段、筛选或独立页面；只读展示。

## 8. 弹窗规格（品质转换 Dialog）

### 8.1 触发与打开前检查

| 项 | 内容 |
| --- | --- |
| 触发 | 批次库存详情页头「品质转换」 |
| 打开前 | 重新按最新数据计算可转换数量；若 ≤ 0 或 SKU 已盘点，不打开，`toast.error` 对应原因 |
| 初始值 | 转换数量 `1`；SN 清单空；货主通知结果空；原因说明空；依据说明空 |
| 幂等标识 | 打开时生成一次 `requestId`，同一弹窗内重复提交复用 |

### 8.2 只读区

按 §5.2 的 10 个字段，两列排布：仓库/货主、商品/库位、批次号/品质、库存数量/已分配、可转换/（空）。原因「在库受损」与货主通知结果同一行。

### 8.3 输入区

| 字段 | 必填 | 控件 | 默认 | placeholder | 校验 | 错误位置/文案 |
| --- | :---: | --- | --- | --- | --- | --- |
| 转换数量 | ✅ | `Input type="number" inputMode="numeric" min=1 max=可转换` | `1` | `common.inputPlaceholder` | 大于 0 的整数且 ≤ 可转换 | 输入框下方；空/0/小数 →「请输入大于 0 的整数」；超上限 →「最多可转换 {{max}} 件」 |
| SN 清单 | 条件 | 复选框网格 | 空 | — | 勾选时个数 = 转换数量；只允许在库同货主同 SKU 同品质 | 清单下方；「已选 {{selected}} 个 SN，需与转换数量 {{qty}} 一致」 |
| 货主通知结果 | ✅ | `OptionSelect` | 空 | `common.selectPlaceholder` | 已通知/待通知/无需通知 | 字段下方；「请填写货主通知结果」 |
| 原因说明 | ✅ | `Textarea` | 空 | `common.inputPlaceholder` | 去空格后非空 | 字段下方；「请填写原因说明」 |
| 依据说明 | ✅ | `Textarea` | 空 | `common.inputPlaceholder` | 去空格后非空 | 字段下方；「请填写依据说明」 |

- 原因说明、依据说明、SN 清单占整行（`span="full"`）。
- 文本不设字数上限；不允许只输入空格。
- SN 清单只在 SN 商品出现；非 SN 商品不占位、不显示。
- 可编辑控件必须有 placeholder；只读控件不设 placeholder。

### 8.4 校验矩阵

| 场景 | 触发时机 | 提示 | 结果 |
| --- | --- | --- | --- |
| 数量为空/0/负数/小数 | 点确认后 | 请输入大于 0 的整数 | 阻断，保留输入 |
| 数量 > 可转换 | 输入时/点确认后 | 最多可转换 {{max}} 件 | 阻断，不截断输入 |
| 必填为空 | 点确认后 | 请填写{{field}} | 阻断，所有空字段同时标错 |
| SN 个数 ≠ 数量 | 点确认后 | 已选 {{selected}} 个 SN，需与转换数量 {{qty}} 一致 | 阻断 |
| SN 已出库/已盘亏/非本 SKU | 提交时动作校验 | SN 与数量不一致、重复或不在本仓本货主该 SKU 的在库清单中 | 阻断；文案修正见 §13 |
| 盘点中 | 打开/提交 | {{sku}} 正在盘点（{{no}}），不能变动库存 | 不打开或提交失败 |
| 不良品 | 打开/提交 | 只有正常品可以转换 | 不打开或提交失败 |
| 非存储/拣货库位 | 打开/提交 | 只有存储、拣货库位上的正常品可以人工转换 | 不打开或提交失败 |
| 转换后可用为负 | 输入时预览 + 提交 | 转换将导致负可用库存，不能提交。请先处理相关订单预占，再重试 | 阻断，保留输入 |
| 数据已变化 | 提交时 | 记录不存在或已变化，请刷新 | 阻断，刷新后重开 |
| 重复确认 | 提交时 | 返回原结果 | 不生成第二组流水 |

### 8.5 变更预览

预览区固定显示两行，随数量实时变化：

| 行 | 文案模板 | 示例 |
| --- | --- | --- |
| 本行 | 正常品 {{goodFrom}}→{{goodTo}}，不良品 {{badFrom}}→{{badTo}}，实际总量不变 | 正常品 10→3，不良品 0→7，实际总量不变 |
| SKU | 预占 {{preFrom}}→{{preTo}}，可用 {{availFrom}}→{{availTo}} | 预占 0→0，可用 10→3 |

- 不良品起始值取同一库位、同一批次、同一容器、同一生产/失效日期的现有不良品行；不存在按 0。
- 可用数量减少但不得为负；为负时显示阻断告警（`Alert variant="destructive"`）。
- 预览只是结果预演，不写入库存。

### 8.6 按钮与关闭

| 按钮/动作 | 文案 | 行为 |
| --- | --- | --- |
| 主按钮 | 确认转换 | 校验 → 提交 → 成功 toast → 关闭 → 刷新派生 |
| 次按钮 | 取消 | 有输入先确认；无输入直接关闭 |
| 关闭图标 | × | 同取消 |
| 遮罩/Esc | — | 同取消，走 `requestClose` |
| 放弃确认主按钮 | 放弃 | 丢弃输入并关闭 |
| 放弃确认次按钮 | 继续编辑 | 保留输入并回到弹窗 |

- 脏关闭确认标题「放弃本次录入？」，正文「已填写的内容不会保存」。
- 未修改任何字段时关闭不弹确认。

### 8.7 提交、幂等与并发

1. 点击确认后，先跑前端校验；不通过则显示字段错误与首次错误聚焦，不发请求。
2. 提交前按最新库存重算可转换上限；若数量已超过最新上限，按 §8.4 阻断。
3. 动作写两条流水：正常品 `-N`、不良品 `+N`，同一业务动作标识；保留原因说明、依据说明、货主通知结果、操作者与时间。
4. 选中的 SN 同步转品质；未选 SN 时按数量转换，不推断具体单件。
5. 成功后关闭弹窗，toast「已把 {{qty}} 件转为不良品」，批次详情顶部出现两条流水。
6. 同一 `requestId` 重复提交返回原结果，不重复改库存、不重复写流水。
7. 提交失败保留输入与弹窗；库存与流水不变。

### 8.8 失败分支

| 分支 | 反馈 | 页面状态 |
| --- | --- | --- |
| 数量超上限 | 输入框下方红字 + `toast.error` | 保留输入与弹窗 |
| 必填缺失 | 字段下方红字 + `toast.error` | 保留输入与弹窗 |
| SN 数量不一致 | SN 清单下方红字 | 保留勾选 |
| SN 不合法 | `toast.error` 动作文案 | 保留勾选 |
| 盘点中/非正常品/非工作库位 | `toast.error` 动作文案 | 不关窗，数据刷新后按钮可能消失 |
| 负可用 | 预览告警 + `toast.error` | 保留输入；不写库存、订单、流水 |
| 记录已变化 | `toast.error` | 建议刷新后重开 |
| 重复提交 | 成功文案（原结果） | 关闭，不新增流水 |

## 10. 派生/计算

只列本对象页面用到的公式，业务规则见[《品质转换主PRD》](品质转换主PRD.md) §7、§12.1。

| 名称 | 公式 | 用于 |
| --- | --- | --- |
| 可转换数量 | 正常品、存储/拣货库位、未盘点时 `max(0, min(库存数量－已分配, SKU可用数量))`；其他为 0 | 入口按钮、只读「可转换」、数量上限 |
| SKU 可用数量 | 该 SKU 良品实际合计－订单预占合计；不良品为 0 | 上限、预览 |
| 本行正常品变化 | `正常品后 = 库存数量－转换数量` | 预览、结果 |
| 本行不良品变化 | `不良品后 = 同库位同批次同容器同日期的不良品实际＋转换数量` | 预览、结果 |
| SKU 预占变化 | 不变 | 预览 |
| SKU 可用变化 | `可用后 = 可用前－转换数量` | 预览、负可用阻断 |
| 实际总量 | 正常品实际＋不良品实际；转换前后不变 | 预览说明 |
| 自动过期可转数量 | 正常品过期、未盘点时 `max(0, min(库存数量－已分配, SKU可用数量))`；仍有已分配时只转未分配且可用支撑的部分，已分配部分保留待补做 | 自动转换、待补做原因 |
| 待补做原因 | 盘点中 → COUNTING；已分配 > 0 → ALLOCATED；可用 ≤ 0 → RESERVED；否则 RETRY | 承载页展示 |

- 不新增「品质转换状态」「转换单号」或「审批状态」。
- 不改变订单预占；不为支撑转换自动释放订单或拒绝订单。

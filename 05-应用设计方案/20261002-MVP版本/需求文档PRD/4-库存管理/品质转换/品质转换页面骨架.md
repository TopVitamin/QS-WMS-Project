# 品质转换页面骨架

> 模板版本：**WMS-V1.1**｜日期：2026-10-27｜状态：待评审。
> 品质转换**不设独立菜单、路由、列表或单据**；本骨架只画批次库存详情中的入口与品质转换 Dialog，以及自动过期转换在页面上的展示位置。业务规则见[《品质转换主PRD》](品质转换主PRD.md)，字段与校验见[《品质转换前端Demo版PRD》](品质转换前端Demo版PRD.md)。

## 页面与弹窗清单

| 页面/容器 | 路由/参数 | 入口 | 用途 |
| --- | --- | --- | --- |
| 批次库存详情（承载页） | `/wms/inventory/stock?view=balance&inventoryId={id}` | 库存查询 → 批次库存 → 点商品 | 展示当前库位、批次、品质的数量与作业状态 |
| 品质转换 Dialog | 无独立路由 | 批次库存详情页头「品质转换」 | 人工把正常品转为不良品 |
| 过期转换展示（字段） | 同上 | 批次库存详情「作业状态」分组 | 展示自动过期已转不良或待补做原因 |

**本期不提供**：

| 入口 | 原因 |
| --- | --- |
| 独立菜单、路由、列表、单据、编号 | 品质转换是库存动作，不建单据 |
| 不良品转回正常品 | 一期只支持正常品 → 不良品 |
| 转换时同时移库 | 转换在原库位、原批次完成；需隔离时转换后另做移库 |
| 手工触发自动过期转换 | 自动过期由系统按仓库当地日期执行，页面只展示结果/待补做 |
| PDA 入口 | 一期 Demo 只实现管理端；PDA 入口延后 |
| 用户授权/角色权限配置 | 一期不配置转换授权 |

容器选型：承载页为[《库存查询页面骨架》](../库存查询/库存查询页面骨架.md)的批次库存详情 `DetailSheet` 880px；转换动作为 `Dialog`（`sm:max-w-lg`，内容超出时 `max-h-[90vh] overflow-y-auto`）；无 Sheet、无独立页面、无向导。

## 文档说明与绘制约定

- **与主 PRD 的分工**：转换范围、数量约束、SN 规则、结果与自动过期规则见[《品质转换主PRD》](品质转换主PRD.md)；骨架只回答「画在哪、叫什么」。
- **与库存查询的分工**：入口所在批次库存详情的字段与分区见[《库存查询页面骨架》](../库存查询/库存查询页面骨架.md)；本文只画转换入口、Dialog 和过期展示，不重复整张详情。
- 人工转换原因说明默认「在库受损」，可补充文本；不提供原因代码字段。
- 只读字段与可编辑字段按两列排布；原因说明、依据说明、SN 清单占整行。
- 校验提示在对应输入框下方，错误出现时不改变已输入值。
- 线框中的 SKU、库位、批次、数量、SN 均为虚构示例。

## 入口：批次库存详情页头

- **用途**：在具体库存行上发起品质转换，转换对象明确到仓库、货主、SKU、库位、批次、品质。
- **关键要素**：页头右侧两个按钮；「品质转换」只在可转换数量 > 0 时出现；转换成功后抽屉顶部出现两条流水提示。

```text
+-- DetailSheet 880px（批次库存详情） -------------------------------------------+
| 批次库存 · CABLE-01 @ B-03-01                          [查看流水] [品质转换]    |
|--------------------------------------------------------------------------------|
| ! 本次转换已记录两条独立流水                                                    |
|   LOG-...-0123 正常品 -2   LOG-...-0124 不良品 +2                               |
|--------------------------------------------------------------------------------|
| Section 身份与位置：仓库 | 货主 | 商品 | 库位（含用途） | 容器号 | 品质          |
| Section 批次效期：批次号 | 生产日期 | 有效期至 | 效期等级                        |
| Section 数量：库存数量 10 | 已分配 3 | 可分配 7                                     |
| Section 作业状态：可分配资格 | 盘点状态 | 作业提示 | 过期转换                    |
| Section 追溯：库存明细号 | 最后库存流水号 | 最后变动时间 | 创建时间              |
| Section SN（有则显示）                                                          |
+--------------------------------------------------------------------------------+
```

**补充说明**：

- 「品质转换」不满足条件时整按钮不渲染，不做 disabled；条件见 Demo PRD §2。
- 转换成功后的两条流水提示只保留本次动作，刷新后按库存流水正常追溯，不在详情常驻。
- 页头「查看流水」跳库存流水并带入货主、SKU、品质、库位、批次，用于查看完整历史。

## 品质转换 Dialog

- **用途**：录入转换数量、原因与通知结果，确认后在同一库位、同一批次把正常品转为不良品。
- **关键要素**：只读上下文 10 项；转换数量、SN 清单、货主通知结果、原因说明、依据说明；变更预览；失败提示；取消/确认。

```text
+--------------------------------------------------------------+
| 品质转换                                                 [×] |
|--------------------------------------------------------------|
| 在原库位、原批次把正常品转为不良品，不搬实物                 |
|                                                              |
| 仓库           | 货主                                        |
| US-LA-01       | C10028 Anker 示例                           |
| 商品           | 库位                                        |
| CABLE-01 数据线 | B-03-01 存储                                |
| 批次号         | 品质                                        |
| LOT-202610     | 正常品                                      |
| 库存数量       | 已分配                                      |
| 10             | 3                                           |
| 可转换         | 转换数量*                                   |
| 7              | [7            ]                             |
|                | 最多可转换 7 件 / 请输入大于 0 的整数        |
| SN 清单（仅 SN 商品）                                        |
| [ ] SN00000111   [ ] SN00000112   [ ] SN00000113             |
| 仅逐件核实时勾选；留空可按数量转换，勾选后个数须等于转换数量 |
| 原因           | 货主通知结果*                               |
| 在库受损       | [已通知          v]                         |
| 原因说明*                                                    |
| [                                                        ]   |
| 依据说明*                                                    |
| [                                                        ]   |
|--------------------------------------------------------------|
| 确认后                                                       |
| 本行：正常品 10→3，不良品 0→7，实际总量不变                 |
| SKU：预占 0→0，可用 10→3                                     |
| ! 转换将导致负可用库存，不能提交（条件出现时）               |
|--------------------------------------------------------------|
|                                      [取消] [确认转换]       |
+--------------------------------------------------------------+
```

**补充说明**：

- 只读区不写 placeholder；可编辑区必须有 placeholder 或明确选项文案。
- 转换数量默认 `1`，上限为「可转换」；输入超过上限时在输入框下方提示「最多可转换 N 件」，保留输入不截断。
- SN 清单只在 SN 商品显示；未勾选时可只按数量转换；勾选后个数必须等于转换数量。SN 只列本仓、本货主、本 SKU、当前品质的在库 SN。
- 预览区必须同时给出本行正常品/不良品变化与 SKU 预占/可用变化；实际总量不变。
- 负可用告警属于阻断提示，不是可忽略的警告；出现时确认按钮不提交。
- 关闭（×、遮罩、Esc、取消）在有输入时先二次确认「放弃本次录入？」；确认丢弃才关闭。
- 确认按钮统一「确认转换」，不使用「保存」「提交」。

## 自动过期转换的展示

- **用途**：让用户知道过期品是否已自动转不良、还有多少未转以及原因。
- **关键要素**：只在批次库存详情的「作业状态」分组展示一个「过期转换」字段；**不画独立页面、不设执行按钮**。

```text
+-- Section 作业状态 ------------------------------------------------------------+
| 可分配资格    | 盘点状态        | 作业提示        | 过期转换                    |
| 否            | [盘点中] P-...  | [暂停分配]      | 待补做：仍有已分配          |
+--------------------------------------------------------------------------------+
```

| 页面展示 | 条件 | 说明 |
| --- | --- | --- |
| `-` | 未启用效期、未过期，或已无可转换数量 | 不显示过期转换信息 |
| 已转不良 | 本行为不良品且效期等级为过期 | 表示系统已按过期规则转换，不显示数量与按钮 |
| 待补做：盘点中 | 正常品已过期，SKU 正在盘点 | 原因来自盘点单 |
| 待补做：仍有已分配 | 正常品已过期，本行仍有已分配未拣 | 分配释放后由系统补做 |
| 待补做：SKU可用不足 | 正常品已过期，SKU 可用不足以支撑转换 | 可用恢复后由系统补做 |
| 待补做：待系统重试 | 正常品已过期，前两类原因都已消除但尚未转换 | 等系统下次执行 |

**补充说明**：

- 自动过期流水的原因说明为「效期过期」，操作者显示「系统」，不在页面上提供修改入口。
- 待补做原因消除后由系统补做，页面只随数据刷新，不提供「立即转换」按钮。
- 盘点中同时暂停人工与自动转换；页面不因「待补做」新增状态字段或筛选。

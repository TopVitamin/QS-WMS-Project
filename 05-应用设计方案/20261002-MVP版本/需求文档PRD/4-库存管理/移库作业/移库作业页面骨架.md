## 页面与弹窗清单

| 页面／容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 移库作业列表 | `/wms/inventory/moves` | 左侧菜单「移库作业」 | 查询 PDA 已提交的移库记录 |
| 移库作业详情 | `/wms/inventory/moves/:moveNo` | 列表点移库作业号 | 查看一次提交的明细、关联流水和操作日志 |

本期不提供的入口：

| 不提供 | 原因 |
| --- | --- |
| 新建移库、下达移库任务、待执行任务列表 | 移库只在 PDA 上扫描并一次提交，管理端不下达任务，也没有执行中状态 |
| 编辑、删除、撤销、重做、再次执行 | 提交成功即生效并写流水，管理端只读 |
| 行勾选、批量操作、行内操作菜单 | 记录没有可办理的后续动作 |
| 状态页签、状态筛选、状态徽标 | 移库作业没有待执行、执行中、已取消等状态 |
| 管理端导出文件 | 页头「导出(Mock)」只提示演示环境未接真实导出 |

## 文档说明与绘制约定

- 本文只回答「画在哪、叫什么」。业务规则见[移库作业主PRD](移库作业主PRD.md)，列级规格、失败文案、Mock 与验收见[移库作业前端Demo版PRD](移库作业前端Demo版PRD.md)，字段以[详细稿](../../../字段清单合集/04-库存与库内/移库作业/移库作业（详细稿）.tsv)为准。
- 通用布局、栅格与占位规则见[需求文档 PRD／AGENTS.md](../../AGENTS.md)，本文不重复。
- 本对象特殊约定：
  - 一次 PDA 提交对应一个 `MV` 号；一个 `MV` 号下有多行，每行有独立的源库位、目标库位、批次／SN、品质和数量。
  - 列表按「单头视角」一行一个 `MV` 号，源／目标库位用摘要；明细只在详情页签展开。
  - 详情是只读业务记录，不设页头业务按钮，只有「返回列表」。
  - 源减流水、目标增流水是两个独立链接，分别打开库存流水详情，不在本页画配对关系图。
  - 空值统一画 `-`；示例值均为虚构 Mock。

## 移库作业列表

- **用途**：在当前仓库内按作业号、商品、货主、源／目标库位、提交时间和操作者查询 PDA 已提交的移库记录。
- **关键要素**：页头仅「导出（Mock）」；`FilterBar` 5 项常显 + 2 项展开；表格 8 列；默认提交时间倒序；无状态页签、无勾选、无行操作。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库 US-LA-01) ------------------------------------------------------+
| PageContainer fill                                                                               |
|  移库作业                                                                        [导出(Mock)]     |
|  移库在 PDA 一次提交即完成，这里只查询记录，不下达或撤销移库                                    |
| +-- Panel (筛选) -------------------------------------------------------------------------------+|
| | FilterBar · 6 列栅格                                                                          ||
| | 移库作业号        | SKU             | 货主            | 源库位          | 目标库位          |   ||
| | [移库作业号      ] | [编码／名称    ] | [全部 v]        | [编码／名称    ] | [编码／名称      ] |   ||
| |                 |                 |                |                 |                  | 查询 ||
| |                 |                 |                |                 |                  | 重置 ||
| |                 |                 |                |                 |                  | 展开 ||
| | 展开后：提交时间 [提交日期] | 操作者 [全部 v]                                                  ||
| +-----------------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) ------------------------------------------------------------------------+|
| | DataTable 工具区                                                                   [列设置]   ||
| | 移库作业号            | 货主            | 明细行数 | 移库总数 | 源库位           | 目标库位 …    ||
| | MV-20261015-0001     | C10028 示例货主 | 1       | 5       | A-01-02         | B-03-01 …    ||
| | MV-20261016-0002     | C10028 示例货主 | 2       | 4       | A-01-02 等 2 个  | B-03-02 …    ||
| | （向右：操作者 | 提交时间）                                                                   ||
| | 共 N 条   每页 20 [20 v]                                                     < 1 2 3 >        ||
| +-----------------------------------------------------------------------------------------------+|
+-------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **常显与展开**：常显 5 项为移库作业号、SKU、货主、源库位、目标库位；第 6 列放查询、重置、展开；提交时间、操作者放展开区。筛选项总数 7，必须有「展开」。
- **移库作业号**：左固定，格式 `MV-{UTC日期}-{序号}`；点击进入详情，行内不设「查看」。
- **源／目标库位摘要**：本次只有 1 个库位时显示库位编码；多个库位时显示「首个库位 等 n 个」，悬停显示完整列表，读屏文本也给出完整列表。
- **明细行数与移库总数**：均取本次提交的汇总。移库总数是各行数量直接相加，不同 SKU 相加只表示件数，不代表单一 SKU 数量；列头或提示中不得写「总库存」「总移库量」。
- **SKU 筛选**：按明细行匹配，任一明细行命中即返回该 `MV` 号；列表不展开明细行。
- **无状态**：列表不画状态页签、状态列或状态徽标；也不画操作列。
- **空态**：当前仓库和筛选条件下没有记录时，表格区显示「当前仓库和筛选条件下没有移库记录」。
- **图中省略**：列宽、排序图标、列设置细节；列级规格见 Demo PRD 第 5 节。

## 移库作业详情

- **用途**：只读查看一次移库提交的全部明细、生成的两组库存流水和操作日志。
- **关键要素**：`DetailTitle`「移库作业 · MV号」，不带状态；页头仅「返回列表」；`DetailOverview` 左侧 3 列基本信息 + 右侧 320px 汇总卡；下方 `DetailTabs` 三个页签：移库明细、库存流水、操作日志。

```text
+--------------------------------------------------------------------------------------------------+
| 移库作业 · MV-20261016-0002                                                    [返回列表]        |
| +-- DetailOverview -----------------------------------------------------------------------------+|
| | +-- Section 基本信息 (3 列) -------------------------+  +-- SummaryCard 320px ---------------+ |
| | | 所属仓库          | 货主            | 操作者        |  | 移库汇总                        | |
| | | US-LA-01 洛杉矶仓 | C10028 示例货主 | Mike Zhang   |  | 明细行数              2         | |
| | | 提交时间                   | 操作终端             |  | 移库总数              4         | |
| | | 2026-10-16 09:20:00       | PDA                 |  | 移库总数是各行数量合计，        | |
| | |                          |                     |  | 不代表单一 SKU 数量             | |
| | +-----------------------------------------------------+  +---------------------------------+ |
| +------------------------------------------------------------------------------------------------+|
| +-- DetailTabs param="tab" ----------------------------------------------------------------------+|
| | (移库明细 2)  (库存流水 4)  (操作日志 1)                                                       ||
| | 行号 | 商品              | 源库位   | 目标库位 | 批次号      | SN清单        | 品质   | 数量 … ||
| | 1    | LOT-DEMO-01 批次装 | C-01-01 | B-03-02 | LOT-202612  | -             | 正常品 | 2    … ||
| | 2    | SN-DEMO-01 序列装  | A-01-02 | B-03-02 | -           | SN-B, SN-C    | 正常品 | 2    … ||
| | （向右：源减流水 | 目标增流水）                                                                 ||
| +------------------------------------------------------------------------------------------------+|
+--------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **基本信息**：所属仓库、货主、操作者、提交时间、操作终端固定 5 项。状态已在对象上不存在，不画状态徽标，也不在基本信息里补「状态」字段。
- **汇总卡**：只放明细行数、移库总数两个指标，底部写清「移库总数是各行数量合计，不代表单一 SKU 数量」；不画进度条，因为移库提交即完成，没有执行进度。
- **移库明细页签**：每个 `MV` 号一行一个明细行，展示行号、商品、源库位、目标库位、批次号、SN 清单、品质、移库数量、源减流水号、目标增流水号。一个明细行只有一个源库位和一个目标库位，不画源位多选或目标位拆分。
- **库存流水页签**：只列本 `MV` 号产生的流水，复用[库存流水页面骨架](../库存流水/库存流水页面骨架.md)的紧凑列（发生时间、流水号、流水类型、数量变化、货主、库位、来源单据）。单行移库 2 条，多行移库按行数 ×2。流水号点击打开流水详情抽屉。
- **操作日志页签**：操作时间、操作、操作者、说明；按时间倒序。
- **页签带条数**：移库明细按行数、库存流水按已生成流水条数、操作日志按日志条数；空数据用各页签自己的空态，不隐藏页签。
- **找不到记录**：`MV` 号不存在或不属于顶栏当前仓库时，整页显示「未找到移库作业」+「返回列表」，不展示其他仓记录。
- **页头**：不画编辑、删除、撤销、重做、再次执行；不画「PDA 执行」按钮，管理端不跳转 PDA。
- **图中省略**：长文本省略、列设置、页签右侧工具区；列级规格见 Demo PRD 第 7 节。

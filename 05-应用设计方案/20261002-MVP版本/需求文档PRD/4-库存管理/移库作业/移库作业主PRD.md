# 移库作业主PRD

> 定义同仓库内的PDA移库执行和管理端记录查询。字段见[移库作业详细稿](../../../字段清单合集/04-库存与库内/移库作业/移库作业（详细稿）.tsv)，业务依据见[库存模块宏观系统架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)第3.1.1节。管理端页面见[移库作业页面骨架](移库作业页面骨架.md)，PDA步骤见[PDA移库前端Demo版PRD](../../7-PDA作业端/移库作业/PDA移库前端Demo版PRD.md)。

## 一、对象与边界

移库作业记录一次PDA提交的库位变化。一次提交可含一行或多行，每行记录源库位、目标库位、SKU、批次／SN、品质和数量；同一次提交只能属于同一仓库、同一货主。它不是管理端下达的任务，不设待执行、执行中或取消状态；整次提交成功后才形成一个移库作业号，每行生成一减一加两行库存流水。

移库只改变库位分布，不改变仓库、货主、SKU、批次、品质和SKU三量合计。不用于跨仓调拨，也不能借移库把不良品变成正常品。

## 二、PDA主流程

1. 当前仓库下扫描源库位。
2. 扫描或选择源位上的SKU；有批次或SN时继续识别到具体实物。
3. 输入移库数量。SN商品也可按数量录入，不强制SN落位；实际采集SN时才校验清单数量与去重。
4. 扫描目标库位，系统检查仓库、启用状态、货主占用、库区用途和品质适配。
5. 确认实物已搬到位，将本行加入待提交清单。需继续时返回扫源库位；后续行须与第一行属于同一货主。
6. 作业人员确认待提交清单后整次提交；系统先重新校验所有行，再一次性生效。

待提交清单仅为本机作业草稿，不占库位、不改变库存。任一行校验失败时整次不生效，不得部分移库；系统保留草稿并标出失败行。因为实物可能已搬到目标位，作业人员须在解决阻断后重新整次提交，或将本次实物全部放回源位后再放弃草稿，不得直接清空草稿继续其他作业。

## 三、提交校验

- 源、目标库位都属于当前仓库且已启用，不得相同，不得是收货暂存或出库暂存库位。
- 源位必须存在本货主、本SKU、本批次、本品质的实际库存；移库数量大于0且不超过实际－已分配。
- 目标位为空或已归同一货主；品质须与目标库区用途适配。目标位已有其他货主实物或未完结作业占用时阻断。
- 盘点中的SKU不得移库。待核对标记按现行规则只暂停新分配、组波、补拣和其他出库指定，不自动新增移库冻结；但现场核对发现源位账实不符时，必须停止本次移库并发起盘点，不能通过移库绕过差异。
- SN商品逐件校验在库、当前源位、SKU、批次和品质一致；同一SN本次不得重复。
- 同一提交的所有行须同仓库、同货主；多行使用同一源批次库存时，累计移库数量不得超过可移数量；同一SN不得重复。
- 同一提交重复发送只返回原移库作业号，不重复改库存。

## 四、管理端查询

管理端只提供移库记录列表和详情，不提供新增、编辑、删除、撤销或重做。列表支持按移库作业号、时间、货主、SKU、源库位、目标库位、操作者查询；详情展示每行源、目标、批次／SN、品质、数量与关联流水。

## 五、权限与异常

执行人须同时具备当前仓库授权和“移库执行”权限。库存不足、库位不适配、盘点中、SN不符均阻断提交并保留草稿。现场确认账实不符时立即标记“待核对”；若清单已有其他已搬到位行，须先提交这些行或全部放回源位并放弃草稿，再进入盘点发起；不通过修改数量绕过差异。

## 六、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| A位正常品10、已分配3，移5至B位 | 提交成功；A减5、B加5；SKU实际／预占／可用不变；生成MV号及两条独立流水 |
| 尝试移8 | 阻断，提示最大可移7；不截断为7，不改变库存 |
| 目标位被另一货主占用 | 阻断并保留草稿 |
| 源或目标为暂存库位 | 阻断，提示暂存货跟随收发单据处理 |
| SKU盘点中 | 阻断并可跳盘点单 |
| 重复提交同一请求 | 返回原MV号，只保留一次库存变化 |
| 两行移库中第二行提交前已不足 | 整次阻断，标出失败行；第一行也不生效 |

# 库存查询页面骨架

> 文档版本：WMS-V0.1｜日期：2026-10-15｜状态：文档初稿，待演示验收。规则见[库存查询主PRD](库存查询主PRD.md)，字段见SKU库存、库存明细和SN库存详细稿，交互见[库存查询前端Demo版PRD](库存查询前端Demo版PRD.md)。

## 页面与容器清单

| 页面／容器 | 路由 | 用途 |
| --- | --- | --- |
| 库存查询 | `/wms/inventory/stock` | 三个视角查询、导出、打开详情；`view`允许`sku`、`balance`、`serial` |
| SKU库存详情抽屉 | 同页 | 数量、库位分布、占用／分配来源、待核对与最近流水 |
| 库存明细详情抽屉 | 同页 | 位置、批次效期、数量、SN与品质转换入口 |
| SN库存详情抽屉 | 同页 | 单件当前位置与轨迹 |

## 列表页

```text
+-- PageContainer fill -------------------------------------------------------------------------+
| 库存查询                                                                [导出当前视角]         |
| [SKU库存] [库存明细] [SN库存]                                                                  |
| +-- Panel 筛选（6列，最多5项常显） ----------------------------------------------------------+ |
| | SKU编码/名称 | 货主 | 分配状态/品质 | 数量条件/效期 | 库位/SN | 查询 重置 展开             | |
| +-------------------------------------------------------------------------------------------+ |
| +-- Panel flex-1 ---------------------------------------------------------------------------+ |
| | SKU视角：商品 | 货主 | 正常 | 不良 | 订单占用 | 实际 | 预占 | 可用 | 分配状态 | 最近变动       | |
| | 明细视角：商品 | 库位 | 批次 | 品质 | 效期等级 | 实际 | 已分配 | 可分配 | 最近变动           | |
| | SN视角：SN | 商品 | 货主 | 当前库位 | 批次 | 品质 | 在库状态 | 最近变动                       | |
| +-------------------------------------------------------------------------------------------+ |
+------------------------------------------------------------------------------------------------+
```

- 顶栏仓库限定当前页数据；视角切换保留SKU和货主条件，清除只适用于上一视角的条件。
- 可用为负显示红色数值和“正常品不足”标签；待核对、盘点中分别显示独立标签，不能合并为一个“锁定”。
- 数量列右对齐；商品显示编码＋名称；库位显示编码＋名称；临期和品质分两列。
- SKU、明细、SN行均可点开右侧详情抽屉；不设置编辑操作列。

## 库存明细与SN详情抽屉

库存明细按“身份与位置、批次效期、数量、追溯”分组；正常品且满足条件时页头显示“品质转换”。SN详情按“当前状态、来源信息、轨迹”分组，轨迹按时间正序并可跳来源记录。

## 品质转换Dialog

```text
+-- 品质转换 ------------------------------------------------------------------+
| 仓库／货主／商品／库位／批次／当前品质（只读）                          |
| 实际10   已分配3   可转换7                                              |
| 转换数量* [ - ] 2 [ + ]     SN清单*（启用SN时显示）                 |
| 原因：在库受损（固定）      原因说明* [........................]             |
| 依据说明* [........................]   货主通知结果* [..............]      |
| 确认后：正常品10→8，不良品0→2，实际总量不变                           |
|                                                     [取消] [确认转换]       |
+----------------------------------------------------------------------------+
```

转换成功后关闭Dialog，刷新当前明细，并展示两条成对流水链接。自动过期转换仅在库存明细详情展示结果或待补做原因，不设手工执行按钮。

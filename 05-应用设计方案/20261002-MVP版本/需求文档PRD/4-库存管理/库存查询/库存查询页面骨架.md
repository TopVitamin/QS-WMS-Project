## 页面与弹窗清单

| 页面/容器 | 路由/参数 | 入口 | 用途 |
| --- | --- | --- | --- |
| 库存查询（三视角） | `/wms/inventory/stock?view=sku｜balance｜serial` | 库存管理 → 库存查询 | 在 SKU库存、批次库存、SN台账之间切换查询 |
| SKU库存详情 | 同路由 `?skuId={id}` | SKU库存视角点商品 | 当前品质数量、库位分布、订单预占、已分配来源、SN 与最近流水 |
| 批次库存详情 | 同路由 `?inventoryId={id}` | 批次库存视角点商品 | 当前库位与批次的数量、效期、作业状态与追溯；发起品质转换 |
| SN台账详情 | 同路由 `?serialId={id}` | SN台账视角点 SN | 单件在库状态、最后来源与实际采集轨迹 |
| 品质转换 Dialog | 无独立路由 | 批次库存详情页头「品质转换」 | 在原库位、原批次把正常品转为不良品 |
| 口径说明 Popover | 无独立路由 | 视角页签下方「口径说明」 | 解释库存数量、订单预占、可用数量、已分配、可分配 |

**本期不提供**：

| 入口 | 原因 |
| --- | --- |
| 手工新增库存、直接改数 | 库存由业务动作写入，查询页只读 |
| 占用/释放、冻结/解冻、维护分配状态 | 订单预占由出库单驱动，标签由原业务或盘点派生 |
| 独立的品质转换菜单、路由或单据 | 品质转换只在批次库存详情内发起，不建单据、不编号 |
| 不良品转回正常品 | 一期只支持正常品 → 不良品 |
| 按 SN 查当前库位 | SN 只记在库仓库，不推断具体库位 |
| 真实导出文件 | 「导出当前视角」为 Demo Mock |

容器选型：列表为 `PageContainer fill` + 上下两个 `Panel`；三个详情均为右侧 `DetailSheet` 880px；品质转换为 `Dialog`（`sm:max-w-lg`）；口径说明为 `Popover`。

## 文档说明与绘制约定

- **与主 PRD 的分工**：数量口径、可分配资格、标签来源、验收见[《库存查询主PRD》](库存查询主PRD.md)；骨架只回答「画在哪、叫什么」。
- **与字段的分工**：列表列、筛选项、详情字段以三份详细稿 TSV 为准；SN 轨迹来自库存流水的实际采集记录，不新增 SN 位置字段。
- 三个视角不是三种业务状态，页签用 `StatusTabs` 组件承载视角切换，文案分别「SKU库存 / 批次库存 / SN台账」。
- 仓库由顶栏当前仓库限定，三视角均不设仓库列与仓库筛选；货主显示编码 + 名称。
- 品质用 `TagLabel` 显示「良品／不良品」；「盘点中」「暂停分配」「不参与分配」直接挂在商品或可分配数量旁，不设独立「分配状态」列。
- SN 列不展示库位、批次或由库位推断的品质。
- 线框中的 SKU 编码、SN、数量、库位均为虚构示例。

## 列表页（三视角共用外壳）

- **用途**：在本仓范围内按视角查询库存，进入三类详情。
- **关键要素**：页头「导出当前视角」；视角页签带计数；固定口径提示行；`FilterBar columns={6}`；表格行点击打开详情，无操作列与勾选。

```text
+-- WmsLayout: 侧栏 | 顶栏（当前仓库 US-LA-01） ------------------------------------+
| PageContainer fill                                                               |
|  库存查询                                              [导出当前视角]             |
| +-- Panel (视角 + 口径 + 筛选) --------------------------------------------------+|
| | (SKU库存 12) (批次库存 18) (SN台账 6)                                          ||
| | SKU 看可用数量，批次看可分配；订单预占不等于已分配。 [口径说明]                 ||
| | FilterBar · columns={6}（各视角条件不同，见下）                                ||
| +-------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) --------------------------------------------------------+|
| | DataTable：商品/SKU 或 SN 左固定；数量列右对齐；行点击开右侧详情                ||
| | 共 N 条   每页 20 [20 v]                                      < 1 2 3 >       ||
| +-------------------------------------------------------------------------------+|
+---------------------------------------------------------------------------------+
```

**补充说明**：

- 视角页签切换时保留 SKU 关键词与货主，清除上一视角专属条件，回第一页；URL 的 `view` 同步。
- 三视角各自维护筛选条件，但共用表格外壳、分页与空态规则。
- 切换顶栏仓库后按新仓重新派生数据；列表不出现仓库列。
- 空态：当前仓库与筛选下无数据时显示「当前仓库和筛选条件下没有库存」。

## SKU库存视角

- **用途**：按「仓库＋货主＋SKU＋品质」看数量、订单预占和可用数量；良品与不良品分行。
- **关键要素**：5 个常显筛选；SKU 数/库存合计条；商品旁条件标签；三列数量。

```text
+-- FilterBar（5 常显，无展开） ------------------------------------------------+
| SKU编码／名称       | 货主            | 品质          | 数量条件        | 最后变动时间          | [查询][重置] ||
| [SKU编码或名称…]    | [全部货主   v]  | [全部     v]  | [全部      v]   | [最后变动日期       ] |              ||
+------------------------------------------------------------------------------+
| 合计（当前筛选）：SKU 数 8    库存合计 126（良品 110，不良 16）               |
| 商品                        | 货主           | 品质   | 库存数量 | 订单预占 | 可用数量 | 最后变动时间         |
| CABLE-01 数据线 [暂停分配]  | C10028 Anker…  | 良品   | 30       | 3        | 27       | 2026-10-20 10:30     |
| CABLE-01 数据线 [盘点中]    | C10028 Anker…  | 不良品 | 5        | 0        | 0        | 2026-10-19 09:00     |
+------------------------------------------------------------------------------+
```

**补充说明**：

- 商品列 `pin: 'left'`；点击商品打开 SKU 详情。正常行不挂标签。
- 数量条件：全部／有库存／零库存／零可用；不设负库存、分配状态筛选。
- 合计条按当前筛选结果计算；SKU 数按「仓库＋货主＋SKU」去重，品质分行不重复计。
- 可用数量原则上非负；若数据异常为负，保留真实负数并标红提示，不截为 0。

## 批次库存视角

- **用途**：按「仓库＋货主＋SKU＋品质＋批次＋库位＋容器」看本库位本批次的实际、已分配、可分配；散件容器为空。
- **关键要素**：5 常显 + 3 展开；库位用途作辅助说明；可分配列带资格标签；行内可发起品质转换（在详情）。

```text
+-- FilterBar（5 常显 + 3 advanced） --------------------------------------------+
| SKU编码／名称       | 货主           | 库位          | 品质         | 效期等级        | [查询][重置][展开] ||
| [SKU编码或名称…]    | [全部货主  v]  | [库位编码或名称] | [全部    v] | [全部       v] |                   ||
| 展开后：批次号 [批次号] | 容器号 [容器号，模糊匹配] | 可分配条件 [全部 v]                        ||
+------------------------------------------------------------------------------+
| 商品                 | 货主          | 库位           | 容器号   | 批次        | 品质  | 效期等级 | 库存数量 | 已分配 | 可分配 |
| CABLE-01 数据线      | C10028 Anker… | A-01-01 拣货   | -        | -           | 良品  | -        | 30       | 3      | 27     |
| LOT-DEMO-01 批次商品 | C10028 Anker… | A-01-02 拣货   | -        | LOT-202610  | 良品  | 正常     | 8        | 0      | 8      |
| CABLE-01 数据线      | C10028 Anker… | STAGE-IN-01 收货暂存 | -  | -           | 良品  | -        | 5        | 0      | 0 [不参与分配] |
+------------------------------------------------------------------------------+
```

**补充说明**：

- 库位列显示「库位编码 + 用途」；用途不单设筛选。
- 非批次商品批次显示 `-`，数量仍按本库位统计，不改记到 SKU 层。
- 「已分配」「可分配」表头带说明；可分配只算普通出库资格，暂存、过期、盘点中、暂停分配或其他出库指定显示 0 并标原因。
- 行点击商品打开批次详情；品质转换入口只在详情页头，列表不设行内转换按钮。

## SN台账视角

- **用途**：按货主＋SKU＋SN 查单件在库状态、当前仓库与最后变动。
- **关键要素**：5 个常显筛选；不展示位置；已出库/已盘亏行灰显。

```text
+-- FilterBar（5 常显，无展开） ------------------------------------------------+
| SN                    | SKU编码／名称      | 货主           | 在库状态       | 最后变动时间          | [查询][重置] ||
| [完整 SN            ] | [SKU编码或名称…]   | [全部货主   v] | [全部      v]  | [最后变动日期       ] |              ||
+------------------------------------------------------------------------------+
| SN              | 商品                | 货主          | 在库状态 | 最后变动时间         |
| SN00000111      | SN-DEMO-01 SN演示…  | C10028 Anker… | 在库     | 2026-10-20 10:30     |
| SN00000112      | SN-DEMO-01 SN演示…  | C10028 Anker… | 已出库   | 2026-10-18 16:00     |
+------------------------------------------------------------------------------+
```

**补充说明**：

- SN 按完整值精确匹配，不做模糊；不设当前库位筛选。
- 不展示库位、批次、由位置推断的品质；详情只展示实际采集记录。
- 已出库、已盘亏行灰显，仍保留用于追溯。

## SKU库存详情

- **用途**：看当前品质行的数量构成、库位分布、订单预占来源、已分配来源与最近流水。
- **关键要素**：`DetailSheet` 880px；标题带 SKU 与条件标签；基本信息 3 列；数量 3 列；5 个页签。

```text
+-- DetailSheet 880px -----------------------------------------------------------+
| SKU库存 · CABLE-01 [暂停分配]                                            [×]   |
| +-- Section 基本信息 ---------------------------------------------------------+ |
| | 仓库 US-LA-01 | 货主 C10028 | 商品 CABLE-01 | 品质 良品 | 待核对来源 … | 关联盘点单 - ||
| +-- Section 数量 -------------------------------------------------------------+ |
| | 库存数量 30 | 订单预占 3 | 可用数量 27                                    | |
| +-- DetailTabs ---------------------------------------------------------------+ |
| | (库位分布 3) (订单预占 1) (已分配来源 2) (SN 4) (最近流水 10)                | |
| | 库位 | 批次 | 品质 | 效期等级 | 库存数量 | 已分配 | 可分配              | |
| +------------------------------------------------------------------------------+ |
+--------------------------------------------------------------------------------+
```

**补充说明**：

- 「查看流水」在基本信息区右上，跳库存流水并带入货主、SKU、品质。
- 库位分布、已分配、流水按当前品质过滤；订单预占只对良品行展示，不良品行页签为空。
- SN 页签按本仓、本货主、本 SKU 列在库 SN，并提示「数量分布不能确定单件位置或品质」；无 SN 时隐藏页签。
- 最近流水最多 10 条，完整流水走「查看流水」。

## 批次库存详情

- **用途**：看本库位本批次的余额、效期、作业资格与追溯；符合条件时发起品质转换。
- **关键要素**：标题「批次库存 · SKU @ 库位」；5 个字段分组；页头「查看流水」「品质转换」；转换成功后顶部提示两条流水。

```text
+-- DetailSheet 880px -----------------------------------------------------------+
| 批次库存 · CABLE-01 @ B-03-01 [盘点中]                     [查看流水] [品质转换] |
| +-- Section 身份与位置 -------------------------------------------------------+ |
| | 仓库 | 货主 | 商品 | 库位（含用途） | 容器号 | 品质                         | |
| +-- Section 批次效期 ---------------------------------------------------------+ |
| | 批次号 | 生产日期 | 有效期至 | 效期等级                                    | |
| +-- Section 数量 -------------------------------------------------------------+ |
| | 库存数量 | 已分配 | 可分配 [不参与分配]                                    | |
| +-- Section 作业状态 ---------------------------------------------------------+ |
| | 可分配资格 | 盘点状态 | 作业提示 | 过期转换（已转不良／待补做：原因）      | |
| +-- Section 追溯 -------------------------------------------------------------+ |
| | 库存明细号 | 最后库存流水号 | 最后变动时间 | 创建时间                      | |
| +-- Section SN（有则显示） ---------------------------------------------------+ |
| | SN00000111  SN00000112 …                                                     | |
+--------------------------------------------------------------------------------+
```

**补充说明**：

- 「品质转换」只在可转换数量 > 0（正常品、存储/拣货库位、未盘点、未被分配且 SKU 可用足够）时显示；否则不显示。
- 转换成功后顶部显示「本次转换已记录两条独立流水」，每条带品质标签、带符号数量与流水号链接。
- 自动过期转换只展示结果（已转不良）或待补做原因（盘点中／仍有已分配／SKU可用不足／待系统重试），不设执行按钮。
- 非批次商品批次号显示 `-`；数量仍按本库位展示。

## SN台账详情

- **用途**：看单件身份、在库状态、最后来源与逐笔实际采集轨迹。
- **关键要素**：标题带 SN 与在库状态；当前状态、来源信息两个分组；轨迹表按时间正序。

```text
+-- DetailSheet 880px -----------------------------------------------------------+
| SN台账 · SN00000111 [在库]                                               [×]   |
| +-- Section 当前状态 ---------------------------------------------------------+ |
| | 商品 SN-DEMO-01 | 货主 C10028 | 仓库 US-LA-01                              | |
| +-- Section 来源信息 ---------------------------------------------------------+ |
| | 最后来源单据 OB-…-0019 | 最后库存流水号 LOG-…-0123 | 最后变动时间 …          | |
| +-- Section 轨迹（贴边表格） -------------------------------------------------+ |
| | 发生时间 | 流水类型 | 品质 | 来源单据 | 流水号                            | |
+--------------------------------------------------------------------------------+
```

**补充说明**：

- 不展示当前库位、批次位置或推断品质。
- 轨迹一笔记一行，不合并移库流水，不出现源／目标库位联动面板。
- 已出库、已盘亏仍保留最后仓库用于追溯。

## 品质转换 Dialog

- **入口**：批次库存详情页头「品质转换」；无独立路由。
- **用途**：在原库位、原批次把正常品转为不良品。
- **关键要素**：只读上下文 + 转换数量 + SN（SN 商品）+ 货主通知结果 + 原因说明 + 依据说明 + 变更预览 + 确认/取消。

```text
+--------------------------------------------------------------+
| 品质转换                                                 [×] |
|--------------------------------------------------------------|
| 在原库位、原批次把正常品转为不良品，不搬实物                 |
| 仓库 US-LA-01 | 货主 C10028 | 商品 CABLE-01 | 库位 B-03-01   |
| 批次号 LOT-202610 | 品质 正常品 | 库存数量 10 | 已分配 3      |
| 可转换 7 | 原因 在库受损                                     |
| 转换数量* [7        ]                                        |
| SN 清单（SN 商品）[ 勾选区 ]                                  |
| 货主通知结果* [已通知 v]                                     |
| 原因说明* [                                        ]         |
| 依据说明* [                                        ]         |
| 确认后：正常品 10→3，不良品 0→7，实际总量不变                |
| SKU：预占 0→0，可用 10→3                                     |
|--------------------------------------------------------------|
|                                      [取消] [确认转换]       |
+--------------------------------------------------------------+
```

- 字段、校验提示、失败分支与自动过期展示详见[《品质转换页面骨架》](../品质转换/品质转换页面骨架.md)；本页只保留入口与承载位置。

## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 库存查询（SKU库存 / 批次库存 / SN台账） |
| 路由 | `/wms/inventory/stock`；视角 `?view=sku｜balance｜serial`，默认 `sku`；详情 `?skuId=`、`?inventoryId=`、`?serialId=` |
| 入口 | 库存管理 → 库存查询；详情由列表行或商品/SN 点击打开 |
| 目标 | 在本仓范围内查询三种库存粒度、追溯数量来源、在批次详情发起品质转换 |
| 适用视角 | SKU库存（仓库＋货主＋SKU＋品质）、批次库存（＋批次＋库位）、SN台账（货主＋SKU＋SN，仓库为属性） |
| 版式 | `PageContainer fill` + 双 `Panel`；视角页签 + 口径提示行 + `FilterBar columns={6}`；详情为右侧 `DetailSheet` 880px |
| 页面边界 | 不提供新增、改数、占用/释放、冻结/解冻、分配状态维护、独立品质转换页、SN 库位推断、真实导出文件 |

> **本期边界**
> - 仓库由顶栏限定；三视角均无仓库列与仓库筛选，不汇总跨仓可用量。
> - 品质转换只在批次库存详情发起；字段、校验、反馈见[《品质转换前端Demo版PRD》](../品质转换/品质转换前端Demo版PRD.md)。本页只写入口与承载。
> - 库存流水完整列表见[《库存流水前端Demo版PRD》](../库存流水/库存流水前端Demo版PRD.md)；本页只展示最近 10 条与「查看流水」入口。
> - 一期不校验用户权限与角色；详情直达只校验记录是否存在且属于当前仓库。

## 2. 查询区

`FilterBar columns={6}`；`draft` / `filters` 双 state；点「查询」写入 `filters` 并回第一页；「重置」清空两者。筛选与 `view` 写入 URL，刷新、分享和详情返回均可恢复。切换视角保留 SKU 关键词与货主，清除上一视角专属条件。

### 2.1 SKU库存（5 常显，无 advanced）

| 字段 | 位置 | 控件 | 匹配 | placeholder / 选项 |
| --- | --- | --- | --- | --- |
| SKU编码／名称 | 常显第 1 列 | `Input` | 编码或名称包含；空格分词，任一分词命中 | `inventory.stock.skuKeywordPlaceholder`（SKU编码或名称，空格分隔多个） |
| 货主 | 常显第 2 列 | `OptionSelect allOption` | 精确 | `common.selectPlaceholder`；「全部」=`FILTER_ALL` |
| 品质 | 常显第 3 列 | `OptionSelect allOption` | 精确 | `common.selectPlaceholder`；良品／不良品 |
| 数量条件 | 常显第 4 列 | `OptionSelect allOption` | 精确 | `common.selectPlaceholder`；有库存／零库存／零可用 |
| 最后变动时间 | 常显第 5 列 | `DateRangePickerField` | 日期范围（含起止日） | `inventory.stock.updatedRangePlaceholder`（最后变动日期） |

- 数量条件口径：有库存＝库存数量 > 0；零库存＝库存数量 = 0；零可用＝可用数量 = 0。不设负库存、分配状态筛选。
- 不良品行订单预占与可用数量恒为 0；「零可用」会同时匹配不良品行，属预期。

### 2.4 查询行为

- 空条件查询返回当前仓库全部记录；查询/重置/切换视角/切换仓库后回第一页。
- 视角页签计数按**当前视角筛选后**的行数计算；不是跨视角总数。
- 详情参数与筛选并存：打开详情追加 `skuId｜inventoryId｜serialId`，关闭详情只移除该参数，保留筛选。
- 切换视角时 URL 的 `view` 更新；保留 SKU 关键词、货主，清除品质、数量条件、库位、效期、批次、容器、可分配、SN、在库状态与时间范围。

## 4. 视角页签（StatusTabs）

| key | 中文 | 计数口径 | 是否业务状态 |
| --- | --- | --- | --- |
| `sku` | SKU库存 | 当前筛选后的 SKU 库存行数（品质分行） | 否，视角切换 |
| `balance` | 批次库存 | 当前筛选后的批次库存行数（库位＋批次＋品质） | 否，视角切换 |
| `serial` | SN台账 | 当前筛选后的 SN 行数 | 否，视角切换 |

- 页签顺序固定为 SKU库存、批次库存、SN台账；URL `?view=`，默认 `sku`。
- 不是业务状态页签，不出现「全部」；不使用 `?status=`。
- 页签下方固定一行口径提示：`SKU 看可用数量，批次看可分配；订单预占不等于已分配。` 同一行右侧放「口径说明」Popover，覆盖五项口径（见 §8.3）。

## 5. 列表表格

### 5.1 视角说明

| 视角 | 一行代表什么 |
| --- | --- |
| SKU库存 | 仓库＋货主＋SKU＋品质；良品、不良品各一行 |
| 批次库存 | 仓库＋货主＋SKU＋品质＋批次＋库位＋容器；有容器号时按容器分行，散件容器为空；非批次商品批次为空，仍按库位一行 |
| SN台账 | 货主＋SKU＋SN；当前仓库为属性，不按库位分组 |

三个视角都不在列表展开容器内容、其他品质或其他库位。

### 5.2 SKU库存列定义

`createDataColumns<SkuStockRow>()`，`selectable={false}`，无操作列；行点击打开详情，商品也可点。

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式/示例 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 商品 | `CodeName` + 条件标签 | 左 | 否 | `-` | `CABLE-01 数据线 [暂停分配]` | `pin: 'left'`；`enableHiding: false`；点击开 SKU 详情 |
| 2 | 货主 | `CodeName` | 左 | 否 | `-` | `C10028 Anker 示例` | 名称截断 |
| 3 | 品质 | `TagLabel` | 左 | 否 | `-` | 良品／不良品 | 良品 green、不良品 red |
| 4 | 库存数量 | `Num` | 右 | 是 | `0` | `30` | 当前品质行实际 |
| 5 | 订单预占 | `Num` | 右 | 是 | `0` | `3` | 只对良品有意义；不良品恒 0 |
| 6 | 可用数量 | `Num`；异常为负时标签 + 红色 | 右 | 是 | `0` | `27` | 良品＝库存数量－订单预占；不良品恒 0 |

- 表格工具区左侧显示合计条：`合计（当前筛选） SKU 数 8 · 库存合计 126（正常 110，不良 16）`。SKU 数按仓库＋货主＋SKU 去重，品质分行不重复计；库存合计为当前筛选行库存数量之和。
- 合计条不是独立统计卡，不占详情空间。

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式/示例 | 说明 |

- 无勾选、无批量操作、无合计导出范围选择。
- 空态：三视角统一显示「当前仓库和筛选条件下没有库存」（`inventory.stock.empty`）；不按视角改写文案。
- 行点击是快捷方式，商品/SKU/SN 必须可单独点击，键盘 Enter/Space 可打开。

## 6. 行操作矩阵

列表没有操作列与行内业务按钮。可执行入口如下：

| 操作 | 位置 | SKU库存 | 批次库存 | SN台账 | 说明 |
| --- | --- | :---: | :---: | :---: | --- |
| 点行/商品打开详情 | 列表 | ✅ | ✅ | ✅（点 SN） | 行点击是快捷方式，编号可单独点 |
| 导出当前视角 | 页头 | ✅ | ✅ | ✅ | Mock toast |
| 查看流水 | SKU 详情、批次详情页头 | ✅ | ✅ | ❌ | 跳库存流水并带条件 |
| 品质转换 | 批次详情页头 | ❌ | 条件 ✅ | ❌ | 批次行可转换数量 > 0 时显示 |
| 点 SN 流水号 | SN 详情轨迹 | ❌ | ❌ | ✅ | 跳库存流水详情 |
| 编辑/删除/冻结/解冻/释放 | — | ❌ | ❌ | ❌ | 不提供 |

- 条件不满足的入口不渲染，不用 disabled 占位。
- 详情内没有二次确认操作；品质转换的确认见[《品质转换前端Demo版PRD》](../品质转换/品质转换前端Demo版PRD.md) §8。

## 7. 详情页/抽屉

三类详情均为 `DetailSheet` 880px，标题用 `DetailTitle`，关闭只移除 URL 参数；记录不存在或不属于当前仓库时显示「无权限或记录不存在」，不展示缓存。

### 7.1 SKU库存详情（`?skuId=`）

标题：`SKU库存 · {skuCode}`，商品后带 `盘点中`／`暂停分配` 标签。正文：

| 区域 | 字段 |
| --- | --- |
| 基本信息（`Descriptions columns={3}`） | 仓库（`CodeName`）、货主（`CodeName`）、商品（`CodeName`）、品质（`TagLabel`）、待核对来源（多行，可多个单号链接；空 `-`）、关联盘点单（链接；空 `-`） |
| 数量（`Descriptions columns={3}`） | 库存数量、订单预占、可用数量（异常为负时标红 + 「正常品不足」） |
| 页头右上 | `[查看流水]`（outline，sm）→ `/wms/inventory/logs?customerId=&sku=&quality=` |

页签（`DetailTabs`，不带 URL param、不嵌套 Sheet）：

| 页签 | 条数 | 列定义 | 空态 |
| --- | --- | --- | --- |
| 库位分布 | 当前品质行的库位行数 | 库位（含用途）、批次、品质、效期等级、库存数量、已分配、可分配 | 当前仓库没有该 SKU 的库位库存 |
| 订单预占 | 未结案普通出库单数 | 出库单号（链接）、业务类型、出库单状态、预占数量 | 没有未结案出库单占用 |
| 已分配来源 | 拣货任务行 + 其他出库指定行 | 分配来源（普通出库拣货分配／其他出库指定）、作业（任务号或出库单号链接）、库位、批次、已分配数量 | 没有未拣的分配或指定 |
| SN | 本仓本货主本 SKU 在库 SN 数 | SN、在库状态 | 当前仓库没有在库 SN |
| 最近流水 | 最多 10 条 | 发生时间、流水号（链接）、流水类型、数量变化（口径 + 前→后 + 带符号变化量）、来源单据 | 暂无流水 |

- 订单预占页签只对良品行展示；不良品行页签条数为 0 并显示空态。
- SN 页签在条数为 0 时隐藏；有数据时顶部提示「本仓该货主、SKU 的在库 SN；数量库位分布不能确定每个 SN 的位置或品质」。
- 最近流水按当前品质过滤，只读，不提供「查看全部」以外的操作；「查看流水」保留品质条件。
- 库位分布中的行不可再点开，避免抽屉套抽屉。
- 标题未含货主；跨货主同 SKU 时靠基本信息区分（见 §13 差异）。

**详情子表列级通用规则**：编码/单号/文本左对齐，数量右对齐；日期时间 `yyyy-MM-dd HH:mm`；空值 `—`；库位分布按库位编码升序，订单预占按出库单创建时间倒序，已分配来源按任务号/出库单号升序，SN 按 SN 升序，最近流水按发生时间倒序。各页签只读，不设勾选、批量操作或列设置。

### 7.2 批次库存详情（`?inventoryId=`）

标题：`批次库存 · {skuCode} @ {locationCode}`，带 `盘点中` 标签（如适用）。正文按分组 `Section`：

| 分组 | 字段 |
| --- | --- |
| 身份与位置 | 仓库、货主、商品、库位（编码 + 用途）、容器号（有档案时链接，否则 `-`）、品质 |
| 批次效期 | 批次号（非批次 `-`）、生产日期（`-`）、有效期至（`-`）、效期等级（未启用 `-`） |
| 数量 | 库存数量、已分配、可分配（暂存良品带 `不参与分配`） |
| 作业状态 | 可分配资格（是／否）、盘点状态（`盘点中` 标签 + 盘点单链接，否则 `-`）、作业提示（`暂停分配` 标签，否则 `-`）、过期转换（`已转不良`／`待补做：原因`／`-`） |
| 追溯 | 库存明细号、最后库存流水号（链接）、最后变动时间、创建时间 |
| SN（有则显示） | 本库存行已登记 SN，逗号/换行平铺，只显示条数与编码，不推断位置 |

页头右上：

| 按钮 | 显示条件 | 行为 |
| --- | --- | --- |
| 查看流水 | 始终 | 跳 `/wms/inventory/logs?customerId=&sku=&quality=&location=&batch=` |
| 品质转换 | 可转换数量 > 0 | 打开品质转换 Dialog；字段与校验见品质转换 Demo §8 |

- 转换成功后在抽屉顶部显示 `Alert`：「本次转换已记录两条独立流水」，并列出两条流水号（链接）、品质标签与带符号变化量。
- 自动过期转换只展示：不良品且过期 → 「已转不良」；正常品过期但有待转数量 → 「待补做：盘点中／仍有已分配／SKU可用不足／待系统重试」。不显示执行按钮。
- 批次行不存在时整抽屉显示空态，不残留旧数据。

### 7.3 SN台账详情（`?serialId=`）

标题：`SN台账 · {serialNo}`，带在库状态。

| 区域 | 字段 |
| --- | --- |
| 当前状态（3 列） | 商品、货主、仓库（在库为当前仓；已出库/已盘亏为最后仓） |
| 来源信息（3 列） | 最后来源单据（可点则链接，否则纯文本）、最后库存流水号（链接）、最后变动时间 |
| 轨迹（贴边表格） | 发生时间、流水类型、品质、来源单据、流水号（链接） |

- 轨迹按业务发生时间正序，一笔记一行；不合并移库流水，不出现源／目标库位字段或联动面板。
- 不展示当前库位、批次位置或由位置推断的品质。
- 空态：暂无涉及该 SN 的流水。
- 已出库、已盘亏仍展示最后仓库用于追溯，状态在标题与当前状态区展示一次。

### 7.4 详情直达与关闭

- 详情 ID 不在当前视角数据中、不属于当前仓或已变化：显示「无权限或记录不存在」，提供返回列表。
- 关闭抽屉只移除 `skuId`／`inventoryId`／`serialId`，保留 `view` 与筛选。
- 抽屉内页签不写 URL；刷新页面回到第一个页签。

## 10. 派生/计算

只列页面用到的公式，业务规则见[《库存查询主PRD》](库存查询主PRD.md) §6～§7。

| 名称 | 公式 | 用于 |
| --- | --- | --- |
| SKU库存行标识 | `仓库::货主::SKU::品质` | 行 key |
| 库存数量（SKU行） | 当前品质的实际合计；良品＝所有良品批次库位实际之和，不良品同理 | SKU 列表 |
| 订单预占（SKU行） | 未结案普通出库单的有效预占合计；不良品行为 0 | SKU 列表、详情 |
| 可用数量（SKU行） | 良品：库存数量－订单预占；不良品：0 | SKU 列表、详情 |
| SKU 数 | 按 `仓库＋货主＋SKU` 去重计数 | 合计条 |
| 实际合计 | 当前筛选行库存数量之和；正常、不良分别求和 | 合计条 |
| 已分配（批次行） | 库存行的 `allocatedQty`（普通出库未拣分配 + 其他出库未拣指定） | 批次列表、详情 |
| 可分配（批次行） | 资格成立时 `库存数量－已分配`，否则 0 | 批次列表、详情、筛选 |
| 普通出库可分配资格 | 良品 且 库位用途为存储/拣货 且 未过期 且 未盘点 且 未暂停分配 | 可分配列、标签 |
| 暂存良品 | 良品 且 库位用途为收货暂存/出库暂存 | `不参与分配` 标签 |
| 可转换数量 | 良品且未盘点时 `max(0, min(库存数量－已分配, SKU可用数量))`；否则 0 | 批次详情按钮、品质转换上限 |
| 效期等级 | 按商品效期阈值与仓库当地日期计算：过期优先于临期；未启用为空 | 效期列、筛选、品质转换标记 |
| SN 行 | 货主＋SKU＋SN；当前仓库为属性；在库状态来自 SN 台账 | SN 列表 |
| 详情页签计数 | 当前对象的子记录行数 | 页签条数 |

- 分配不写库存流水；订单预占不是已分配；不得把暂存、过期、盘点中、暂停分配的库存算进可分配。
- 不新增「分配状态」字段或枚举；标签由盘点单、暂停分配来源派生。

# 库存查询主PRD

> 定义SKU库存、批次库存和SN台账的查询。数量规则见[库存模块宏观系统架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)，字段见[库存字段清单](../../../字段清单合集/04-库存与库内/README.md)，布局与交互见同目录页面骨架、前端Demo版PRD。

## 一、范围与记录粒度

| 查询 | 一行代表什么 | 用途 |
| --- | --- | --- |
| SKU库存 | 仓库＋货主＋SKU＋品质 | 按良品、不良品分行看库存数量、订单预占和可用数量 |
| 批次库存 | 仓库＋货主＋SKU＋品质＋批次＋库位 | 查某批货放在哪个库位、数量和分配情况；未启用批次时批次为空 |
| SN台账 | 货主＋SKU＋SN，当前仓库为属性 | 查单件在库状态、所在仓库及已实际采集的业务记录；不要求登记库位 |

容器内容在关联详情查看，不在数量查询中重复计量。顶栏当前仓库限定数据范围，不汇总跨仓可用量；按项目公共能力控制访问。

## 二、数量与标签

1. SKU库存良品、不良品分行。良品行：库存数量＝良品实际，订单预占＝未结案普通出库单的有效预占合计，可用数量＝良品实际－订单预占。不良品行：库存数量＝不良品实际，普通订单预占和可用数量均为0。不良品不可用，不计入订单预占。
2. 全仓总库存＝良品实际＋不良品实际。不能把含不良品的总库存写成订单预占＋可用数量。页面只保留“订单预占”，不并列“订单预占”“预占”两列。
3. 批次库存展示库存数量、已分配、可分配。可分配仅包括存储／拣货库位的未过期良品，且SKU未暂停分配、未盘点；不符合资格显示0并以标签提示原因。其他出库的不良品指定沿用原业务规则，不与可分配混算。列名简称“可分配”，表头说明保留“普通出库”资格口径。
4. 收发暂存良品仍计入SKU可用数量，但可分配为0；上架／返库完成后才可分配。
5. 实际、订单预占、可用数量和已分配等数量均不得为负。会造成任一库存负数的提交整次阻断，提示SKU及可用数量上限；不得截为0、自动释放订单预占或自动改订单。盘点实录结果可保存，确认失败时账、流水和完成状态不变。
6. 不设独立“分配状态”字段、枚举、筛选或维护入口。在商品旁根据现有盘点单／暂停分配依据派生“盘点中”“暂停分配”标签或图标；正常记录不显示“正常”。提示说明原因和关联业务记录。标签不增加预占或已分配，不改变品质。
7. 临期／过期是效期等级，与良品／不良品分开展示。合计条按筛选结果显示库存合计、良品／不良品数量；SKU数按仓库＋货主＋SKU去重，品质分行不重复计SKU。

页面用下表统一口径，SKU 列头和批次列头可按此简称，但不得互称：

| 名称 | 记在哪 | 公式／口径 | 回答的问题 |
| --- | --- | --- | --- |
| 库存数量 | SKU 行：当前品质实际；批次行：本库位、本批次实际 | 按当前行统计；非批次商品批次为空，仍按本库位统计 | 账上有多少 |
| 订单预占 | SKU 良品层 | 未结案普通出库单的有效预占合计 | 已被订单占多少 |
| 可用数量 | SKU 良品层 | 良品实际－订单预占 | 还能接多少单 |
| 已分配 | 批次库位层 | 已排给拣货任务或其他出库指定、尚未拣走的数量 | 这个库位有多少不能再分 |
| 可分配 | 批次库位层 | 实际－已分配，再按普通出库资格过滤 | 这个库位还能排多少拣货 |

页面须提供“口径说明”入口，至少覆盖上表五项，并用一句话提示“SKU 看可用数量，批次看可分配；订单预占不等于已分配”。批次列头的“已分配”“可分配”须带说明：已分配的货仍在库位，只是不能再分配；可分配只算普通出库、不含其他出库指定和暂存等不合格库存。

## 三、筛选、详情与追溯

| 查询 | 筛选 | 详情 |
| --- | --- | --- |
| SKU库存 | SKU编码／名称、货主、品质、数量条件、最后变动时间 | 当前品质数量、对应批次库位分布、良品订单预占来源、已分配来源、相关SN及流水（SN按本仓货主＋SKU查询，不按品质推断单件归属） |
| 批次库存 | SKU、货主、库位、批次、品质、效期等级、可分配条件 | 当前余额维度、数量、标签、相关业务记录；符合条件时发起品质转换 |
| SN台账 | SN、SKU、货主、在库状态、最后变动时间 | 当前／最后仓库、在库状态、实际采集的收发与确认记录；无当前库位筛选 |

SN可以只记录“本仓在库”，不能从SKU库位分布推断具体SN位置。SN身份不因上架、移库变化。仓内数量盘点不自动把某个SN判为丢失；只有逐件核实的SN差异才能改变其在库状态。轨迹逐条显示实际记录，不把两条移库流水合成源位→目标位，不补造没有SN采集依据的节点。

库存查询不提供手工新增、直接改数、占用／释放、冻结／解冻入口。标签的解除由原业务处理或盘点结果驱动，取消盘点不自动清除未核实差异的暂停分配标识。

## 四、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| 良品8、不良2、订单预占3 | 同SKU两行：良品8／预占3／可用5，不良2／预占0／可用0；SKU数1、库存合计10 |
| 同一批次分布两个库位 | 批次库存分为两行；品质不同继续分行 |
| 收货暂存良品5，存储良品3，存储已分配2 | SKU可用数量8；暂存可分配0，存储可分配1。页面同时能解释“可用8”和“可分配1”不是同一个数 |
| 不良品、过期品、盘点中或暂停分配库存筛选“可分配大于0” | 不返回不具备普通出库资格的行 |
| 非批次商品有库位实际、批次为空 | 批次库存仍按本库位显示库存数量、已分配、可分配；批次列显示“—”，不得改记到SKU层 |
| 良品4、订单预占4，确认盘亏1或转不良1 | 阻断；不新增流水、不改订单预占、不完成盘点／转换 |
| SKU正在盘点或暂停分配 | 商品旁显示相应标签，无“分配状态”列与筛选 |
| SN已收货，上架未登记SN库位 | 仍查到该SN在本仓在库，不显示推测库位；上架可按数量提交 |
| 查看移库流水 | 源库位减、目标库位加各自一条；每条只有自己的库位与前后数量，无源／目标库位字段或联动面板 |

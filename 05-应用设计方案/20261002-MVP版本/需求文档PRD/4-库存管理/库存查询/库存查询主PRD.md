# 库存查询主PRD

> 定义SKU库存、库存明细和SN库存的查询、追溯及品质转换入口。数量与对象依据见[库存模块宏观系统架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)第二、三节；字段分别见[SKU库存](../../../字段清单合集/04-库存与库内/SKU%20库存/SKU%20库存（详细稿）.tsv)、[库存明细](../../../字段清单合集/04-库存与库内/库存明细/库存明细（详细稿）.tsv)和[SN库存](../../../字段清单合集/04-库存与库内/SN%20库存/SN%20库存（详细稿）.tsv)。页面见[库存查询页面骨架](库存查询页面骨架.md)和[库存查询前端Demo版PRD](库存查询前端Demo版PRD.md)。

## 一、目标与范围

管理人员需要从SKU汇总追到具体库位、批次、品质和SN，判断“本仓本货主还有多少、其中多少可接单、多少已经分给作业、实物在哪里”。本期提供三个查询视角，不提供新增、编辑、导入或直接改库存。

| 视角 | 一行是什么 | 主要用途 |
| --- | --- | --- |
| SKU库存 | 仓库＋货主＋SKU | 看正常品、不良品、订单占用及实际／预占／可用；识别可用为负、待核对、盘点中 |
| 库存明细 | 仓库＋货主＋SKU＋库位＋批次＋品质 | 看位置、效期、实际、已分配和可分配；进入品质转换 |
| SN库存 | 货主＋SKU＋SN | 查单件当前仓库、库位、批次、品质、在库状态与轨迹 |

四仓分别查询，不合并跨仓可用量。用户只能查看有仓库授权的数据；有某仓权限即可查看该仓全部货主库存，一期不做货主级数据授权。

## 二、数量与展示规则

1. SKU库存：实际＝正常品实际＋不良品实际；预占＝订单占用＋不良品实际；可用＝正常品实际－订单占用。
2. 库存明细：可分配＝实际－已分配。普通出库只使用存储、拣货库位上的正常品可分配数量；页面不得把可用与可分配混成一列。
3. 收货暂存、出库暂存库位的正常品计入SKU可用，但库存明细上标明“不参与分配”。
4. 可用为负时保留真实负数，醒目标记“订单占用的正常品不足”，不得截为0。
5. 临期是效期等级，不是品质；临期正常品仍可出库。过期且已转不良的记录同时展示“过期”和“不良品”。
6. 分配状态为“待核对”时展示原因来源和关联盘点，不把它写成库存锁定或第三种品质。

## 三、查询与追溯

| 视角 | 必备筛选 | 行级查看 |
| --- | --- | --- |
| SKU库存 | SKU编码／名称、货主、分配状态、实际或可用是否为0、可用是否为负 | 打开SKU库存详情，查看库位分布、占用来源、最近流水和SN |
| 库存明细 | SKU、库位、货主、批次、品质、效期等级、可分配是否为0 | 打开库存明细详情；符合条件时发起品质转换 |
| SN库存 | SN、SKU、货主、在库状态、仓库、库位 | 打开SN详情及轨迹；从轨迹跳来源单据或库存流水 |

- 顶栏仓库为默认数据范围；SN可跨四仓识别身份，当前页仍只展示用户有权限的仓库数据。查询另仓位置时须切换到有权限的仓库。
- SKU库存详情至少展示库位分布、相关出库订单占用、当前已分配来源、待核对来源、最近库存流水。占用与分配都只读，并跳原业务记录。
- SN轨迹按业务发生时间正序展示收货、上架、移库、拣货、返库、盘点、品质转换和确认出库中的实际发生节点；不补造未发生节点。

## 四、允许操作

| 条件 | 操作 | 结果 |
| --- | --- | --- |
| 任一库存记录 | 查看流水 | 带仓库、货主、SKU及可用的库位／批次／SN条件进入库存流水 |
| 库存明细为正常品、实际－已分配大于0、非盘点中 | 品质转换 | 打开品质转换确认；规则见[品质转换主PRD](../品质转换/品质转换主PRD.md) |
| SKU待核对 | 查看来源／关联盘点 | 跳原业务依据或盘点单，不在库存查询页手工解除 |
| SKU盘点中 | 查看盘点单 | 跳盘点详情；库存查询只展示冻结原因 |

库存查询不提供手工冻结、解冻、占用、释放、移库、改数量或改货主入口。移库通过PDA作业完成，盘点差异由盘点单确认。

## 五、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| 正常8、不良2、订单占用3 | SKU行显示实际10、预占5、可用5；明细仍按库位和品质分行 |
| 收货暂存正常5，存储正常3，其中已分配2 | SKU可用包含8件正常品；收货暂存行标明不参与分配；存储行可分配1 |
| 盘点调减导致正常4、订单占用5 | 可用显示－1并告警；不修改订单占用，不允许新接单占用 |
| 搜SN-A001 | 展示当前仓库、库位、批次、品质和在库状态；轨迹能跳实际来源记录 |
| 未授权仓库用户切换仓库 | 不显示该仓库存；直接访问记录显示无权限，而非泄露记录详情 |
| 待核对SKU查看详情 | 展示原差异依据及关联盘点；没有手工解除按钮 |

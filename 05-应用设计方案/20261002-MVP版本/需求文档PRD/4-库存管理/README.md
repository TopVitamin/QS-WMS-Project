## 共用口径

- SKU库存按仓库＋货主＋SKU唯一，维护正常品实际、不良品实际、订单占用，并计算实际、预占、可用。
- 库存明细按仓库＋货主＋SKU＋库位＋批次＋品质唯一，维护实际、已分配、可分配。库存明细不按SN拆行。
- 收货暂存、出库暂存库位上的正常品计入可用，但不能参与分配；普通出库只从存储、拣货库位上的正常品可分配数量中分配。
- 发现账实不符时立即按仓库＋货主＋SKU标记“待核对”；它只暂停新分配、组波、补拣和其他出库指定，不改变三量或接单规则。主管确认盘点完成后解除；等待任务收尾或盘点取消都不解除未核实标记。
- 移库不设待执行任务，PDA一次提交可含一行或多行，全部行一次生效或整次失败；品质转换不设单据；盘点单状态为盘点中、已完成、已取消。
- 暂存库位不移库、不盘点，也不做过期自动转换；暂存期间丢失按应上架或应返库量提交后，通过盘点调减。

本目录是文档设计交付，不表示页面、PDA、接口或并发行为已经实现或通过演示验收。页面和Demo PRD中的路由、组件与Mock为实现要求，业务规则以各主PRD、需求分析和业务设计为准。

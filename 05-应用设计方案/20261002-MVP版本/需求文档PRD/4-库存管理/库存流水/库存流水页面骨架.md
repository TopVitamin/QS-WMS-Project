## 页面与弹窗清单

| 页面／容器 | 路由 | 入口 | 用途 |
| --- | --- | --- | --- |
| 库存流水列表 | `/wms/inventory/logs` | 左侧菜单「库存流水」；库存查询的 SKU、批次库存、SN 详情跳转 | 按仓库、时间、类型和余额维度查询已生效流水 |
| 流水详情抽屉 | 同页 `?log={流水id}` | 列表点流水号或点行；库存查询、移库详情、盘点详情带 `log` 参数打开 | 查看本条数量口径、余额维度、来源与操作留痕 |
| 口径说明浮层 | 同页，列表页头「口径说明」 | 页头按钮 | 解释库存数量、订单预占、可用数量、已分配、可分配五个量的关系 |

本期不提供的入口：

| 不提供 | 原因 |
| --- | --- |
| 新建、编辑、删除、冲销流水 | 流水是已生效事实记录，不可人工改数；误操作恢复走原业务规则 |
| 行勾选、批量操作、行内菜单 | 本页无写操作，也没有可批量办理的业务 |
| 成对流水跳转、源／目标库位对照、联动影响面板 | 一减一加是两条独立流水，各自只描述自己的余额维度 |
| 流水状态页签、状态筛选 | 一期只保存「已生效」流水，无第二状态 |
| 跨仓查询 | 顶栏当前仓库限定数据范围，其他仓记录不展示 |

## 文档说明与绘制约定

- 本文只回答「画在哪、叫什么」。记账规则见[库存流水主PRD](库存流水主PRD.md)，列级规格、失败文案、Mock 与验收见[库存流水前端Demo版PRD](库存流水前端Demo版PRD.md)，字段以[详细稿](../../../字段清单合集/04-库存与库内/库存流水/库存流水（详细稿）.tsv)为准。
- 通用布局、栅格与占位规则见[需求文档 PRD／AGENTS.md](../../AGENTS.md)，本文不重复。
- 本对象特殊约定：
  - 流水没有状态机、没有行操作、没有勾选列。列表只负责查到并打开详情。
  - 「数量变化」列固定两行：第一行数量口径，第二行「变化前 → 变化后（增减）」。不允许把两种口径合并到一格。
  - 详情固定用右侧 880px `DetailSheet`，不拆页签；按「变动 → 余额维度 → 来源 → 本次涉及 SN → 原因与留痕」纵向排列。
  - 同一动作的一减一加画成两条独立记录，线框不画连接线、配对箭头或「查看另一条」。
  - 空值统一画 `-`，不写中文破折号；示例值均为虚构 Mock。

## 库存流水列表

- **用途**：在当前仓库内查询已生效库存变化，按类型、来源、商品、批次、库位、品质和 SN 定位到单条流水。
- **关键要素**：页头「口径说明」「导出（Mock）」；`FilterBar` 5 项常显 + 5 项展开；表格 11 列；默认业务发生时间倒序；无状态页签、无勾选、无行操作。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库 US-LA-01) ------------------------------------------------------+
| PageContainer fill                                                                               |
|  库存流水                                                     [口径说明] [导出(Mock)]             |
| +-- Panel (筛选) -------------------------------------------------------------------------------+|
| | FilterBar · 6 列栅格                                                                          ||
| | 流水号          | 流水类型        | 来源单号        | SKU             | 业务发生时间      |   ||
| | [流水号        ] | [全部 v]       | [来源单号      ] | [编码／名称    ] | [业务发生日期  ] |   ||
| |                 |                |                |                 |                  | 查询 ||
| |                 |                |                |                 |                  | 重置 ||
| |                 |                |                |                 |                  | 展开 ||
| | 展开后：货主 [全部 v] | 品质 [全部 v] | 库位 [编码／名称] | 批次 [批次号] | SN [完整 SN] |   ||
| +-----------------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) ------------------------------------------------------------------------+|
| | DataTable 工具区                                                                   [列设置]   ||
| | 发生时间          | 流水号  | 流水类型      | 数量变化（本行口径）      | 商品        | 货主 … ||
| | 2026-10-15 10:30 | 000123 | 移库          | 批次库位实际              | CABLE-01    | C10028 … ||
| |                 |        |               | 5 → 3（-2）               | 线材        |        … ||
| | 2026-10-15 09:12 | 000118 | 预占          | SKU订单预占               | CABLE-01    | C10028 … ||
| |                 |        |               | 0 → 2（+2）               | 线材        |        … ||
| | （向右：库位 | 批次 | 品质 | 来源单据 | 操作者）                                                ||
| | 共 N 条   每页 20 [20 v]                                                     < 1 2 3 >        ||
| +-----------------------------------------------------------------------------------------------+|
+-------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **常显与展开**：常显 5 项为流水号、流水类型、来源单号、SKU、业务发生时间；第 6 列放查询、重置、展开。货主、品质、库位、批次、SN 放展开区。筛选项总数 10，必须有「展开」。
- **流水号**：系统内部编号，无业务前缀；左固定，点击打开详情抽屉；行本身也可点开，行内不再放「查看」。
- **数量变化**：第一行口径只能是 `批次库位实际` 或 `SKU订单预占`；第二行是 `变化前 → 变化后（增减）`。正数保留 `+`，负数保留 `-`，颜色只作辅助。排序列按增减数值，不按格式化文本。
- **订单预占行**：库位、批次显示 `-`，品质显示 `正常品`；不得给预占行补库位或批次。
- **非批次商品**：批次显示 `-`，库位仍有值，数量口径仍是 `批次库位实际`，不得因批次为空改记成 SKU 层。
- **来源单据**：移库作业号、盘点单号、入库单号、出库单号、退货单号等有独立详情页时可点；品质转换等无独立单据的动作显示 `-`，靠业务动作标识、原因和操作留痕追溯。
- **页头**：「口径说明」用浮层说明五个量，不把总库存、可用、锁定、冻结并列成四张卡；「导出(Mock)」只提示演示环境未接真实导出，不生成文件。
- **空态**：当前仓库和筛选条件下没有流水时，表格区显示「当前仓库和筛选条件下没有流水」，保留筛选区。
- **图中省略**：列宽、省略号、排序图标、列设置细节；列级规格见 Demo PRD 第 5 节。

## 流水详情抽屉

- **用途**：只读查看一条流水的完整口径与追溯依据，不提供任何修改入口。
- **关键要素**：880px 抽屉；`DetailTitle`「库存流水 · 流水号」；右上角「来源单据」按钮（仅有可跳转来源时出现）；五个字段分组；无页签、无底部按钮。

```text
+-- DetailSheet 880px -----------------------------------------------------------------------------+
| 库存流水 · 000123                                                              [来源单据]  [×]   |
| +-- Section 变动 --------------------------------------------------------------------------------+|
| | 流水类型         | 流水状态     | 数量口径         | 本口径变化量   | 变化前        | 变化后     ||
| | 移库            | 已生效      | 批次库位实际      | -2            | 5            | 3         ||
| | 业务发生时间              | 说明：本条只记该库位、批次（有则）、品质的实际数量变化，不代表 SKU 总量 ||
| | 2026-10-15 10:30:00      | 非批次商品的批次为空，仍记在本库位。                                ||
| +------------------------------------------------------------------------------------------------+|
| +-- Section 余额维度 ----------------------------------------------------------------------------+|
| | 所属仓库          | 货主            | 商品                  | 库位         | 批次          | 品质     ||
| | US-LA-01 洛杉矶仓 | C10028 示例货主 | CABLE-01 线材         | A-01-02     | LOT-202610    | 正常品   ||
| | 关联库存明细号（占整行）                                                                       ||
| | INV-000123                                                                                     ||
| +------------------------------------------------------------------------------------------------+|
| +-- Section 来源 --------------------------------------------------------------------------------+|
| | 来源单据类型      | 来源单号              | 来源行号     | 关联作业记录        | 业务动作标识      ||
| | 入库单           | IB-20261015-0001     | 3           | PA-20261015-0002   | ACT-...           ||
| +------------------------------------------------------------------------------------------------+|
| +-- Section 本次涉及 SN（仅有实际采集 SN 时显示） -----------------------------------------------+|
| | SN-A001  SN-A002  SN-A003                                                                      ||
| +------------------------------------------------------------------------------------------------+|
| +-- Section 原因与留痕 --------------------------------------------------------------------------+|
| | 货主通知结果      | 操作者        | 操作终端      | 原因说明（占整行）       ||
| | 已通知            | Mike Zhang    | PDA           | -                        ||
| | 依据说明（占整行）：-                                                                          ||
| +------------------------------------------------------------------------------------------------+|
+--------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **只读**：抽屉没有编辑、删除、冲销、重做按钮；也没有「查看成对流水」「查看源库位」「查看目标库位」入口。
- **标题**：`DetailTitle` 只带固定文案和流水号，不带状态徽标；流水状态在「变动」分组展示一次。
- **数量口径**：`批次库位实际` 的变化前／后标签写「批次库位实际变化前／后」，并说明「不代表 SKU 总量；非批次商品批次为空，仍记在本库位」；`SKU订单预占` 的标签写「SKU订单预占变化前／后」，并说明「库位、批次不适用」。
- **订单预占详情**：库位、批次、关联库存明细号显示 `-`，品质固定 `正常品`。
- **来源单据按钮**：仅当来源单号能解析到对应列表详情时出现；点击跳来源对象详情，不在抽屉内嵌第二层详情。品质转换等无独立单据的动作不显示该按钮，来源单号显示 `-`。
- **盘点调整**：数量口径为 `批次库位实际`，来源单据为盘点单；「原因与留痕」下方提示「盘点快照、实盘与差异依据见盘点单」。
- **SN**：仅展示本次实际采集并写入流水的 SN；没有采集时整段不显示，不按数量补造 SN。
- **找不到记录**：流水不存在，或所属仓库与顶栏当前仓库不一致时，抽屉正文只显示「记录不存在或当前仓库不一致，无法查看」，不展示缓存数据或其他仓数据。
- **图中省略**：字段空值样式、长文本换行；字段完整清单和空值规则见 Demo PRD 第 7 节。

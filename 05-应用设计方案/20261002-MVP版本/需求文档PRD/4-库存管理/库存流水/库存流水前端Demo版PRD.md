## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 库存流水列表页（含流水详情抽屉） |
| 路由 | `/wms/inventory/logs` |
| 入口 | 左侧菜单「库存流水」；库存查询的 SKU 库存、批次库存、SN 详情带筛选参数跳转；移库详情、盘点详情带 `?log={流水id}` 打开详情 |
| 页面目标 | 在当前仓库内查询已生效库存变化，定位到单条流水并核对数量口径、余额维度、来源和操作留痕 |
| 适用状态 | 一期只有「已生效」流水；无状态页签、无状态筛选、无状态列 |
| 版式 | `PageContainer fill` + 筛选 `Panel` + 表格 `Panel`；详情为右侧 880px `DetailSheet` |
| 页面边界 | 不提供新建、编辑、删除、冲销、行勾选、批量操作、成对流水跳转、源／目标库位字段、跨仓查询、正式文件导出 |

**URL 状态**：

| 参数 | 含义 | 写入时机 |
| --- | --- | --- |
| `no` | 流水号前缀 | 查询 |
| `type` | 流水类型 | 查询 |
| `sourceNo` | 来源单号／关联作业记录 | 查询 |
| `sku` | SKU 编码／名称分词 | 查询 |
| `occurredFrom`、`occurredTo` | 业务发生日期起止 | 查询 |
| `customerId` | 货主 | 查询 |
| `quality` | 品质 | 查询 |
| `location` | 库位 | 查询 |
| `batch` | 批次号 | 查询 |
| `sn` | 完整 SN | 查询 |
| `log` | 当前打开详情的内部流水 id | 打开／关闭详情 |

- 筛选写入 URL，刷新、分享、从详情返回都能恢复；排序和分页不写入。
- 从库存查询跳转时带入 `customerId`、`sku`、`quality`，有库位或批次时同时带入 `location`、`batch`。
- 顶栏切换仓库后，列表按新仓库重新取数；已打开的详情若不属于新仓库，关闭并显示不存在。

## 2. 查询区

`FilterBar columns={6}`。常显 5 项占第 1～5 列，第 6 列底对齐放查询、重置、展开；其余 5 项放 `advanced`。筛选项总数 10，必须出现「展开」。

| # | 筛选项 | 区域 | 控件 type | 匹配方式 | placeholder key | 选项／空值 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 流水号 | 常显 | `input` | 显示流水号前缀匹配，不区分大小写 | `inventory.logs.logNoPlaceholder` | 空串；输入去首尾空格 |
| 2 | 流水类型 | 常显 | `select` | 精确匹配 | `common.selectPlaceholder` | 全部 + 10 种类型；默认 `FILTER_ALL` |
| 3 | 来源单号 | 常显 | `input` | 包含匹配；同时匹配来源单号和关联作业记录号 | `inventory.logs.sourceNoPlaceholder` | 空串 |
| 4 | SKU | 常显 | `input` | 空格分词，任一分词命中 SKU 编码或名称即匹配 | `inventory.stock.skuKeywordPlaceholder` | 空串 |
| 5 | 业务发生时间 | 常显 | `date-range` | 闭区间，按业务发生时间比较 | `inventory.logs.occurredRangePlaceholder` | 起止都为空表示不限 |
| 6 | 货主 | advanced | `select` | 精确匹配货主 id | `common.selectPlaceholder` | 全部 + 当前货主资料；默认 `FILTER_ALL` |
| 7 | 品质 | advanced | `select` | 精确匹配 | `common.selectPlaceholder` | 全部／正常品／不良品；默认 `FILTER_ALL` |
| 8 | 库位 | advanced | `input` | 包含匹配库位编码 | `inventory.stock.locationPlaceholder` | 空串 |
| 9 | 批次 | advanced | `input` | 包含匹配批次号 | `inventory.stock.batchPlaceholder` | 空串 |
| 10 | SN | advanced | `input` | 完整 SN 精确匹配，不区分大小写 | `inventory.logs.serialPlaceholder` | 空串；不做前缀或模糊匹配 |

**流水类型选项**（与字段清单闭集一致，按此顺序）：

1. 收货入暂存库位
2. 上架移库
3. 拣货移入出库暂存库位
4. 返库上架
5. 品质转换
6. 移库
7. 盘点调整
8. 确认出库扣减
9. 预占
10. 释放

**交互行为**：

| 行为 | 规则 |
| --- | --- |
| 查询 | 把草稿条件写入生效条件并写 URL；表格回到第 1 页；展开区收起后条件仍生效 |
| 重置 | 清空全部 10 项（含展开区），回到第 1 页；保留顶栏仓库，不关闭已打开的详情 |
| 展开／收起 | 只切换筛选项可见性，不触发查询，不清空已填条件 |
| 空条件 | 直接返回当前仓库全部流水，按业务发生时间倒序 |
| 日期范围 | 选满起止后 Popover 自动关闭；中文界面显示中文月份和星期 |
| 筛选无结果 | 表格显示空态，不弹 Toast |

## 4. 状态页签

**无。** 一期库存流水只保存「已生效」记录，没有草稿、待处理、已冲销等状态，因此：

- 不渲染 `StatusTabs`，也不渲染「全部／已生效」单页签。
- 不提供状态筛选或状态列；流水类型是业务分类，不是状态，放在查询区与表格列中。
- 列表默认直接展示当前仓库全部已生效流水。

## 5. 列表表格

### 5.1 视角说明

**流水行视角**：每行是一条库存流水，代表一个数的一次变化。同一业务动作产生的多条流水各自成行：

- 上架、移库、品质转换、拣货移入暂存等「一减一加」显示为两行，不合并。
- 普通出库确认出库显示为两行：一行 `批次库位实际`，一行 `SKU订单预占`，不合并成「一条同时写两个口径」；其他出库没有订单预占，只显示批次库位实际减项。
- 分配不写流水，因此列表不会出现分配行。

### 5.2 列定义

| # | 列名 | 展示形式 | 对齐 | 排序 | 空值 | 格式／示例 | 说明 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 发生时间 | 日期时间 | 左 | 是（日期时间） | `-` | `2026-10-15 10:30:00` | **默认排序**，降序；按仓库时区显示 |
| 2 | 流水号 | 链接 | 左 | 否 | `-` | `000123` | 左固定；系统内部编号，无业务前缀；点击打开详情 |
| 3 | 流水类型 | 文本 | 左 | 否 | `-` | `移库` | 取值见第 2 节 10 种类型；不使用状态徽标 |
| 4 | 数量变化（本行口径） | 两行文本 | 右 | 是（按变化量数值） | `-` | 第一行 `批次库位实际`，第二行 `5 → 3（-2）` | 第一行口径；第二行变化前、变化后、带符号增减；正数绿、负数红，符号必须保留 |
| 5 | 商品 | Code-Name | 左 | 否 | `-` | `CABLE-01 线材` | SKU 编码 + 名称；超宽省略，悬浮显示全称 |
| 6 | 货主 | Code-Name | 左 | 否 | `-` | `C10028 深圳示例电子` | 同编码商品靠货主区分；不只显示名称 |
| 7 | 库位 | 编码 | 左 | 否 | `-` | `A-01-02` | `SKU订单预占` 行为 `-`；非批次商品仍有库位 |
| 8 | 批次 | 文本 | 左 | 否 | `-` | `LOT-202612` | 订单预占、非批次商品为 `-` |
| 9 | 品质 | 标签 | 左 | 否 | `-` | `正常品`／`不良品` | `SKU订单预占` 行固定 `正常品` |
| 10 | 来源单据 | 链接／文本 | 左 | 否 | `-` | `MV-20261015-0001` | 有独立详情页时可点；无独立单据（品质转换）显示 `-` |
| 11 | 操作者 | 文本 | 左 | 否 | `-` | `Mike Zhang` | 系统动作显示「系统」；不做人员头像或账号链接 |

### 5.3 本页列表约定

| 项目 | 规则 |
| --- | --- |
| 默认排序 | 业务发生时间降序；同一时刻按流水写入顺序倒序，使同一动作的减项、加项相邻 |
| 固定列 | 流水号左固定；无右侧固定操作列 |
| 列设置 | 除流水号外均可显隐；不提供拖拽改列顺序 |
| 分页 | 底部固定分页：总条数、每页 10／20／50／100 条（默认 20）、页码；查询、重置、切页签后回第 1 页 |
| 勾选 | 无勾选列，不支持批量选择 |
| 行点击 | 点行或点流水号打开详情；行可按 Enter／Space 打开，流水号链接是主入口 |
| 空态 | 「当前仓库和筛选条件下没有流水」 |
| 数量变化格式 | `批次库位实际` 显示该库位、批次（有则）、品质的实际数量；`SKU订单预占` 显示 SKU 良品层预占数量，不带库位、批次 |
| 负数格式 | 变化量 `-2`，前后值 `5 → 3`；不使用会计括号或红色负号替代符号 |
| 来源单据可点性 | 仅当来源单号能解析到对应业务详情时渲染为链接；解析不到时按普通文本显示，不用禁用链接 |

## 6. 行操作矩阵

本页没有行操作列，也没有行内按钮。唯一行级动作是打开详情。

| 操作 | 全部流水 | 说明 |
| --- | :---: | --- |

| 批量选择／批量操作 | ❌ | 无勾选列 |

## 7. 详情抽屉

### 7.1 容器与标题

- 容器：右侧 `DetailSheet`，宽度 880px；桌面端覆盖列表右侧，列表仍可见。
- 标题：`DetailTitle`「库存流水 · {流水号}」，不带状态徽标。
- 页头右侧：`来源单据` 按钮，仅在来源单号有可跳转详情时出现；关闭按钮 `×`。
- 无页签、无底部操作区、无编辑入口。

### 7.2 字段分组

#### 变动

| 字段 | 展示 | 空值 | 说明 |
| --- | --- | --- | --- |
| 流水类型 | 文本 | `-` | 10 种类型之一 |
| 流水状态 | 文本 | `-` | 固定「已生效」；**当前实现未展示，待实现** |
| 数量口径 | 文本 | `-` | `批次库位实际` 或 `SKU订单预占` |
| 本口径变化量 | 带符号数值 | `-` | 正数 `+n` 绿、负数 `-n` 红 |
| 变化前 | 数值 | `-` | 按口径取实际数量或订单预占 |
| 变化后 | 数值 | `-` | 满足「变化后 = 变化前 + 变化量」 |
| 业务发生时间 | 日期时间 | `-` | 按仓库时区显示；不等于单据创建时间 |

底部说明按口径切换：

- `批次库位实际`：「本条只记该库位、批次（有则）、品质的实际数量变化，不代表 SKU 总量；非批次商品的批次为空，仍记在本库位。」
- `SKU订单预占`：「本条记该 SKU 良品层的订单预占变化；库位、批次不适用。」

#### 余额维度

| 字段 | 展示 | 空值 | 说明 |
| --- | --- | --- | --- |
| 所属仓库 | Code-Name | `-` | 当前仓库 |
| 货主 | Code-Name | `-` | 货主编码 + 名称 |
| 商品 | Code-Name | `-` | SKU 编码 + 名称 |
| 库位 | 编码 | `-` | `SKU订单预占` 为空 |
| 批次号 | 文本 | `-` | `SKU订单预占`、非批次商品为空 |
| 品质状态 | 标签 | `-` | 正常品／不良品；订单预占固定正常品 |
| 关联库存明细号 | 文本 | `-` | 实际数量流水关联库存明细；订单预占为空；**当前实现未展示，待实现** |

#### 来源

| 字段 | 展示 | 空值 | 说明 |
| --- | --- | --- | --- |
| 来源单据类型 | 文本 | `-` | 入库单／退货单／出库单／盘点单／移库作业／其他业务记录／无独立单据 |
| 来源单号 | 链接／文本 | `-` | 有详情页时可点；品质转换等无独立单据显示 `-` |
| 来源行号 | 数值 | `-` | 明细级动作有值 |
| 关联作业记录 | 链接／文本 | `-` | 上架单、拣货任务、返库上架单等；无则为 `-` |
| 业务动作标识 | 编码文本 | `-` | 仅追溯用，不作为业务单号；不提供成对流水联动 |

#### 本次涉及 SN

- 只有本次实际采集并写入流水的 SN 时显示整段；无 SN 时整段不显示。
- 一行一个 SN，多个 SN 用顿号或换行展示；不按数量补造 SN。
- SN 只读，不链接 SN 轨迹（本期库存流水不嵌 SN 轨迹页）。

#### 原因与留痕

| 字段 | 展示 | 空值 | 说明 |
| --- | --- | --- | --- |
| 货主通知结果 | 文本 | `-` | 已通知／待通知／无需通知 |
| 操作者 | 文本 | `-` | 管理端、PDA 操作者或系统 |
| 操作终端 | 文本 | `-` | 管理端／PDA／系统 |
| 原因说明 | 多行文本，整行 | `-` | 人工品质转换必填 |
| 依据说明 | 多行文本，整行 | `-` | 人工品质转换必填 |

- 盘点调整时，在该段下方显示「盘点快照、实盘与差异依据见盘点单」，并链接来源盘点单。
- 其他类型不显示该提示。

### 7.3 状态与异常

| 场景 | 展示 |
| --- | --- |
| 流水不存在 | 抽屉正文显示「记录不存在或当前仓库不一致，无法查看」，不展示缓存数据 |
| 流水属于其他仓库 | 同上，不展示其他仓的库位、货主、商品 |
| 来源单号无详情页 | 来源按钮不显示；来源单号按普通文本展示 |
| 来源单据已不存在 | 点击后由来源页面显示自己的未找到态，不在本抽屉内报错 |
| 同一动作的另一条流水 | 不显示链接、不显示配对提示；需要时通过类型、时间、业务动作标识在列表自行筛选 |

## 10. 派生与计算

本页只展示流水字段，不另造业务规则。页面用到的派生如下，规则来源见[库存流水主PRD](库存流水主PRD.md)：

| 项 | 公式／口径 | 说明 |
| --- | --- | --- |
| 数量口径 | `level = SKU` → `SKU订单预占`；否则 `批次库位实际` | 一期只有这两种口径 |
| 本口径变化量 | `批次库位实际`：`qtyChange`；`SKU订单预占`：`reservedChange` | 变化量非零整数 |
| 前后值校验 | `变化后 = 变化前 + 变化量` | 页面不重算，直接展示流水快照 |
| 流水号显示 | 按流水写入顺序生成 6 位显示编号 | 仅 Demo 展示；正式实现使用后端流水号，前端不加业务前缀 |
| 默认排序 | `业务发生时间` 降序，同一时刻按写入顺序倒序 | 成对流水相邻 |
| 数量变化排序值 | 带符号的变化量 | 不按「5 → 3（-2）」文本排序 |
| 来源单据可点 | 来源单号前缀能映射到业务详情路由 | 无映射时只显示文本 |
| 订单预占空值 | 库位、批次、关联库存明细号为空；品质固定正常品 | 不补默认库位或批次 |

| 拣货移入出库暂存库位 | 2 | 一减一加，来源出库单／拣货任务 |
| 移库 | 6 | 3 个 `MV` 号：单行普通 SKU、转不良后移到不良隔离库位、多行含批次 + SN；每行一减一加 |
| 品质转换 | 2 | 一减一加，原因「在库受损」，货主通知结果有值；无独立来源单号 |
| 盘点调整 | 1 | 有差异的盘点行确认后生成，来源盘点单 |
| 普通出库确认出库扣减 | 2 | 一条 `批次库位实际` 减、一条 `SKU订单预占` 减，同一出库单，不合并；其他出库只写批次实际 |
| 预占 | 1 | `SKU订单预占` 正数，库位、批次为空，品质正常品 |
| 释放 | 1 | `SKU订单预占` 负数，来源出库单 |
| 非批次商品实际流水 | 1 | 批次为 `-`，库位有值，口径仍为 `批次库位实际` |
| 带 SN 的流水 | 1 | 「本次涉及 SN」有值，SN 去重 |
| 自动过期转换 | 1 | 原因「效期过期」、操作者为系统、终端为系统；**现有种子未覆盖，需补** |
| 单仓流水总数 | ≥25 | 覆盖以上组合，能撑起 2 页分页演示 |

**边界与组合**：

- 同一动作的减项、加项必须共用业务动作标识，但列表仍分成两行。
- 必须存在「同一时刻」的两条流水，用于验证同时间按写入顺序倒序。
- 必须存在一条来源单号无法解析详情的流水（品质转换），用于验证来源单据显示 `-` 且不出现禁用链接。
- 必须存在一条流水属于其他仓库，用于验证跨仓打开详情时显示不存在。
- 所有枚举值必须落在字段清单范围内，不自造流水类型、来源类型或品质；原因只写说明文本。

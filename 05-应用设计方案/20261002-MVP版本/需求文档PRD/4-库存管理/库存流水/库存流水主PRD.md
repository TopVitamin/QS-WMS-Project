# 库存流水主PRD

> 定义库存流水的查询与追溯。字段见[库存流水详细稿](../../../字段清单合集/04-库存与库内/库存流水/库存流水（详细稿）.tsv)，记账口径见[库存模块宏观系统架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)第2.4节。页面见[库存流水页面骨架](库存流水页面骨架.md)和[库存流水前端Demo版PRD](库存流水前端Demo版PRD.md)。

## 一、流水记什么

库存流水是已生效库存变化的只读记录，一行只记一个数的一次变化：

- 实际数量变化记在库存明细层，带库位、批次、品质；SKU库存的实际不另记第二笔流水。
- 订单占用变化记在SKU层，库位、批次、品质为空。
- 上架、拣货移入出库暂存、返库上架、移库、品质转换等位置或品质转移记一减一加两行，并以同一业务动作标识成对关联。
- 分配与其他出库指定只改变库存明细的已分配，不写库存流水，追溯看拣货任务和出库单明细。

一期流水类型闭集：收货入暂存库位、上架移库、拣货移入出库暂存库位、返库上架、品质转换、移库、盘点调整、确认出库扣减、预占、释放。

| 流水类型 | 变动对象 | 来源单据／作业 | 是否成对 |
| --- | --- | --- | --- |
| 收货入暂存库位 | 实际数量 | 入库单／收货记录 | 否 |
| 上架移库、返库上架 | 实际数量 | 上架单或返库上架单 | 是 |
| 拣货移入出库暂存库位 | 实际数量 | 出库单／拣货任务 | 是 |
| 品质转换 | 实际数量 | 无独立单据；使用业务动作标识追溯 | 是 |
| 移库 | 实际数量 | 移库作业 | 是 |
| 盘点调整 | 实际数量 | 盘点单 | 否 |
| 确认出库扣减 | 实际数量、订单占用 | 出库单 | 否 |
| 预占、释放 | 订单占用 | 出库单 | 否 |

品质转换没有来源单号时，列表显示“—”，详情以业务动作标识、原因和操作留痕追溯，不为此虚构品质转换单号。品质转换的原因代码只有两个取值：人工转换为在库受损，系统自动过期转换为效期过期。流水号是系统内部编号，不带业务前缀。

## 二、查询与详情

| 区域 | 要求 |
| --- | --- |
| 筛选 | 流水号、类型、业务发生时间、来源单据号、货主、SKU、库位、批次、SN；顶栏仓库限定数据范围 |
| 列表 | 发生时间、流水号、流水类型、变动对象、SKU、库位、批次、品质、变化量、变化前／后、来源单据、操作者 |
| 详情 | 全部余额维度、来源单据及行号、关联作业记录、成对流水、SN清单、原因、操作终端及操作者 |

变化量正数显示“＋”，负数显示“－”。订单占用类在“变动对象”显示“订单占用”，库位、批次、品质显示“—”；实际类显示“实际数量”。列表默认业务发生时间倒序。

## 三、追溯规则

- 来源单号或关联作业记录号有值时可跳对应详情；对象不存在或用户无仓库权限时不展示敏感详情。
- 成对流水在详情中互相链接。移库、品质转换等不得只展示减项而隐藏加项。
- 启用SN的商品展示本次涉及SN清单，并可进入SN轨迹。
- 重复提交返回既有结果，不新增第二组流水；同一流水不可编辑、删除或手工冲销。
- 品质转换原因、依据及通知结果在流水详情显示；盘点调整显示盘点快照、实盘与差异依据的链接。

## 四、范围边界

不提供手工新增流水、修改余额、批量导入或“冲销流水”按钮。业务误操作的恢复路径由原业务规则决定；一期未定义实收误记更正入口，不得通过库存流水绕过。

## 五、验收

| 条件与操作 | 预期结果 |
| --- | --- |
| 收货确认正常品3 | 生成收货暂存库位实际＋3一行，前后量可核对 |
| 上架暂存3至A-01 | 同一动作显示暂存－3、A-01＋3两行，SKU实际合计不变 |
| 接单预占2 | 生成订单占用＋2一行，库位／批次／品质为空 |
| 生成拣货任务分配2 | 不生成流水；库存明细已分配增加，可从任务追溯 |
| 重复提交同一移库 | 仍只有原成对流水，库存不再变化 |
| 按SN筛选 | 只返回涉及该SN的流水，并能打开SN轨迹 |

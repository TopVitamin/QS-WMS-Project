# 库存流水主PRD

> 定义库存流水的查询与追溯。字段见[库存流水详细稿](../../../字段清单合集/04-库存与库内/库存流水/库存流水（详细稿）.tsv)，记账口径见[库存模块宏观系统架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)第2.4节。页面见[库存流水页面骨架](库存流水页面骨架.md)和[库存流水前端Demo版PRD](库存流水前端Demo版PRD.md)。

## 一、流水记什么

库存流水是已生效库存变化的只读记录，一行只记一个数的一次变化：

- 库存数量变化记在批次库存层，带库位、批次、品质；SKU库存的实际不另记第二笔流水。
- 订单预占变化记在SKU层，库位、批次为空，品质为良品。
- 上架、拣货移入出库暂存、返库上架、移库、品质转换等分别记减项、加项两条独立流水。每条只有自己的库位、批次、品质与前后数量，不增加源库位／目标库位字段，不合并或联动展示。内部动作标识仅用于幂等和追溯。
- 分配与其他出库指定只改变批次库存的已分配，不写库存流水，追溯看拣货任务和出库单明细。

一期流水类型闭集：收货入暂存库位、上架移库、拣货移入出库暂存库位、返库上架、品质转换、移库、盘点调整、确认出库扣减、预占、释放。

| 流水类型 | 数量口径 | 来源单据／作业 | 是否一减一加成对 |
| --- | --- | --- | --- |
| 收货入暂存库位 | 批次库位实际 | 入库单／收货记录 | 否 |
| 上架移库、返库上架 | 批次库位实际 | 上架单或返库上架单 | 是 |
| 拣货移入出库暂存库位 | 批次库位实际 | 出库单／拣货任务 | 是 |
| 品质转换 | 批次库位实际 | 无独立单据；使用业务动作标识追溯 | 是 |
| 移库 | 批次库位实际 | 移库作业 | 是 |
| 盘点调整 | 批次库位实际 | 盘点单 | 否 |
| 确认出库扣减 | 批次库位实际、SKU订单预占 | 出库单 | 否 |
| 预占、释放 | SKU订单预占 | 出库单 | 否 |

确认出库扣减按数量口径分别记 `批次库位实际` 和 `SKU订单预占` 两行，不是一减一加配对，也不合并为一行。品质转换没有来源单号时，列表显示“—”，详情以业务动作标识、原因和操作留痕追溯，不为此虚构品质转换单号。品质转换的原因代码只有两个取值：人工转换为在库受损，系统自动过期转换为效期过期。流水号是系统内部编号，不带业务前缀。

## 二、查询与详情

| 区域 | 要求 |
| --- | --- |
| 筛选 | 流水号、类型、业务发生时间、来源单据号、货主、SKU、品质、库位、批次、SN；顶栏仓库限定数据范围 |
| 列表 | 发生时间、流水号、流水类型、数量变化（本行口径）、SKU、货主、库位、批次、品质、来源单据、操作者 |
| 详情 | 数量口径、全部余额维度、来源单据及行号、关联作业记录、SN清单、原因、操作终端及操作者 |

“数量变化”单元格先写口径，再写变化前→后和增减，例如 `批次库位实际 200→120（-80）`、`SKU订单预占 0→2（+2）`。变化量正数显示“＋”，负数显示“－”。

- `批次库位实际`：记在库存明细行，库位必有值；有批次商品的批次号有值，非批次商品批次为空，仍按本库位记录，不得改记到 SKU 层。
- `SKU订单预占`：记在 SKU 良品层，库位、批次为空，品质为良品。

前后值只属本条数量口径和本条余额维度：`批次库位实际` 的前后值不是 SKU 总量，`SKU订单预占` 的前后值不带库位、批次。列表不把同一动作的实际流水和预占流水合并，也不并列总库存、可用数量、已分配、锁定或冻结。列表默认业务发生时间倒序。

## 三、追溯规则

- 来源单号或关联作业记录号有值时可跳对应详情；对象不存在或用户无仓库权限时不展示敏感详情。
- 移库两条记录在列表中各自展示。详情不设置成对流水链接、源／目标库位或联动影响面板。变化前后只指本条变动对象、本条余额维度；非批次商品批次为空，仍属批次库位实际，不因批次为空改记到 SKU 层。
- 启用SN的商品展示本次涉及SN清单，并可进入SN轨迹。
- 重复提交返回既有结果，不新增第二组流水；同一流水不可编辑、删除或手工冲销。
- 品质转换原因、依据及通知结果在流水详情显示；盘点调整显示盘点快照、实盘与差异依据的链接。

## 四、范围边界

不提供手工新增流水、修改余额、批量导入或“冲销流水”按钮。业务误操作的恢复路径由原业务规则决定；一期未定义实收误记更正入口，不得通过库存流水绕过。

## 五、验收

| 条件与操作 | 预期结果 |
| --- | --- |
| 收货确认正常品3 | 生成 `批次库位实际 0→3（+3）` 一行，库位为收货暂存，前后量可核对 |
| 上架暂存3至A-01 | 同一动作显示 `批次库位实际` 暂存－3、A-01＋3两行，SKU实际合计不变 |
| 接单预占2 | 生成 `SKU订单预占 0→2（+2）` 一行，库位／批次为空，品质为良品 |
| 确认出库80 | 生成两条：`批次库位实际 200→120（-80）` 与 `SKU订单预占 500→420（-80）`；不生成一条同时写两个口径的流水 |
| 非批次商品收货2 | 生成 `批次库位实际 0→2（+2）`，库位有值、批次为空；不得只写SKU层预占或改记到SKU库存 |
| 生成拣货任务分配2 | 不生成流水；批次库存已分配增加，可从任务追溯 |
| 重复提交同一移库 | 仍只有原两条独立流水，库存不再变化 |
| 按SN筛选 | 只返回涉及该SN的流水，并能打开SN轨迹 |

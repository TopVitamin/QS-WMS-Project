# 盘点单前端Demo版PRD

> 用途：实现[盘点单主PRD](盘点单主PRD.md)的管理端创建、查询、实盘、差异确认与取消。PDA见[PDA盘点前端Demo版PRD](../../7-PDA作业端/盘点作业/PDA盘点前端Demo版PRD.md)，布局见[盘点单页面骨架](盘点单页面骨架.md)，字段见[盘点单详细稿](../../../字段清单合集/04-库存与库内/盘点单/盘点单（详细稿）.tsv)。
> 版本：WMS-V0.2｜日期：2026-10-21。

**样式与组件**：布局与占位须符合[需求文档PRD／AGENTS.md](../../AGENTS.md)“布局硬规则”。

## 一、页面与路由

| 路由 | 页面 | URL状态 |
| --- | --- | --- |
| `/wms/inventory/counts` | 盘点单列表 | `status`、筛选、分页 |
| `/wms/inventory/counts/:stocktakeNo` | 盘点单详情 | `tab`允许`lines`、`serials`、`evidence`、`logs` |

## 二、列表与创建

`FilterBar columns={6}`，5项常显，无advanced。

| 筛选项 | 控件 | 匹配／取值 | Placeholder key |
| --- | --- | --- | --- |
| 盘点单号 | Input | 精确或前缀匹配 | `common.inputPlaceholder` |
| SKU | Input | 编码／名称空格分词包含 | `common.inputPlaceholder` |
| 来源 | Select | 全部／计划盘点／发现账实不符 | `common.selectPlaceholder` |
| 发起人 | Select | 精确匹配 | `common.selectPlaceholder` |
| 发起时间 | DateRangePickerField | 时间范围，匹配单头发起时间 | `inventory.stocktake.createdRangePlaceholder` |

状态页签为全部、盘点中、已完成、已取消。列与顺序以[盘点单页面骨架](盘点单页面骨架.md)为准。

“创建计划盘点”Dialog只在有盘点创建权限时出现：货主、库区使用Select，SKU使用可搜索多选，未选时均使用`common.selectPlaceholder`；盘点说明使用Textarea和`common.inputPlaceholder`。选中区显示是否存在进行中上架、返库上架或拣货任务，以及SKU是否已在其他盘点中（给出盘点单号）；有任一阻断时整次不创建，返回全部原因，不静默跳过SKU。

## 三、详情与动作

详情为概览卡＋多页签。基本信息按状态显示差异确认人和确认时间，或取消人、取消时间和取消原因。盘点明细支持按“全部／未盘／有差异”过滤；账面、实盘、差异右对齐。SN页签按盘点行展示账面SN、实盘SN及多出／缺失；账面SN取自创建时的快照，不随实盘改变。发现依据页签只在发现依据有内容时出现，按追加顺序分段展示。

| 动作 | 实现要求 |
| --- | --- |
| 管理端实盘 | Sheet逐行录入；可保存分次结果；SN商品使用逐件清单，数量由SN数派生 |
| 差异确认 | 主管二次确认；列出盘盈、盘亏、品质变化、可用转负提示；提交一次生效 |
| 取消 | 必填原因；明确不调账，来源为账实不符时仍待核对；成功后记录取消人和取消时间 |

所有动作共用盘点业务action，管理端和PDA不得各存一份实盘。请求重复只返回已有结果；盘点状态已变化时刷新并提示，不覆盖。

## 四、派生与权限

差异数量＝实盘－账面。列表和汇总卡的SKU数、明细行数、已盘行数、差异行数取单头汇总字段，差异行数只统计已盘且差异不为0的行。按钮同时受仓库授权、动作权限和盘点状态控制。无权限不渲染动作；直接调用仍返回无权限。冻结提示引用受影响SKU及盘点单号，其他业务页可跳回详情。

## 五、Mock与走查

每仓至少准备：无差异、盘亏导致可用为负、盘盈新批次、不良品短少、SN缺失、发现账实不符后取消六类盘点。走查创建阻断（含SKU已在其他盘点中）、PDA分次实盘、PDA对已在盘点中的SKU追加发现依据、管理端重录、确认、取消、重复确认、过期转换补做、待核对解除与未解除分支。文档走查通过不等于实际页面、并发或生产验收。

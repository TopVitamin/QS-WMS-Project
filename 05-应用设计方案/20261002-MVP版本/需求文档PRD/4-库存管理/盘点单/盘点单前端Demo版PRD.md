## 1. 页面概述

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 盘点单列表页、盘点单详情页、创建计划盘点 Dialog、实盘录入 Sheet、差异确认 Dialog、取消盘点 Dialog |
| 路由 | 列表 `/wms/inventory/counts`；详情 `/wms/inventory/counts/:stocktakeNo` |
| 入口 | 左侧菜单「盘点单」；列表页头「创建计划盘点」；列表点盘点单号；PDA 发起的盘点单在列表同样可见 |
| 页面目标 | 查询本仓盘点单，查看账面快照与实盘差异，完成计划盘点创建、实盘录入、差异确认和取消 |
| 适用状态 | `盘点中`、`已完成`、`已取消`；状态驱动页头动作和基本信息字段 |
| 版式 | 列表：`PageContainer fill` + 筛选 `Panel` + `StatusTabs` + 表格 `Panel`；详情：`DetailTitle` + `DetailOverview` + `DetailTabs`；创建／确认／取消用 `Dialog`；实盘用 880px `DetailSheet` |
| 页面边界 | 不提供普通编辑页、删除、审批／驳回、导入、恢复、直接改账面数量、管理端发起「发现账实不符」、批量勾选、账号／角色／仓库授权校验 |

**URL 状态**：

| 页面 | 参数 | 含义 |
| --- | --- | --- |
| 列表 | `status` | `COUNTING`／`COMPLETED`／`CANCELLED`；`ALL` 不写 |
| 列表 | `no` | 盘点单号前缀 |
| 列表 | `sku` | SKU 编码／名称分词 |
| 列表 | `source` | `PLAN`／`DISCREPANCY` |
| 列表 | `createdBy` | 发起人 |
| 列表 | `createdFrom`、`createdTo` | 发起日期起止 |
| 详情 | `tab` | `lines`（默认）／`serials`／`evidence`／`audit` |

- 列表筛选和状态页签写入 URL；排序、分页不写入。查询、重置、切页签后回第 1 页。
- 详情页签写入 URL；刷新、返回仍停在原页签。非法 `tab` 回落到「盘点明细」。
- 从详情返回列表时恢复原页签、筛选和页码。
- 顶栏切换仓库后，列表按新仓库取数；详情的盘点单不属于当前仓库时显示未找到态。

## 2. 查询区

`FilterBar columns={6}`。5 项全部常显，第 6 列放查询、重置；筛选项总数 5，不出现「展开」。

| # | 筛选项 | 区域 | 控件 type | 匹配方式 | placeholder key | 选项／空值 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 盘点单号 | 常显 | `input` | 前缀匹配，不区分大小写 | `inventory.stocktake.noPlaceholder` | 空串；输入去首尾空格 |
| 2 | SKU | 常显 | `input` | 空格分词，任一分词命中单头盘点商品的 SKU 编码或名称即匹配 | `inventory.stock.skuKeywordPlaceholder` | 空串 |
| 3 | 来源 | 常显 | `select` | 精确匹配 | `common.selectPlaceholder` | 全部／计划盘点／发现账实不符；默认 `FILTER_ALL` |
| 4 | 发起人 | 常显 | `select` | 精确匹配发起人 | `common.selectPlaceholder` | 全部 + 当前仓盘点单出现过的发起人；默认 `FILTER_ALL` |
| 5 | 发起时间 | 常显 | `date-range` | 闭区间，按单头发起时间比较 | `inventory.stocktake.createdRangePlaceholder` | 起止都为空表示不限 |

**交互行为**：

| 行为 | 规则 |
| --- | --- |
| 查询 | 草稿条件写入生效条件并写 URL；回到第 1 页；保留当前状态页签 |
| 重置 | 清空 5 项，回到第 1 页；保留当前状态页签和顶栏仓库 |
| 空条件 | 返回当前仓全部盘点单，按发起时间倒序 |
| SKU 筛选 | 按单头盘点商品匹配；命中任一 SKU 即返回整张盘点单 |
| 筛选无结果 | 显示表格空态，不弹 Toast；状态页签计数同步变为 0 |

## 4. 状态页签

| key | 文案 | 计数口径 |
| --- | --- | --- |
| `ALL` | 全部 | 当前仓库 + 当前筛选条件下的全部盘点单 |
| `COUNTING` | 盘点中 | 当前仓库 + 当前筛选条件下状态为盘点中的条数 |
| `COMPLETED` | 已完成 | 同上，状态为已完成 |
| `CANCELLED` | 已取消 | 同上，状态为已取消 |

- 页签在表格上方，使用 `StatusTabs`；每个页签带条数。
- 计数先应用顶栏仓库和查询条件，再按状态分组；**不**受当前选中页签影响，因此切页签时其他计数不变。
- 页签切换写 URL `status`；选「全部」时移除 `status` 参数。
- 默认「全部」。切换页签不改变筛选条件，回到第 1 页。
- 列表行另用 `StatusBadge` 显示状态：盘点中蓝、已完成绿、已取消灰；页签与行内状态文案一致。

### 5.3 本页列表约定

| 项目 | 规则 |
| --- | --- |

| 列设置 | 除盘点单号外均可显隐；不提供拖拽改列顺序 |

## 10. 派生与计算

| 项 | 公式／口径 | 说明 |
| --- | --- | --- |
| 差异数量 | `实盘数量 - 账面数量` | 未盘时为空，显示 `-`，不按 0 计算 |
| 实盘状态 | `实盘数量` 有值 = 已盘；空 = 未盘 | 录入 0 仍表示已盘 |
| 明细行数 | `lines.length` | 含实盘新增的账面 0 行 |
| SKU 数 | 单头盘点商品个数 | 创建后不变 |
| 已盘行数 | 实盘数量有值的行数 | 用于进度和确认前置校验 |
| 差异行数 | 已盘且差异 ≠ 0 的行数 | 未盘行不计入 |
| 进度 | `已盘行数 / 明细行数` | 分母为 0 时进度为 0 |
| 盘盈 | 差异 > 0 的行数与差异合计 | 确认 Dialog 摘要 |
| 盘亏 | 差异 < 0 的行数与差异合计 | 同上 |
| 正常品变化 | 正常品行差异净额 | 同上 |
| 不良品变化 | 不良品行差异净额 | 同上 |
| 负库存预演 | `预演后可用 = 当前可用 + 该 SKU 正常品差异合计` | 小于 0 时阻断确认；页面只预演，最终以提交时重新校验为准 |
| 页签条数 | 盘点明细 = 明细行数；SN 明细 = 涉及 SN 的盘点行数；操作日志 = 日志条数 | 发现依据不带条数 |

- 单头汇总字段在页面上取同一套明细计算结果，不另存第二份数字。
- 差异确认不改变账面快照；完成后账面、实盘、差异保留用于追溯。

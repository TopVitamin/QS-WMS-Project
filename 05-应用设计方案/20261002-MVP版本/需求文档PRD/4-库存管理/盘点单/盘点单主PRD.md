# 盘点单主PRD

> 定义盘点建单、冻结、实盘、差异确认和取消。字段见[盘点单详细稿](../../../字段清单合集/04-库存与库内/盘点单/盘点单（详细稿）.tsv)，状态和数量依据见[库存模块宏观系统架构](../../../../../01-全局背景信息/07-库存模块宏观系统架构.md)第3.1.2、六节。管理端页面见[盘点单页面骨架](盘点单页面骨架.md)，PDA实盘见[PDA盘点前端Demo版PRD](../../7-PDA作业端/盘点作业/PDA盘点前端Demo版PRD.md)。

## 一、范围与发起

盘点按仓库＋SKU建单，一张可选多个SKU，盘这些SKU在存储、拣货、不良隔离库位上的库存。收货暂存、出库暂存库位不盘，实物继续跟随上架单、出库单处理。

| 来源 | 发起端 | 要求 |
| --- | --- | --- |
| 计划盘点 | 管理端 | 选择本仓一个或多个SKU；可先按库区筛选SKU，但盘点范围仍按SKU展开到本仓全部可盘库位 |
| 发现账实不符 | PDA | 发现时立即按本仓库＋货主＋SKU标记“待核对”；发现人员先提交手上作业，再发起盘点并记录发现环节、原单、库位、差异数量和说明 |

这些SKU有进行中的上架单、返库上架单或拣货任务时不能建单，须先让任务提交完成。等待期间保持“待核对”，不恢复新分配、组波、补拣或其他出库指定。创建成功即生成账面快照并进入“盘点中”；创建盘点单不是标记“待核对”的触发点。

已在盘点中的SKU不能再建单。计划盘点选到这类SKU时整次阻断，并列出所在盘点单号；PDA发现差异时若该SKU已在盘点中，不新建盘点单，把本次发现环节、原单号、库位、差异数量和说明追加到该单的发现依据。SKU照常保持待核对：该单完成时按本次实盘一并解除，该单取消则继续待核对。

## 二、状态与操作

| 状态 | 允许操作 | 结果 |
| --- | --- | --- |
| 盘点中 | 查看、PDA或管理端录入／重录实盘、差异确认、取消 | 实盘不动库存；确认后调账并完成；取消不调账 |
| 已完成 | 查看、追溯、导出 | SKU解冻；解除本次已核实差异的待核对；补做暂停的过期转换 |
| 已取消 | 查看、追溯 | 只解除盘点冻结；尚未核实差异的待核对标记保留 |

已完成、已取消均不可恢复到盘点中；需要重盘时新建盘点单。

## 三、盘点期间冻结

- 这些SKU不能收货；含这些SKU的上架单、返库上架单不能开始。
- 新出库单仍可接收、按可用预占，也可受理取消；不能分配、组波、补拣、拣货、复核、确认出库或其他出库指定。
- 不能移库、人工品质转换；过期自动转换暂停，盘点完成后补做。
- 冻结按仓库＋货主＋SKU生效，不冻结同SKU在其他仓或其他货主的数据。

## 四、实盘与差异确认

盘点明细按库位、货主、SKU、批次、品质形成数量快照行，不假设SN已经绑定库位。实盘可分人、分次按数量录入；现场逐件扫描的SN只作为实际核实依据，不要求其原账面位置等于实盘库位。未逐件核实的数量差异不能随意选择SN标记盘亏。快照没有但现场发现的已确认归属实物可新增明细行，账面数量为0；认不出货主或商品的实物不加到盘点单，按无主货登记。新增效期库存时，现场手工录入生产日期或失效日期其中一项；生产日期加保质期天数等于失效日期，系统按此公式计算另一项，录入失效日期时反算生产日期；两项均可手动修改，且生产日期不得晚于失效日期。

差异数量＝实盘数量－账面数量。差异确认时：

1. 再次校验盘点单仍为盘点中、实盘已覆盖全部范围；有采集SN时校验身份、去重及SN与数量一致。
2. 先在提交副本中演算全部差异，校验实际、订单预占、可用、已分配等数量非负；通过后同时调整批次库存和按品质汇总的SKU库存，生成盘点调整流水。只有已逐件核实的SN差异才更新SN台账。
3. 盘亏后良品不足以支撑现有订单预占时，整次确认失败；实盘记录保留、单据仍为盘点中，库存和流水不变。不得自动退占、截零或完成盘点；先按原出库规则处理占用，再重新确认。
4. 不良品差异同步调整不良品实际；调减后不足以支撑已分配／已指定实物时也阻断，先取消原指定再重新确认。
5. 确认成功后整单已完成，所有调整一次生效；重复确认返回原结果。

## 五、权限

一期不做账号、角色或权限配置；计划创建、盘点发起、实盘录入、差异确认与取消只受单据状态和业务规则约束。不提供审批、驳回或直接编辑账面数量的操作。

## 六、验收

| 条件与操作（数字为模拟） | 预期结果 |
| --- | --- |
| SKU有未完成拣货任务时计划建单 | 阻断，列出任务号；不生成快照或冻结 |
| 计划盘点选到已在盘点中的SKU | 整次阻断，列出所在盘点单号；不生成快照 |
| 正常5、不良2、订单预占4，创建盘点 | 快照7；SKU冻结；新单仍可预占，作业等待 |
| 实盘正常4、不良2，订单预占5时确认 | 整次阻断；实盘保留、仍盘点中，账和流水不变；预占不自动调整 |
| 实盘正常4、不良2，订单预占4时确认 | 实际由7调为6，良品4／预占4／可用0，不良2／预占0／可用0，完成并写流水 |
| 发现一个归属明确的新批次 | 新增账面0的实盘行，确认后形成对应批次库存与流水 |
| PDA对已在盘点中的SKU上报差异后发起盘点 | 不新建盘点单；本次发现追加到该单发现依据并返回原单号，SKU保持待核对 |
| 取消“发现账实不符”盘点 | 不调账，只解盘点冻结；SKU仍待核对 |
| 重复差异确认 | 返回既有结果，不重复增减库存 |

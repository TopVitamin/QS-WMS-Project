## 页面与弹窗清单

| 页面／容器 | 路由／打开方式 | 入口 | 用途 |
| --- | --- | --- | --- |
| 盘点单列表 | `/wms/inventory/counts` | 左侧菜单「盘点单」 | 按状态、来源、商品、发起人和时间查询盘点单 |
| 盘点单详情 | `/wms/inventory/counts/:stocktakeNo` | 列表点盘点单号 | 查看快照、实盘、差异、SN、发现依据与操作日志 |
| 创建计划盘点 Dialog | 列表页头打开 | 「创建计划盘点」 | 选择本仓 SKU，创建账面快照并冻结 |
| 实盘录入 Sheet | 详情页头打开 | 盘点中「录入实盘」 | 管理端逐行录入或重录实盘，可分次保存 |
| 差异确认 Dialog | 详情页头打开 | 盘点中「确认差异」 | 主管查看盘盈盘亏摘要后一次确认调账 |
| 取消盘点 Dialog | 详情页头打开 | 盘点中「取消盘点」 | 填写原因后取消；不调账，只解除盘点冻结 |

本期不提供的入口：

| 不提供 | 原因 |
| --- | --- |
| 普通编辑页、删除、恢复盘点单 | 盘点单没有可编辑正文；已完成、已取消不可恢复，重盘必须新建 |
| 审批、驳回、主管复核单据 | 一期不设审批流，差异确认本身就是主管动作 |
| 直接修改账面数量 | 账面数量是创建时快照，只读 |
| 管理端发起「发现账实不符」 | 该来源只由 PDA 在拣货、复核、上架、返库上架、移库现场发起 |
| 批量勾选、批量确认、导入盘点结果 | 每张盘点单的范围和差异不同，须逐单确认 |
| 账号、角色、仓库授权校验 | 一期不做权限配置，只受单据状态和业务规则约束 |

## 文档说明与绘制约定

- 本文只回答「画在哪、叫什么」。建单、冻结、实盘、差异确认和取消规则见[盘点单主PRD](盘点单主PRD.md)；列级规格、校验文案、Mock 与验收见[盘点单前端Demo版PRD](盘点单前端Demo版PRD.md)；字段以[详细稿](../../../字段清单合集/04-库存与库内/盘点单/盘点单（详细稿）.tsv)为准。
- 通用布局、栅格与占位规则见[需求文档 PRD／AGENTS.md](../../AGENTS.md)，本文不重复。
- 本对象特殊约定：
  - 页面动作完全由盘点状态决定：盘点中显示录入、取消、确认；已完成、已取消只有返回列表。
  - 盘点明细是创建时的账面快照 + 实盘结果；快照行只读，实盘只在实盘动作中录入，不在详情表格里直接编辑。
  - 差异数量固定等于「实盘数量 - 账面数量」；未盘行不按 0 计算，显示「未盘」。
  - 实盘录入用右侧 880px `DetailSheet`，不跳独立页；创建、确认、取消用 `Dialog`。
  - 空值统一画 `-`；示例值均为虚构 Mock。

## 盘点单列表

- **用途**：按状态页签和筛选条件查询本仓盘点单，进入详情办理实盘、确认或取消，或从页头创建计划盘点。
- **关键要素**：页头「创建计划盘点」「导出（Mock）」；`FilterBar` 5 项常显、无展开；`StatusTabs` 全部／盘点中／已完成／已取消（带计数）；表格 9 列；默认发起时间倒序；无勾选、无行操作。

```text
+-- WmsLayout: 侧栏 | 顶栏(当前仓库 US-LA-01) ------------------------------------------------------+
| PageContainer fill                                                                               |
|  盘点单                                                  [创建计划盘点] [导出(Mock)]              |
| +-- Panel (筛选) -------------------------------------------------------------------------------+|
| | FilterBar · 6 列栅格                                                                          ||
| | 盘点单号          | SKU             | 来源            | 发起人          | 发起时间          |   ||
| | [盘点单号        ] | [编码／名称    ] | [全部 v]        | [全部 v]        | [发起日期      ] |   ||
| |                 |                 |                |                 |                  | 查询 ||
| |                 |                 |                |                 |                  | 重置 ||
| +-----------------------------------------------------------------------------------------------+|
| +-- Panel flex-1 (表格) ------------------------------------------------------------------------+|
| | StatusTabs: (全部 12) (盘点中 4) (已完成 4) (已取消 4)                                        ||
| | DataTable 工具区                                                                   [列设置]   ||
| | 盘点单号              | 状态   | 来源         | SKU数 | 明细行数 | 差异行数 | 发起人 …        ||
| | ST-20261015-0001     | 盘点中 | 计划盘点     | 3     | 12       | 2        | Lily Chen …     ||
| | ST-20261014-0004     | 已完成 | 发现账实不符 | 1     | 1        | 0        | Lily Chen …     ||
| | （向右：发起时间 | 确认时间）                                                                 ||
| | 共 N 条   每页 20 [20 v]                                                     < 1 2 3 >        ||
| +-----------------------------------------------------------------------------------------------+|
+-------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **常显与展开**：常显 5 项为盘点单号、SKU、来源、发起人、发起时间；第 6 列放查询、重置。筛选项总数 5，不出现「展开」。
- **状态页签**：全部、盘点中、已完成、已取消；计数按当前仓库和筛选条件统计各状态条数，不含当前页签本身。页签值写入 URL 的 `status` 参数，`ALL` 不写。
- **盘点单号**：左固定，格式 `ST-{UTC日期}-{序号}`；点击进入详情，行内不设「查看」。
- **状态与来源**：状态用 `StatusBadge`（盘点中蓝、已完成绿、已取消灰）；来源用标签（计划盘点灰、发现账实不符橙）。
- **三个计数**：SKU 数、明细行数、差异行数取单头汇总。明细行数含实盘新增的账面 0 行；差异行数只统计已盘且差异不为 0 的行，未盘行不计入。
- **确认时间**：仅已完成单据有值；盘点中、已取消显示 `-`。
- **无行操作**：列表不画「录入」「确认」「取消」行内按钮，所有动作进入详情后按状态出现。
- **空态**：当前仓库、页签和筛选条件下没有盘点单时，表格区显示「当前仓库和筛选条件下没有盘点单」。
- **图中省略**：列宽、排序图标、列设置细节；列级规格见 Demo PRD 第 5 节。

## 盘点单详情

- **用途**：查看一张盘点单的账面快照、实盘进度与差异，按状态办理实盘、差异确认或取消。

**补充说明**：

- **页头按钮按状态**：
  - 盘点中：`返回列表`、`录入实盘`、`取消盘点`、`确认差异`（主按钮）。还有未盘行时，`确认差异` 置灰，并在按钮左侧写明「还有 N 行未盘」；不弹阻断对话框。
  - 已完成、已取消：只有 `返回列表`。
- **基本信息**：所属仓库、盘点来源、发起人、发起时间固定；盘点商品占整行，展示 SKU 编码 + 名称 + 货主，不折叠成数量。
  - 来源为发现账实不符时，增加「发现环节」「关联原业务记录」；计划盘点显示 `-`。
  - 已完成时增加「差异确认人」「差异确认时间」；已取消时增加「取消人」「取消时间」「取消原因」（占整行）。
  - 盘点说明始终显示，占整行。
- **汇总卡**：进度条按「已盘行数 / 明细行数」，全部已盘转绿；数量清单放 SKU 数、明细行数、已盘行数、差异行数。差异行数大于 0 时用橙色，0 用默认色。
- **盘点明细页签**：表格上方放「全部 / 未盘 / 有差异」三个过滤按钮，过滤只影响表格，不写 URL。列包含盘点行号、库位、容器号、货主、商品、批次号、生产日期、有效期、品质、账面数量、实盘数量、实盘状态、差异数量、最后实盘人、最后实盘时间、差异原因说明、调整流水。实盘新增行在库位列加「实盘新增」标签；未盘行的实盘数量显示 `-`，实盘状态显示「未盘」。
- **SN 明细页签**：只有存在启用 SN 的盘点行时才显示；列为库位、商品、账面 SN、实盘 SN、多出、缺失。账面 SN 取创建时快照，不随实盘改变。
- **发现依据页签**：只有发现依据有内容时才显示，不带条数。按追加顺序展示发现环节、商品、库位、差异数量、说明、关联原业务记录、发现人、发现时间。
- **操作日志页签**：操作时间、操作、操作者、说明；按时间倒序。
- **只读**：盘点明细页签不提供行内编辑、删除、重录按钮；所有实盘录入从页头「录入实盘」进入 Sheet。
- **找不到记录**：单号不存在或不属于顶栏当前仓库时，整页显示「未找到盘点单」+「返回列表」。
- **图中省略**：页签右侧工具区、长文本省略、筛选按钮样式；列级规格见 Demo PRD 第 7 节。

## 创建计划盘点 Dialog

- **用途**：在本仓选择一个或多个 SKU，创建账面快照并进入盘点中。
- **关键要素**：标题「创建计划盘点」；核心提示「按库区只缩小候选；盘点范围仍是这些 SKU 在本仓全部存储、拣货、不良隔离库位」；货主、库区两个筛选；SKU 搜索与候选勾选列表；已选 SKU 及阻断原因；盘点说明；底部取消、创建。

```text
+-- Dialog sm:max-w-lg ------------------------------------------------------------------------+
| 创建计划盘点                                                                           [×] |
| 按库区只缩小候选；盘点范围仍是这些 SKU 在本仓全部存储、拣货、不良隔离库位。                  |
| 货主 [全部 v]                         | 库区 [全部 v]                                      |
| 盘点商品* [搜索 SKU                                                                    ]   |
| +-- 候选列表（可滚动） --------------------------------------------------------------------+ |
| | [ ] CABLE-01 线材                         C10028                                        | |
| | [x] LOT-DEMO-01 批次装                    C10028                                        | |
| | [x] SN-DEMO-01 序列装                     C10028                                        | |
| +------------------------------------------------------------------------------------------+ |
| 已选 2 个 SKU                                                                                |
| LOT-DEMO-01 批次装  C10028                                                                   |
| SN-DEMO-01 序列装   C10028                     |
| 盘点说明 [多行文本                                                                      ]    |
|                                                                    [取消] [创建计划盘点]     |
+----------------------------------------------------------------------------------------------+
```

**补充说明**：

- **候选范围**：本仓存储、拣货、不良隔离库位上实际数量大于 0 的 SKU，按货主、库区和 SKU 编码／名称搜索缩小；库区只影响候选列表，不影响建单后的盘点范围。
- **已选与阻断**：已选区逐个 SKU 列出阻断原因，可同时出现多条。一期唯一阻断是已在盘点中（列出盘点单号）；已有拣货、上架、返库任务不阻断建单，任务继续。有任一阻断时底部「创建计划盘点」不可用，整次不创建，不静默跳过 SKU。
- **必填**：至少选 1 个 SKU；未选时提交在字段下方显示错误。货主、库区、搜索都可不选。
- **不提供**「发现账实不符」来源选择；该来源只由 PDA 发起。
- **脏关闭**：已选 SKU 或已填说明时，点遮罩、Esc、关闭按钮或取消都先二次确认「离开后未保存的内容将丢失」。
- **成功后**：关闭 Dialog，Toast 显示新盘点单号并进入详情；列表刷新。
- **图中省略**：候选空态、搜索无结果、滚动高度；交互与文案见 Demo PRD 第 8.1 节。

## 实盘录入 Sheet

- **用途**：管理端对盘点明细逐行录入或重录实盘，可分次保存；可对快照外归属明确的实物新增账面 0 行。
- **关键要素**：右侧 880px `DetailSheet`；标题「录入实盘 · 盘点单号」；提示「可分次保存；SN 商品可逐件录入 SN，填写时条数须等于实盘数量」；明细表与「保存实盘（n 行）」；下方「新增实盘行」表单。

```text
+-- DetailSheet 880px --------------------------------------------------------------------------------+
| 录入实盘 · ST-20261015-0001                                                                   [×] |
| 可分次保存；SN 商品可逐件录入 SN，填写时条数须等于实盘数量，不填表示按数量盘点。                   |
| +-- Section 盘点明细 (flush) ------------------------------------------------ [保存实盘（3 行）] ---+ |
| | 行号 | 库位     | 商品              | 批次       | 品质   | 账面 | 实盘        | 差异 | 差异原因说明 | |
| | 1    | A-01-02 | CABLE-01 线材     | -          | 正常品 | 10   | [ 9       ] | -1   | [缺一件    ] | |
| | 2    | B-03-02 | SN-DEMO-01 序列装 | -          | 正常品 | 3    | [ 2       ] | -1   | [少一件    ] | |
| |      |         |                  |            |       |      | [SN清单多行] |      |             | |
| | 3    | B-03-03 | LOT-DEMO-01 批次装| LOT-202612 | 正常品 | 0    | [ 1       ] | +1   | [盘盈      ] | |
| +--------------------------------------------------------------------------------------------------+ |
| +-- Section 新增实盘行 ----------------------------------------------------------------------------+ |
| | 快照里没有、但货主和商品明确的实物，按账面 0 新增；认不出归属的去无主货登记。                     | |
| | 库位* [          ] | 商品* [选择 v]      | 品质* [正常品 v] | 实盘数量* [        ]             | |
| | 批次号* [        ] | 生产日期 [日期]     | 有效期 [日期]    | 实盘 SN [多行，条件显示]          | |
| | 差异原因说明 [占 2 列                                                            ]   [新增]     | |
| +--------------------------------------------------------------------------------------------------+ |
+------------------------------------------------------------------------------------------------------+
```

**补充说明**：

- **明细表**：行号右对齐；库位显示编码 + 用途，实盘新增行加标签；商品显示编码 + 名称；批次号、品质、账面只读；实盘与差异原因说明可编辑；差异由 `实盘 - 账面` 即时显示，正数带 `+`，负数带 `-`；未录入时差异显示 `-`。
- **SN 商品**：实盘数量下方出现 SN 多行输入；SN 清单可选，填写时条数须等于实盘数量且不得与其他行重复；不填表示按数量盘点，不按数量差额补造 SN。
- **保存**：只提交本次改动过的行；实盘数量为空表示本行未盘，不提交；已保存行清空输入不会撤销已保存的实盘。保存只记数，不改库存。
- **新增实盘行**：库位、商品、品质、实盘数量必填；启用批次或效期的商品，批次号必填；启用效期的商品，生产日期或有效期至少填一项，系统按商品保质期天数计算另一项，两项都可手动改，生产日期不得晚于有效期。库位不可为暂存位，且不得有另一货主的库存。
- **脏关闭**：有未保存改动或新增表单已填写时，关闭先二次确认。
- **图中省略**：滚动、条件字段显隐、日期自动计算提示；交互与文案见 Demo PRD 第 8.2 节。

## 差异确认 Dialog

- **用途**：主管在提交前查看盘盈、盘亏和品质变化摘要，确认后一次性调账并完成盘点。
- **关键要素**：标题「确认盘点差异」；提示「确认后按差异调整库存明细、SKU库存和 SN 库存，生成盘点调整流水，整单完成且不可恢复」；摘要块；负库存阻断提示；待核对解除提示；底部取消、确认差异。

```text
+-- Dialog sm:max-w-md ------------------------------------------------------+
| 确认盘点差异                                                        [×] |

| +-- 差异摘要 -----------------------------------------------------------+ |
```

**补充说明**：

- **前置**：只有全部明细行已盘时才允许打开；还有未盘行时页头按钮置灰，不进入本 Dialog。
- **摘要口径**：盘盈、盘亏按行数与数量合计；正常品变化、不良品变化按差异数量净额。全部无差异时显示「全部无差异，确认后只解冻」，不画四行摘要。
- **负库存阻断**：预演后 SKU 良品可用为负时，红色提示列出 SKU 与预演后数量，确认按钮不可用；实盘保留、单据仍盘点中，不自动退占、截零或完成盘点。
- **待核对解除**：本次盘点 SKU 存在待核对标记时，提示确认后解除；来源为发现账实不符但取消的，不解除。
- **重复确认**：提交一次生效；重复确认返回原结果，不重复增减库存。
- **图中省略**：提交失败后的状态变化提示；文案见 Demo PRD 第 8.3 节。

## 取消盘点 Dialog

- **用途**：终止本次盘点，不调账，只解除盘点冻结。
- **关键要素**：标题「取消盘点单」；提示「取消不调账，只解除盘点冻结；来源为发现账实不符的，SKU 仍保持待核对」；取消原因必填；底部取消、取消盘点。

```text
+-- Dialog sm:max-w-md ------------------------------------------------------+
| 取消盘点单                                                          [×] |
| 取消不调账，只解除盘点冻结；来源为发现账实不符的，SKU 仍保持待核对。      |
| 取消原因*                                                               |
| [请输入取消原因                                                      ]   |
|                                              [取消] [取消盘点]           |
+--------------------------------------------------------------------------+
```

**补充说明**：

- **必填**：取消原因不能为空，字段下方红字提示「请填写取消原因」。
- **结果**：状态变为已取消，记录取消人和取消时间；未核实差异的待核对标记保留；已冻结 SKU 解除盘点冻结。
- **不可恢复**：已取消不能恢复到盘点中，需要重盘时新建盘点单。
- **脏关闭**：已填原因时关闭先二次确认。
- **图中省略**：状态已变化时的提示；文案见 Demo PRD 第 8.4 节。

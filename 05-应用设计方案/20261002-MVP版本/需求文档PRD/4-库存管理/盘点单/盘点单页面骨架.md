# 盘点单页面骨架

> 文档版本：WMS-V0.1｜日期：2026-10-15｜状态：文档初稿，待演示验收。规则见[盘点单主PRD](盘点单主PRD.md)，字段见[盘点单详细稿](../../../字段清单合集/04-库存与库内/盘点单/盘点单（详细稿）.tsv)，PDA布局见[PDA盘点页面骨架](../../7-PDA作业端/盘点作业/PDA盘点页面骨架.md)。

## 页面与弹窗清单

| 页面／容器 | 路由 | 用途 |
| --- | --- | --- |
| 盘点单列表 | `/wms/inventory/counts` | 状态查询、计划盘点建单 |
| 盘点单详情 | `/wms/inventory/counts/:stocktakeNo` | 快照、实盘、差异、SN和操作日志 |
| 创建计划盘点Dialog | 列表打开 | 选择本仓SKU并建单 |
| 实盘录入Sheet | 详情打开 | 管理端录入或重录实盘 |
| 差异确认Dialog | 详情打开 | 主管确认调账 |
| 取消Dialog | 详情打开 | 主管填写原因后取消 |

- 盘点中显示“录入实盘”、“取消”、“确认差异”；按钮不可用时，在按钮附近预留原因提示位置，具体校验见Demo版PRD。
- 已完成、已取消只读。发现账实不符来源展示原业务记录链接；计划盘点不显示发现环节。

## 创建、确认与取消

创建Dialog包含库区、货主、SKU筛选区和已选SKU列表。差异确认Dialog按盘盈、盘亏、正常／不良变化分组展示确认摘要。取消Dialog包含取消原因和不调账提示；字段必填性、阻断和提交行为见Demo版PRD。

# 字段清单维护说明

规则以上位[全局背景信息](../../../01-全局背景信息/)为准；字段清单承接对象、取值和关联，动作校验见[系统架构](../系统架构设计/README.md)及[PRD](../需求文档PRD/README.md)。文件名沿用现有目录，不因术语“货位”改为“库位”批量迁移路径。

| 目录 | 2026-10-14状态 | 维护方式 |
| --- | --- | --- |
| 基础资料 | 多数对象已有初稿和详细稿；与入库关联的仓库、库位、商品字段已修正 | 本轮同步仓库暂存预占、单位和默认收货方式，删除库位混放开关并补货主占用展示，统一商品尺重单位与新品回写；仓库、库位、商品三组字段初稿与详细稿成对一致；其他基础资料未宣称全部成对一致 |
| 入库管理 | 入库单、收货记录、上架单、入库异常、新品维护、无主货六类对象，12份TSV同步 | 详细稿维护13列；初稿为详细稿5列投影，字段顺序、名称、类型、来源和描述一致，不独立修改 |
| 出库管理 | 6份现有初稿 | 本轮只读，原文件保留；后续按出库宏观架构补详细稿和PRD |
| 库存与库内 | 6份现有初稿 | 本轮只读，原文件保留；后续按两层库存账、SN与流水补详细稿和PRD |
| 系统集成与对接 | 消息记录、回传记录仅有表头；4份映射表只有表头，4份JSON只是占位 | 尚未定义完整字段与可运行样例，不能称已完成映射或联调 |
| 公共能力 | 用户、角色、操作记录初稿 | 详细字段及页面待补 |
| 退货 | 尚无独立字段目录 | 退货单、退货收货与异常待补；共用上架单已包含退货来源关联 |

入库表中“新增页”表示对象生成或作业录入阶段，不表示管理端提供手工新增该单据。收货记录和入库异常在入库单详情内展示；上架实际明细只有提交前可编辑。字段表中的“—”表示不适用，不用空白猜含义。

单号使用IB／RC／EX／PA／NS／UG等英文前缀、UTC日期、全系统同前缀同日序列，见[单据术语与生成规则](../../../01-全局背景信息/08-单据术语与生成规则.md)。入库单完成时间与取消受理时间分别记录；人工收货完结标记不替代由数量推导的行收货是否完结。SN收货与上架行均保留关联，以支持已确认的单件位置追溯。

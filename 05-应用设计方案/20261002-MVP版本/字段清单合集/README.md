# 字段清单维护说明

规则以上位[全局背景信息](../../../01-全局背景信息/)为准；字段清单承接对象、取值和关联，动作校验见[系统架构](../系统架构设计/README.md)及[PRD](../需求文档PRD/README.md)。文件名沿用现有目录，不因术语“货位”改为“库位”批量迁移路径。

| 目录 | 当前状态（2026-10-15） | 维护方式 |
| --- | --- | --- |
| 基础资料 | 多数对象已有初稿和详细稿；容器、容器类型已补初稿和详细稿；与入库关联的仓库、库位、商品字段已修正 | 本轮同步仓库暂存预占、单位和默认收货方式，删除库位混放开关并补货主占用展示，统一商品尺重单位与新品回写；容器按容器档案与库存维度设计落字段；仓库、库位、商品三组字段初稿与详细稿成对一致；其他基础资料未宣称全部成对一致 |
| 入库管理 | 入库单、收货记录、上架单、入库异常、新品维护、无主货六类对象，12份TSV同步 | 详细稿维护13列；初稿为详细稿5列投影，字段顺序、名称、类型、来源和描述一致，不独立修改 |
| 出库管理 | 6类对象，12份TSV | 详细稿维护13列，初稿为5列投影；必填性统一为是／否／条件必填／不适用（系统赋值）四值，作业类对象不提供编辑页，「编辑页」列一律只读；指定实物、原单份额、实拣归属与有效复核量已补，规则见出库PRD套件 |
| 库存与库内 | 6类对象，12份TSV | SKU库存、批次库存、SN台账、库存流水、盘点单、移库作业均以13列详细稿为权威版本；初稿为5列投影。品质转换不另建对象，结果进入批次库存、SN台账和库存流水 |
| 系统集成与对接 | 商品/货主/入库/退货映射与样例、出库指令映射与样例已补；上游消息记录、回传记录字段已补齐 | 沿用信封与版本规则；当前前端Mock采用表单，不提供JSON上传或真实HTTP接口；系统集成独立页面PRD仍待补 |
| 公共能力 | 操作记录初稿与详细稿 | 一期不做用户与角色；操作记录页面已实现，独立主PRD与页面骨架待补 |
| 退货 | [退货管理字段目录](05-退货管理/)：退货单、退货收货记录、退货异常三组对象，各有初稿和详细稿 | 详细稿维护13列；初稿为详细稿前5列投影；共用上架单继续维护退货来源、RR关联和品质分流字段 |

作业类对象的「新增页」表示对象生成或作业录入阶段，不表示管理端提供手工新增该单据；「编辑页」对不提供编辑页的对象一律写「只读」，可改通道写在字段说明里，不要用「可改」表达系统带入后的重算。必填性统一用四值：`是`（录入时必须）、`否`（可空）、`条件必填`（按类型、商品配置或容器触发，条件写在说明里）、`不适用（系统赋值）`（系统生成、汇总、计算、带出或分配）。收货记录和入库异常在入库单详情内展示；上架实际明细只有提交前可编辑。字段表中的“—”表示不适用，不用空白猜含义。

单号使用IB／RC／EX／PA／NS／UG等英文前缀、UTC日期、全系统同前缀同日序列，见[单据术语与生成规则](../../../01-全局背景信息/08-单据术语与生成规则.md)。入库单完成时间与取消受理时间分别记录；人工收货完结标记不替代由数量推导的行收货是否完结。SN收货与上架行均保留关联，以支持已确认的单件位置追溯。

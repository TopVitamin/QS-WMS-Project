## 书写约定

1. 每条字段注明：所属对象、是否必填、值域来源（FR 编号或 03 状态表）、演示样例（标注「课程沙盘」）。
2. 新增枚举须先改 [03-单据与状态流转](../系统架构设计/03-单据与状态流转.md)，再回本目录补展示名。
3. 数量类字段不得与 [02-实体§四](../系统架构设计/02-实体对象关系.md) 公式冲突；预占/可用/实际命名与 INV-FR-002 一致。

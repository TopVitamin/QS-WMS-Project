库存配合字段见[SKU库存详细稿](<../04-库存与库内/SKU 库存/SKU 库存（详细稿）.tsv>)，包括品质分行的数量及盘点／暂停分配提示来源；可用数量不得为负，失败提交整次阻断。

指定实物挂出库单，原单份额与实拣归属挂拣货任务；复核关联实拣归属并维护有效量。返库按应返库行保存多次落位与对应SN，整单提交才更新库存，不新增业务单据。

指令的预期对象版本与处理前后对象版本落在[上游消息记录](<../05-系统集成与对接/上游消息记录/上游消息记录（详细稿）.tsv>)，出库单不另设版本字段；结果回传一期只含各行实发、未发，复核容器明细留在仓内复核记录。

# 消息信封与公共字段（一期 Mock）

下列字段为各类 Mock → WMS 消息的**公共壳**，WMS 落库到「上游消息记录」；语义以 [06-接口与OMS Mock消息设计](<../../../系统架构设计/06-接口与OMS Mock消息设计.md>) 第二节为准。具体列名已落到[上游消息记录（详细稿）](../上游消息记录/上游消息记录（详细稿）.tsv)和[回传记录（详细稿）](../回传记录/回传记录（详细稿）.tsv)。

| 逻辑名 | 说明 |
| --- | --- |
| 消息来源 | 固定为 OMS Mock 演示来源标识 |
| 消息标识 | 来源内唯一；重发同标识同内容返回原结论 |
| 消息类别 | 基础资料推送、新建业务指令、明细变更、出库取消等 |
| 业务对象键 | 来源 + 业务类型 + 上游指令号（资料类按货主/商品身份） |
| 预期对象版本 | 首次为 0；变更/取消须与 WMS 当前版本一致 |
| 消息体 | 类别相关载荷，字段见 `映射/` 与对应业务清单 |
| 接收时间 | WMS 接收时刻（UTC 存储） |
| 处理结论 | 接受 / 拒收及原因类别 |
| 处理前后对象版本 | 接受后推进版本；拒收不推进 |

WMS → Mock 的回传使用「回传记录」+ 结果序号，见 [回传记录（初稿）](../回传记录/回传记录（初稿）.tsv)。

# 库存与库内字段清单

本目录维护库存管理六类对象的字段事实。13列详细稿是权威版本；同名初稿只保留“字段所属分组、字段名称、字段类型、字段来源、字段说明／描述”五列，由详细稿投影，不独立修改。

| 对象 | 业务唯一性或识别 | 详细稿 | 对应PRD |
| --- | --- | --- | --- |
| SKU库存 | 仓库＋货主＋SKU | [SKU库存详细稿](SKU%20库存/SKU%20库存（详细稿）.tsv) | [库存查询](../../需求文档PRD/4-库存管理/库存查询/库存查询主PRD.md) |
| 库存明细 | 仓库＋货主＋SKU＋库位＋批次＋品质 | [库存明细详细稿](库存明细/库存明细（详细稿）.tsv) | [库存查询](../../需求文档PRD/4-库存管理/库存查询/库存查询主PRD.md) |
| SN库存 | 货主＋SKU＋SN | [SN库存详细稿](SN%20库存/SN%20库存（详细稿）.tsv) | [库存查询](../../需求文档PRD/4-库存管理/库存查询/库存查询主PRD.md) |
| 库存流水 | 库存流水号 | [库存流水详细稿](库存流水/库存流水（详细稿）.tsv) | [库存流水](../../需求文档PRD/4-库存管理/库存流水/库存流水主PRD.md) |
| 盘点单 | 盘点单号；按仓库＋SKU建单 | [盘点单详细稿](盘点单/盘点单（详细稿）.tsv) | [盘点单](../../需求文档PRD/4-库存管理/盘点单/盘点单主PRD.md) |
| 移库作业 | 移库作业号；一次PDA提交一条记录 | [移库作业详细稿](移库作业/移库作业（详细稿）.tsv) | [移库作业](../../需求文档PRD/4-库存管理/移库作业/移库作业主PRD.md) |

品质转换不是单据，也不另建字段对象：转换前后的数量和SN位置分别体现在库存明细、SN库存与库存流水中。订单占用的业务来源在出库单明细，拣货分配的来源在拣货任务；库存对象只维护合计与追溯关系，不复制第二套占用或分配明细。

标记约定：明细分组字段（盘点明细、移库明细）的「列表展示」指详情页明细表是否显示该列，单头列表只显示单头和汇总字段。所属仓库、当前仓库由顶栏限定，列表和筛选区都不重复展示，只在详情展示。「可筛选」只标Demo版筛选区实际提供的条件；盘点状态、库位用途等以标签或小字展示的字段不设筛选。

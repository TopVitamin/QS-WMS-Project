# QS-WMS 海外仓管理系统 Demo

海外仓 WMS 后台 + PDA 作业端的前端原型。纯前端，数据存在浏览器 localStorage，不需要后端。

## 运行

```bash
npm install
npm run dev
```

打开终端里显示的地址：

- WMS 后台：`http://localhost:5173/#/wms/dashboard`
- PDA 作业端：`http://localhost:5173/#/pda`（后台右上角"打开 PDA"会在新标签页打开）

构建静态文件：`npm run build`，产物在 `dist/`，可直接部署到任意静态服务器。

## 演示闭环

1. 后台"入库单"里找一张"已签收"或"收货中"的单子，记下单号。
2. 打开 PDA → 收货：扫描入库单号（可点下方模拟扫码按钮）→ 扫 SKU → 录良品/不良品数量 → 确认。
3. PDA → 上架：选择待上架的 SKU → 扫推荐货位 → 确认数量。
4. 回到后台，入库单状态、已收数量、库存查询会同步变化（两个标签页实时同步）。

右上角用户菜单里有"重置演示数据"。

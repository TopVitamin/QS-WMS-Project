# QS-WMS 海外仓管理系统 Demo

海外仓 WMS 后台 + PDA 作业端的前端原型。纯前端，数据存在浏览器 localStorage，不需要后端。

## 运行

```bash
npm install
npm run dev
```

打开终端里显示的地址：

- WMS 后台：`http://localhost:5173/#/wms/dashboard`
- PDA 作业端：`http://localhost:5173/#/pda`（后台右上角"打开 PDA"会在新标签页打开）

构建静态文件：`npm run build`，产物在 `dist/`，可直接部署到任意静态服务器。

## 演示闭环

1. 后台"入库单"里找一张"待收货"或"收货中"的单子（如 `IB-20261002-0001`），记下单号。
2. 打开 PDA → 收货：扫入库单号 → 扫容器（箱唛/托唛）→ 扫商品录入良品/不良/拒收 → 加入本容器。一个容器装满了点「新增容器」继续扫下一个；最后「提交收货」，可勾选部分容器分批提交，一次提交生成一条收货记录。录入随时暂存在本机，刷新后可继续。
3. PDA → 上架：选上架单（可扫上架单号、容器号或商品条码）→ 扫目标货位 → 保存落位（只记进度）→ 全部落完后「提交上架单」（库存从暂存库位移到目标货位）。不良品只能放不良隔离货位。
4. 回到后台，入库单状态、收货记录、上架单、库存查询会同步变化（两个标签页实时同步）。
5. 后台"退货单"里选一张待收货退货单，走「Web 端退货收货」或 PDA 收货；提交后生成退货收货记录和共用上架单，上架提交后回写退货单进度与结果。

没有扫描枪时，每个扫码步骤下方都有「模拟扫码」候选值；扫码框右侧可切换键盘输入。右上角用户菜单里有"重置演示数据"。

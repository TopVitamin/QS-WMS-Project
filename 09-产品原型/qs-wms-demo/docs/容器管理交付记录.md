# 容器管理交付记录

2026-10-22，按用户确认的“容器档案＋库存维度”方案，先落首版容器管理页面和作业联动。背景见[容器档案与容器库存](../../../05-应用设计方案/20261002-MVP版本/系统架构设计/07-容器档案与容器库存.md)。

## 已完成

| 能力 | 结果 |
| --- | --- |
| 容器档案 | `ContainerMaster`：容器号、类型、来源、所属货主、仓库、状态、容量、当前库位、父容器、备注、最近扫描 |
| 容器管理列表 | 基础资料 → 容器管理；按容器号、类型、货主、状态、当前库位筛选；显示内容摘要、最近扫描时间 |
| 容器详情 | 基本信息、容量与备注、内容明细、关联单据、操作记录 |
| 新增/编辑 | 新增可循环/内部容器；编辑类型、容量、父容器、备注；容器号和货主创建后只读 |
| 停用/启用 | 列表和详情可停用/启用；使用中或已有库存的容器改为空闲会被拒绝 |
| 收货自动建档 | 入库/退货首次扫容器自动建档为“收货中”；停用、货主不符、占用中的容器阻断 |
| 上架回写 | 上架提交后更新容器状态：整箱落一个库位为“在库”并记当前库位，拆散为“已释放” |
| 种子 | 从已有收货、上架、复核记录回放容器档案；补常用容器容量 |
| 测试 | 容器新增/编辑/停用、收货自动建档、上架回写、停用/货主不符阻断 |

# 一期演示走查脚本

> 用途：按[一期完成判断标准](../../../01-全局背景信息/03-阶段规划与一期交付标准.md#三一期完成的判断标准)逐项演示。数据为本机 Mock 种子，页面数量以当前种子为准；本文只写操作路径和应看到的结果，不把课程样例当成真实仓库制度。

## 1. 演示前准备

1. 进入 `09-产品原型/qs-wms-demo`，执行 `npm run dev`，打开 WMS 后台和 PDA 两个标签页。
2. 右上角用户菜单执行一次“重置演示数据”，清掉本机草稿和旧持久化数据。
3. 确认顶栏仓库、语言、时区可切换；PDA 首页显示入库、退货、库内、出库四组入口。

## 3. 关键案例

| 案例 | 操作 | 预期 |
| --- | --- | --- |
| 正常入库分批收货 | 打开美西 `IB-20261002-0003`，Web 端或 PDA 分两次收货，第二次提交后确认收货完结 | 实收/拒收累计正确；未收转最终短少；收货暂存库存增加；生成按容器×品质的上架单 |
| 全拒收零实收 | 打开已取消的全拒收单 | 单据与明细已取消；保留收货记录和入库异常；不生成上架单和入库库存 |
| 多容器收货 | PDA 收货扫两个容器，分别录良品/不良品，一次提交 | 生成一条收货记录、按容器×品质多张上架单；已用容器不能在本单重复 |
| 新品阻断 | 扫到未维护 SKU | 阻断该 SKU 收货，完成量方后可继续；同单其他 SKU 不受影响 |
| 无主货 | PDA 或管理端登记无主货 | 只登记、暂存，不生成入库单或库存；认领入口不存在 |
| 上架分次保存 | PDA 上架按推荐库位逐站，保存后刷新，再提交整单 | 保存不动库存；提交后暂存减、目标位增；同 SKU 不同批次不串行 |
| B2C 出库 | 美西 B2C 单分配、PDA 拣货、复核、确认出库并登记交接 | 拣货即下架到出库暂存；复核不动库存；确认出库扣暂存并形成交接和结果 |
| FBA 缺量 | 打开 FBA 缺量单，实拣复核后确认出库 | 实发小于需求，未发为缺量；再次确认不重复扣库 |
| 拣后取消返库 | 打开已拣后取消单，完成返库上架 | 原单已取消；返库单完成后库存回目标位；库存流水成对 |
| 盘点差异 | 管理端或 PDA 录实盘，主管确认差异 | 确认前只记实盘；确认后按差异调账并写盘点调整流水；待核对解除 |
| 库存品质转换 | 库存明细发起在库受损转换 | 正常品减少、不良品增加，成对流水；可用可为负 |
| 退货三类来源 | 美西客户退货、派送失败；德国平台仓退件 | 按退货单收货，生成退货收货记录、异常和共用上架单；上架提交后回写进度 |
| 退货多容器与 SN | PDA 选退货单，扫两个容器；SN 商品扫原出库 SN 和不一致 SN | 多容器生成一条退货记录；不一致 SN 只能进拒收 |
| OMS Mock | 入库 Mock 新建/变更/取消，出库 Mock 新建/变更/取消，退货 Mock 预报 | 重复消息不重复建单；拒收有原因；结果可重试；资料推送样例可在字段样例中核对 |

## 5. 预期库存核对

每个作业完成后，用库存查询按“仓库＋货主＋SKU＋库位＋批次＋品质＋容器”核对：

- 收货确认：收货暂存库位库存增加，实收＝良品＋不良品；拒收不进库存。
- 上架提交：来源暂存减少、目标库位增加，总实际不变；保存未提交不动库存。
- 拣货：来源库位减少、出库暂存增加；确认出库：出库暂存减少，预占释放/扣减。
- 返库上架：出库暂存减少、目标库位增加，总实际不变。
- 盘点确认：按实盘差异调整；确认前库存不变。
- 品质转换：同库位正常品减少、不良品增加，总实际不变。
- 退货收货：退货暂存增加；上架提交后移到目标位；不一致 SN 只记拒收，不形成库存。

库存流水应能与上述动作一一对应；重复提交、刷新、切换仓库后不得重复增减。

- 独立到货登记：一期不做，到货识别在收货环节完成。

- 计费结算、系统参数、FBA 退货、无主货认领、报损/销毁。

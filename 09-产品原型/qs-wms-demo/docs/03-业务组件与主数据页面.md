# 业务组件与主数据页面

> 沉淀自仓库、库区、货位、商品、货主、物流承运商、物流渠道七个主数据模块和入库单。新页面优先复用本文的组件、hooks 与路由/页签约定；视觉 token、显示规则与交互规则见[《02-设计规范》](02-设计规范.md)。写《前端 Demo 版 PRD》时的布局硬规则见[《需求文档 PRD / AGENTS.md》](../../../05-应用设计方案/20261002-MVP版本/需求文档PRD/AGENTS.md)。

## 1. 主数据页面结构

| 页面 | 路由模式 | 页签标题（i18n） | 样板 |
| --- | --- | --- | --- |
| 列表 | 菜单 path，如 `/wms/master/warehouses` | 菜单 `titleKey`（`PageContainer title={t('menu.*')}`，勿另起 `listTitle`） | `warehouse-list-page.tsx`、`location-list-page.tsx` |
| 新增 | `…/new`（字面量，排在 `:code` 前） | 页签 `*.tabCreate`、页头 `createTitle`（须带对象，如「新增仓库」）；列表主按钮用 `*.create`（统一「新增」） | `warehouse-create-page.tsx` |
| 详情 | `…/:code` | 页签固定文案 `*.tabDetail`；页头 `<DetailTitle title={t('*.detailTitle')} code status />` | `warehouse-detail-page.tsx` |
| 编辑 | `…/:code/edit` | 固定文案 `*.tabEdit` | `warehouse-edit-page.tsx` |

**例外**：货主按其 PRD 不提供新增与独立编辑路由，编辑走详情同路由 `?edit=1`；承运商、渠道按 PRD 用弹窗维护（渠道无独立详情路由，点编码打开查看弹窗）。

**页签**：在 `config/page-tabs.ts` 的 `resolvePageTab` 为子路由注册**完整 pathname**，不要复用列表 path。`WmsLayout` 只调用 `resolvePageTab`。

**列表「新增」 vs 页签文案**（勿混用同一 key）：

| 场景 | i18n key | 中文示例 |
| --- | --- | --- |
| 列表页头主按钮 | `masterWarehouse.create` 等 | 新增 |
| 顶栏页签 + 新增页 `PageContainer` 标题 | `*.tabCreate`、`*.createTitle` | 新增仓库 / 新增库区 / 新增货位 |

**列表页头**：按 PRD，`新增`（primary，`Plus`）在左 + `导出`（outline）在右；无新增的模块（货主、商品）只有导出。

## 2. 布局与字段展示

| 区域 | 约定 |
| --- | --- |
| 列表 | `PageContainer fill` + 筛选 `Panel` + 表格 `Panel`；`FilterBar` 固定 6 列栅格：常显最多 5 个筛选项 + 第 6 列查询/重置；第 6 个及以后才放 `advanced`。主数据列表无 `StatusTabs`、无行勾选 |
| 列表列 | 编码列 `pin: 'left'`（前面可有所属仓库、货主等上下文列）；关联对象用 `<CodeName>`；操作列 `<RowActions>`：编辑 + 启用/停用（停用标 `danger`） |
| 详情 | `<DetailTitle>` + `<MasterDetailActions>`；每组 `<Section>` + `Descriptions columns={4}`；子表用 `<Section flush>`；最后 `<MasterAuditPanel>` |
| 新增/编辑 | 共享 `*-form-fields.tsx`（`mode: 'create' \| 'edit'`）；每组 `<Section>` + `<FormGrid>` + `<FormField>` |
| 使用状态 | **不进新增/编辑表单和维护弹窗**：新建默认启用；启停只在列表操作列与详情页头，经 `use*MasterStatusToggle` 二次确认和停用前校验 |
| 只读系统字段 | 编辑时不可改的编码、上游标识、同步时间等用 `<Input readOnly>`（自动灰底）；需要格式化的值先格式化 |
| 必填 / 报错 | `<FormField required error={fieldError('key')}>`：红色 `*`，错误在字段下方 |
| 占位提示 | 可编辑 `Input`/`Textarea`：编码/名称用模块 `*Placeholder`，其余 `common.inputPlaceholder`；`OptionSelect` 默认 `common.selectPlaceholder`；只读字段不设 placeholder |

## 3.1 跨模块复用（hooks / lib / config）

| 能力 | 路径 | 用法 |
| --- | --- | --- |
| 列表 draft / filters | `hooks/use-list-filters.ts` | `const { filters, draft, setDraft, applySearch, reset } = useListFilters(empty)` |
| 新增/编辑取消 | `hooks/use-master-discard-navigate.ts` | `useMasterDiscardNavigate('masterWarehouse')` → `leave(path, dirty)` |
| 启用/停用 | `hooks/use-master-usage-status-toggle.ts` | 模块 hook（`use*MasterStatusToggle`）内调用；停用前校验用 `beforeDisable` |
| 表单字段错误 | `hooks/use-master-form-field-error.tsx` | `useMasterFormFieldError(scope)` → 作为 `FormField` 的 `error` |
| 重置演示数据 | `hooks/use-reset-demo.ts` | 带二次确认，顶栏与命令面板共用 |
| 筛选常量 | `lib/master-data.ts` | `FILTER_ALL`、`FILTER_YES` / `FILTER_NO`、`matchYesNo`、`masterCompositeRowId`、`sortByUpdatedAtDesc` |
| 文字样式与占位 | `lib/typography.ts` | `textLink`、`textCode`、`EMPTY_TEXT`、`codeNameText` |
| 状态色 | `config/status.ts` + `lib/tone-styles.ts` | 各状态/枚举的 `*Meta`；`toneSurfaceClass` / `toneDotClass` / `toneTextClass` |
| 地址与国家 | `lib/warehouse-master.ts` | `formatFullAddress`、`countryLabelKey` |

i18n 命名空间为 `masterWarehouse` / `masterZone` / `masterLocation` / `masterSku` / `masterCustomer` / `masterCarrier` / `masterChannel`（`MasterDataI18nScope`），须包含 `backToList`、`edit`、`enableAction` / `disableAction`、`discard*`、`statusChangeSuccess`、`error.*`、启停确认文案。

**仍按模块保留**：`*-form-fields.tsx`、承运商/渠道/商品条码弹窗（`pages/wms/master/`）、`lib/*-master.ts` 里的校验、路径与空表单初始值、列表页的 `match*` 筛选函数。

## 5. 写新主数据模块时的检查单

1. 在 `page-tabs.ts` 增加 `new` / `:code` / `:code/edit` 解析与页签文案 key。
2. 在 `router.tsx` 注册路由，顺序：`new` → `edit` → `detail`。
3. Demo PRD 写清：FilterBar 常显与 `advanced`、详情 4 列、表单 4 列、状态只在列表与详情页头启停。
4. 主 PRD / 字段 TSV 同步「新增页可编辑列」。
5. `zh-CN.ts` / `en-US.ts` 同步 `detailTitle`、`tabDetail`、`tabEdit`、`tabCreate` 等文案。
6. 跑 `npm run lint`（含设计规范检查）。

## 6. 与业务单据页面的差异

| 项 | 业务单据（入库单等） | 主数据 |
| --- | --- | --- |
| `StatusTabs` | 常用 | 不用 |
| 筛选 | 6 列；可把条件写进 URL | 6 列 |
| 行勾选 | 按需 | 不用 |
| 主详情 | 独立路由页（标题「入库单 · 单号」） | 独立路由页（标题「查看××详情 · 编码」） |
| 子记录 | 点编号开 `DetailSheet` | 子表在详情页 `Section flush` 里 |

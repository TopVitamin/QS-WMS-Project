# QS-WMS 海外仓原型 Demo 项目规划

## 1. 这个 Demo 要做成什么样

一个可以直接打开演示的海外仓 WMS 前端原型，包含两端：

- **WMS 后台**（`/#/wms/*`）：仓库主管、仓管员在电脑上使用，负责单据管理、库存查询、波次调度、计费。
- **PDA 作业端**（`/#/pda/*`）：一线作业员在手持终端上使用，负责签收、收货、上架、拣货、移库、盘点。

两端共用一个前端 mock 数据库（Zustand + localStorage）。在 PDA 上完成收货、上架，切回 WMS 后台，入库单状态和库存会同步变化。演示时可以跑通完整的业务闭环。

不做的事：不接真实后端，不做登录鉴权，不做货主 OMS 端（货主侧的数据用 mock 预置）。

## 3. 国际化设计（全局约定）

| 维度 | 做法 |
|---|---|
| 多语言 | 所有界面文字走 `t('key')`，禁止写死中文。语言包在 `src/i18n/locales/` |
| 多币别 | 金额一律存 `{ amount, currency }`。显示用 `<Money>` 组件：显示原币，悬停可看折算后的"显示币别"金额。顶栏可切换显示币别 |
| 多时区 | 时间一律存 UTC ISO 字符串。显示用 `<DateTime>`，默认按"当前仓库时区"，顶栏可切换为"本地时区" |
| 多单位 | 重量存克、尺寸存厘米。显示用 `<Weight>` / `<Dimension>`，按仓库默认单位制（美国仓英制，其他公制），可手动切换 |
| 多仓 | 顶栏仓库切换器，切换后所有业务数据按 `warehouseCode` 过滤 |

预置 5 个仓库：美西洛杉矶 `US-LA-01`、美东新泽西 `US-NJ-01`、德国法兰克福 `DE-FRA-01`、英国伦敦 `UK-LON-01`、日本东京 `JP-TYO-01`。

## 5. 里程碑

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| **M0 骨架**（本次） | 工程搭建、设计规范、后台布局（侧边栏/顶栏/多页签）、PDA 布局、mock 数据库、入库单列表样板、库存查询、PDA 收货和上架 | PDA 收货上架后，WMS 入库单状态、库存查询数据同步变化 |
| M1 入库闭环 | 新建入库单、签收、收货记录、上架任务、PDA 签收 | 入库单从"待入库"走到"已完成" |
| M2 库内 | 库存流水、移库单、盘点单（盲盘/明盘）、PDA 移库/盘点/查询 | 盘点差异审批后库存平账 |
| M3 出库 | 出库包裹、波次生成、PDA 拣货、复核打包称重、出库交接 | 包裹从"待打单"走到"已发货"，库存扣减 |
| M4 扩展 | 计费、基础资料、无主件认领、退件 | 费用流水按币别展示 |
| M5 打磨 | 语言包补全、演示脚本、演示数据重置 | 中英文切换无遗漏 |

## 6. 目录结构

```
src/
  app/                路由、全局 Provider
  i18n/               i18next 初始化与语言包
  types/              业务类型（入库单、SKU、货位、库存……）
  mock/               种子数据 + Zustand mock 数据库（含业务动作）
  stores/             全局设置（仓库/语言/币别/时区/单位）、多页签
  config/             菜单配置、状态枚举与颜色映射
  lib/                utils、格式化工具（金额/时间/重量）
  components/
    ui/               shadcn 原始组件（尽量少改）
    biz/              业务通用组件：DataTable、FilterBar、StatusBadge、Money……
  layouts/            WmsLayout、PdaLayout
  pages/
    wms/              后台页面，按模块分目录
    pda/              PDA 页面
```

## 7. 让 AI 继续生成页面的方式

1. 开发规范写在 `docs/02-设计规范.md`，并通过 `.cursor/rules/qs-wms-frontend.mdc` 自动生效。
2. 新增列表页：照着 `pages/wms/inbound/inbound-list-page.tsx` 的结构写。
3. 新增 PDA 流程：照着 `pages/pda/receive-page.tsx` 的结构写。
4. 新增业务数据：先在 `types/` 定类型，再在 `mock/seed.ts` 造数据，最后在 `mock/db.ts` 加业务动作。

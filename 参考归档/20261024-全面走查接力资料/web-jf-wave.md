# 波次发货>波波次业务设置、生成波次

更新于 2026年06月04日

复制链接

**一、定义**

当仓库订单比较多，简易打单发货流程效率达到上限，可以根据波次规则，把需要处理的订单按照规则分成不同的拣货任务，每一个任务称为一个波次，可以将不同波次分配给不同的拣货员处理，拣货、二次分拣、扫描包装、扫描发货等，提高效率。

波次的处理流程：

![](https://download.jfwms.com/prod/static/back_help/img/74/20250610152607/ed19586f00576ef260b4058f4e5cbe9e.jpg)

**二、操作路径**

**第一步：波次业务设置**

**操作路径：设置** >业务设置>波次设置>开启波次规则>多品混包波次设置>边拣边分（ **波次拣货有边拣边分和先拣货后二次分拣**）

![](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260601072605/51de5d1af7bf7c245699313cc4a68b4e.png)

1.通用设置：

波次分批规则：每个波次中的包裹属于相同物流组

拣货单设置：可以按商品维度、也可以按包裹维度，拣货单纸张大小、拣货单信息

![](https://download.jfwms.com/prod/static/back_help/img/74/20250610152315/96d332e6826bd60d1cedd535d520ce8f.jpg)

2.单品波次设置：

![](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260601072641/fc3513868f82b107cb071d0bdbcd178d.png)

单品合并：开启后，将把单品单数包裹和单品多数包裹在一起拣货

波次最大包裹里：每次生成波次，多少订单在一起

面单打印方式：可以选择扫描拣货单批量打印，或者扫描商品标签逐个打印

立即发货：如果勾选立即发货，那么打印面单就自动把订单提交发货状态

SKU核对数量：允许卖家手动输入sku核对数量，关闭后就需要扫描数量

3.多品混包波次设置：

![](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260601072702/673c264aebbcc19634c1655c1d1dcc00.png)

波次最大包裹量：每一波次多少包裹，需要根据分拣架的最大处理量来设置。

分拣架设置：统一拣货的如果用拣货车，然后需要把混在一起的货按照包裹分别区分，这里需要分拣架，分拣架设置就是，需要设置有多少行、多少列，这样分拣货时，拿到的商品显示第一号框，那么只需要把商品放入1号框即可。

分拣架设置之后，可以设置打印分拣框标签，贴到对应的分拣筐

分拣方式有2种：

边拣边分：边拣货，边按包裹对应的框放入商品。

先拣后分：先拣货，后二次按包裹分拣，放对应的商品。

打印面单方式有3种：

扫描拣货单批量打印：出面单速度快

扫描分拣筐号逐个打印：扫描分拣筐的标签逐个打印

扫描商品标签逐个打印：准确率高

立即发货：当勾选了立即发货，打印面单就会自动把包裹提交发货状态。

4.爆款包裹的波次设置

![](https://wms-1382655522-cos.jfwms.com/prod/temp/system/img/143/20260601072726/b4364cb968a06ebc2f6bcb662acd4664.png)

开启爆款：当节日大促时，经常设置活动，订单信息一致性程度高，出单量大，这个时候为了提高拣货效率，可以开启爆款包裹波次设置。

波次最大的爆款处理量：根据仓库处理能力大小。

面单打印类型：立即发货，打印面单，自动把订单提交发货状态。

第二步：生成波次

**可以筛选仓库、物流、平台等条件，生成拣货波次**

**操作路径：** 出库>波次管理>生成波次>设置波次条件>生成

# 出库管理页面骨架

版本：WMS-V0.1｜2026-10-15。规则见[主PRD](出库管理主PRD.md)，交互见[Demo PRD](出库管理前端Demo版PRD.md)。沿用现有管理端概览卡、多页签与列表组件。

## 一、页面与入口

| 入口 | 页面 | 操作位置 |
| --- | --- | --- |
| 出库单 | 列表、详情 | 列表右上“创建其他出库”“OMS Mock”；表格勾选后组波；详情页头业务按钮 |
| 波次 | 列表、详情 | 列表查波次，详情看成员、原单顺序与拣货任务 |
| 拣货任务 | 列表、详情 | 详情页头进入PDA拣货；应拣明细、原单份额、实拣归属页签 |
| 返库上架单 | 列表、详情 | 详情进入PDA返库上架；应返库明细与已保存目标 |

## 二、出库单列表

```text
出库单                     [创建其他出库] [OMS Mock] [指令处理记录]
┌────────────────────────────────────────────────────┐
│ 仓库    货主    单号    业务类型    状态    查询 重置 │
└────────────────────────────────────────────────────┘
┌────────────────────────────────────────────────────┐
│ [组波] 已选数量                          列设置     │
│ □ 单号     类型  货主 状态 需求 预占 已拣 已复核 实发│
│ □ OB-…     B2C   …    …    3    3    1     0      0 │
│                                         分页       │
└────────────────────────────────────────────────────┘
```

常显5项，第6列查询与重置；当前仓库默认带入，可查询其他仓。单号本身可点开详情，不另设「查看」按钮。不另设复核／交接列表。缺货、待拣及待核对在行内或明细提示，不发明额外主状态。

## 三、出库单详情

```text
出库单 · OB-… [状态]       [返回] [分配] [复核] [确认出库] [更多]
┌────────────────────────────────┐ ┌─────────────────┐
│ 基本信息（3列）                │ │ 数量进度        │
│ 类型    仓库    货主           │ │ 需求／已拣进度条│
│ 来源    上游号  渠道           │ │ 需求 预占 已拣  │
│ 收件方  地址    邮件依据       │ │ 已复核 实发 未发│
└────────────────────────────────┘ └─────────────────┘
┌─────────────────────────────────────────────────────┐
│ 商品明细 | 拣货任务 | 复核 | 交接 | 返库上架 | 操作记录│
│ 当前页签表格；复核页签可删除重做，交接页签登记        │
└─────────────────────────────────────────────────────┘
```

已取消时保留返库页签；有未完成返库时显示数量。其他出库商品页签展示指定库位、批次／SN和指定数量。

## 四、创建、复核与交接

创建其他出库弹窗：上方仓库、货主、邮件依据；下方具体不良品库存行、指定量和SN；底部取消／主管确认。OMS Mock弹窗共用指令编辑区，可切新建、变更、取消，处理记录里可对失败消息重发；创建结果回到处理记录，不伪装成真实OMS连接。

复核作业从详情进入PDA。每次复核填写方式、容器类型和号，B2C随打包可填模拟重量／运单；退拣按钮填写数量、原因和对应实拣。交接弹窗双列：方式、对象、渠道、凭证号、件箱托数、时间、备注；确认按钮在底部。确认出库弹窗可在同一处登记交接，不填则只出库；已出库后仍可用同一弹窗补登。

## 五、其余列表与详情

三类列表都沿用“页头→6列筛选区→表格”。波次筛选仓库、货主、编号、状态；任务增加来源类型；返库增加原因。没有第6个筛选条件时不出现展开按钮。

详情都沿用上方基本信息＋320px数量卡、下方页签。波次以成员表为首个页签，展示成员状态并链接原单和任务；拣货任务以应拣表为首个页签，归属页签展示实际落到原单的数量与SN；返库以应返库表为首个页签，展示保存目标与提交数量。

PDA骨架见[拣货](../7-PDA作业端/拣货作业/PDA拣货页面骨架.md)、[复核](../7-PDA作业端/复核作业/PDA复核页面骨架.md)、[返库上架](../7-PDA作业端/返库上架作业/PDA返库上架页面骨架.md)。

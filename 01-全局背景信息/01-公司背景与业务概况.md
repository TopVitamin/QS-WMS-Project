## 公司与业务

强盛科技（QS-Tech）成立于2016年，是一家以3C数码硬件为主的出海品牌企业，自主研发产品，通过代工厂生产，面向海外电商平台、品牌独立站和当地批发客户销售。自营货盘包括快充设备、移动电源、线缆及拓展配件；外部货主的商品范围更广，包括轻小件、大件和异形货。

业务从国内生产与集货开始，经跨境运输进入仓网，再完成当地订单履约或平台仓转运。香港仓兼顾集货中转与当地履约；美西、美东、德国仓承担海外仓储与履约。生产、采购、仓外运输和渠道经营构成业务背景，不属于WMS的管理职责。

## 为什么建设强盛WMS

强盛早期使用外部海外仓，难以及时掌握收货差异、商品位置和实际作业情况。2021年自建海外仓后，履约控制力提高，但淡季仓容闲置、固定成本较高。2023年开始向外部品牌开放仓容和仓配服务，形成自营与第三方货主共享仓网的模式。

仓库由此需要在同一场地处理不同货主、不同商品和不同履约方式的业务。以往依赖总量账、纸质指令和人员经验的方式，难以支撑多仓、多货主及大促作业。沙盘中的典型问题包括：账面安排发货时实物已被其他业务提走；只知道商品总量、不掌握存放位置；不同货主之间发生错发。项目需要建立可信的仓内作业和实物库存记录。

## 仓储业务的主要特点

| 业务特点 | 对项目的方向性要求 |
| --- | --- |
| 四仓共同运营 | 一套系统同时覆盖香港、美西、美东和德国仓，兼容不同仓库的业务差异。 |
| 自营与外部货主共享 | 强盛自营作为普通货主使用共同能力；区分货主的商品、库存与作业记录。 |
| 多品类 | 同时考虑3C轻小件、大件和异形货；带电商品的安全与追溯要求进入后续调研。 |
| 多种履约形态 | 支持包裹履约、平台仓转运、当地B2B批发及仓间调拨。 |
| 后续服务扩展 | 退货、换标和换包装等属于后续建设方向，不计入一期范围。 |

## 主要干系人

| 群体 | 关注的问题 |
| --- | --- |
| 仓库管理与作业人员 | 收发存是否清楚、现场作业能否执行、货物与记录能否对应。 |
| 强盛自营团队 | 仓库库存可见性和履约结果。 |
| 外部品牌货主 | 货物是否独立管理、收发结果是否透明可靠。 |
| 集团管理与财务人员 | 可信的业务记录及后续经营分析、财务核算所需的结果。 |

强盛WMS服务强盛自有仓网，不规划向其他仓储运营商销售软件。共享仓服务外部货主，不等同于对外提供WMS软件产品。

# 02 强盛WMS项目定位与范围

## 项目定位与交付目标

强盛WMS是本项目正式名称，旧资料中的QS-WMS为旧称。

强盛WMS服务强盛自营与第三方货主共享的仓网，负责仓内位置、实物作业和库存记录。项目交付为可运行、可操作、可供学习的演示系统，使用课程沙盘数据展示业务执行与结果变化。四仓均需在演示中跑通，但不代表已经在真实仓库完成生产部署。

整个项目分阶段建设：一期完成WMS业务闭环，二期建设作为WMS客户端的OMS。客户退货入库、退货质检、增值服务、深圳仓及商业计费按后续阶段评估；已收货入库单被上游要求取消时，WMS拒绝取消，已收货物需先完成质检、上架并形成实际库存，再通过一期的退回出库处理。未进入库存的暂存实物在线下处理。阶段安排统一见[05-阶段规划与交付边界](05-阶段规划与交付边界.md)。

## 一期范围

| 维度 | 已确认范围 |
| --- | --- |
| 仓网 | 香港、美西、美东、德国四仓同时纳入一期演示范围；四仓使用相同功能框架，均需能够切换进入并跑通入库、库存和出库主链，不表达真实仓库的上线或部署顺序。 |
| 服务对象 | 强盛自营与外部品牌货主；一期通过不同货主的商品、库存和单据隔离来演示多货主能力，不提供外部货主自助端。系统服务强盛自有仓网，不建设面向其他仓储运营商的软件产品。 |
| 商品 | 包括3C及类似轻小件，也包含大件、异形货和需要批次、生产日期、有效期或保质期管理的商品；支持按商品配置带电、SN、批次和效期要求。 |
| 基础能力 | 支撑仓库、库区、货位、货主、商品及实物库存的基本管理。 |
| 入库 | 接收上游业务指令，完成到货、收货、质检、上架及结果记录；其他仓调入在WMS中作为一类入库业务处理。 |
| 库存与仓内作业 | 支撑仓内货物管理、库存查询及作业记录；具体业务清单与规则在需求分析和业务设计中展开。 |
| 出库 | 覆盖B2C包裹履约、平台仓转运、当地B2B批发、调拨出库，以及已收货物按后续指令退回的退回出库；B2C可选择基础波次，B2B按单摘果拣货；不建设人员派工和大促产能方案。 |
| 调拨边界 | WMS不建立跨仓调拨主单，也不对两仓记录进行调拨号关联或差异对账。调出仓按一类出库指令执行，调入仓按一类入库指令执行；调拨计划、途中运输和差异跟进属于上游业务。 |
| 业务入口 | 生产目标链路为ERP或货主业务先进入OMS，再由OMS向WMS推送基础资料、入库单和出库单。一期不建设真实OMS客户端，由OMS Mock模拟这一上游角色并接收WMS结果；一期暂不支持WMS自行导入上游业务指令。 |
| 使用端 | WMS管理端与PDA仓内作业端。PDA覆盖收货、质检、上架、拣货、复核、移库、盘点等现场操作；打印机和电子秤一期使用模拟或手工数据，不做真实设备集成。 |
| 权限 | 数据范围按仓库授权；拥有仓库权限即可查看该仓全部货主数据。菜单、目录和业务动作通过RBAC角色授权，不按管理员或操作员名称预设固定动作权限。 |

一期不包含客户退货接收、退货质检、换标、换包装及退货重新入库，也不包含商业计费和结算引擎。这里排除的是从客户侧退回仓库的逆向入库业务，不排除正常入库，也不排除已收货物按新指令退回仓外的退回出库。

“Mock推送”在一期统一指OMS Mock：它模拟未来OMS向WMS推送货主、商品等基础资料以及入库单、出库单、变更和取消消息，并接收WMS执行结果。仓库、库区、货位等WMS自有资料仍由WMS管理端维护。

## 系统职责边界

| 系统 | 职责 | 与强盛WMS的关系 |
| --- | --- | --- |
| 强盛自研ERP | 采购、供应链计划等业务管理，以及ERP层面的全局库存协同。 | 自营业务先进入OMS，不直接向WMS推送；具体接入方案后续设计，一期不依赖真实ERP接入。 |
| OMS客户端 | 面向自营业务与外部货主的业务接入和协作，承接ERP或货主侧数据，再向WMS推送基础资料与业务单据并接收执行结果。 | 二期建设真实客户端；一期由OMS Mock模拟其与WMS的协作，不直接照搬竞品OMS功能全集。 |
| 强盛WMS | 仓内位置、收发存及实物作业记录。 | 接收业务指令并通过管理端、PDA记录仓内执行结果；实物作业覆盖到仓接收至出仓交接，系统可在到货前接收相关指令。 |
| 承运商及物流系统 | 运单服务、仓外运输与配送。 | 与仓库交接，按出库需要提供物流服务；一期通过Mock数据演示承运商与交接信息，不验证真实物流服务。 |
| 集团财务ERP | 存货成本、总账、税务及正式财务核算。 | 与自研业务ERP是两套系统；WMS提供相关业务结果，不承担财务核算。 |

渠道经营、集团全局库存协同决策、仓外运输跟踪与配送、法定财务核算均不属于WMS职责。OMS客户端属于项目后续交付，但其对客功能不因此并入WMS作业端。

## 必要术语

- 货主：仓内货物的业务归属主体，包括强盛自营和外部品牌客户。
- 平台仓转运：从本项目仓库向电商平台仓库发货的业务。
- 调拨出库／调拨入库：强盛自有仓网内两个仓库之间发生货物转移时，调出仓按出库业务执行，调入仓按入库业务执行。WMS不建立跨仓调拨主单，不负责两端对账、调拨计划和途中运输。
- SKU：用于区分商品规格的库存管理单位。
- SN：单品序列号；一期支持按商品启用SN管理，在收发作业中采集SN并跟踪SN库存，唯一性范围和具体状态在PRD中细化。

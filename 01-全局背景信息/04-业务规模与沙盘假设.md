# 04 业务规模与沙盘假设

> 以下为课程沙盘设定或规划量级，不代表真实企业统计、性能验收指标或容量上限。

## 货盘与作业量级

| 维度 | 沙盘口径 | 使用边界 |
| --- | --- | --- |
| 自营商品 | 常年动销核心SKU约300—500个，历史长尾SKU约3500个。 | 不等于四仓在库SKU数，也不包含全部外部货主商品。 |
| 货主规模 | 强盛自营1家，外部品牌数十家；既有沙盘以100家作为规划参考。 | 不作为系统硬性容量上限；接入节奏及每家商品量未核定。 |
| 商品形态 | 自营以3C为主；外部货主包含轻小件、大件与异形货。 | 不据此编造各品类比例或具体存放规则。 |
| 淡季仓容 | 既有沙盘描述自营库存占用不足总体仓容的35%。 | 用于说明开放共享仓的动因，不能作为当前四仓容量配置依据。 |
| 大促出库 | 单日破万包裹的峰值场景。 | 仓库统计范围、持续时间与准确峰值未核定，不直接作为性能验收指标。 |
| 履约时效 | 部分渠道有约48小时履约要求的背景设定。 | 起止节点及具体服务承诺待后续需求调研确定。 |
| 货物流转单位 | 单件、包裹、箱和托盘并存。 | 用于理解业务形态，不在此规定包装换算。 |

未定义计量口径的货量比例不作为规划依据。跨境补货周期较长是业务背景，仓外运输时长及管理不纳入WMS范围。

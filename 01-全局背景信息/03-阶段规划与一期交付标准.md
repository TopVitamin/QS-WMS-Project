# 强盛WMS阶段规划与一期交付标准

> 本文说明系统建设阶段、一期怎么交付、怎样算完成，以及演示资料的准备要求。一期范围见[项目定位与范围](01-项目定位与范围.md)，能力与系统协作见[能力蓝图与系统协作](02-能力蓝图与系统协作.md)。

## 一、阶段规划

| 阶段 | 建设目标 | 交付边界 |
| --- | --- | --- |
| 一期：WMS仓内业务 | 完成仓内业务及异常处理的可运行演示系统 | 覆盖[一期范围](01-项目定位与范围.md#二一期范围)，外部协作采用[模拟接入](02-能力蓝图与系统协作.md#二一期演示系统协作) |
| 二期：OMS客户端 | 面向外部货主的业务接入与协作：衔接业务资料、仓内指令和WMS执行结果，承接无主货信息展示与认领、上游入库取消 | 方向已定；对客功能、真实接口范围和接入深度在二期设计中明确。一期完成不以二期建设为前提 |

其他后续建设或评估事项见[范围文档第4.1节](01-项目定位与范围.md#41-后续建设或评估)，期号与实施安排尚未确定。系统开发可分批交付，实际租仓、开仓与上线安排另行确定。

## 二、一期交付内容与方式

管理端与PDA应实际处理业务操作，更新业务记录和库存，并展示异常处理及上下游交接结果。这里要求的是演示系统内的业务执行，不代表已在真实仓库上线。

- **允许分批。** 每批可以完成部分模块或场景，但全部一期范围完成才算一期完成。已有页面或某一条出库样板，只代表对应部分的进度。
- **案例安排。** 商品差异、特殊出库和异常案例按覆盖安排分配到各仓，不要求每个仓重复全部案例。
- **配套资料。** 准备仓库、库区、货位、货主、商品、作业容器、入出库指令及退货预报，配齐正常与异常案例、预期库存结果；课程沙盘样例需标明性质。

一期按本机运行交付，PDA采用浏览器页面并模拟扫码，不要求实体PDA真机验收。具体约定由[应用设计](../05-应用设计方案/20261002-MVP版本/系统架构设计/README.md)承接；本机启动、访问、数据保存及样例初始化与恢复步骤，交付前需补齐。

## 三、一期完成的判断标准

| 维度 | 应能验证的结果 |
| --- | --- |
| 仓库与业务覆盖 | 四仓分别跑通入库、库存和出库主链；正常入库、调拨入库、一期各类出库、三类退货来源和库内作业均有可运行路径 |
| 多货主与商品差异 | 自营与外部货主的资料、库存和单据分别归属；轻小件、大件、异形货，以及按商品启用的质检、带电、批次、效期和SN要求都有演示覆盖 |
| 库存与异常结果 | 实际、预占、可用库存与业务记录对应；收货差异、质检不合格、缺货／短拣、已拣取消返库上架和盘点差异能追溯到原业务及处理记录，退回的货能追到原出库单或退货预报；涉及库存或占用变化的，能核对相应库存记录 |
| 管理端与PDA一致 | 两端使用同一份业务记录和库存，结果一致，重复提交不造成重复库存变化 |
| 上游与物流协作 | OMS Mock下发资料及新建、明细变更、出库取消消息后，能查看接收或拒绝与执行结果；重复消息不重复建单、不重复改变库存；回传失败后可重试已有结果；承运商模拟信息能参与出库流程 |
| 无主货与零实收 | 无主货（含认不出货主的退件）只登记、暂存，不生成入库单或库存；零实收且不再接收时，保留到货／拒收记录，仓库通知上游，一期由 OMS Mock 取消消息受理后原单已取消 |
| 公共能力 | 仓库与角色权限按规则生效，中文／英文与时间处理可验证，关键动作保留操作者、时间和结果 |

各开发批次合起来应覆盖完整一期范围。案例与覆盖安排见[关键走查场景](../04-业务分析和设计/06-海外仓典型业务场景与方案.md#84-关键走查场景)。

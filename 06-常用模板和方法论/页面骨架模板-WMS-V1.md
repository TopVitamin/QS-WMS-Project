## 绘制约定（WMS 管理端）

管理端列表列数、主数据默认无状态页签／行勾选／导入、详情列数等硬规则统一维护在[需求文档 PRD / AGENTS.md](../05-应用设计方案/20261002-MVP版本/需求文档PRD/AGENTS.md)；本模板只规定骨架表达方式，不另立一套布局验收口径。页面专属的信息分区和入口仍按对象主 PRD 与实际任务设计。

| 项 | 约定 |
| --- | --- |
| 页面壳 | 左侧菜单 + 顶栏（含当前仓库切换）；内容区 `p-4`、`gap-3` |
| 列表上块 | `Panel` + `FilterBar`；列数、常显项与操作按钮位置见 PRD 目录约定，不在本模板重复定义 |
| 查询按钮行 | 按对象 Demo PRD 显示查询、重置及筛选展开入口；线框标出其相对位置 |
| 列表下块 | `Panel flex-1` + `DataTable`；**列设置**在表格工具区（非 ERP 六列栅格） |
| 主数据列表 | 是否显示状态页签、勾选或导入按目录约定与对象主 PRD；线框只画该对象实际入口 |
| 详情只读 | 详情响应列数、标签和值的排列见 PRD 目录约定；按对象信息量展示备注、地址等长字段 |
| 编辑表单 | 分组标题 + `Panel` 内 3～4 列表单项；必填标 `*` |
| 编码类字段 | 线框示例用 `font-mono` 语义（如 `HK-WH-01`），不写 CSS |

- **用途**：[保存可编辑字段]。
- **关键要素**：页头 **取消**、**保存**（无「提交审核」）；分组与详情一致。
